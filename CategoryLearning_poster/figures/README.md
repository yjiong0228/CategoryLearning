## 图的结构与模型含义

本图说明同一套归一化规则信念如何连接选择、反馈学习、局部搜索和容量替换。
归一化使当前活跃规则的信念之和为 1，表示这些规则的相对可信度。
属于机制示意图，图标与条形长度为说明过程而设置，未使用参与者数据。
上行从左向右表示当前试次的决策；下行从右向左表示收到反馈后的学习。
绿色回线将更新后的活跃规则连接到下一试次。

1. **Perception**：四个刺激特征形成带有知觉误差的内部刺激；各活跃规则共享这次知觉。
2. **Active rules**：当前集合受容量 K 约束。各规则根据类别区域距离和判断精度形成类别概率；
   精度越高，概率越集中于距离较小的类别。
3. **Choice**：按规则信念混合类别概率，再从混合分布抽取回答。图中采用四类别示意。
4. **Feedback**：环境对所选类别评分。部分反馈任务使用 0、0.5、1，其余任务使用 0、1。
5. **Update all active rules**：先根据本题反馈调节已有信念的保持程度，再按反馈似然更新。
   反馈似然是规则预测实际反馈的概率。所有活跃规则使用作答时的预测学习，判断精度也按
   对数反馈似然的梯度更新。正确反馈完整保留更新前的信念比例，错误反馈使用个体保持率，
   半分反馈取两者中间值。
6. **Search**：失败累积量控制搜索概率。局部路线按更新后信念抽取父规则，再提出一次结构修改；
   结构邻域没有候选时，采用功能相似性回退。全局路线从非活跃规则目录提出候选。
7. **Rule entry**：搜索发生后，有空位就加入新规则；容量已满就替换已有规则中信念最低者。
   有空位时，新规则获得新集合的均匀份额；满容量时，其份额由刚完成试次的反馈决定。
   正确反馈接替被移除规则的份额，错误反馈给予 1/K，半分反馈取两者平均。
   新规则继承替换前全部活跃规则的反馈后信念加权平均精度；部分反馈任务还继承整体配对信念。
   新规则从下一题开始接受自身的反馈学习。没有搜索时，更新后的原集合进入下一题。

依据为 [Model 1023 正式说明](../../src/Bayesian_state/docs/model_architecture/model_1023.tex)
及信念保持、入场份额和精度继承的对应实现。该版本采用信念加权混合选择。
海报中的结果图仍来自已有 Model 0826 开发分析，模型机制和结果来源分别在页脚标明。
本次新增拟合、模拟和口述编码均为零。

## 编辑与重建

画布为 15.6 × 6.85 英寸，与海报左图区域等宽。全部文字、色块、圆形、规则图标和连线
均为独立 PowerPoint 原生对象；文字使用指定的 Arial 常规体和粗体。
可在 PowerPoint 直接选择对象修改，或全选复制到另一张幻灯片。
生成的海报中也保留这些原生对象。

从仓库根目录运行：

```bash
python -m CategoryLearning_poster.figures.build_figure3 \
  --output-dir CategoryLearning_poster/figures
```

输出为 `figure3.pptx`、300 dpi 的 `figure3.png` 和 `figure3.manifest.json`。
已生成同名文件时，脚本拒绝覆盖；后续版本可指定新的子目录。
代码生成的独立图和海报共用 `draw_figure3`。
手工编辑独立 PPTX 后，可复制修改后的对象到海报；脚本重建使用 Python 源码中的内容。

## 检查范围

检查 PPTX 的原生对象类型、未分组状态、可编辑文字、字体和零图片媒体。
本版共 117 个原生对象：44 个文字框、58 个形状和 15 条连线。独立图和海报中的对应对象
内容及位置一致，并完成单独文字框、连线修改后的保存与重新打开检查。
用临时字体配置核对指定 Arial 文件，转换出的检查 PDF 用于核对文字完整性、文本框边界、
实际字体和零栅格图片；检查 PDF 保存在临时目录。独立图和海报均完成目视检查。
Office 默认主题效果在每个对象中关闭，以保持矢量导出。

通用 Nature 绘图静态检查器能检查本脚本语法与 Arial 声明，但其 SVG 导出和 Matplotlib
字体配置规则不适用于 PowerPoint 原生对象。本任务按用户指定的 PPT 编辑方式，使用原生
对象检查及实际 PDF 矢量检查验收。实际画布、字号、对象边界和导出器版本见清单。
二进制图与生成清单保留本地，源码和本说明纳入 Git。
