# SUSTAIN：Python 模型与验证

本目录实现 Love、Medin 与 Gureckis（2004）的 SUSTAIN 类别学习模型。
模型逐试次形成刺激簇，调整各维度的注意调节参数，并学习簇到类别的连接权重。
每个试次先生成类别反应概率，再使用反馈更新状态。Python 核心使用 NumPy，参数搜索使用 SciPy。

当前实现覆盖完整类别反馈下的分类学习，以及独立的无监督聚类。
分类接口支持两个或多个类别、名义特征和具有明确量程的连续特征。
推断学习中查询不同刺激维度、混合监督模式、缺失特征和部分类别反馈尚待实现。
这些任务需要另外明确被查询的维度、可见信息及反馈更新规则。

## 模型如何完成一个试次

输入是刺激向量 \(x\)，反馈提供正确类别 \(y\)。类别标签与刺激特征分开传入。
内部状态包括簇位置 \(h_j\)、各维度的调节参数 \(\lambda_i\) 和簇到类别的连接权重 \(w_{jk}\)。
这里 \(i\) 表示刺激维度，\(j\) 表示簇，\(k\) 表示类别。
簇数随学习变化；一个类别可以对应多个簇。

1. **计算刺激到各簇的距离。** 名义维度用 one-hot 向量编码，例如二值特征的两个值编码为
   `[1, 0]` 与 `[0, 1]`。学习后，簇在该维度的位置是各值的比例。
   名义维度的距离为 \(\mu_{ij}=\frac12\sum_v|x_{iv}-h_{jiv}|\)，其中 \(v\) 枚举该维度的名义值。
   这是论文 Eq. 4，距离在 0 到 1 之间。
   连续维度按预先给定的量程缩放到 `[0, 1]`，采用绝对距离 \(\mu_{ij}=|x_i-h_{ji}|\)。
   连续量程及这一距离约定是本实现对连续实验输入的明确设定。
2. **计算簇激活并选出获胜簇。** 论文 Eq. 5 给出
   \(a_j=\sum_i\lambda_i^r e^{-\lambda_i\mu_{ij}}/\sum_i\lambda_i^r\)。
   指数项使远离簇的刺激产生较弱响应；分母将维度权重归一化，使其和为 1。
   注意参数 \(r\) 控制不同维度权重的差异。簇中激活最大的一个负责作答。
3. **计算簇竞争后的输出。** 对获胜簇 \(j\)，论文 Eq. 6 给出
   \(o_j=a_j^{\beta+1}/\sum_l a_l^\beta\)，其他簇的输出为零。
   \(l\) 枚举所有簇，\(\beta\) 控制竞争强度。其他相似簇会降低获胜簇的输出。
4. **生成反馈前的类别概率。** 类别输出为 \(c_k=o_jw_{jk}\)，再按论文 Eqs. 7–8 计算
   \(P(Y=k\mid x,\text{过去刺激与反馈},\theta)=e^{dc_k}/\sum_q e^{dc_q}\)。
   \(q\) 枚举类别，\(d\) 控制决策一致性，\(\theta\) 表示固定模型参数。
   代码使用对数形式计算概率和似然，避免指数溢出。初始无簇时，各类别概率相等。
5. **根据反馈决定是否招募簇。** 默认使用类别输出判断预测是否正确。
   当正确类别没有唯一最大的输出时，在当前刺激位置招募一个簇，新簇权重初始化为零。
   招募后重新计算激活和输出，并由新簇完成当前反馈学习。
6. **更新获胜簇及注意参数。** 论文 Eqs. 12–13 给出
   \(h_j\leftarrow h_j+\eta(x-h_j)\) 和
   \(\lambda_i\leftarrow\lambda_i+\eta e^{-\lambda_i\mu_{ij}}(1-\lambda_i\mu_{ij})\)。
   \(\eta\) 是学习率。两项更新使用同一次学习事件中、位置更新前的距离。
   簇中心向刺激移动；注意调节随该簇在各维度上的匹配程度改变。
7. **更新类别连接权重。** 论文 Eqs. 9、14 使用 humble teacher 目标：
   正确类别的目标为 \(t_k=\max(c_k,1)\)，其他类别为 \(t_k=\min(c_k,0)\)。
   更新为 \(w_{jk}\leftarrow w_{jk}+\eta(t_k-c_k)o_j\)。
   当输出已充分支持正确类别时，这个目标使对应的学习误差为零。

步骤 6、7 都使用位置和注意更新前计算的激活与输出。代码先更新连接权重，再更新位置和注意参数，
从而避免一个更新后的量混入同一试次的其他公式。类别位置也随获胜簇更新，用于作者版本的招募判断。
类别维度在分类阶段被查询，其位置及调节不会参与当前刺激的距离加权。
本实现只保存参与分类激活的刺激维度调节参数。

无监督实例用 `n_categories=None` 创建。每次 `step(x)` 用当前刺激学习；
最大簇激活低于 \(\tau\) 时招募簇，随后更新位置与注意参数。
无监督阈值 \(\tau\) 在监督分类模式中不参与招募。

## 实现版本与边界约定

原论文、作者 Python 示例与 `catlearn` 的边界处理存在差异。本实现提供两个明确命名的招募选项，
其余核心计算共用同一组函数。

| 设置 | 具体行为 |
| --- | --- |
| `recruitment: prediction_error`，默认 | 按类别输出检查错误；正确类别须有唯一最大的输出；招募后由新簇学习 |
| `recruitment: cluster_label` | 按作者 Python 示例检查获胜簇的类别位置是否与目标 one-hot 完全一致；招募后重新选获胜簇 |
| `ties: first`，默认 | 多个簇的计算激活相等时，选择最早建立的簇；固定参数与日程产生确定的学习状态 |
| `ties: random` | 在并列簇中按指定种子随机选择；供生成研究使用，当前评分与拟合接口拒绝此模式 |

原论文没有完整规定并列输出和重复簇的处理。默认模式将类别最大输出并列视为尚未正确区分类别；
新簇即使与旧簇的刺激位置一致，也保留该次招募，并接收当前反馈。
`cluster_label` 保留作者示例的重新选簇行为，包括新旧簇位置相同时可能选中旧簇的情况。
原始示例还可以在监督模式下使用非零距离阈值，本实现将阈值限定于无监督学习。

作者数值对照比较的是分类概率、刺激维度的调节参数、刺激与类别位置、被查询类别的连接权重。
作者示例还更新被查询类别维度的调节参数，该参数在固定分类任务中不参与激活。
目前没有验证在不同查询任务之间转换时的等价性。

`catlearn` 会避免重复招募完全相同的簇，当前默认并列簇策略为随机。
本目录历史追踪函数招募后仍用招募前的类别输出来计算权重误差；Python 实现按论文及作者示例
重新计算该输出。因此，所有边界序列与旧 R 结果逐值相等不属于当前实现承诺。

参数约束为 \(r,\beta,d\geq0\)、\(0\leq\eta,\tau\leq1\)，初始 \(\lambda_i\geq1\)。
\(\lambda_i\) 表示感受野的调节程度，归一化后的 \(\lambda_i^r\) 表示当前维度的相对贡献。
它们的含义及数值尺度应随所用特征编码一起解释。

## 数据与反馈接口

YAML 的 `features` 明确列出每个刺激列及编码方式；其余 CSV 列不会进入刺激向量。
名义特征需要完整的 `values` 列表，例如 `[-1, 1]`；连续特征需要实验规定的 `bounds`。
量程和取值目录由任务设计提供，代码不根据当前样本或未来试次估计它们。
类别通过 `category_values` 指定完整的反应目录，核心模型内部使用从 0 开始的索引，CSV 输出保留原标签。

支持两种反馈语义：

- `binary_correctness`：仅适用于两个类别。答对时目标为实际选择，答错时目标为另一类别。
  当前 Task2 条件 1 的类别已经是 1／2；Python 接口保留这两个类别。
- `category_label`：配置列必须表示反馈时向学习者揭示的正确类别。支持多分类。
  如果实验只给出对错或分数，数据表里的隐藏正确类别不能据此视为学习者可见反馈。

`audit_category_column` 仅用于核对反馈还原出的类别。若不一致，程序报错；该列不会作为缺失反馈的替代来源。
Task2 条件 2 的四分类对错反馈与条件 3 的 0／0.5／1 反馈不能普遍唯一确定正确类别，
当前工作流尚未接入这些条件。其学习机制需要单独定义和验证。

`filters` 选择被试、条件和会话；独立被试及条件须分别建模。
`order_columns` 必须唯一且已按时间递增；重复、逆序和关键值缺失会报错。
加载器保留原文件顺序和来源行号。`max_trials` 只截取合法日程的前缀。
`session_policy: single` 要求单会话；`carry` 明确允许跨所选会话延续状态。
跨夜遗忘、任务切换和实验停止规则需要另外的协议设置与验证。

## 拟合、生成与状态解释

拟合目标是训练前缀中实际选择的负对数似然，即各试次所选类别对数概率之和的相反数。
优化器搜索 `r`、`beta`、`d`、`eta`；范围、预算和训练前缀长度在 YAML 中指定。
同一初始状态和 `ties: first` 使每次目标计算确定。
参数搜索采用单进程差分进化；若搜索点不及初始点，则保留初始点。
优化器是否收敛、调用次数及预算均写入结果。小预算结束不表示已经找到稳定参数。

训练后缀评价固定已选参数，并依次利用之前各题已经发生的反馈更新状态。
当前题的概率始终在当前反馈更新前记录。后缀的选择与反馈不参与参数搜索。
这对应持续反馈任务的逐题预测；已经查看过的数据保持开发资料身份。

生成时，选择从反馈前的类别概率采样。固定日程中的目标类别用于提供该题的完整类别反馈；
在确定性二分类中，模拟选择与其正确性给出的类别信息相同。
这种任务下，固定刺激和参数的学习状态由类别反馈决定，采样选择本身不会触发招募。
因此，固定日程上不同随机选择路径可以共享相同的簇和注意轨迹。
当前生成接口不模拟选择依赖的下一题安排及达标停止；六类基准单独实现了连续无错区块的停止约定。

状态记录以固定参数和已给定反馈历史为条件。`lambdas_before` 与 `prediction_winner` 属于反馈前，
`post_feedback` 与 `learning_winner` 属于反馈更新后。初始试次反馈前没有簇，因此获胜簇为 `null`。
簇编号从 0 开始。状态数组是模型轨迹的快照；本实现尚未进行参数不确定性积分或状态恢复研究。

## 输出与复现信息

| 输出 | 内容 |
| --- | --- |
| `trials.csv` | 来源行号、试次标识、类别反馈、实际或生成选择、反馈前类别概率、评分模式下的选择 NLL |
| `state_trace.json` | 可选的逐试次反馈前摘要与完整反馈后状态 |
| `final_state.json` | 最后一次反馈后的簇、类别位置、注意调节参数、连接权重 |
| `summary.json` | 模式、参数、训练与后缀评分、簇数、优化器状态和使用范围 |
| `provenance.json` | 完整配置、输入哈希、选中来源行、随机种子、代码提交与工作区状态、源码哈希、软件版本 |
| `benchmark.json` | 六类任务的平均曲线、全部实际生成路径及最终状态 |

六类基准每个区块随机排列八个刺激；配置中的 `criterion_blocks: 4` 表示连续四个区块无错后停止。
曲线在停止后记零错误，与作者示例的汇总方式一致。原始路径只保存实际模拟的试次，保留停止长度。
`criterion_blocks: null` 则完成全部区块。

## 历史 R 文件的检查记录

原有四个 R 文件保持原样，供追溯旧分析。静态检查发现以下差异或问题：

- `optimization.R` 将条件 1 的类别 1／2 合并为 1；当前 Task2 文件中 1／2 已是最终二分类标签。
- `simulation.R` 将末尾的 `choice`、`feedback` 一并传给追踪函数；追踪函数把这些列纳入类别输出。
- 追踪函数比较升序排列后最小的两个类别输出是否相等，多分类中这不等于最大输出并列。
- 追踪函数的预测读取 `which.max`，学习选择另用 `winner`，随机并列时可能使用不同簇。
- 连续输入在旧追踪函数中也乘以 0.5；新实现对连续坐标使用明确的单位量程绝对距离。

这些记录来自代码与数据定义的核对。旧结果未被重写，其有效性需要结合当时的数据版本和实际调用方式检查。
