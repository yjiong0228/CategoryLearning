# Model 0826：冻结规则后的三名新被试核查

本轮用没有参与近期流程校准的三个被试，检查一套有计算上限的完整拟合流程。
六人试点及其定向复核已经属于开发/校准证据；本轮结果揭晓后不临时修改门槛、预算或被试。
这是流程在新被试上的核查，行为评分仍为样本内拟合，不是行为的留出预测检验。

## 冻结了什么

配置为 `configs/exp123/specific_models/model_0826_frozen_validation.yaml`。
它与当前默认 v2 只有 `analysis_id` 不同；搜索、种子、评分预算、参数支持和停止逻辑均保留。
S307 增加到64次重复仍未消除数值不确定，已有证据不足以支持全体默认增加粒子或重复。
本轮检验现有有界流程的实际表现，不宣称已解决旧试点发现的所有问题。

| 情况 | 冻结的处理规则 |
|---|---|
| 搜索 | 45个分散起点；局部、整块及跨块联合移动；每循环最多4轮 |
| 出现平台 | 连续两轮引导平均NLL改善≤0.001，再做一轮联合挑战与有限边界检查 |
| 独立评分 | 先R128×B16；尚未明确需要重搜且仍有不确定问题时，升R256×B32 |
| 评分通过 | 预先提名相对冻结候选库的平均NLL损失上界≤0.005 |
| 低档明确较差 | 按v2原规则进入下一搜索循环，不先升级该循环；单独报告其发生情况 |
| 需要重搜 | 独立判断提名较差、挑战有可靠收益，或常规搜索仍未形成平台；最多两循环 |
| 纯评分不确定 | 到最高预算后保留标记，不自动再开整轮搜索 |
| 人为触边 | 保留范围复核标记；允许范围对所有人相同，不因个体结果自动扩范围 |
| 到达总上限 | 保留参数、近优候选和未解决原因；不追加到“通过”为止 |

R为粒子数，B为完整PF随机重复数。发现用R32×B4，引导用R128×B16；不同用途的分数不混排。
评分前固定代表、候选库和挑战双方；独立审查种子不能在选出赢家后被重复称为验证。
alpha=.05分给两个问题×两个档位×两个循环，每项每次.00625；bootstrap=6000。
这是有限粒子下的近似数值判断，不是参数置信区间或全局最优保证。

上一批暴露的低预算提名波动、整库升级成本和触边问题仍单独记录。
本轮不实现未经完整验证的新升级策略；有限外层点没有收益也不能证明原支持已校准。
认知机制、原始数据、作答前预测以及先平均概率再取log均保持不变。

## 被试、上限和运行

每个condition从未参与近期校准的候选中，选试次长度最接近该条件全组中位数的一人，同距取较小编号。
排除既往六人及已知诊断、恢复模板、反事实检查对象；排除清单、来源与数据哈希在计算前记录，选人不读取拟合成绩。

| condition | 被试 | 完整试次 | 计分试次 |
|---|---|---:|---:|
| 1 | S122 | 256 | 255 |
| 2 | S222 | 832 | 831 |
| 3 | S315 | 704 | 703 |

总计1792个完整试次，1789个默认计分试次；首试次参与递推但不计分。
按提案和轮数的最大配额推导，每人最多9252次完整PF，三人合计最多27756次；去重、缓存和早停只会减少实际计算。
这是任务量上限，不是墙钟时限。最多128个worker、各一个数值线程，仅一层进程并行；不额外凑任务占核。

## 事先约定怎样解读

分别报告软件完成、搜索平台、提名评分、挑战和范围标记；不把所有问题合成一个含糊的“失败”。
整体暂时停止仍沿用原要求，必须各项通过；到预算上限不改称收敛。
完整序列、缓存概率、原始反应顺序、计分掩码、冻结提名及最终NLL均核验，并实际检查完成后的resume不新增PF。

不预设三人必须全部通过，也不因出现未解决项重选被试、重跑或放宽门槛。
三人中的通过比例只描述这三个案例，不能精确估计全体通过率；即使三人通过也不自动启动全体拟合。
若仍发现同一系统性问题，应结合保留的失败模式讨论规则，不能把计算完成当科学验收通过。
状态精度、参数恢复及exp4/exp5不在本轮范围。
