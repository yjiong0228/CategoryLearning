# Model 0826 参数范围校准

三名新被试完整拟合后的最新有限检查见[冻结三人的外侧范围检查](FROZEN_BOUNDARY_CHECK.md)：
保留全部原入围点，包含更新率与跨组联合探针；原正式支持及历史结论保持不变。

2026-09-19 的实测结果见 [完整序列校准报告](../../../results/model_0826/boundary_calibration_20260919/README.md)：
S103/S129 通过固定候选集合内的选参复核；S203/S301 达到预算后仍为 unresolved。
近优候选的人工边界标记继续保留，正式默认范围未因此自动扩大。

后续两组争议候选的独立评分协议及 S129 多解的解释见
[少量候选评分复核](PRECISION_FOLLOWUP.md)。候选对通过不会自动解除整组拟合的未解决状态。

默认拟合入口已接入自适应搜索与边界标记；正式范围仍须用观察数据与恢复实验校准。
本工具从历史候选出发，只改指定参数，其余参数固定，检查原来的搜索边界是否可能
挡住更好的解。模型方程、试次顺序、选择发生在反馈前的计分方式都不变。
扩展取值改变的是可估计的参数范围，不能把结果解释为完全等价的计算加速。

## 运行

从仓库根目录运行：

```bash
python -m src.Bayesian_state.workflows.analysis.calibrate_model_0826_boundaries --dry-run
python -m src.Bayesian_state.workflows.analysis.calibrate_model_0826_boundaries --smoke --output-dir <新目录>
python -m src.Bayesian_state.workflows.analysis.calibrate_model_0826_boundaries --output-dir <新目录>
python -m src.Bayesian_state.workflows.analysis.calibrate_model_0826_boundaries --output-dir <原目录> --resume
```

协议位于 [`model_0826_boundary_calibration.yaml`](../../../configs/exp123/specific_models/model_0826_boundary_calibration.yaml)。
依赖其中指定的历史候选 JSON；这些研究结果不随代码分发，缺失时须恢复原始归档。
历史文件只提供参数点，所有评分重新计算，不复用历史分数或粒子缓存。
正式校准使用四位被试的完整序列。`--smoke` 仅运行首位被试的前 32 个试次、
R=2、B=2、1 个进程，不能用来推断拟合效果。

|---|---:|---|---:|

| S129 / condition 1 | 30 | 容量与保持率、E_C 与 δ_E、跨组联合调整、另一历史解的 c_A 上界 | 6 |

每类探针的最佳候选，再按分数补足数量，防止一种参数调整占满所有位置。

## 评分、提名与独立复核

1. 59 个候选用 R=128、B=16 筛查完整序列。R 是每个粒子滤波器的粒子数；B 是独立随机种子数。
2. 入围后，condition 1/2 使用 R=256、B=32；condition 3 使用 R=512、B=32。
   使用新种子重新比较，从中提名一个参数点，并在复核前写入冻结文件。
3. 使用另一组独立种子复核整个入围集合。容忍差距为每个有效试次平均 NLL .005。
   复核结果即使偏爱别的点，也不能当场改选并宣布通过。
4. 只有 S301 在第一次复核仍无法判定时，将同一组 R=512 复核从 B=32 补到 B=64，
   原 32 个完整粒子滤波结果保留；两次查看各分配 alpha=.025。明确劣于容忍值或已通过则不补算。
   B=64 仍无法判定就保留 unresolved，不无限增加预算。

最多 2,416 次完整粒子滤波：944 次筛查、640 次高预算选参、640 次首次复核、
192 次可选追加。每次预算都预先固定；最多用 128 个进程、每进程一个数值线程、
一个进程并行层，受可用 CPU 与待运行任务数限制。

每个种子先得到逐试次预测概率，再跨种子平均概率，最后取观测选择的负对数。
全部试次递推，首试次不计入默认 NLL。完整种子作为 bootstrap 单位，保持时间协方差
及候选间共同随机数关系。区间描述数值误差，不是被试参数的置信区间。
两次查看的 alpha 分配只能限制重复查看的近似 bootstrap 判断，不能消除有限 R 偏差。

## 输出与解释

`manifest.json` 记录配置、源代码、数据、规则资源、历史候选文件哈希和环境版本；
`frozen_banks.json`、`shortlists.json`、`*/nominations.json` 记录候选与冻结决定。
`batches/` 保存计分计划与校验记录；`cache/` 保存原始逐种子概率；`subjects/` 与
`results.json` 保存独立复核及边界诊断。中断后只补缺失的完整种子；配置或源代码变化会拒绝续跑。

若扩展点在独立复核仍明显优于原点，说明原范围或原搜索覆盖值得扩大。
若分数几乎相同但参数差很多，应该报告近似等价候选，不能强行给出唯一的心理解释。
γ=1、c_A=0 等合法机制边界与 M=8 这样的本轮人为上界必须区分。

本轮并没有对每个固定参数重新优化其余所有参数，因而不是 profile likelihood；
没有从头重跑全局搜索，也不能证明未入围候选都较差。四位被试不是总体抽样，不能给出
三个 condition 的触边比例，更不能替代参数恢复、状态轨迹精度或全体拟合。
