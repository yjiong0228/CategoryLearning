## 已固定的执行约定

默认入口为 `python -m src.Bayesian_state.run_model_0826_fit`，配置为
`configs/exp123/specific_models/model_0826_adaptive_fit.yaml`。算法与配置未因本次整理而改变。

| 环节 | 工作设置及结束规则 |
|---|---|
| 起步 | 45个分散点，R32×B4发现，R128×B16引导；保留优良、分散和随机抽查候选 |
| 搜索 | 局部、整块、跨块联合移动；每循环最多4轮，连续两轮改善≤平均NLL .001记为平台 |
| 停前检查 | 一轮联合挑战加90个分散点；有限边界提案；去重与缓存照常生效 |
| 独立评分 | 先冻结代表及候选库，再以独立种子检查；R128×B16，必要时R256×B32 |
| 是否再搜 | 可靠的挑战收益、提名较差或未形成平台才开启下一循环，最多2循环 |
| 纯数值不确定 | 到评分预算上限后保留标记，不自动重搜或再加重复 |
| 范围 | 保持原共同支持，`boundary.extensions: {}`；人为触边单列，默认内侧提案不是外侧范围验证 |
| 判据 | 容差为平均NLL .005；alpha .05分给两个问题×两个预算档×两个循环；bootstrap 6000 |
| 输出 | 原提名、近优候选、完整诊断和问题清单；到顶不改称收敛或参数唯一 |

每人最多9252次完整PF是当前提案配额推导的宽上限，不是每人必须达到的目标，也不是墙钟上限。
剩余87人对应最多804924次PF；实际去重、缓存和早停通常减少计算。
R是一次PF粒子数，B是完整PF随机重复数。所有试次参与递推，首试次不计分；作答前预测，先平均概率再取log。
仅一层进程并行，128-worker预算，每worker一个数值线程，按可用CPU和就绪任务取小，不预留核。

只有平台、挑战、独立评分与边界均满足原规则时，整体状态才是
`provisional_stop_within_tested_scope`。其他结果仍为 `unresolved`；诊断原因必须分开报告。
本次未放宽门槛，也没有实施“只升级挑战双方”“先定向复核再重搜”等尚未验收的改进。

## 全体完成后先回答什么

1. 每个condition按全体被试列出平台、挑战、评分与边界问题，保留原提名及近优候选。
2. 检查任务内学习曲线、选择偏向、错误模式和极低概率试次。全序列拟合的成绩是样本内成绩。
3. 全部人均保留并按诊断作敏感性分析；不得把未通过者删掉后只报告稳定者。
4. 若群体结果显示反复且影响结论的问题，再提出有上限的定向补算。新范围须对所有人共同声明。
5. 解释心理参数前做恢复；留出预测须另按时间前缀拟合；内部轨迹另查状态精度。

数值种子独立不是行为数据留出。已有九人及更早试点的开发来源应保留；剩余人中也可能存在更早诊断对象，
“待完整拟合”不等于“从未被查看”。本轮不声称任何子组是未经开发影响的独立验证集。
