# Model 0826：三个认知坐标与被试分群

日期：2026-09-21。本文回应 Further 新摘要中的 hypothesis search、belief updating 和 belief-to-choice mapping。它是分析建议，不是已运行的降维、聚类或机制验证结果；不修改模型、参数范围与拟合流程。

建议先建立有机制依据的连续画像，再检验画像是否存在可重复的分群。**三个机制模块、三个统计维度和三类被试是三个不同命题。** 三个模块可用来组织指标，但不保证每个模块只有一个维度，也不保证存在离散人群。

## 1. 术语与当前参数的对应

以下以 [模型方程](model_0826.tex) 及 [condition 1 配置](../../../../configs/exp123/model_struct/pmh_model_cond1_0826.yaml) 为依据；参数名与共享核心核对过。表中的分块是解释用途，不是互不相连的因果分解。

| 摘要术语 | 主要参数与配置字段 | 候选认知坐标及解释边界 |
|---|---|---|
| Hypothesis search：假设搜索 | $E_C,E_E$：`event_after_correct/error`；$c_A$：`accumulator_logit_gain`；$g_0$：`global_search`；$c_G$：`global_search_failure_gain` | 搜索发生倾向、对失败的反应、局部／全局范围。搜索频率和范围可能需要两个坐标，不能先认定可压成一个。 |
| Belief updating：信念更新 | $\gamma$：`memory_mod.kwargs.gamma`；$\beta_0,\eta_+,\eta_-$：`beta_init`、`increase_rate`、`decrease_rate` | 旧证据保持与支持／反驳后的规则精度变化。$\gamma$ 是最直接的证据保持坐标；$\eta_\pm$ 更新的是精度，不是通常意义上的信念学习率。 |
| Belief-to-choice mapping：信念到选择的映射 | $\chi$：`persistent_execution.enabled`；以及同一组 $\beta_0,\eta_+,\eta_-$ | 信念混合读出与持续执行结构、规则预测的明确程度。$\chi$ 为二元结构选择，不能直接当连续“执行能力”；$\beta$ 也影响反馈似然。 |
| 贯穿上述过程的资源 | $M$：`capacity`；个体知觉误差来自独立知觉测量；$\gamma$ 也具有资源解释 | 容量影响可考虑的规则、竞争和迁移；不能在只讨论三个过程时将其遗漏。 |

共同固定的 $\alpha=1$、$s_{\mathrm{exec}}=0.20$、$\delta_F=0.60$、$\tau_L=0.10$ 不是可恢复的个体差异；PF 粒子数和随机种子数也不是认知参数。拟合使用 $E_E=E_C+(1-E_C)\delta_E$ 的受约束参数化，不能把 $E_C,E_E,\delta_E$ 都当独立特征。

当前结构中，$\beta$ 同时决定单规则选择概率与反馈诊断性；搜索又通过集合替换和信念迁移影响积累。持续执行的切换概率为 $E_t s_{\mathrm{exec}}$，因此表达也与搜索相连。三个坐标可以相关，不必正交。$M=1$ 时两种读出不可区分，拟合只保留 $\chi=0$；这一编码约定不能被解释为发现一种被试类型。

## 2. 怎样给每名被试定义位置

先区分两个问题：参数画像描述“这个人在相同条件下怎样反应”；轨迹画像描述“这个人在实际任务中经历了什么”。前者可给每人一个坐标，后者通常应随试次变化。用整段实际轨迹求平均会混入刺激、失败次数、学习阶段和观察长度的差异。

建议构建**同任务内统一的诊断条件**，把每个人的参数放入同一组预先规定的反馈历史、刺激和可行状态。诊断条件与权重不能依据分群图或口述一致性挑选。以下是待验证的定义示例，并非现有输出字段。

### 搜索坐标：在相同反馈历史下的全局探索倾向

预先固定一组成功、孤立错误和连续失败历史 $\mathcal F$，用现有控制器计算

$$
S_s=\sum_{f\in\mathcal F}w_f E_s(f)g_s(f),\qquad \sum_f w_f=1.
$$

$S_s$ 表示设计所定义的“搜索发生倾向 × 全局提议比例”的平均强度，值高对应更多全局探索倾向；它不是搜索效率或简单规则偏好。还须保留 $\sum w_fE_s(f)$、$\sum w_fg_s(f)$ 和失败效应，检查低频广搜与高频窄搜是否被相同乘积掩盖。实际新人覆盖还受容量、排除规则和提议核影响。若频率与范围提供独立解释，就保留两个指标，不强求一个搜索轴。

不直接用各人真实错误历史计算被试层搜索倾向分数：错误更多本身就会提高 $E_t$ 和 $g_t$。真实历史用于另行展示实际动态。

### 更新坐标：证据保持，而非笼统的“更新能力”

最透明的初版是 $B_s=\gamma_s$。在工作空间不变、没有差异性新证据的条件下，任意两条规则的对数信念比每次更新保留 $\gamma_s$ 倍。因此，对 $0<\gamma_s<1$，可辅助报告对数信念比的半衰期

$$
t_{1/2,s}=\frac{\log(1/2)}{\log\gamma_s}.
$$

$\gamma=0$ 时下一次更新即去除旧差异，$\gamma=1$ 时没有这种衰减；不将边界硬塞进有限半衰期。该半衰期不等于存在持续反馈与集合迁移时的实际保持时间。

另用相同的支持、反驳条件检查 $\eta_\pm$ 与 $\beta_0$ 怎样影响证据积累和错误后恢复。若它们不能由一个保持分数概括，应将“证据保持”和“精度适应”分开。不要简单取 $\eta_+/\eta_-$ 作为稳健性：更新公式的上限距离、当前精度和证据强度并不对称。

### 表达坐标：有支持的规则能否影响诊断性选择

这一轴需要功能测量，不能直接把 $\chi$ 编码成高／低。可在一组可行参考状态中固定候选规则、信念支持强度、知觉条件与规则间分歧；设置支持已经形成但持续执行规则可能不同的情境。测量模型选择受支持规则所预测类别的概率，汇总为 $C_s$。这里衡量对受支持规则的表达，不以该规则是否客观正确来定义表达能力。

参考状态须包含规则给出不同反应的刺激、执行一致与不一致情境，并按预定权重整合。若所有规则在刺激上预测相同类别，该试次无法识别表达差异。无持续执行时按混合读出计算，不伪造唯一执行规则；持续执行时按其真实状态机制计算。即时指标可以区分读出与当前精度，多步指标则会重新引入搜索和更新的影响。$\eta_\pm$ 只有通过历史生成的 $\beta_t$ 才进入当前表达，不能声称一个静态测试涵盖了全部精度适应。

先检查这一功能分数能否超出 $\chi$ 的二元编码、是否能区分知觉噪声与规则精度、是否在替代可行状态下保持排序。若不成立，第三轴只能暂称“读出结构与精度画像”，尚不能声称得到可辨识的连续表达维度，更不能命名为意识访问或顿悟阈值。

三个候选分数形成 $\mathbf z_s=(S_s,B_s,C_s)$。必要时在训练被试内进行预定的尺度变换，再应用于留出被试。$M_s$、知觉测量与 $\chi_s$ 的结构差异应在图中标注、分层或建模；若它们提供额外且不可忽略的信息，就扩展画像。三维图是沟通选择，不能成为遗漏机制的理由。

## 3. 三个坐标怎样获得依据

1. **方程与功能对应。** 在统一诊断条件下改变相关参数，并检查所有坐标的变化；目标坐标应有可解释的主要敏感性，同时报告跨模块影响。相关参数同向变化不等于独立机制，三个名称也不等于三个已证实的因子。
2. **参数和坐标恢复。** 用已知参数生成选择，重新估计参数，再计算坐标。既检查个体排序与偏差，也检查区间覆盖和类型误判；坐标恢复可能比单参数恢复更好，也可能更差。这一步的通用依据见 [Wilson & Collins, 2019](https://elifesciences.org/articles/49547)。
3. **估计不确定性。** 目前 Hyper-CD 给出所选参数点，PF 表示固定参数下的状态不确定性。PF repeats、搜索起点、前几名候选均不是参数后验样本。近优参数可作敏感性分析；坐标区间需要另行开展保留序列依赖的生成式重拟合，或正式参数不确定性推断，不能从 PF 重复直接计算。
4. **维度检验。** 若每模块有多个可靠的功能指标，可探索因子结构并与预设的三模块解释比较。用平行分析等工具评估维数、重采样检验载荷稳定性，允许交叉载荷和相关因子。每模块只有一个汇总值时，三因子结构实际上已由定义给出，不能再当独立验证。样本不足时以透明的功能分数和恢复为主，不拟合复杂因子模型。

PCA 找最大方差方向；因子分析考察协变结构；聚类分配被试。这三者回答不同问题。先对全部原始参数做 PCA，再把前三轴命名为搜索、更新、表达，并不能提供机制证据。对参数变量本身聚类也只得到相关变量组，不直接得到被试坐标。若做探索性降维，应公开载荷、维数选择和解释过程，在留出资料上验证，不写成事先预测。

## 4. 怎样检验是否存在几类被试

**优先比较连续画像与离散分群，而不是默认聚三类。** 若坐标可靠、样本和分离程度允许，可将少量高斯混合／潜在剖面模型作为探索方案；组数包括 $K=1$，结合信息准则、留出密度预测、组大小及成员归属不确定性判断。不存在适用于本数据的自动“最优算法”。一维偏态、重尾或连续弯曲分布也可能被多个高斯成分逼近，多成分不自动等于自然类型。

聚类输入必须先处理量纲、边界堆积和混合参数类型。$M$ 为离散、$\chi$ 为二元，不能将全参数 z-score 后默认独立高斯。保留精确零／一边界，不为 logit 变换随意抹掉结构边界；不要将估计误差很大的参数赋予与可靠参数相同的解释权重。

至少需要三类检验：

- **无分群对照：** 从拟合的连续人群分布生成参数和行为，经过同一估计、变换、降维和聚类流程，检查有限试次、参数网格、$M/\chi$ 约束及优化误差会不会制造相似分群。只生成最终坐标上的单高斯噪声不足以覆盖这些来源。
- **稳定性：** 按被试重采样并重做整个数据依赖流程，同时传播参数估计不确定性；比较载荷、簇中心、共归属和匹配后的分类一致性。试次有顺序依赖，不能随机打散当独立样本。稳定性本身仍不证明存在离散人群。[Dinga et al., 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6543446/) 提供了获得最佳聚类解但缺少可靠分型证据的实例。
- **外部效度：** 冻结指标、权重与分群规则，再检验未用于这些决定的口述、后段选择、保持和迁移。群间用于聚类的参数有差异是算法结果，不是外部验证；用全序列选择拟合后，再在同一序列上比较快慢只能作描述。应比较分群标签相对于连续坐标是否提供额外的预测或可重复解释价值。

文稿提到的 96 人是总体数，任务内的独立样本还需核实，不能按“总人数足够”直接决定分几组。若同一人有多次记录，训练／验证划分与重采样都按被试整组进行。三任务先分别处理类别目录、反馈语义、试次数和 condition 3 的配对不确定性；简单任务内 z-score 不能保证可合并。跨任务稳定身份还需要测量可比性或跨任务重复证据。聚类检出能力取决于分离度、组大小与方法，不能只看总样本量。[Dalmaijer et al., 2022](https://doi.org/10.1186/s12859-022-04675-1)

## 5. 后解释可以做，但怎样避免循环论证

可以先探索分群，再依据参数／功能画像给组命名，例如“高探索、弱保持”这样的描述。但解释与检验应分开：发现集用于选维度、分组和命名；验证资料用于检验这些组是否具有预测的轨迹或报告差异。若没有可用留出资料，就明确为探索性画像，避免声称确认了自然类型。大量外部比较需预定主要终点并处理多重比较。

“快速、缓慢、突变”是轨迹性质，不天然互斥，也不是预设的机制类别。高保持也可能使错误规则持续存在，高探索也可能帮助或拖慢学习；同一参数画像可能因经历不同产生不同轨迹。可以先展示连续坐标怎样关联轨迹，再在分群证据成立时讨论组别。解释补偿仍需固定其他因素的模型对照与人的独立证据，不能由参数负相关或分群命名推出因果关系。

## 6. 对新摘要的直接影响

新英文摘要已按用户原文更新到 [Further](model_0826_further.pdf)，只移除粘贴带入的 HTML 空格标记。以下证据边界另列，不擅自改写确认措辞：

- **Simpler hypotheses：** 当前基础先验均匀，没有独立的复杂度偏好参数。局部搜索不等于偏爱简单规则；需预先定义复杂度，再在可比条件下检验实际访问／使用内容。
- **Reset beliefs：** 当前没有独立的全局清零参数。需分别度量证据衰减、候选淘汰、迁移重分配与新人精度初始化。
- **Outside awareness / consciously available：** 当前潜变量区分考虑、支持与读出，没有意识状态或访问阈值。支持先于行为／口述只能约束时间关系，口述缺失或没有提到某条规则也不等于无意识。还需要能区分意识状态的直接测量或收窄措辞。
- **Independently validated：** 口述未进入选择参数拟合，但现有计划注明口述曾参与规则目录构建。冻结目录、编码和选择规则后，用未参与这些决定的资料评价，才可界定独立性；不能一面用口述挑坐标或分群，一面把同批口述当最终独立验证。

建议实施顺序：盘点任务内参数与近优候选 → 固定功能指标及诊断条件 → 小规模坐标恢复与敏感性 → 连续画像及留出验证 → 有足够证据时检验分群。本次未启动这些计算。
