## 拟合前的观察与固定问题

已读取全部原始口述。前64题主要描述整个动物，现有编码中63条涉及四个部位，
其中包含最长、最短和部位间比较。具体描述与示例记忆相容，记忆方式仍需检验。
第89—115题连续描述头与脖子的比较：实际刺激下，头长于脖子选1、头短于脖子选2
可以解释24/27次选择。两套规则在6题上冲突，被试5题遵循比较规则。
第106题原文与实际比较方向不一致，保留人工复核标记；按原文明示方向检查，26条中23条符合该映射。
随后还有其他比较尝试；第230题起逐渐集中脖子，第321—384题63条只谈脖子，1条为操作说明，
实际正确率60/64。第194题说腿与脖子；第255题口述缺失；第308、352题为操作说明。

主要问题是行为推断能否支持中间的具体错误规则，并在后期支持正确规则。
规则目录中的0号为脖子单维规则，6号为脖子与头的差值规则，类别方向按共享目录核对。
先固定第1—64、89—115、193—208、230—320和321—384题作为描述窗口；
第193—208题包含不同内容，整个窗口保留。窗口来自本例口述观察，属于开发资料上的描述。
部位集合吻合与具体规则执行概率分别报告，同时涉及头和脖子的内容可能使用不同判断方法。

口述用于选人和固定描述问题，参数评分与粒子权重仅使用行为。
