## 1. 比较哪些机制

四方案共用规则目录、失败状态、搜索控制、局部与全局提议、证据退出、信念分配及作答读出。
精度β统一采用上一轮ADD10范围：配置中的学习率乘以10后进入加法更新，β上限为25。
β决定规则给出的类别概率有多集中。
反馈证据是规则赋予已发生反馈的概率相对于机会水平的对数比：正值增加支持，负值降低支持。
在线证据在规则活跃时按当时的精度积累；历史回顾用β初值重新评价可回忆的经验。

| 方案 | 候选如何获得证据 | 容量已满时怎样比较 |
|---|---|---|
| BASE | 候选以零证据进入 | 移除平均保留证据最低的旧规则，接纳新规则 |
| NEW | 用已完成反馈评价候选 | 候选的历史平均证据与旧规则在线积累的平均证据竞争 |
| POOL | 用已完成反馈评价候选和旧规则 | 对全部竞争规则使用相同历史、β初值和记忆权重，再比较平均证据 |
| DRAW | 与POOL使用相同历史评价 | 抽样一组共同的历史权重，按这组权重比较全部规则 |

容量已满时，NEW、POOL和DRAW允许拒绝新规则。获准进入的候选以回顾所得证据和暴露量初始化保留状态。
历史权重随H证据保持率δ衰减；δ同时控制在线保留证据和历史回顾。
条件3沿用每次经验发生时、加入该次反馈前的配对边缘分布。
完整公式、认知假设和固定参数结果见前一轮说明。

## 2. 怎样公平估计参数

九位被试为107、108、109、205、207、208、305、306、308。
每人每方案使用相同14个参数坐标、候选范围、训练边界及阶段预算。
参数包括搜索基线、失败增益、失败保持、全局搜索及其失败增益、容量、退出率、
局部结构权重、信念转移尺度、作答惯性、信念记忆γ、精度初值、精度学习率和H证据保持率δ。
某些参数组合会关闭另一个参数的作用通道，结果表另外标注这些情况。
γ控制旧信念证据的保持程度。δ控制H保留证据的衰减，在NEW、POOL和DRAW中还控制历史回顾权重。
DRAW使用Dirichlet分布抽取总和为1的一组非负经验权重，分布参数为上述历史权重；
δ还通过权重总量影响抽样波动。
β初值在这三个方案中同时影响新规则的类别预测和历史评价。
这些参数的解释以各自作用通道为条件，参数恢复检验用于检查不同作用能否从行为中区分。

初始32个参数点在四方案间逐值相同。它们包含上一轮ADD10优胜参数，
以及将ADD1优胜参数的学习率除以10后的等效参数；其余起点覆盖容量并分散取自共同参数空间。
纳入ADD1参数用于保留上一轮已找到、且属于本轮共同范围的好参数。

每方案按训练评分选两个有差异的起点，各追加八个局部、跳跃或双坐标联合候选。
随后把每方案在初筛与追加中排名前二的候选，以及旧ADD10参考参数合并，
形成该被试四方案共用的交换候选表。每方案重新评价这张表，允许采用另一方案发现的参数。
交换表去重后最多九个参数点。同一被试的四方案使用相同表长。

| 阶段 | 每方案参数点数 | 粒子数 | 独立滤波种子数 |
|---|---:|---:|---:|
| 初筛screen | 32 | 128 | 2 |
| 联合追加refine | 16个新点及2个起点 | 128 | 2 |
| 交换exchange | 共同表，最多9点 | 256 | 2 |
| 选择selection | 最多4点，保留旧参考 | 512 | 4 |
| 复核confirmation | 2点，保留旧参考 | 512 | 8 |
| 冻结后评价evaluate | 最终1点 | 512 | 8 |

305在选择、复核和冻结后评价中使用2048粒子，沿用此前的数值精度安排。
各阶段种子彼此独立；同一被试同一阶段的机制与参数点共用种子表。
每阶段按共同粒子数、种子数、题数和候选数核对计算预算。
耗时取决于机制及实际搜索次数，因此另行记录CPU时间。

这是一次有上限的联合搜索。48个原生候选与跨方案交换使比较覆盖更多已知好参数，
搜索空间仍大于已评价的候选集合。候选优胜表示它在本轮已完成比较中的训练评分最低。

## 3. 选参目标与数据边界

个体参数按训练段逐题选择负对数似然（NLL）选择。
每题概率在读取该题回答前计算，内部状态已条件于此前回答与反馈。
同一参数的重复滤波先对每题回答概率取均值，再计算负对数并按题数平均。
复核阶段选择最终参数，随后写入冻结记录。

拟合阶段只打开`training.npz`。冻结后另用新种子从任务起点滤波，
后段预测继续条件于当时已经观察到的回答与反馈，参数保持冻结。
训练段的重复评分用于检查数值稳定性；后段评分用于检验后续回答的预测。
九位被试此前均已参与机制开发，本轮后段评价属于开发验证。
本轮参数由训练段估计，用于比较各机制的预测与生成表现。
机制确定后，再用完整行为估计描述个体的参数，并通过参数恢复与不确定性检验明确其解释范围。

自主评价每方案每人生成128条完整路径，共4608条。
模型使用自己的回答产生任务反馈，再由这些反馈更新状态；实际刺激顺序和任务类别沿用已有任务记录。
真实回答只进入后续评价。正确规则身份只用于输出发现、保留和作答贡献诊断。
仓库已有[自适应任务与停止时间检验](model_0923_h_design_study.md#首次达标时间的分布评分)：
每64题检查一次，排除模糊刺激后各类别正确率均达到0.9时停止，后续刺激分配随此前表现调整。
本轮四种准入方案与新参数尚待接入该任务流程。

## 4. 用哪些结果判断下一步

首先比较复核候选及独立训练重复，判断新参数的优势能否重复。
对确认评分与独立重复之间的差异，报告合成模拟标准误；超出两倍标准误的单元明确标记。
复核评分同时用于挑选优胜参数，因此独立重复还会暴露选优带来的乐观偏差。
该标记需结合有限滤波次数、粒子近似和选优过程共同判断。

其次并列查看后段选择NLL与自主曲线Energy score。
条件曲线随实际回答与反馈历史更新；自主路径从任务起点使用自身回答和反馈学习。
两者使用同一组冻结参数，条件信息不同。前者评价给定已有行为历史时的下一题预测，
后者评价整段学习过程的生成分布。
Energy衡量完整模拟曲线分布与真实曲线的距离，同时考虑模拟路径之间的分散程度；值越低越好。
计算时，先取模拟曲线与真实曲线的平均欧氏距离，再减去模拟曲线两两距离平均值的一半，
最后按区块数的平方根缩放。
图中保留全部路径及10%—90%分位带，并显示末128题正确率的完整经验分布。
狭窄分布只有覆盖相应行为时才有价值，单独缩窄分布不构成优化目标。
`late_reaches_observed`记录末段正确率至少达到被试水平的路径比例，用于检查被试较高的末段表现在模拟中是否少见。
各阶段的末段取该段最后128题；阶段不足128题时使用整段。这个比例描述末段正确率，完整曲线仍由Energy评价。
比例为零表示128条路径中未出现达到该水平的路径，有限模拟仍可能遗漏概率很低的事件。

最后连接行为差异与内部过程：检查正确规则是否出现、后期是否仍在集合中、
以及它对回答贡献多少。208重点检查保留改善后对实际错答的解释；
207与308重点检查搜索发现和规则作答贡献。
阶段表中的`target_ever`表示截至该阶段终点，正确规则至少出现一次的路径比例。
`target_proposed`表示截至该阶段终点，正确规则至少被搜索提议一次的路径比例；
`max_active_count`是该阶段全部路径中实际活跃规则数的最大值，用于核对容量竞争是否可能发生。
`target_late_beta_when_present`只在正确规则活跃的末段试次中计算β均值；
该规则全程缺席时记为缺失值。它用于区分规则贡献不足与类别预测精度不足。
正确题指实际回答与任务类别一致的题目；其余回答计入错误题，其中包含条件3的半正确反馈。
两类题目的NLL贡献都以该阶段总题数为分母，相加等于该段NLL。

误差线使用删除一个完整滤波重复或完整自主路径的jackknife模拟标准误。
路径内的试次顺序与相关性得到保留。这些误差条件于已估计参数，衡量有限模拟的数值不确定性。
`cohort_pairwise.csv`保存四方案全部六对比较，按被试等权平均；差值为`model`减去`reference`。
独立被试检验、参数恢复与参数不确定性估计仍需要另行完成。

## 5. 本轮结果

### 5.1 训练复核：参数调整明显改变比较结果

九人、四方案的独立复核全部完成。每个参数点使用八个滤波种子，305使用2048粒子，其他人使用512粒子。
下表对九位被试等权平均；差值以各自重新拟合的BASE为参照。标准误只衡量有限滤波次数产生的计算波动。

| 方案 | 训练NLL／题 | 相对BASE的差值 | 差值模拟标准误 |
|---|---:|---:|---:|
| BASE | 0.782613 | 0 | 0 |
| NEW | 0.782764 | +0.000151 | 0.000596 |
| POOL | 0.783291 | +0.000677 | 0.000558 |
| DRAW | 0.781793 | −0.000821 | 0.000658 |

三个差值均小于相应模拟标准误的两倍。当前训练复核对四方案总体排序的分辨率有限，
冻结后的独立重复、后段预测与自主分布提供进一步区分，结果见下文。

208的POOL由旧参考参数的1.0212降至0.9743，改善0.04686，配对模拟标准误为0.00018；
同一轮BASE为0.9756。这项比较固定POOL准入流程，改变其个体参数，
说明前一轮固定旧参数时的较大似然损失可以通过联合适配明显降低。
本次同时改变了搜索、退出、信念记忆和精度等参数，单个参数的作用需结合定向对照解释。

### 5.2 参数选择与可辨识性

305的DRAW选中容量2，旧参考容量为6，其余13个参数相同。
八次训练复核中，NLL降低0.008900／题，配对模拟标准误为0.002922。
这项比较明确了本轮候选中较小容量取得的训练优势。
容量作为个体特质的解释还需要确认：模型能否从已知容量生成的行为中恢复该值，
以及其他参数与机制变化是否会改变这一估计。

108的BASE和DRAW分别各有两组最终候选，仅失败保持率不同：一组为0，旧参考为0.3。
两组参数在八次复核中产生完全相同的逐题回答概率。
原因是影响搜索发生和全局搜索比例的两种失败增益均为0，失败保持率的两条作用通道都已关闭。
固定排序决定保存哪一组参数；这一排序没有提供失败记忆长短的行为证据。

结果表将这些已关闭的通道单独列出，并保留全部原始参数值和预测，供复核使用。
其余参数的个体差异解释仍需参数恢复与不确定性检验。

机制也可能在某组参数下没有机会表现出差别。109的NEW、POOL和DRAW选中相同参数，
其128条自主路径中的活跃规则数最多为6，容量上限为8，满容量竞争始终没有发生。
三个方案的自主回答与概率相同。这组路径中的三种满容量竞争机制均未实际生效。

### 5.3 自主完整曲线：NEW的平均改善最明显，逐人仍有取舍

九人、四方案的4608条完整自主路径已完成。下表对被试等权平均，
每个单元均为128条路径，Energy越低表示整个学习曲线分布与被试越接近。

| 方案 | 完整曲线Energy | 相对BASE的差值 | 差值模拟标准误 |
|---|---:|---:|---:|
| BASE | 0.115922 | 0 | 0 |
| NEW | 0.106090 | −0.009831 | 0.001675 |
| POOL | 0.112402 | −0.003519 | 0.001705 |
| DRAW | 0.112497 | −0.003425 | 0.001709 |

NEW在六人上降低Energy，在109、305和306上升高。
主要改善来自207和208，差值分别为−0.039586和−0.069911；109的差值为+0.033217。
POOL在205和306上分别升高0.029424和0.013773，因此平均优势小于NEW。
这些结果比较各方案按同一预算重拟合后的预测，机制与所选参数共同决定差异。
直接配对比较中，NEW相对POOL的平均Energy差为−0.006312，模拟标准误0.000638；
相对DRAW为−0.006407，模拟标准误0.001175。这里的分辨率来自有限模拟的数值检查，
被试总体效应及参数不确定性尚未估计。

### 5.4 剩余差距：发现、保留与使用需要分别检查

三位重点被试的末128题平均正确率如下。每个模拟单元均使用全部128条路径。

| 被试 | 实际 | BASE | NEW | POOL | DRAW |
|---|---:|---:|---:|---:|---:|
| 207 | 0.9141 | 0.4857 | 0.5515 | 0.5466 | 0.5423 |
| 208 | 0.9063 | 0.6209 | 0.7357 | 0.7086 | 0.5968 |
| 308 | 0.8906 | 0.4745 | 0.4973 | 0.4907 | 0.4952 |

这十二个单元均有0/128条路径达到对应被试的末段正确率。
该结果描述固定日程下的末段分布；完整曲线评分还会考虑早期与中期表现。
例如208的DRAW末段平均正确率低于BASE，其完整曲线Energy仍低于BASE。

207的NEW有60/128条路径曾出现正确规则，末段正确规则在场比例为0.4368，作答贡献为0.3329。
其余68条路径始终没有提议到正确规则。308的POOL有68/128条路径曾出现正确规则，
末段在场比例为0.4881，作答贡献为0.1703；其余60条路径始终没有提议到正确规则。
本轮207与308的四方案中，所有曾提议正确规则的路径最终都至少一次将其纳入活跃集合。
初始集合中已有正确规则的路径也计入`target_ever`。
这些记录将候选供给不足与规则进入后的作用区分开来。

208的四方案均在全部路径中发现过正确规则。BASE的末段在场比例为0.5332，
NEW和POOL分别提高到0.9971和0.9769；两者的作答贡献都约为0.604。
因此，208的保留缺口明显缩小，规则在场后对回答的影响仍有进一步解释空间。
作答贡献由信念和执行过程共同形成，当前路径比较尚未独立干预这两个过程。

本轮参数使用训练前缀估计。后期生成差距同时涉及未来学习预测、固定的刺激日程和记录长度。
完整任务下的达标时间检验、受控机制比较及参数恢复将进一步限定这些差距的解释。

### 5.5 后段选择预测：自主改善伴随似然取舍

参数冻结后，全部方案各运行八次新滤波。九人的后段共1728题，均使用此前实际回答与反馈更新内部状态。
下表仍按被试等权平均。NLL越低，表示对后续实际回答赋予的概率越高。

| 方案 | 后段NLL／题 | 相对BASE的差值 | 差值模拟标准误 |
|---|---:|---:|---:|
| BASE | 0.431937 | 0 | 0 |
| NEW | 0.438452 | +0.006515 | 0.000794 |
| POOL | 0.437842 | +0.005905 | 0.000886 |
| DRAW | 0.432891 | +0.000954 | 0.000903 |

NEW与POOL的平均后段损失超过模拟波动；DRAW与BASE的等权差值处于当前模拟波动范围内。
按题数加权时，NEW、POOL、DRAW相对BASE的差值分别为+0.007810、+0.006894、+0.006142，
模拟标准误分别为0.001114、0.001253、0.001269。DRAW在短序列305上的改善较大，
其总体接近BASE的程度会随被试权重改变。

逐人看，NEW改善107、108、205、207和208的后段NLL；损失主要出现在305、306和308，
分别为+0.023886、+0.027600和+0.036690／题。
208的NEW同时改善后段选择NLL和自主Energy，支持在这一被试上继续检验候选历史初始化。
308的NEW自主Energy略有改善，后段选择预测却变差，这项取舍需要后续机制解释。

208的独立训练重复还显示了正确与错误回答的平衡。
POOL相对BASE的正确题NLL贡献降低0.031587，错误题贡献升高0.025643，总NLL降低0.005944。
联合调参明显减小了此前的总似然损失，错误回答的相对代价仍然存在。
正确题与错误题贡献均以全部训练题数为分母。

36个单元中，107／POOL、108／BASE和205／BASE的训练重复差值超过两倍合成模拟标准误。
差值依次为+0.000280、−0.001772和−0.000986／题；相应标准误为0.000119、0.000879和0.000414。
208／BASE的差值为+0.004911，标准误为0.002871，未超过该检查线。
这些记录随表保留，用于约束细小排名的解释。该检查衡量重复滤波波动与选优影响，粒子近似的系统偏差另需粒子数敏感性检验。
