全部自主路径、形态比例及模拟区间、边界和失败原因。集合可能为空，也可能包含相距较远的组合。
这些有限候选概括本次搜索支持的范围。连续参数区域、置信覆盖和人群差异需要进一步研究。

全部有效选择按原时序参与选参，包括首题和末题。存储文件仍保留已有的 training/sealed_test 两部分，
本轮计分将它们连接为完整记录。参数整段固定，认知状态逐题学习。生成形态也参与本轮参数选择。
所有真人案例均为开发资料；新随机种子提供独立计算确认，经验推广需要独立真人资料。
口述资料待用户最终人工检查，新增口述验证和编码修改继续暂缓。

## 一、选择评分和数值检查

每次粒子滤波预测本题选择后，再输入本题实际选择和反馈。单次滤波得到完整序列条件概率的乘积。
多次滤波先平均完整序列似然，再取负对数并除以有效题数；程序在对数尺度求和。
旧的逐题平均概率分数随结果保存，用于检查汇总方法的影响。

以整个独立滤波为重复单位，逐次删除一个系统估计蒙特卡洛标准误（MCSE）。候选使用相同
种子编号配对，初筛、确认和追加确认各有独立种子库。报告单个系统的相对序列似然权重，
防止把少量系统主导的结果解释为稳定估计。有限重复不能排除共同的粒子近似偏差。

每题NLL工作容忍同时报告 **0.005、0.01、0.02**，0.01为主表。参考点为独立确认候选中最低NLL点。
候选与参考点的差值加两倍配对MCSE不超过容忍，才记为通过选择检查；差值减两倍MCSE仍超过
容忍则记为超出；其余为边界未确定。候选、参考点和差值的两倍MCSE均须不超过0.005，系统最大
权重不超过0.9。两倍MCSE不超过0.002另报为较高精度。这些门槛是本轮工作标准，尚未经覆盖率校准。

校准先评价每人两个既有锚点，各两次128粒子；第一个锚点再四次512粒子。记录粒子数差异和
重复稳定性。未通过校准精度的案例继续标为探索；最终确认不能消除的数值问题直接进入交付结论。

## 二、先粗后细的联合候选搜索

每人最多24个完整组合：8个初始点，随后最多4轮，每轮4个新点。初始点包括原选择点、已有
联合选参点、旧确认点和分散的粗取值组合。旧结果提供起点，全部新评分使用完整记录重新计算。
每点两次128粒子滤波，另生成32条完整路径。每轮同时参考似然较好点和似然容忍0.02以内形态较好点。

| 参数 | 初始粗取值 | 后续细化与解释 |
|---|---|---|
| 基础搜索概率 p0 | .005, .05, .2, .65, .95 | 检查低搜索至高搜索；相邻值及中点 |
| 失败敏感度 ae | 0, .5, 2, 8 | 零作用边界；正值可用几何中点 |
| 失败保留 λ | 0, .6, .95, 1 | ae=0时统一记为0以去重，并标为无作用 |
| 全局搜索比例 g0 | 0, .2, .5, 1 | 两端及中间取值 |
| 活跃容量 K | 2, 4, 8 | 后续整数相邻值；触及上界可检查10 |
| 规则保持 δ | 0, .5, .9, 1 | 两端及较高保持区间 |
| 初始精度 β0 | .1, 1, 5, 15, 25 | 覆盖模型允许范围；正值几何中点 |
| 精度学习 η | 0, .003, .03, .3, 1 | 无学习、低至高学习率 |
| 执行维持 κ | 0, 1, 3, 8 | 零边界；触及上界可检查12 |
| 配对保持 γ | 0, .6, .95, 1 | 仅条件3；其他条件固定1 |

表中取值用来提出有限联合组合，24点不会穷举各参数的笛卡尔积。后续每点变动一至两项参数，
按结果细化相邻值；最后一轮允许一次边界外扩，优先检查K、κ、ae中首先触界者（分别10、12、12）。
较疏的网格节省初筛计算；参数之间是否可区分仍需看行为差异和恢复证据。

确认至多4个不同组合，包含似然最优、容忍内形态较优和其余较分散组合。
每点四次512粒子滤波和256条新自主路径。若数值仍未确定，在36 CPU小时确认预算内为该人的
所有确认点再各增加四次512粒子；完整批次才能并入配对比较。未完成追加结果单独保留。

每个确认点另以新种子进行两次1024粒子过滤。512与1024粒子NLL差值的绝对值，加两倍
独立误差合并值（两个MCSE平方和的平方根），须不超过.005，且高粒子系统最大权重不超过.9，
才通过粒子数检查。超过或跨越门槛分别记录为敏感或边界，缺失结果单列。最终联合集合还要求
候选及参考点都通过此检查。两次高粒子过滤是有界检查，仍不能排除更高计算量下的变化。
κ=0的过滤采用已验证行为等价的加权读出，以降低计算波动；自主路径继续保留单规则执行身份。
这一等价性限定于已核对的当前学习、容量处理与概率读出模块。

## 三、自主轨迹形态的具体计算

先逐条处理正确性序列，再统计分布。每条轨迹保留原始选择、反馈和模拟内部状态。
多条轨迹均值的缓升可能来自随机时点的突然改善；水平均值也可能来自持续较高与较低路径混合。
因此“缓升均值”和“水平均值”无法直接对应两种个体学习类型。

对一条长度T的0/1正确性序列，拟合 `q(t)=l+(u-l)*sigmoid((t-c)/s)`。
四个量分别表示两端水平、变化中心和变化速度尺度。允许下降，拟合用二值对数损失；
三个中心起点、两个尺度起点取有限最优。10%至90%的宽度为 `2*log(9)*s`。
与整段固定正确率相比，描述性BIC改善至少6且两端差绝对值至少.15，才记录清楚变化。
该门槛用于行为描述，历史相关的二值序列不据此作显著性推断。

主要距离使用11维连续特征：

- 水平与保持（平方距离权重.35）：两端水平、变化完成后最多64题的正确率。
- 变化形式（.35）：正向幅度、`log(1+宽度)/log(1+8T)`、清楚变化标志、截断标志。
- 波动（.30）：16、32、64题块相邻正确率差的均方根，及32题块相对拟合趋势的标准化残差离散程度。

组内按维数均分权重。残差离散程度为各块 `块长*(观察均值-拟合均值)^2 / max(拟合均值*(1-拟合均值),.02)`
的平均，进入距离时截在10再除以10。无清楚变化时，两端记为整段正确率，宽度分量置0，同时
保留“无清楚变化”标志。随访不足保留实际分母和截断标志，绝对变化中心单独保存。
时间平移可能改变有限窗口和边界信息，因此指标是近似容许时点变化。

另报告描述标签及全部路径概率：明显波动优先（残差离散程度>3）；随后区分无清楚改善、持续较高
（整段≥.8）、下降、变化截断、改善后回落（随访低于拟合高水平>.1）、短时改善并保持（宽度≤32）、
渐进改善并保持（宽度≥64）、中间宽度。边界或终点后不足64题记截断。下降与上升均按实际变化终点计算可观察随访；保持形态的心理含义需要内部过程证据。
各类均计入分母，报告Wilson模拟区间；零计数仍保留有限模拟的上界。

全部路径计算Energy评分：平均模拟—被试距离，减去一半不同模拟路径之间的平均距离。
该评分用于候选排序，衡量整个特征分布。同时保留旧的固定32题时间位置与反应混淆Energy诊断。
改善时点、末段水平、完全正确率和条件3反馈得分单列，便于发现形态摘要遗漏的问题。

## 四、生成相容性及空集合处理

256条确认路径按预定种子顺序分为128条参考、128条校准。计算目标轨迹到参考集合中最近
`floor(sqrt(参考条数))` 条轨迹的平均距离（至少2条；正式确认11条）。多邻居距离检查目标附近
是否有模拟质量，避免单条幸运路径决定结论，也避免两群之间的低概率空隙被总体均值掩盖。
每条校准路径同样计算这个距离。距离大于等于被试距离的次数为k，校准条数为n。
报告尾部秩 `(k+1)/(n+1)` 和 `k/n` 的95% Wilson区间：

- 区间下界>.05：在这些形态特征下相容。
- 上界<.05：不相容。
- 区间跨越.05：未确定。

区间只反映固定参考集合下的模拟计数误差，不含参数、参考集合或指标选择的不确定性。
32条初筛路径仍使用同一规则，但精度较低；主要用于排序，最终按256条新路径确认。
形态相容性、似然容忍、数值精度三者同时通过，才保留联合候选。阈值是开发阶段工作判断。

全部失败时交付空集合，并分开列出：数值未解决、似然差距、生成形态低概率、边界触及、预算
导致的未检查部分。不能把有限搜索失败概括为整个模型没有任何合适参数。全部参数表现相近时，
交付较宽联合集合及参数补偿；心理解释依赖跨组合稳定的量。

预计时间。96 CPU小时是累计计算预算，不是96小时等待。审稿、排版与人工解释时间另外记录。
本轮将原模拟恢复预算转给六个真人案例及每个候选的自主生成。完整重复参数恢复、模型恢复和
状态恢复分开安排，现有低恢复率及持续执行机制证据边界继续保留。

## 本轮方法判断记录

1. 扩展为每条件一名常规和一名困难被试，检验完整流程在不同难度的可用性。
2. 所有初筛候选均生成路径，预算从恢复试例移到真实候选联合评价。
3. 完整序列似然按整个独立系统合并，旧逐题汇总保留诊断。
4. 形态相容性使用多个邻居和独立模拟校准，持续较高/较低混合不自动构成学习。
5. 数值精度、相对似然和形态相容分别报告，空集合与未确定均为允许的研究结果。
6. 本轮搜索和形态门槛属于有界先导，长期参数区间覆盖及心理类型解释仍需额外证据。
