## 1. 本轮要交付什么

本轮回答三个问题：

1. 使用一个人的完整记录，能否稳定比较不同参数对实际选择的解释能力？
2. 从少量、间隔较大的候选开始，再局部细化，从不同起点搜索后能否找到相近的高评分区域？
3. 对已知参数生成的少量完整记录，估计流程能否找到至少同样能解释数据的参数？

最终交付包括三个真人案例的参数与评分、全部搜索记录、三个模拟案例的恢复误差、
参数范围检查表、实际计算费用，以及扩大研究或先修正流程的决定。
三个模拟案例提供流程可行性证据。重复轨迹下的偏差、区间覆盖及人群参数可靠性需要后续研究。

已有两参数恢复在其他参数已知的12条路径中，容量与信念保持率同时精确恢复2次；
早期完整恢复也发现估计点在独立评分时明显劣于生成点。这些结果要求先分清评分误差、
搜索不足和资料无法区分参数。本先导分别检查这三类原因。

## 3. 先利用已有计算，再确定最低可用精度

先读取旧运行保存的完整逐题概率及计时元数据，核对参数、源码、任务语义、数组长度和种子。
可直接重算的旧点分数予以复用；新种子确认单独计数。固定参数的旧数组继续按原身份保存。
对零维持点使用已验证的执行身份解析求和前，核对与原模型的行为概率等价性。
具有正维持值的点保持对应的执行历史依赖。

本轮拟合目标是完整选择序列的概率。对每个独立粒子滤波，先将其逐题实际选择概率相乘，
得到整段序列概率估计；再对多个独立估计取平均，最后取负对数并除以题数。
实现使用对数运算，避免长序列概率乘积下溢。粒子是计算中保留的可能内部学习过程。

旧评分先平均各次滤波的逐题概率，再取对数。本轮保留它作数值对照，分别命名，
检查两种汇总是否改变候选排序。新的整段汇总须先通过小型精确参照、观测时点、
反馈规则及概率下限影响检查。若需要重写核心推断方法，本轮在此结束并交付问题清单。
增加独立计算次数不能自动消除固定粒子数带来的误差。

每名被试选择两个固定参照点：原纯选择拟合点和共同选参点；两者相同时，使用原12个确认
候选中与前者网格秩距离最远的点，并列按原分数、候选标识处理。网格秩距离按各坐标的
候选序号范围缩放后取平均绝对差。选择过程在新计算前冻结。
每点最多计算两次128粒子和四次512粒子，共36次完整过滤。每人至多一个未解决点可追加
四次1024粒子，共最多12次。先完成110，再决定是否继续另外两个案例。

数值分辨率暂定为每题负对数似然差0.002。它表示本先导愿意分辨的评分差，
与统计置信区间、心理上有意义的参数差分别报告。候选差的蒙特卡洛标准误，以独立完整
过滤为单位估计；保留整段系统权重，检查平均是否由一个系统主导。

继续条件如下：512粒子关键差值的两倍标准误不超过0.002；对已经能区分的候选，
128粒子初筛给出相同方向。需要1024粒子复核时，两级关键差值的变化也不超过0.002。
小于分辨率的差值保留为并列。四个独立系统中最大归一化证据权重超过0.8时，
该批次标为证据不足并按上述限额复核。概率下限影响排序或不同精度出现未解释的排序冲突时，
结束该条件的搜索准备，保留失败。其余通过的条件可以继续。
四次独立计算得到的标准误是小样本数值诊断；通过上述门槛只支持本先导的比较精度。
序列证据高度不均时，增加少量重复仍可能漏掉重要路径，此时交付数值证据不足。

## 4. 小规模搜索，同时检查候选范围

每个案例最多评价24个不同参数组合。两个搜索起点分别分配12个名额：先评价6个初始点，
再提出6个局部或联合改变的点。初始点含共同的旧参照及各自的分散取值；重复点复用。
两组各自的提案只使用自身已完成分数。提案次序、并列规则、种子及名额在启动前固定。
每个点用两次128粒子计算完整记录，最多48次初筛过滤。

### 4.1 候选范围与初始分辨率

以下是初始分散搜索的建议值；旧参照的完整参数组合也保留，并计入24个组合。
表中的数值帮助提出少量参数组合，每个案例仍受24个组合限制。
各参数候选的全部排列组合不进入本次计算。

| 参数 | 在模型中的作用 | 初始候选建议 |
|---|---|---|
| 基础搜索概率 p0 | 没有累积失败时提出新规则的概率 | 0.005、0.05、0.2、0.65、0.95 |
| 失败敏感度 a_e | 累积失败使搜索概率增加的强度 | 0、0.5、2、8 |
| 失败累积保留 λ | 一次完全正确后保留多少既往失败量 | 0、0.6、0.95、1 |
| 全局搜索比例 g0 | 搜索时从整个可用目录提出规则的概率 | 0、0.2、0.5、1 |
| 活跃规则容量 K | 同时保留的规则数量上限 | 2、4、8 |
| 规则信念保持 δ | 零分反馈后保留原有规则信念差异的程度 | 0、0.5、0.9、1 |
| 初始判断精度 β0 | 任务开始时类别距离对选择概率的影响强度 | 0.1、1、5、15、25 |
| 精度学习率 η | 反馈引起的精度更新幅度，实际步长为10η | 0、0.003、0.03、0.3、1 |
| 执行维持 κ | 提高继续执行上一条规则的概率，倍数为exp(κ) | 0、1、3、8 |
| 配对信念保持 γ | 条件3中各规则内部配对知识的保留程度 | 0、0.6、0.95、1 |

条件1、2估计前九项，条件3再估计γ。独立知觉测量、规则目录、任务反馈和模型固定设置
沿用当前定义。当前K的实现下界为2，精度限制在0.1至25；这些限制单独登记。

初始候选覆盖零作用、较弱、较强和边界情形。正参数跨数量级时采用较大比例间隔，零值
单独保留。参数坐标相距较远是否产生可区分行为，仍需通过评分和恢复检查。
δ接近1、κ较大等区域可能具有不均匀的行为变化，等距取值并无统一的科学依据。

后续提案在两个搜索各自的较好区域补入中间值，例如K为3、5、6、7，δ为0.95、0.99，
或者正学习率的几何中点。局部细化和联合改变共用原有提案名额。每项自由参数都需在
初始点或后续提案中发生变化，并保留参数差异较大但评分相近的候选。

24个组合只用于检查流程、明显改善和严重搜索不足。9或10维空间中的全局搜索充分性
需要后续预算；每项参数都变化过也不足以证明各项的作用均已分开。

### 4.2 结构上没有作用的参数

当a_e为0时，搜索概率恒等于p0，λ改变的失败量无法影响后续行为。205、306的旧参照正处于
这一边界。对其他参数相同且a_e为0的候选，合并只在λ上不同的重复计算，λ报告为该分支下
无法由行为识别。具有正a_e的候选继续改变λ；旧点的边界结果不决定其他分支的λ取值。

κ为0时使用已经验证的行为等价关系复用计算，结论限于相应模块。η为0表示精度不随反馈
改变，属于需要保留的模型边界。边界值、参数无作用及有限资料下差异太小分别记录。

### 4.3 边界检查与独立确认

若目前较好的点位于搜索边界，每组最后一个提案名额可用于一个边界检查，仍计入24点。
优先次序为容量、执行维持、失败敏感度、基础搜索概率。相应的外侧检查值为容量10、
执行维持12、失败敏感度12、基础搜索概率0.001或0.99。只对触及对应搜索边界的坐标使用
这些登记检查值；没有触边时，该名额用于联合改变。λ为1已包含在初始候选中。
检查发现范围不足即记录，范围的进一步扩张留到后续协议。

规则信念保持率、配对保持率及学习率继续遵守现有数学范围。容量1和判断精度上限25
涉及当前模型的限定，本轮记录其影响边界，另行设计机制范围检验。
评分接近时，保留不同参数及其预测差异，不以减少候选值来提高精确命中率。

每例最多三个点进入独立确认：两个搜索各自的最优点和最优旧参照，去重后各做四次512粒子。
确认评分最好的两个点再用四个新的配对种子作独立评分，共最多八次512粒子。
最终选择只依据完整选择评分；落在数值分辨率以内的候选共同报告，
确定性展示点按候选标识选取。对边界检查后仍有疑问的参数，仅交付范围不足的结论。
第3节数值分辨率与权重集中判据也用于新候选的确认和复核。未通过时保留并列或数值失败，
不增加未登记的计算。两个搜索得到接近结果仍只支持已检查范围内的稳定性。

## 5. 三个模拟案例检查估计流程

每种条件生成一条完整记录，分别保留110、205、306的刺激日程、知觉设置和448、704、768题长度。
生成参数以各自旧纯选择拟合点为背景，将精度学习率改为该值与下一较大旧候选值之间的中点：
两个端点均为正时取几何中点；包含零时取算术中点；原值在上界时使用相邻较小值。
110的生成学习率为sqrt(0.001×0.003)，205、306为sqrt(0.03×0.06)。这些值均在旧网格之间。

三个生成案例分别承担以下检查：

| 外部日程 | 生成参数建议 | 主要检查 |
|---|---|---|
| 110 | 修改学习率，其余沿用旧纯选择点；a_e=0.25，κ=0 | 较短记录、零执行维持边界、网格之间的学习率 |
| 205 | 修改学习率，其余沿用旧纯选择点；a_e=0，κ=2 | 正执行维持，以及λ在该生成分支中无行为作用 |
| 306 | 修改学习率，并设a_e=0.5、κ=3，其余沿用旧纯选择点 | 条件3中错误驱动搜索、正执行维持和配对学习共同存在 |

306的两项改动使相应机制在生成设定中处于启用状态，数值用于先导设计。205的λ单独标记为
结构上无法恢复，不计入有效参数的恢复错误率。启用某一机制也不保证单条路径会提供足够
信息；事件是否出现按生成后的完整记录报告。全部真值在看到生成行为之前固定。

每条件使用一个新的固定生成种子，全部路径进入评价。拟合端只接收模拟行为、任务信息
和与真人先导相同的固定开发候选来源；生成参数、状态和生成点标识单独保存。
候选不得依据模拟真值增加、删除或缩小范围。使用第4节同样的24点名额、完整记录评分
和独立确认。模拟拟合的随机种子与真人拟合分开。

参数冻结后，使用同一批四个新过滤种子评价生成点和确认评分最好的两个点，最多12次512粒子。
这12次替代真人阶段的八次独立复核。若估计点比生成点的每题负对数似然差超过0.002
加两倍差值标准误，记录搜索未通过。一次偏离真值的估计可以比真值更好地拟合该次随机记录；
参数误差与搜索质量分别报告。保留各参数的绝对误差、边界情况、两次搜索差异及行为差异。
三例不估计区间覆盖率，也不据此判断所有被试或整个参数空间均可恢复。
学习率的网格间真值只检查该坐标的离散化问题。三个背景仍接近既有开发参数，正式恢复需
增加远离这些背景的参数区域、更多坐标的网格间真值，以及每个真值下的多条独立路径。

## 6. 少量自主生成检查学习过程

对每名已完成拟合的真人案例，比较旧纯选择参照与全程选出的展示点，各生成64条完整路径，
最多384条；参数相同时复用。全部路径参与评价。
展示完整时间曲线、每条路径的改善幅度及随后保持，并报告既有行为特征的Energy分数。
Energy衡量模拟行为分布与实际行为的距离，此处只用于拟合后的描述。
既有Energy特征为32题块正确率和按真实类别分组的选择频率，两类各占0.5权重。条件3另报
完整类别正确率与反馈平均得分。改善定义为相邻两个32题窗口的正确率差，保持定义为再后
一个完整32题窗口的正确率；只在具有完整后续窗口的位置比较，并保留发生时点。
最大局部增幅及其后保持同时报告绝对水平，避免将低表现中的波动解释为已学会。
生成结果不返回参数搜索。64条路径未出现某种学习形态时，报告有限样本下的零计数。
口述、真人逐题潜在状态标签及完整历史平滑保持原来的待验收状态。

| 评分核查 | 36次完整过滤，最多12次1024粒子补查；小型参照与流程检查计入本项 | 16 |

| 三个模拟拟合 | 每例同样初筛和确认，另有生成点及2个估计点复核，最多216次过滤 | 38 |

| 合计 | 完整过滤最多468次；重复点、兼容旧记录和未通过条件会减少实际数量 | 96 |

CPU小时为各数值进程占用CPU时间之和。单层进程并行，每进程一个数值线程；
工作进程数取128、可用CPU数和就绪任务数的最小值。先导通过减少参数点和记录数节省总计算，
并行用于缩短等待时间。前后依赖的步骤按顺序开展，小型检查使用一个工作进程。

预算调度同时累计已完成用量及在途任务预留。若下一任务的预留会超出阶段或总预算，
停止提交；进程计时包括失败和中断尝试，并为预算到达时的停止保存已完成结果。
每完成一批即更新实际成本和剩余时间。预算不能因结果不理想而自动增加。
若长案例的128粒子初筛不足以可靠保留好候选，停止该条件并给出更高精度的成本估计，
本轮不自动加倍全部拟合预算。

两组各三个案例的初筛合计约38 CPU小时；按对应旧中位数估算，确认与最终复核约33 CPU小时，

按最近环境核查中可见128个CPU、机器负载较低的条件，预计新增科学计算等待约2—4小时；
工作流适配与核查约2—3小时，结果整理约0.5—1小时，完整交付约5—8小时。

预计约1—2小时即可给出暂缓扩大的原因。新候选成本、机器竞争及实现问题可能延长等待；

## 8. 先导之后怎样检验参数可靠性

本先导交付的是已检查候选之间的差异和问题定位。每个参数的正式置信区间、重复测量
稳定性及人群推广属于后续任务，未包含在96 CPU小时内。

先用全部搜索记录寻找参数补偿线索。例如较低初始精度与较高学习率、较大规则容量与
较强执行维持，可能在有限资料上产生相近评分；具体是否发生由计算决定。
正式检查时固定一个参数的不同取值，每次允许其他参数重新优化，再比较能够达到的最好
评分。这称为似然剖面，用于判断其他参数能否补偿该参数的改变。只固定其他参数画一条
曲线得到的是条件敏感性，不能据此声称该参数已被单独识别。

随后在若干登记真值下各生成多条独立行为记录，对每条记录完整重新估计。报告参数误差、
系统偏差、边界比例、区间宽度和区间包含真值的比例。每个真值使用几条路径，依据本轮
实际费用和需要分辨的恢复水平另定；三条先导记录无法提供这些重复估计。

最终结果可以是某项参数得到较窄约束，也可以是多个参数共同形成宽区域。若单项参数
区分困难，继续检验发现正确规则、维持高表现等功能量是否稳健。把参数解释为跨任务的
个人特质，需要来自重复任务或其他测量的证据。口述人工审核完成后再接入外部检验。
