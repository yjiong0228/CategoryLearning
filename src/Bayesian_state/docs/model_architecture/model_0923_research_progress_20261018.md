# Model 0923 持续研究记录：规则学习与个体参数

## 目标与研究边界

目标是建立能够解释被试如何发现、保留和使用规则的学习模型，并让个体参数具有可信的心理含义。
口述报告用于检验模型推断出的局部判断和表征变化。行为参数用选择数据估计；自主生成用于检验整段
学习过程是否有合理的生成概率。三者分别提供预测、过程和表征证据。

2026-10-18，用户授权自主持续运行数小时，根据每轮结果决定下一步，充分利用可用CPU。
本记录保存已完成工作、当前计算、研究判断和后续检验。原始数据、已有拟合及科研结果保留。
每轮新运行使用独立目录，代码和方法说明在相关验证后本地提交。

## 起点与判断标准

九名开发被试的BASE、NEW、POOL、DRAW联合重拟合已经完成。
NEW的平均自主曲线Energy较低，BASE的平均后段选择负对数似然较低。
因此继续用口述检验这些方案是否推断出更符合报告的学习过程。
已有比较见[联合重拟合说明](model_0923_episodic_refit.md)。

机制选择依据可重复的过程改善、后续行为预测、口述表征对应及设计解释的简洁性。
个体差异、行为与表征指标之间的取舍均单独报告。
某个机制获得稳定的口述或过程优势时，要检查行为预测的损失及其模拟误差，再决定是否继续该方向。
单个被试或单项指标的改善只支持相应范围的结论。

参数解释按作用通道逐项检查：参数如何影响模型过程、行为数据是否能区分该作用、
其他参数是否能够补偿，以及模拟数据中是否能恢复这一差异。
参数不确定性和作用通道关闭的情况与点估计并列保留。

## 阶段A：完整作答依据读出

已实现行为条件状态读出，计算粒子、规则与实际选择的联合贡献后再汇总到类别分量。
各规则的局部分量权重沿用原口述模块的内部刺激距离约定。
导出完整分量质量、活跃规则集合和选择条件下粒子权重，口述内容不进入状态计算。
几何支持和显式谓词支持的定义沿用[口述约束方法](model_0923_oral_constraints.md)。

对跨种子结果，先平均选择—局部依据联合质量，再除以平均选择概率。
“至少一条支持规则存在”的概率通过每个粒子的完整活跃集合求并集后计算，保留规则共现关系。
对多分量规则同时保留“每个分量支持”与“至少一个分量支持”的存在概率范围。
作答依据支持由实际分量权重计算。

## 阶段B：表征与行为的共同诊断

状态重放完成后按以下顺序评价：

1. 在相同完整解析报告上比较四方案的显式支持、几何支持、冲突和未确定质量，逐被试保留结果。
   缺失、解析片段、参照未定和不一致编码继续单列。
2. 先检查207和308的明确分支描述，再看九人全序列、训练段与后段。
   比较支持规则是否进入活跃集合，以及进入后是否对实际选择有足够贡献。
3. 将完整动态状态与训练段形成的类别内平均依据分布比较，检查状态变化是否提供额外解释。
   此项是针对表征时间变化的诊断；基准的冻结时间和类别可用性须记录。
4. 将结果与已有后段选择负对数似然、自主曲线Energy及末段表现并列，检查不同证据的一致处和取舍。

自动完整解析表示语法覆盖，人工语义核验仍需进行。
108的躯干参照、多项描述中的依据／补充角色，以及清晰表达的漏解析分别整理为复核任务。
修改编码需有独立语义理由，并在所有方案上统一应用。

### 完整任务环境的接入

根据联合重拟合说明中已列出的后续检验，新增入口
`workflows.analysis.model_0923_episodic_adaptive_task`。
它复用已有任务生成器和认知生命周期，按原拟合记录安装精度及历史准入方案。
九人的原类别标签、模糊刺激标记、试次顺序及64次类别配额转移均已核对通过。

正式协议保持36组参数和原128条自主路径的种子，比较三种刺激流程：
固定真实日程、均衡类别重采样、依据模拟回答自适应调整类别配额。
每64题排除模糊刺激后计算各类别正确率，所有类别均达到0.9即停止。
自适应与均衡流程的行政观察上限为20组；全部未达标路径保留为截至该时点尚未达标。
固定日程流程在首次达标或原记录结束时停止，保留试次须与已有自主路径逐项一致。
每次会话开始重复原第一组刺激，认知状态跨会话保持；后续抽样使用NumPy随机数。
这些设置沿用任务生成器的既定假设，并保存在运行协议中。

运行方式为：

```bash
python -m src.Bayesian_state.workflows.analysis.model_0923_episodic_adaptive_task \
  --config configs/shared/model0923_episodic_adaptive_task.yaml \
  --output results/model_0923/episodic_adaptive_NEW
```

`--smoke`使用一个被试、四方案、每种流程一条路径和一个进程；均衡与自适应流程最多两组。
`--subjects`指定协议内的被试子集。107、207、308的三条件短验证均已完成，
共36条路径，其中12条固定日程路径精确重放通过。任务及队列边界的22项测试通过。
正式批量任务在状态重放释放计算资源后逐步接入，两批合计最多128进程，每进程一个数值线程。
配置的`resource_predecessor`声明前一批状态重放；队列根据其未完成任务数保留相应工作进程额度。
