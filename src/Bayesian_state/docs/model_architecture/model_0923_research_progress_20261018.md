# Model 0923 持续研究记录：规则学习与个体参数

## 目标与研究边界

目标是建立能够解释被试如何发现、保留和使用规则的学习模型，并让个体参数具有可信的心理含义。
口述报告用于检验模型推断出的局部判断和表征变化。行为参数用选择数据估计；自主生成用于检验整段
学习过程是否有合理的生成概率。三者分别提供预测、过程和表征证据。

2026-10-18，用户授权自主持续运行数小时，根据每轮结果决定下一步，充分利用可用CPU。
本记录保存已完成工作、当前计算、研究判断和后续检验。原始数据、已有拟合及科研结果保留。
每轮新运行使用独立目录，代码和方法说明在相关验证后本地提交。

九名开发被试的BASE、NEW、POOL、DRAW联合重拟合已经完成。
NEW的平均自主曲线Energy较低，BASE的平均后段选择负对数似然较低。

| POOL | 关闭 | 关闭 |
| PRIOR | 关闭 | 开启 |
| SEARCH | 开启 | 关闭 |
| BOTH | 开启 | 开启 |

记第\(i\)条已完成反馈在规则\(h\)下的概率为\(L_i(h)\)，随机选择的相应反馈概率为\(c_i\)，
证据保持率为\(\delta\)。在第\(t\)题开始前，回顾证据为
\(E_t(h)=\sum_{i<t}\delta^{t-1-i}\log[L_i(h)/c_i]\)。
所有回顾均使用初始规则精度，条件3保留各次反馈前的配对分布。

SEARCH将原候选概率\(q_t(h)\)更新为与\(q_t(h)\exp E_t(h)\)成比例的概率，再归一化抽样。
原提议核赋予零概率的候选继续为零。PRIOR仅在新规则实际入集时，将最终活跃集合内的信念设置为
与\(\pi(h)\exp E_t(h)\)成比例，其中\(\pi(h)\)是基础规则权重。
这一步从共同历史重建信念；其后继续原有在线反馈更新。
回顾精度固定为初始精度，因此这是一项明确的回顾式信念假设，尚需检验它与实际学习中的精度变化是否协调。
