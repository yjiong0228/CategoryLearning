## 起点与判断标准

九名开发被试的BASE、NEW、POOL、DRAW联合重拟合已经完成。
NEW的平均自主曲线Energy较低，BASE的平均后段选择负对数似然较低。
因此继续用口述检验这些方案是否推断出更符合报告的学习过程。
已有比较见[联合重拟合说明](model_0923_episodic_refit.md)。

机制选择依据可重复的过程改善、后续行为预测、口述表征对应及设计解释的简洁性。
个体差异、行为与表征指标之间的取舍均单独报告。
某个机制获得稳定的口述或过程优势时，要检查行为预测的损失及其模拟误差，再决定是否继续该方向。
单个被试或单项指标的改善只支持相应范围的结论。

参数解释按作用通道逐项检查：参数如何影响模型过程、行为数据是否能区分该作用、
其他参数是否能够补偿，以及模拟数据中是否能恢复这一差异。
参数不确定性和作用通道关闭的情况与点估计并列保留。
当前已确认207两方案的失败保持率，以及308完整目标参数中的三个搜索坐标处于关闭通道；
这些坐标标为行为无法区分，原数值仅用于复现。具体条件与实际模型检验见[通道检查](#搜索通道关闭与参数解释范围)。

### 当前H候选与定型条件

截至2026-10-18，下一版H的共同设计是：**用反馈证据管理活跃规则集合，让新旧规则在同一批历史经验上
竞争容量，并区分规则是否在场、对作答贡献多少、以及规则执行精度。** POOL作为共同历史准入方案，
SEARCH进一步让历史证据影响候选的产生。两者继续并列比较。精度保持是独立的开发候选：
规则离场时保存最近的已学精度，重入时恢复；首次进入仍用原精度初值。
当前这些实现通过实验上下文启用，正式主路径保持原有配置行为。

这份设计已有三项具体依据。第一，新旧候选的历史共同评价能改善部分被试的保留过程，
值得作为后续比较的共同结构。第二，发现规则、持续保留规则和依靠规则作答可以分别出现困难，
需要分别诊断。第三，活跃集合容量与已学状态的保存具有不同作用；208的规则离场重入诊断
已经显示，原先的精度重置会放大容量限制对自主学习的影响。

下面给出当前代码实际执行的顺序。每题反馈发生时记录知觉刺激、所选回答和反馈，随后完成原有的
信念与精度更新。下一题准备阶段消耗这次反馈，使用上题精度更新前已计算的反馈似然更新H证据。
本题作答依据在本题反馈前形成。条件3另外保留经验发生时的配对信念，完整时点见
[历史经验记录](model_0923_episodic_admission.md#2-记录哪些经验何时使用)。

| 环节 | 当前实现 | 本环节要解释的现象 |
|---|---|---|
| 1. 更新失败与规则证据 | 失败积累影响搜索发生率；在场规则按历史保持率累积相对机会水平的反馈证据 | 什么经验促使继续尝试或重新搜索 |
| 2. 条件性自主退出 | 仅对累计证据为负的规则，按退出率与相对信念抽样退出；至少保留一条具有正信念的旧规则 | 尚无新候选时，哪些已有解释会被放弃 |
| 3. 搜索并提出候选 | 局部／全局路线和结构／功能邻近关系规定基础分布；SEARCH进一步用已完成经验的回顾证据调整候选概率，保留原有零概率边界 | 哪种规则在何时被发现 |
| 4. 共同评价与容量准入 | 有空位时接纳；满容量时，新旧规则用同一批历史、同一初始精度和同一时间权重比较，平均证据最低者退出，并列时随机选择；候选自身也可被拒绝 | 新规则出现后，哪些内容留在活跃集合 |
| 5. 分配集合内信念 | 保留下来的旧信念归一化；接纳新规则时按亲和度（规则间相似性）向它转移部分信念；普通反馈更新仍使用信念保持率 | 多条在场规则各获得多少支持 |
| 6. 准备执行状态 | 原实现对重入规则重新初始化精度；精度保持候选恢复该规则最近在场时的精度。执行惯性与规则信念共同决定作答贡献 | 规则是否能被稳定、准确地使用 |
| 7. 形成回答并接收反馈 | 各规则按自身精度预测，依照作答贡献混合形成选择概率；随后记录新经验并更新信念与精度 | 学习过程如何产生真实选择序列 |

流程对应[集合转换](../../model/modules/hypothesis_transition/mechanistic_rule_search.py)、
[历史准入](../../model/modules/hypothesis_transition/episodic_admission.py)、
[历史搜索](../../model/modules/hypothesis_transition/episodic_proposal.py)与
[精度保持](../../model/modules/hypothesis_transition/reentry_precision.py)。
精度保持对全部规则统一应用，离场期间精度冻结；无限期保存是本轮原型的明确假设。
历史经验另行保存，活跃容量只限制参与当前处理的规则数。
SEARCH按完整目录计算历史提议证据，其心理计算成本仍需进一步约束。

记第\(i\)条已完成反馈在规则\(h\)下的概率为\(L_i(h)\)，随机选择的相应反馈概率为\(c_i\)，
证据保持率为\(\delta\)。在第\(t\)题开始前，回顾证据为
\(E_t(h)=\sum_{i<t}\delta^{t-1-i}\log[L_i(h)/c_i]\)。
所有回顾均使用初始规则精度，条件3保留各次反馈前的配对分布。

SEARCH将原候选概率\(q_t(h)\)更新为与\(q_t(h)\exp E_t(h)\)成比例的概率，再归一化抽样。
原提议核赋予零概率的候选继续为零。PRIOR仅在新规则实际入集时，将最终活跃集合内的信念设置为
与\(\pi(h)\exp E_t(h)\)成比例，其中\(\pi(h)\)是基础规则权重。
这一步从共同历史重建信念；其后继续原有在线反馈更新。
回顾精度固定为初始精度，因此这是一项明确的回顾式信念假设，尚需检验它与实际学习中的精度变化是否协调。

### 类别关联的概率计算原型

新增`hypothesis_space.observation_model.response_association`，将几何规则与作答类别关联分开表示。
规则h仍占用一个规则位置；其四个区域到四个作答类别的24种一一对应记为π。
条件3继续保留三个反应类别的科配对状态z。每条规则内部保存关联与配对的联合条件分布
\(a_h(\pi,z)\)，对π和z求和为1；条件2的z轴只有一个位置。
这一联合表示保留类别关联与科配对之间的依赖。

选择概率先由几何区域概率转换到作答类别，再对关联不确定性求和。
设\(q_{hg}(x)\)为规则h对刺激x属于区域g的概率，\(\pi(g)\)为该区域对应的作答编号，则
\[
p_h(c\mid x)=\sum_{\pi,z}a_h(\pi,z)q_{h,\pi^{-1}(c)}(x).
\]
这里c表示作答类别。后续完整模型可用原有规则作答贡献混合这些规则内预测。
每条规则的关联分布归一化，因此加入24种对应后，该规则原先获得的总先验质量保持不变。
容量的设计单位继续是几何规则；关联不确定性保存在该规则的内部状态中。

反馈核\(L_h(\pi,z)\)表示该规则、关联和科配对产生本题反馈的概率。
条件2的正确反馈取所选类别概率，错误反馈将其他类别概率相加。
条件3复用已有`pairing_feedback_kernel`，分别计算反馈1、0.5和0的事件概率；
这里的科配对定义于作答类别，几何区域须先经过π转换。
新接口只接收区域概率、实际选择和实际反馈，口述与真实任务类别均不作为输入。

更新时先在每条规则内部对旧关联分布施加保持，再计算该规则的边缘证据：
\[
\widetilde a_h(\pi,z)=
\frac{a_h(\pi,z)^\eta}{\sum_{\pi',z'}a_h(\pi',z')^\eta},\qquad
e_h=\sum_{\pi,z}\widetilde a_h(\pi,z)L_h(\pi,z).
\]
η是原型显式接收的保持率；η=0时使用均匀分布。它与现有γ或δ的关系仍待模型比较，
目前未加入个体参数配置。随后得到
\(a'_h(\pi,z)=\widetilde a_h(\pi,z)L_h(\pi,z)/e_h\)。
完整模型将用同一个\(e_h\)更新规则边缘信念，使反馈只计入一次。
原型在\(e_h=0\)时保留有效关联分布并返回零证据，供调用方处理该规则的零边缘质量。

独立计算原型已实现四个接口：`associated_probabilities`转换全部对应，
`association_choice_probabilities`汇总选择概率，`association_feedback_kernel`计算反馈事件，
`update_associations`返回关联后验及规则边缘证据。现有引擎配置和运行结果保持原版本。
验证包括全部24种对应的独立枚举、固定恒等对应与现有科配对核完全一致、三类反馈概率和为1、
分解更新与直接联合Bayes更新一致，以及逐题反馈识别关联。
在无噪声示例中，前三个不同区域的正确反馈使相容对应数依次从24降为6、2、1，
第四个区域的作答在反馈前已经确定。14项新原型测试与26项已有科配对测试全部通过。

完整接入还需同时处理三个环节。第一，历史搜索与容量准入应使用对关联积分后的候选证据，
使搜索评价与选择预测采用相同的规则含义。第二，新规则进入时，应根据该规则的几何内容和可用历史
初始化关联；不同几何规则的区域编号可能对应不同内容，关联数组不能仅按编号复制。
第三，状态克隆、粒子重采样及口述作答依据读出须携带完整联合分布。
尤其207、208的原拟合γ为0，直接沿用该值控制关联保持会在反馈更新前抹去先前关联信息；
加入这种表征后需重新估计参数并检查学习过程。原型的数值验证与完整机制的实证验证分别记录。

### 类别关联状态的口述读出准备

新增`evaluation.oral.association_basis.AssociatedDecisionBasis`，在反馈前将规则与关联信念
转换成规则—几何区域—局部分量的联合质量。其输入只有规则权重、关联分布、区域预测、刺激和实际选择。
若实际选择为c，对每条规则h、每个几何区域g，先汇总所有将g对应到c的关联：
\[
B_{hg}=w_h\sum_{\pi:\pi(g)=c}\sum_z a_h(\pi,z),\qquad
J_{hg}=B_{hg}q_{hg}(x).
\]
这里\(w_h\)是规则作答权重，\(a_h\)是反馈前的关联／科配对分布，\(q_{hg}(x)\)是区域预测概率。
B在全部规则和区域上求和为1，J求和为模型对实际选择的预测概率。随后用该概率归一化J，
得到条件于实际选择的判断依据分布。

每个区域内部直接复用既有`DecisionBasisCollector`的最近分量约定，距离并列时平均分配。
因此，新接口保留相同的局部读出含义，并携带几何区域这一额外坐标。
完整口述约束将在状态记录完成后，分别评价这些分量，再用联合质量汇总。
类别对应、规则和分量均按行为模型赋予的质量参与评分。

### 自主末段错误的分解

为区分正确规则的发现、作答贡献和预测精度，进一步分析三人两机制已有的768条自主路径。
每组128条路径均从任务开始自行作答；参数仍为原训练段选定值。该分析复用保存的规则在场状态、
作答贡献和精度，并以原随机种子和归档知觉模块恢复逐题知觉刺激。随后调用归档规则预测函数，
得到正确规则在当时精度和知觉输入下的正确类别概率。

这里的正确规则沿用原几何审查：三人的训练与完整物理刺激日程均只有规则42完全正确。
该身份用于事后诊断。模型实际作答时继续使用自己形成的规则集合与贡献权重。

分解的目的是确定模型预期错误落在哪些状态和规则上。令 \(I\) 表示正确规则是否在场，
\(c\) 表示其作答贡献，\(q\) 表示它对正确类别的预测概率，\(p\) 表示原模型的总正确概率。
当前读出按规则贡献线性加权，因而 \(cq\) 是正确规则提供的正确作答概率质量，
\(p-cq\) 是其他规则提供的相应质量。每题的总预期错误可写为：

\[
1-p=(1-I)(1-p)+c(1-q)+I\{(1-c)-(p-cq)\}.
\]

右侧三项依次表示正确规则缺席时的全部错误、正确规则自身产生的错误，以及正确规则在场时
其他规则产生的错误。缺席时 \(c=0\)，对应的正确规则错误记为零。
这三项为描述性的概率质量分配。改变发现、竞争或精度机制还会改变后续反馈与认知状态，
其因果作用需要自主干预轨迹检验。

### 正确规则预测中的知觉与精度

此前错误分解发现，即使任务正确规则已经进入集合，其自身仍会给错误类别分配相当的概率。
本轮沿用207、208、308各自POOL与SEARCH的128条自主轨迹，共768条，进一步区分知觉扰动
与精度不足在当题预测中的作用。正确规则身份来自任务定义，属于诊断信息；本轮保持所有拟合参数。

每条路径按原种子重建知觉输入，并从保存的状态读取正确规则的精度、作答贡献与原混合概率。
分别计算四种正确规则预测：原知觉与原精度、物理刺激与原精度、原知觉与精度25、物理刺激与精度25。
物理刺激指加入知觉噪声前的任务输入。25是原配置中的精度上限。三人的知觉噪声均来自独立知觉任务
的被试测量值，四个维度的均匀扰动半宽约为0.019至0.028，保留在每组结果的`perception`字段。

替换后的混合概率用于衡量当题效应。设原混合正确概率为$p$，正确规则的作答贡献为$c$，
其原预测为$q_0$，替换后的预测为$q_1$，则新概率为$p+c(q_1-q_0)$。
正确规则缺席时$c=0$，替换对该题没有影响。其他规则的预测、所有权重、规则集合与后续状态均保持原值。
因此，这些数值是既有状态上的读出诊断；改变知觉或精度学习后形成的整条新轨迹需要另行生成。

### 搜索通道关闭与参数解释范围

新增只读入口`workflows.analysis.model_0923_search_gate_audit`，检查已完成拟合中是否有搜索参数的
作用被其他参数完全关闭。它读取冻结候选及执行源码的哈希，保留原候选和排序，输出逐坐标标记。
当前检查覆盖207、208、308的原联合拟合、308的两种估计范围，以及新完成的306联合拟合，
共12条参数记录、168个坐标。相同被试的不同机制与估计范围分别保留。

检查依据是实际H模块中的两个概率。设基础搜索率为b、错误增益为e，已完成反馈形成的累积失败为A_t，
当题发生搜索的概率为σ(logit(b) + e A_t)，其中logit(b) = log[b/(1−b)]为基础概率的对数优势，
σ为将实数映射到0至1的逻辑函数。
基础全局搜索比例为g₀、失败引起的全局增益为η、平滑失败状态为F_t，
搜索时采用全局提议的概率为g_t = g₀ + (1 − g₀)ηF_t。
失败保持率λ控制F_t的平滑，并控制A_t在成功后的衰减；局部结构权重α只在局部搜索分支中使用。
这些关系带来三项精确条件：

- g₀ = 1时，每次搜索均走全局分支，α的数值不影响规则提议。
- g₀ = 1时，g_t恒为1，η的数值不影响搜索范围。
- e = 0，且（η = 0或g₀ = 1）时，失败状态同时失去对搜索发生率和全局比例的影响，λ的数值不影响行为。

检查使用精确等号。接近边界的参数仍可能影响过程，其数值大小和可辨识程度需要另外评价。
某个增益估计为0本身也可能具有可检验的行为含义；该增益所控制的下游状态参数才可能随之失去作用。
历史回顾的保持率δ与反馈信念保持率γ另有作用通道，当前检查保留二者的原含义。

| 207，POOL与SEARCH原前段目标 | λ = 0.99；两者e = 0、η = 0 | 行为无法据此确定失败保持时间 |
| 308，POOL与SEARCH完整目标 | λ = 0.3、η = 1、α = 0.25；两者g₀ = 1、e = 0 | 这三个保存值只标识当前数值候选，行为无法区分它们的取值 |
