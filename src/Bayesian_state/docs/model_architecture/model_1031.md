# Model 1031：从具体经验形成局部概括

**2026-11-01采用版本：** 本轮十参数结构见[完整定义](model_1031.tex)及[PDF](model_1031.pdf)。
`1031-unified-v2`覆盖三种反馈条件，保留精度学习、信念保持和执行维持；
条件3保存模板类别与同科配对的条件分布。初选七参数方案在保留样本检验中失败，
修订比较及证据范围见[版本确定研究](model_1031_finalization_study.md)。
以下正文保留首版定义，便于复现既有先导结果。

版本：`1031-experience-v1`。本版是 Model 1024 之后的研究候选，使用同一个
`StateModel`、选择读出和粒子滤波框架。用户确认的首版范围为条件1的二分类及条件2的
四分类，两者均接收“对／错”反馈。条件3的半对反馈另行设计。

本版检验一个具体假设：学习者先保存动物及其类别信息，随后尝试忽略部分特征，形成适用
范围更广的局部概括；已有规则目录提供进一步表达这些概括的候选。具体记忆、局部概括
和目录规则共同占用有限的工作区。每次反馈决定它们以后影响选择的程度。

## 1. 表示什么

工作区最多容纳 K 项内容，每项内容具有信念权重和判断精度 β。内容有两种存储形式：

| 内容 | 保存的状态 | 对新刺激的作用 |
|---|---|---|
| 经验模板 | 当时感知到的四维特征、仍需比较的维度、类别信念 | 相似时支持记忆中的类别，距离较远时趋于均匀预测 |
| 目录规则 | 原有规则目录编号 | 通过共享的类别边界与判断精度产生类别概率 |

模板保留全部四个维度时，描述一只具体动物；删除部分维度后，描述一组局部相似的动物。
类别信念 θ 是各类别的概率。例如，四分类任务中选择 A 后得到“错”，新记忆记录
`[0, 1/3, 1/3, 1/3]`，保留 B、C、D 三种可能。模型接收实际选择及反馈，正确类别仅供
自主模拟的实验环境生成反馈。

特征按输入的 feature1–feature4 顺序保存，均在 [0,1]。身体部位名称来自被试实验设置。
例如，若第二维为脖子，模板保留该维且记住 0.2，则表示“脖子接近记住的长度”。
“脖子小于某个界限”的完整范围由随后进入的目录规则表达。本版模板中心保持固定，
概括通过删除维度扩大适用范围；模板中心移动、连续注意权重和新的关系运算留待后续研究。

同一个位置会被新的内容替换。每项内容另有路径内编号 uid、来源编号 parent_uid 和
进入试次。uid 用于追踪一条路径中的衍生关系；不同粒子中的相同编号可能表示不同内容。

## 2. 一道题如何完成

1. 初始工作区含一个“尚未形成内容”的位置，第一题均匀选择。
2. 知觉模块给出当前刺激。工作区根据已完成的历史决定是否加入具体记忆、局部概括或规则。
3. 从当前信念中抽取本题执行内容；上一题的内容仍在场时，保留原有的执行维持作用。
4. 执行内容给出类别概率，再抽取回答。实际行为估计则计算被试真实选择的概率。
5. 接收反馈，先计算各项内容对该反馈的概率，再更新其信念、判断精度和模板类别信念。
6. 下一题的搜索可以使用本题已完成的经历。

第一次有效反馈之后，第一项具体记忆确定进入工作区。之后每题最多产生一个新候选。
当前选择的预测始终在读取当前反馈之前完成。选择似然、自主生成及行为重放共用以上顺序。

## 3. 局部模板如何预测

相似度 a 表示当前动物在保留维度上与记忆动物接近的程度：

\[
a(x)=\exp\left[-\frac{\sum_{d\in M}(x_d-v_d)^2}{2\sigma^2}\right].
\]

x 是当前感知特征，v 是记住的特征，M 是保留维度集合，σ 是相似范围。σ 越大，相似
动物的范围越宽。删除一个维度后，该维度的差别不再降低相似度。

判断精度 β 决定匹配时对记忆类别的偏向强度。令 C 为类别数，定义

\[
s(\beta)=\frac{1-e^{-\beta}}{1+(C-1)e^{-\beta}},\qquad
g=a(x)s(\beta),\qquad
p(c\mid x)=\frac{1-g}{C}+g\theta_c.
\]

θ_c 是该模板支持类别 c 的概率。刺激很远时 g 接近零，各类别概率接近 1/C；刺激很近且
判断精度高时，预测接近 θ。该表达式等价于先对每一种可能的记忆类别形成 softmax 选择
概率，再按 θ 求平均，因此类别不确定性与执行不确定性均保留。

目录规则继续使用现有的边界距离概率。两类内容通过同一反馈事件接受评价：选 c 后得到
“对”的概率为 p(c)，得到“错”的概率为其余类别概率之和。

## 4. 如何形成概括和规则

搜索机会沿用累计失败机制。搜索基准概率为 p₀，错误增益为 η，失败累积为 F。
错误后 F 增加1，正确后 F 乘以保持系数 ρ；搜索概率为

\[
P(\mathrm{search})=\operatorname{logistic}
\left[\log\frac{p_0}{1-p_0}+\eta F\right].
\]

正确之后仍保留至少 p₀ 的搜索机会，因此成功经验也能产生概括。一次搜索按以下共同策略提出候选：

- 工作区已有局部概括时，以原有的全局搜索比例 g_rule 尝试规则候选。
  先按信念选择一个局部概括，再比较目录规则与该概括的类别倾向。
  保留维度取记忆中心的值，被忽略的维度分别取0和1，组合成至多8个检查点。
  每个检查点计算规则类别预测与模板类别信念的重合程度；对这些重合度取几何平均，
  再除以各候选得分的总和（归一化），得到规则抽取概率。这些检查点只用于提议候选，
  反馈学习只使用真实完成的试次。
- 其余搜索在“保存上一题的具体经验”和“删除已有模板的一个维度”之间各分配一半机会。
  删除维度时，先按信念选择可简化的模板，再均匀选择一个保留维度删除。
  至少保留一个维度。只有一种局部操作可用时，采用该操作。
- 新概括继承来源模板的中心和类别信念。父模板与子模板可以共同保留，继续分别接受反馈。
  与已有内容完全重复的候选跳过，当题结束搜索。

规则候选来自原有29条二分类／152条四分类完整目录，每条尚未在场的规则保留正提议概率。
在局部概括范围内给出一致预测的规则更容易被提议。多维规则仍可进入，随后由实际反馈检验。
关系运算和目录本身是预设的表示资源，学习这些运算的起源超出本版范围。

删除某一维度是一个待检验的概括。比如忽略尾巴后，模型能把原先的类别倾向推广到尾巴不同的
动物；这些动物的反馈持续一致时，该概括得到支持；反馈冲突时，其相对信念下降。
因此，本版允许形成错误概括并保留它被后续经验削弱的过程。

## 5. 信念、容量和执行

各项内容的信念 π 使用 Model 1024 的归一化幂更新。反馈 r 为0或1，基础保持率为 δ，
当题保持率为 δ_t=δ+(1−δ)r。将 π 的 δ_t 次幂乘以反馈似然后归一化，得到新信念。
所有活跃内容接受反馈，执行内容决定本题的选择概率。

工作区未满时，新候选获得 1/(当前项数+1) 的信念，其他内容按原比例分享余量。
工作区已满时，替换信念最低的一项；并列时随机抽取。新候选信念沿用
`r × 被移除信念 + (1−r)/K`，其余项保持相对比例。K=1时每次加入会替换原内容。
新候选的判断精度继承加入前的信念加权平均。

本题执行内容按照 π_i exp(κ I_i) 归一化后抽取。I_i 表示该内容是否为上一题执行的同一项，
κ 为已有的执行维持参数。位置被新内容占用后，旧内容的维持作用结束。κ=0可用于无维持比较；
持续执行的心理证据继续沿用研究指南中的候选边界。

判断精度沿用共享的反馈对数似然梯度及 ADD10 更新，范围为 [0.1,25]。
模板梯度对上述模板概率求导，目录规则梯度调用原有边界实现。
模板类别信念在信念与精度更新完成后，用更新前的 β 及 θ 进行条件更新：
将每个候选类别的 θ 乘以该类别下反馈发生的概率，再归一化。
这一步与信念更新分别表示“此内容有多可信”和“此内容关联哪个类别”。新记忆的来源反馈
用于初始化；加入之后的真实反馈才开始评价它。

## 6. 参数和本次实现选择

新增的个体候选参数只有相似范围 σ。容量 K、搜索基准、失败增益、失败保持、全局搜索比例、
信念保持、精度初值、精度学习率及执行维持沿用已有功能。旧模型中针对固定目录的结构距离、
功能距离和提议温度未用于本版模板搜索。两个模型的参数需要各自估计。

下列选择是首版共同假设，记录供之后审阅：局部操作固定各半、每次删除一个维度、保持模板中心、
从模板类别信念继承子模板、以忽略维度的端点比较规则提议，以及首个反馈后立即保存经验。
这些选择控制实现规模，尚未通过行为或口述证据比较。配置中的 σ=0.25、K=4及其他数值是
运行检查值。随后完成的S118、S128及[S113个案](model_1031_subject113_pilot.md)各检查16个参数候选；
完整参数区域与可辨识性仍待检验。

## 7. 状态输出和口述边界

`representations_pre`保存每题选择前的具体内容。粒子观察接口同时导出各粒子的模板中心、
保留维度、类别信念、目录规则编号及权重。`predictive`为选择前权重，`filtered`为观察当前
选择后的权重，两个时点均在当前反馈之前。

跨粒子的语义汇总使用四组：尚未形成内容、具体示例、局部概括、目录规则；分别报告信念质量和
执行概率。原有按位置排列的数组继续供计算使用，其编号表示可复用的存储位置。按 uid 或位置
直接把不同粒子归为同一心理状态会混合不同内容，报告应使用实际内容及祖先路径。
搜索概率单独保存，粒子中的实际加入事件用于估计加入概率，重复候选也进入该分母。

本版尚未建立从模板到自然语言报告的观测模型。原有规则口述读出在本版配置下明确拒绝使用。
四维模板能表示完整动物经验；真实被试是否采用这种表示，需要行为拟合、状态恢复和人工复核后
的口述对照。当前口述原文、编码和历史结果保持原状。

## 8. 运行、检查和下一步

两个配置为
`configs/exp123/model_struct/model_1031_cond1_experience_v1.yaml`及
`model_1031_cond2_experience_v1.yaml`，通过常规 `StateModel` 加载。无需运行时全局补丁。
所有自适应内容均随粒子状态保存、恢复；各粒子共享只读目录，分别保存自身内容。
历史预测使用对应试次保存的内容重放。
首版使用`particle_blocks=1`，多分块配置会报错；独立进程可分别运行独立的完整滤波器。

小规模入口从仓库根目录运行：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m src.Bayesian_state.workflows.runs.run_model_1031_smoke \
  --condition 1 --subject-id 102 --trials 32 --particles 16 \
  --output results/model_1031/new_smoke_run
```

省略 `--subject-id` 时生成合成刺激。入口最多允许128题、64粒子、单进程，拒绝已有输出目录。
输出配置、种子、输入与源码哈希、选择概率、逐粒子内容和一条自主路径。
自主路径使用同一刺激日程，由模拟回答及实验正确类别产生反馈。

实现检查覆盖：初始无规则、条件2错误反馈的类别不确定性、成功后的概括、反例作用、父子共存、
规则来源、概率与精度梯度、跨粒子隔离、状态恢复、固定种子复现、自主行为重放和旧模型数值回归。
短程运行只确认实现与数据接口。随后三个个案按各自冻结预算检查表示演变与行为拟合，
相关结果见个案协议。数值收敛、完整参数区域、参数恢复、状态恢复与口述预测仍需分别评价。


本轮检查结果：28项新机制测试与75项相关既有检查通过，含期刊迁移前保存的数值参考。
S102与S205各32题、16粒子的单进程检查通过，自主生成与逐题重放的概率最大差均为0。
