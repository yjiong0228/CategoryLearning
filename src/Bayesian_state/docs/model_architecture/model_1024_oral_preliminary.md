# Model 1024：本题选择理由的初步对齐

本轮用户要求先看口述初步结果，并确认指导语是“汇报本题选择这个选项的理由”。
口述仍待最终人工复核。本分析读取六名开发被试的既有原文、编码和行为推断状态，
在新目录生成逐条对照。参数、状态权重和原始记录保持原样。

## 对齐的对象和时间

实验程序在选择之后录音，在录音之后呈现反馈。因此主对照使用“本题选择后、反馈前”
的过滤状态：它结合此前行为及本题选择，给出各执行规则及所选类别局部分量的概率。
规则的局部分量指该类别的一块连续刺激区域，例如“腿短且头长”。完整历史重建另列，
它还结合了后续选择。两种状态的参数都由完整行为记录估计，结果属于开发资料的回顾性解释。

原始口述按被试、场次和原试次连接。流程核对冻结行为记录中的刺激、选择、反馈和行顺序，
并核对当前原文与旧审查表完全一致。规则几何维度按每名被试的部位映射解释。
口述与概率之间没有重新加权步骤；每条局部规则的分数按原行为状态概率平均。
候选参数分别输出，候选最小值和最大值仅表示这几个已检查参数的差异。

## 两个方向的内容覆盖

首先记录理由涉及哪些部位。关系判断同时涉及其比较对象；“腿最长”涉及腿与其余三个部位。
含否定归因、让步或猜测等词句的记录单列待复核，初版不自动把其中所有部位认定为肯定理由。

两个覆盖率使用不同的分母：

1. 理由部位覆盖：口述涉及的部位中，有多少进入了这条局部规则。
2. 规则部位覆盖：这条局部规则涉及的部位中，有多少出现在口述中。

例如口述“腿短、头长、尾巴短”，局部规则为“腿短且头长”，前者为2/3，后者为2/2。
尾巴这一理由继续保留为尚未解释的内容。若规则还需要脖子，规则部位覆盖也会下降。
两者一起看，可以区分模型只解释了部分口述、口述只表达了部分规则，以及双向完整覆盖。
这些部位集合由规则几何定义；作答概率还涉及其他类别的比较，因此本分析另存整条规则的部位覆盖，
作为局部定义的敏感性结果。部位覆盖描述内容范围，因果影响需要另行检查。

随后检查具体判断，如“腿短”“头比尾巴长”。沿用已有中点编码，将每个已编码判断等权计分：

- 支持：局部规则区域中的所有刺激都满足该判断。
- 冲突：局部规则与该判断没有正体积交集；仅共享边界也按冲突处理。
- 未确定：该规则对这个判断仍允许多种结果，或判断的参照尚未确定。

“腿短”和“腿长”会涉及同一部位，但方向相反。部位一致和判断支持需要分别报告。
本轮分句得分沿用旧编码的原子判断单位；一条最长、最短或相等语句可能包含多条不等式，
它的得分权重受编码单位影响。原子平均是暂定描述指标，逐句等权需要人工确认分句后另行定义。
另存规则中直接被说到的标准判断占比，以及旧的整组判断共同支持质量，便于检查部分解释与整句解释的差别。

主要语义汇总限定在完整、无矛盾、可数值表达且理由角色未被标记的报告。
解析片段保留在逐题表中，片段支持不推广到整句。符号参照、缺失、编码冲突和未解析文字分别保留。
“长／短”沿用0.5中点、“相等”沿用旧容差等既有约定，均待人工确认；流程不选择使模型更匹配的解释。

## 参照与解释边界

第一种参照对目录内规则等权，再在所选类别的分量内等权。
第二种参照只看当前物理刺激和当前所选类别：筛出该类别区域包含当前刺激的规则，
对这些规则等权，再在包含刺激的分量内等权。它忽略学习历史和知觉噪声，属于简单的内容参照。
找不到兼容规则的试次保留缺失标记；模型与参照的差值使用共同有效试次。
高于这个参照可说明结果超过此种简单目录匹配；学习机制的独立贡献仍需更严格的匹配对照。

原状态的数值检查结果随表保留。本轮另将新内容指标投影到已保存的较低粒子数状态，
报告两档计算差异。新指标的独立重复分组检查尚未完成，原执行分布的稳定性也不能直接替代它。
S129四组仍为诊断参数，其余五人共13组为已保留候选。口述评分不参与增删参数。

下一层理由检验可以固定本题推断状态，改变口述所指判断，检查所选选项的概率如何变化。
这种检验需要保留知觉输入、类别比较、配对状态，以及联合判断间的作用。
本轮高精度汇总档案缺少其中部分信息，当前交付限定为内容对齐。
后续可复用现有固定状态读出工具，先核对未经改变的输入能复现原选择概率，再接入理由检验。

## 执行与产物

配置为 `configs/shared/model1024_oral_preliminary.yaml`。使用一个进程、一个数值线程，
分析预算30分钟；本轮粒子滤波与自主模拟次数均为0。运行前固定上述定义，停止后保留已生成文件。
从仓库根目录运行：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
python -m src.Bayesian_state.workflows.analysis.model_1024_oral_preliminary \
  --output results/model_1024/oral_alignment_NEW
```

`trial_review.csv`和`review.html`保存全部原文及逐条审查内容；`candidate_trial_scores.csv.gz`
保存每个候选、每种条件状态的逐题分数；`summary.csv`保存全段和64题窗口摘要；
`particle_sensitivity.csv`保存两档粒子数差异。`manifest.json`记录输入哈希、实际时间、软件版本及分析范围。
初版解释入口为`workflows.reports.model_1024_oral_preliminary_report --source 已完成的分析目录`，
它核对产物哈希、逐题身份及分数范围，再写入`report.md`和`report_audit.json`。
该解释入口限定当前六人、17组候选；解释中的例子用于审查计算含义。
