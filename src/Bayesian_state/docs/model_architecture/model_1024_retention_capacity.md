# Model 1024：信念保持率与容量的局部对照

登记日期：2026-10-25。依据[研究指导](../RESEARCH_GUIDE.md)及上一轮共同前段状态诊断，
本轮分别改变信念保持率和活跃规则容量，检验正确规则进入后丢失及学习时序的差距。
本轮使用现有生成模型，保持知觉、精度、执行和搜索机制，重新估计其中两个坐标。

## 对象与参数干预

使用129、229、317的MIX与STICKY，共六组。每组的起点是上一轮训练共同选参后冻结的参数。
MIX按规则信念加权作答，STICKY每题执行一条规则，并保留被试层面的执行维持倾向。
其他参数固定在相应起点，错误后信念保持率δ取0、0.3、0.6、0.8、1，容量K取2、3、6，
形成每组15个组合。原起点均在该范围内。317的原始似然参照另行保留，供比较与守门检查。

δ控制收到错误反馈时既有规则信念的保留程度，具体保持率为δ+(1−δ)r，r为本题用于信念更新的
反馈得分，更新结果进入下一题。r=0时保留率为δ；r=1时保留率为1。K限制同时活跃的规则条数。每个候选从任务开始按自己的
参数生成、过滤，保持自身合法容量。正确规则身份只在评分时用于描述内部过程。

固定其余参数后，保持K相同的比较检验δ的作用，保持δ相同的比较检验K的作用。完整矩形
网格同时检查两者的相互作用。它们是现有模型中的参数干预，后续学习由各自生成的选择与
任务反馈推动。对照保留全体组合；具体效应在统一的独立评价批次报告。

## 训练剖面估计与冻结

每个组合用两个新种子、256粒子计算训练负对数似然NLL，并生成32条新的训练长度路径，
用32题块正确率和类别条件反应频率的Energy评分，两个特征族各占0.5权重。Energy评价所选
行为特征上的预测分布，越低表示越接近观测。所有组合使用配对种子和相同预算。

每组最初的行为似然提名作为固定NLL参照，同样用本轮两个过滤种子计算。原参照与当前起点
分别记录。训练资格为NLL相对该固定参照增加不超过0.02；资格内选择训练Energy最低的组合，
并列依次取NLL更低和标识字典序更前者。资格为空时保留当前起点。

每组至多提出一次替换。若拟议组合改变，以一批独立的128条训练路径比较当前起点与拟议点，
并以六个独立种子、512粒子确认原NLL参照、当前起点及拟议点。采用新点同时要求：

1. 新点相对最初NLL参照的每题NLL差加两倍模拟标准误不超过0.02。
2. 新点相对当前起点的训练Energy差加两倍模拟标准误小于0。

确认失败时保留当前起点。容忍量始终相对最初的NLL参照计算。组合排序与确认仅使用训练
选择及任务输入，工作进程禁止打开后段数组；口述保持外部检验用途。冻结全部决定后再评价。
各训练组合及分数全部保留。局部剖面只重估δ和K，其余坐标固定，保留这一估计范围。

## 冻结后的共同评价

所有90个组合各生成128条完整自主路径；317的两个原NLL参照另各生成128条。生成时仅使用
规定刺激、任务类别、模型作答及任务语义给出的反馈。每组当前起点、最终点和原NLL参照还用
共同的六个新种子、512粒子评价逐题条件选择概率。所有参数冻结后保持不变。

主要评价完整序列、训练段和后段Energy，条件训练/后段NLL及后段正确率分布。保持与容量的
单项差值及相互作用使用同一配对种子计算，保存完整路径作为模拟误差单位。进一步报告：

- 正确规则在场、作答贡献、精度、首次进入和进入后缺席等已知生成状态。
- 最大相邻32题增幅及完整随访保持；改善中心限定仍有第二个后续32题窗口，平局取最早位置。
- 增幅、保持同时达到真人的路径比例；另加中心相差不超过32题的时点条件，并保留原事件比例。
- 最低128题表现及同一窗口的类别/反应边际独立参照，窗口按既有64题步长扫描。

时点条件在本轮模拟之前固定。真人后段已经参与开发，全部后段比较标为开发评价；独立种子
检验数值稳定性。局部训练NLL资格集合用于描述候选的取舍，参数后验及置信区域另行建立。
计算过程、完整轨迹改善、参数恢复、状态恢复及口述相容性分别验收。
