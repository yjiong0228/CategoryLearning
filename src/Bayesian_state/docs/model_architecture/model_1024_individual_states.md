# Model 1024：个体内部状态推断与暂定口述对照

日期：2026-10-28。用户已授权数小时计算，并要求展示口述外部验证，供次日集中人工复核。
本轮沿用已确认的个体参数工作方案，推断每道题作答时可能存在的内部状态。口述原文和编码保持原样。

## 研究问题与输入

首先区分三个问题：被试可能正在考虑哪些规则；这些规则各有多大信念权重；本题可能执行了哪条规则。
判断精度另行记录，它决定规则对类别的区分程度。对每个问题保留概率分布，并比较不同候选参数得到的结果。

输入为六名被试的全部有效行为记录和既有参数候选。S110、S205、S229、S306、S317共13组参数进入主分析；
S129的4组参数用于条件诊断，其参数集合尚有数值问题。S229保留自主轨迹波动不足的限制。
各组参数来自上轮已列出的完整组合，本轮使用固定参数推断状态。全部真人记录继续作为开发资料。

每个被试从首题推断到末题。历史存储文件名包含 `training` 和 `sealed_test`；本轮按原时序连接两者，
读取全部选择、刺激和反馈。模型通过反馈继续学习，参数在这次任务内保持固定。

## 状态时点和两种推断

所有状态对应“本题已选择、本题反馈尚未出现”。实验程序先记录选择和录音，再显示反馈，
顺序可在 `exp_program/exp123/Task2_learning.m` 的步骤5—8核对。

过滤推断使用截至本题的选择和之前的反馈。完整历史重建进一步使用后续选择，回看本题可能的内部状态。
后续行为可以帮助判断早期是否已经考虑某条规则，因此两种结果可能不同。
两种图均以整次任务估计得到的固定候选参数为条件，其用途是拟合后的过程解释。

粒子表示一条可能的内部过程。观察到一次选择后，能够更好解释该选择的粒子得到更高权重。
完整历史重建沿保存的父子关系追溯最终粒子，使用最后一次选择后、最后一次反馈前的权重。
每个早期时点的祖先数量及有效数量同时保存，以显示多少不同历史仍被计算保留。

重复过滤使用相同参数和独立随机种子。合并时按照各次过滤估计的行为序列概率加权：
过滤图的权重使用截至该题的累计选择概率，完整历史图的权重使用整段累计选择概率。
这样合并的依据与图中使用的行为范围一致。若少数重复计算获得绝大多数权重，数值诊断会显示这一点。

不同参数的结果分别保存。图中的参数范围表示这些有限候选结果的最小值与最大值；它没有统计置信区间含义。
每组参数内的状态概率来自该组参数下的潜在过程推断。两种不确定性分开呈现。

## 执行身份与口述内容

持续执行强度大于零时，粒子保留实际执行规则身份。强度为零时，沿用已验证的局部积分方法，
先计算各规则产生当前选择的概率，再得到观察到该选择后各执行规则的概率。
因此执行身份的分布反映当前实际选择提供的信息。

规则的某个类别可能含多个不相连的局部区域。沿用既有口述读出约定：根据粒子的内部刺激表示，
确定离它最近的类别区域；距离相同时平分权重。新增捕获保存每个粒子的规则、局部区域及其联合质量，
使过滤和完整历史重建均能用各自的状态权重评价口述。

规则在场概率允许多条规则同时较高，其和可以超过1。信念和执行概率各自对全部规则求和为1。
每条粒子路径中，规则在场时保留它的精度，未在场时该值记为零；再按粒子权重汇总均值和平方均值。
需要“规则在场时的平均精度”时，用第一个均值除以在场概率。每个粒子内各条规则的精度原值同时保存。
在场概率很低的规则，其条件精度解释需要结合在场概率一起阅读。

## 计算预算与停止规则

配置为 `configs/shared/model1024_individual_states.yaml`。

| 项目 | 登记工作量 |
|---|---|
| 每组真人参数的基础计算 | 512粒子，16次独立过滤 |
| 每组真人参数的精度检查 | 1024粒子，8次独立过滤 |
| 有限追加 | 未通过数值检查的组，各追加16次1024粒子过滤，最多一轮 |
| 模拟状态恢复 | 六人各取第一组列示候选最前两条已有模拟路径（数组索引0、1），共12条；每条512粒子、8次过滤 |
| 精确复现 | S110、S205、S317各复现一个已有完整过滤，逐题核对选择概率 |
| 初始工作量 | 507次过滤；全部组都追加时，最多779次 |
| 并行及上限 | 至多32个独立工作进程，每进程一个数值线程；160 CPU小时、主运行6小时上限 |

每个工作进程最多3600 CPU秒。队列先为运行中的工作预留其上限，再启动新工作；单次失败保留日志并保守计入上限。
累计3次工作进程失败时停止派发新工作。时间上限到达时停止运行，已经完成的结果保留。
准备、口述审计和报告整理的耗时另列计算账本。

数值检查同时查看四个目标规则摘要：在场概率、信念质量、信念达到0.5的概率和执行概率；
并查看全部规则的信念与执行分布。后两项用总变差距离表示，两分布完全相同时为0、互不重叠时为1。
各项差异在全部试次上汇总，避免大量零概率规则稀释差异。

每个条件范围分别要求：独立过滤有效数量至少4，单次过滤最大权重不超过0.5；
把独立重复分为两组后，平均差异不超过0.025、差异的95%分位不超过0.10。
512与1024粒子的比较采用同样的差异门槛。完整历史和过滤结果各自标记是否通过。
这些是本轮计算稳定性的工作门槛，概率校准仍由模拟真值评价。
追加后仍不通过时保留数值受限标记，停止追加。
摘要另外列出整段平均状态量的差异，用于区分逐题变化与整段占比的计算敏感性；这些描述量保留原验收门槛。
最终表格还分别列出各项正确规则摘要、完整规则信念分布和执行分布的计算差异，帮助判断分歧集中在哪些状态量。

## 模拟真值检查

12条路径的索引在推断前固定，沿用原参数研究已经生成并保存的状态。使用生成时的真实参数过滤这些模拟选择，
检查状态推断本身。记录正确规则在场、信念、执行的误差，也检查完整规则信念分布和活跃精度联合量。
尤其保留“正确规则已在场但本题执行其他规则”的试次数量，说明这一难恢复状态在本轮是否得到足够观察。
该检查覆盖有限参数和固定路径，完整参数恢复及总体概率校准继续单独报告。

## 暂定口述外部验证

本次授权恢复口述对照展示；最终人工复核仍待用户完成。口述用于检验状态解释，参数和状态计算仅使用行为资料。
现有编码对整句或已解析片段产生约束，再与每条可能执行规则的当前类别局部区域比较。
对同一条口述同时给出三种质量：相容、冲突、无法判断。

相容有两个层次。结构相容要求口述中的每条判断约束都明确出现在模型局部区域的描述中；
功能相容要求该区域能推出整组口述约束。冲突指两组约束无法同时成立；其余情况标为无法判断。
例如，模型使用“头长且腿短”，可以支持“头比腿长”的功能内容；两者明确写出的判断操作仍有差别。
未说出的额外规则条件保留在模型描述中。

相容分数等于所有相容内部状态的概率质量。它评价内容兼容程度，口述句子的生成概率尚未建立。
完整编码的报告全部进入主分母，包括目录没有任何支持项的报告。片段单列；缺失、待复核及编码约束矛盾均保留原行。

沿用两种既有解释：按范围中点理解长短，以及将符合既定文本条件的长短组合解释为部位间相对关系。
两种解释均不读取模型成绩来决定如何编码。结果显示解释变化带来的影响，供人工判断真实语义。

基准一在当前选择的规则和局部区域中平均分配质量；基准二使用同一被试同一选择类别的整段平均内容分布。
基准二检验随试次变化的状态是否提供额外内容解释，属于使用完整记录的描述比较。
报告同时列出模型对照相对两种基准的变化，保留不利结果。

主要工作流依次为：

```bash
python -m src.Bayesian_state.workflows.analysis.model_1024_individual_states \
  --phase prepare --config configs/shared/model1024_individual_states.yaml --output NEW_RUN

  --phase run --output NEW_RUN
python -m src.Bayesian_state.workflows.analysis.model_1024_individual_state_summary \
  --source NEW_RUN --output NEW_SUMMARY
```

每位被试的CSV保留原文、原始场次与试次、当前解释、候选参数范围和人工修正空列；HTML支持按被试和文本检索。

颜色范围、平滑窗口、列示候选和参数范围含义均在图注说明。所有候选的数值数组保留，口述分数不会决定列示参数。
