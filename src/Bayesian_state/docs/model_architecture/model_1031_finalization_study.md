## 参数搜索与版本选择

先使用共同Sobol离散候选，并纳入此前先导在拟合前生成的全部16个预设点；旧结果的排序
不参与候选生成。将候选投影到各简化边界；随后从每个版本的领先点作局部
搜索。嵌套复杂版本同时接收其简化版本的领先候选，防止有限搜索造成虚假的简化优势。
独立粒子系统的整段似然先求均值再取对数。后段条件似然由完整段与前段的合并似然之比
计算，保留重复系统之间的权重关系。候选选择与后段评价阶段分别保存。
同一配置若在不同粒子数下复用相同种子，先在种子内部合并似然，再跨独立种子计算数值
标准误。该分组保持原序列似然分数，避免把相关的粒子数复核视为独立重复。

首要比较量为开发被试等权的后段每题负对数似然。优先保留在最好版本每题0.01工作容忍
以内、每个条件相对后悔不超过0.03且自主分布评分恶化不超过10%的简洁版本，并计入
数值不确定性。这些值是本轮工作决策阈值。版本尚不能可靠区分时，确定一个带明确限制的
工作版本，并保留有竞争力的替代配置。正式结果分别报告选择决定与科学支持程度。

正式拟合前的运行标定显示，原方案的最坏计算量超过总预算。保留原协议和六项短程标定，
登记v2计算方案：共同候选48点、局部候选16点，24粒子各2次初筛，4点以96粒子各2次
确认，2点以256粒子各4次复核，必要时增加到512粒子各4次。先导的全部16点仍在共同
候选中。两个领先结构另以1024粒子各4次检查固定参数下的后段预测，再完成结构选择。
该调整使用运行时间和日程长度；调整时尚未启动正式结构搜索，也未查看模型拟合排序。

两个精度复核对象为初步最低NLL版本与满足容忍条件的最简版本；两者相同时，另取完整版本，
若完整版本已入选则取八参数版本。最终结构在这两个预选对象中确定。数值上界使用平均差
加两倍标准误之和，保留共同随机数相关性未知时的保守余量。每个条件的平均差及自主Energy
分别通过原定保护条件。高精度复核使用相互独立的随机种子，参数保持训练前段选定的值。
结构冻结后，6名评价被试比较所选版本与完整版本；所选版本为完整版本时，以八参数版本
作为比较对象。不同粒子数差异超过每题0.01或单个重复系统占整段似然权重超过0.8时，
相应评价记录数值限制。

自主评价使用全部路径，包含32题块正确率、反应频率、改善时点和保持等指标。条件3
分开记录种正确率、科正确率及反馈得分。已知生成模型的有限恢复检查用于区分搜索不足、
机制混淆和内部状态恢复限制；新增模拟与拟合均计入同一预算。

有限恢复检查使用每条件名单中的第一名开发被试作为刺激与知觉背景，即S110、S202、S303。
所选版本与比较版本各生成2条独立路径，共12条。每种版本以64个独立Sobol点重新搜索，
前两点以256粒子各2次确认；嵌套大模型同时接收小模型的领先边界点。生成参数另用独立
随机种子评分，以诊断搜索不足。机制比较采用完整模拟记录的似然，作为有限搜索诊断；
真人后段评价沿用其独立的数据用途。边界上等价的生成配置按最简有效结构记录。
已知参数的状态恢复使用512粒子、2次独立运行，目标为当前选择之后、当前反馈之前的过滤
状态，包括内容组执行概率、内容信念、模板维度质量及条件3配对信念。区间覆盖是相关
试次上的描述性校准检查。真实潜在状态只来自模拟。
