# Model 0923：简单规则机制的条件预测对照

本对照检验：固定规则或简单随机切换在接受同样的粒子推断后，能否达到完整0923的选择预测水平。
对象为已有续跑结果中的MEG 335和exp123 307，均为条件3。
主要指标为真实选择的平均负对数似然（NLL），数值越低表示真实回答得到的预测概率越高。
正确概率曲线及规则状态用于解释分数差异。

## 机制与信息边界

| 模型 | 每条路径中的规则变化 | 待估计参数 |
|---|---|---|
| 完整0923 | 反馈驱动搜索、局部与全局提出、候选退出、支持转移和主导惯性 | 沿用已有13项参数 |
| 固定单规则 | 初始从完整目录抽取一条规则，后续始终保留 | 精度初值、精度学习率、证据保持率，共3项 |
| 随机切换单规则 | 每题以恒定概率换为另一条规则，候选数始终为1 | 上述3项，加切换概率，共4项 |

两个基线沿用152条规则的完整目录和原初始规则先验，不预先指定R42或其他目标规则。
知觉配置、条件3的三值反馈、规则与配对的分层遗忘、反馈梯度精度更新及选择概率计算沿用共享实现。
基线每条路径仅有一条规则，因此路径内规则信念与作答权重都集中在该规则上。
路径之间仍可能持有不同规则，外层粒子权重根据真实选择逐题变化。

随机切换发生在本题选择之前。切换概率不随错误、信念或失败累积量改变，新规则从当前未使用的规则中
按原始先验抽取。旧规则的配对信念通过现有逐对质量转移进入新规则；新规则的精度初始化为拟合的精度初值。
固定单规则与随机切换基线均保留反馈学习，因此本次直接考察的是复杂规则搜索机制的必要性。

各模型先产生并保存本题类别概率，再用真实选择更新粒子权重，随后完成真实反馈引起的认知更新。
粒子有效样本量低于粒子数的一半时重采样。主评价A使用该共同条件推断。
附加对照B在同一参数下沿真实选择和反馈推进，设置粒子等权并关闭重采样。
第一题用于初始化，后续全部有效试次进入选择评分。

固定单规则基线的条件预测也可以随时间变化。令第 \(i\) 条路径持有规则 \(h_i\)，
其本题类别概率为 \(p_i(c_t\mid x_t)\)，观察者在本题选择前赋予该路径的权重为
\(w_{i,t}^{-}\)。汇总预测为

\[
p(c_t\mid x_t,\mathcal H_{t-1})=\sum_i w_{i,t}^{-}p_i(c_t\mid x_t).
\]

这里 \(x_t\) 是本题刺激，\(\mathcal H_{t-1}\) 是此前真实选择与反馈构成的历史。
保存该预测后，真实选择 \(c_t^{\mathrm{obs}}\) 用于更新路径权重：

\[
w_{i,t}^{+}\propto w_{i,t}^{-}p_i(c_t^{\mathrm{obs}}\mid x_t).
\]

将这些权重归一化，使其总和为1，便得到更新后的路径分布。连续多个真实回答符合某条规则时，
持有该规则的路径会获得更高权重。重采样进一步复制高权重路径。每条路径的规则身份保持不变，
观察者对不同路径的权重可以持续变化；路径内部的精度和配对信念也继续从反馈学习。
因此，A的上升需要结合外层状态推断与路径内部反馈学习共同解释。
B仍使用真实行为历史，与自主生成的C有不同的信息条件。

## 有预算上限的基线拟合

配置文件为 [`configs/shared/model0923_simple_baselines.yaml`](../../../../configs/shared/model0923_simple_baselines.yaml)。
每个被试、每个基线采用以下固定流程：

1. 确定24个参数点。第一个使用完整模型的精度初值、精度学习率和证据保持率；随机切换初始概率固定为0.02。
   其余点通过固定种子的Sobol分散抽样从配置支持值中选择，去除重复点。
2. 使用64粒子、2个种子评价各点，按汇总预测的选择NLL排序。
3. 将最好的4点使用128粒子、4个新种子重新评分，选取NLL最低者。
4. 固定选定参数，使用128粒子、16个种子生成最终A预测。这16个种子与原完整模型一致，
   并与基线筛选和确认种子分开。不同模型的状态和随机数消费会分化，相同种子不保证逐路径配对。
5. 对选定参数运行同预算B对照，再以512粒子、4个独立种子检查A的数值敏感性。
   检查时每次滤波的粒子数增加，独立重复数减少，两种配置的粒子数乘重复数均为2048。

支持值为：精度初值0.1、0.5、1、2、5、10、25；证据保持率0、0.3、0.6、0.85、1；
精度学习率0、0.1、0.3、0.6、1；随机切换概率0.001、0.005、0.02、0.1、0.3、1。
固定单规则的切换概率为0。参数范围和预算在读取基线拟合结果之前保存。

所有分数先对独立种子的类别概率取均值，再计算NLL。另保存逐种子NLL及其标准差。
独立种子检验数值误差；各模型参数均使用完整行为序列估计，本次属于样本内机制比较。
基线采用有限参数搜索，尚未进行全空间收敛验收。完整模型使用已有拟合，其搜索预算和停止状态保持原记录。
因此本次统一的是粒子推断与最终评分预算，各模型的参数搜索投入分别报告。

## 固定规则的粒子覆盖问题

固定规则基线的每条路径不能重新发现规则，重采样会复制当前权重较高的路径并可能删除其他规则。
低粒子预算下，重要规则可能初始未被抽到，也可能过早失去全部代表路径。
为区分这一数值问题与机制表现，输出每次运行的初始、最终规则覆盖数及重采样次数。
选定参数在128与512粒子预算下的汇总NLL差超过0.02时标记为 `budget_sensitive`。
这个阈值用于描述数值敏感性，两个预算同时使用不同种子；通过阈值也不等于精确积分已得到证明。

335和307的真实后期正确率分别为82.8%和95.3%。307的各模型仍低估该阶段的正确率。
完整0923在本次主评价中的选择NLL均最低，其相对335两个基线的优势约为每题0.03，
相对307随机切换基线的优势约为每题0.025。

335的固定单规则模型提供了直接的机制对照：A的正确概率从前64个计分试次的32.9%升至后期81.3%，
后期R42的粒子汇总权重为1。其每条路径始终持有初始规则，规则身份在路径内从未改变。
因此，这条明显上升的条件预测曲线可以由外层规则路径选择与内部反馈学习共同产生。
相同参数的B后期正确概率为29.7%，每次滤波512粒子时的A后期正确概率仍为81.3%。
这一结果表明，条件预测的上升可同时出现在机制复杂度差别很大的模型中。

307随机切换基线的拟合切换概率为0.02，搜索不根据失败程度调节。
它也在后期升至76.4%，每次滤波512粒子时为78.8%。这为固定概率搜索提供了一个可比较的预测基线。
完整模型在这些已评估参数点下仍有更好的选择预测；两条上升曲线本身提供的机制区分有限。

307固定规则模型标记为数值敏感：A选择NLL从0.9402变为0.8982，后期正确概率从60.9%变为74.6%。
128粒子时每次运行初始平均覆盖86.8条规则，512粒子时覆盖147.5条；规则目录共152条。
这一变化与规则覆盖和重采样退化的影响相符，需要在进一步比较该模型时处理。
另外，335随机切换的NLL变化仅0.0033，后期正确概率仍从77.1%变为80.9%。
NLL阈值只检查所定义的总体分数，末期曲线也应结合不同数值配置单独查看。
