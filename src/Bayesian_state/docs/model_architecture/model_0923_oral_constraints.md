# Model 0923：用口述约束检验作答依据

本轮实现 `oral-partial-constraints-v1`，并完成九名开发被试的原始口述审查。
方法把每条实际出现的口述转成局部判断约束，检查模型的作答依据对整组约束的支持、冲突与未确定部分。
比较对象由这条口述确定，计算所需的状态概率由行为模型提供。行为参数继续只用选择数据估计。

当前交付包括约束评价函数、状态权重汇总函数、14 个方法实例、真实语料的目录审查，
以及九人BASE、NEW、POOL、DRAW的固定参数状态重放和完整口述评价。
目录审查表示现有规则的表达范围；状态评价进一步计算模型对整条报告的支持质量。
结果入口为 [审查报告](../../../../results/model_0923/oral_constraint_audit_20261018_v2/index.html)。
已有的完整报告生成方法见 [口述表示与模糊参照](model_0923_oral.md)。

## 1. 对齐的对象与时间

口述提供的是被试当时表达出的判断。省略、补充描述和模糊参照会影响表达内容，因此需要同时保存
原话、所选类别、试次身份、特征顺序、完整解析状态及尚未确定的内容角色。
本方法首先检验“本题作答依据包含或蕴含了哪些已报告判断”。
推断整个规则集合的保留状态，需要再结合跨类别口述和模型的时间过程。

状态取本题作答后、当前反馈前的行为条件分布。历史行为用于推断潜在状态，本题选择用于确定
各规则对该选择的贡献；当前口述只用于计算评价指标。
[Task2实验程序](../../../../exp_program/exp123/Task2_learning.m)第501行开始录音，第543行进入反馈呈现，
确认该任务采用选择后、反馈前的报告时点。本轮静态目录审查不依赖这一时点。

每条口述的多个判断作为一个合取整体评价。例如，“脖子短且尾巴长”需要同一个局部依据
同时支持这两项判断。分别支持一项的两种状态，在混合后仍然缺少对整句话的联合支持。
规则中未被口述提及的判断保留为未知：口述“脖子短”允许规则还包含“头长”。

## 2. 两种支持及三种结果

规则的一个类别可以包含多个局部区域。本轮先对每个区域分量分别评价，保留完整结果。
设分量区域为 \(R\)，口述数值约束所定义的区域为 \(O\)，特征空间为 \([0,1]^4\)。
“显式判断”指区域边界中直接列出的判断谓词，例如 \(x_{\mathrm{neck}}<0.5\)。
一对描述近似相等的相反边界按一个带状谓词处理，沿用现有编码器。

| 判定 | 显式判断支持 `structural` | 几何支持 `functional` |
|---|---|---|
| 支持 `support` | 口述中的全部谓词直接出现在分量的谓词集合中 | 分量内所有点满足口述的全部数值约束，即 \(R\subseteq O\) |
| 冲突 `conflict` | 分量与口述约束的交集没有正体积 | 同左 |
| 未确定 `undetermined` | 其余情形 | 其余情形，包括尚无数值解释的躯干参照 |

“未确定”保留了信息不足。例如，规则只规定头长，口述说脖子短；规则允许脖子短，
但也允许脖子长，因而尚不能支持这项判断。显式判断支持自动满足几何支持。
代码中的 `structural` 只识别显式几何谓词；判断执行顺序、注意顺序和实际认知操作需要额外证据。

几何包含关系通过线性规划检查：依次求每条口述不等式在规则区域内的最大违反量。
冲突检查通过求交集内部球的最大半径完成，并显式加入特征空间边界。
仅在边界相交的区域按冲突处理，采用连续特征、边界概率为零的解释，数值容差固定为 \(10^{-9}\)。
依赖离散刺激或非零边界概率的模型需要另行定义这个判定。

| 口述 | 局部规则 | 显式判断支持 | 几何支持 |
|---|---|---|---|
| 脖子短 | 脖子短且头长 | 支持 | 支持 |
| 脖子短 | 头长 | 未确定 | 未确定 |
| 脖子短 | 脖子长 | 冲突 | 冲突 |
| 头比腿长 | 头长且腿短 | 未确定 | 支持 |
| 头长且腿短 | 头比腿长 | 未确定 | 未确定 |
| 脖子短且尾巴长 | 脖子短 | 未确定 | 未确定 |
| 脖子比躯干短 | 脖子短 | 未确定 | 未确定 |

这里的“长／短”沿用现有 0.5 阈值约定，近似相等沿用 0.10 容差。
这些是编码约定，个人心理阈值尚未测定。后续比较需要共同的尺度敏感性检查。
“躯干”保留比较对象和方向，心理参照位置尚未确定。

## 3. 从局部判定到模型支持质量

状态读出先根据行为模型计算本题各局部依据的概率，再汇总这些依据的判定。
对采用规则混合的选择模型，设粒子 \(p\) 的选择前权重为 \(\alpha_p\)，该粒子中规则 \(h\)
的作答贡献为 \(u_{ph}\)，规则给实际选择 \(y\) 的概率为 \(\ell_{ph}(y)\)。
选择条件下的联合权重为：

\[
q_{ph}=\frac{\alpha_p u_{ph}\ell_{ph}(y)}
{\sum_{p',h'}\alpha_{p'}u_{p'h'}\ell_{p'h'}(y)}.
\]

分子保留同一粒子内状态与选择概率的关联，分母对所有粒子和规则归一化一次。
实现为 `choice_conditioned_weights`，输入各自归一化的粒子权重和粒子内贡献权重。
它要求这些贡献与规则类别概率确实构成该模型的选择混合；模型若含额外输出噪声或混合后的非线性变换，
需要相应的联合读出定义。规则混合权重描述作答贡献；解释为实际选中一条规则还需要相应机制假设。

若一个类别含多个分量，分量权重 \(\rho_{phm}\) 在读取口述内容前确定。本实现沿用原口述读出的
内部刺激距离规则：选择距离最小的分量，平局时均分。令 \(q_{phm}=q_{ph}\rho_{phm}\)。
对任一种支持定义，报告的支持质量为：

\[
S_t=\sum_{p,h,m}q_{phm}\,\mathbf{1}\{\text{本题报告在该分量上得到支持}\}.
\]

冲突质量 \(C_t\) 与未确定质量 \(U_t\) 使用对应的判定指示函数，同一口径下
\(S_t+C_t+U_t=1\)。`summarize_matches` 接收完整权重与分量判定，输出两种口径各三个质量。
报告内容不参与选粒子、选规则、选分量或重新归一化。缺失口述没有这组三项分数。
条件 3 保留模型内部的类别—反应配对含义，按该模型的实际选择概率计算权重。

每个方案使用原评价的八个独立滤波种子。跨种子先平均选择—依据联合质量，再除以平均实际选择概率，
随后在共同报告集合上取平均。模拟标准误通过每次删除一整个滤波种子后重新计算获得；
该误差描述滤波近似的数值波动。个体参数和被试抽样不确定性尚未计入。

支持质量回答“行为推断出的依据中，有多少概率质量支持这条口述内容”。
完整报告的生成概率还依赖为什么说出这些内容、为什么省略其他内容等表达过程。
当前方法没有定义这层过程，因此支持质量用于表征检验，不能直接作为报告对数似然。

正式模型比较应在共同试次上同时展示支持、冲突、未确定和编码覆盖率，并保留个体结果。
较多未确定质量说明当前口述与模型表征之间仍缺少可判定关系。
主指标固定后，再用具有明确表达过程的报告预测作补充检查。

## 4. 内容角色与编码边界

本轮将所有已编码内容作为待检验判断，内容角色标为未确定。
“脖子短，尾巴长”可能是两项作答依据，也可能是“主要依据加补充描述”；这两种解释需要独立标注。
方法实例另含一个预先标注“尾巴长为补充”的合成例子，只评价标注后的核心“脖子短”。
真实语料尚未进行这类核心／补充标注。

人工复核应直接阅读原话及约定的实验上下文，保留依据、刺激描述、数量关系、参照和不确定角色。
评审者对待比较模型的拟合权重保持盲态。角色含混的句子继续保留多种解释及未确定标记。
内容角色依据独立语义证据确定。当前机制比较使用冻结的原版编码，并在评价前检查约束一致性。

每题单独保存以下范围：

| `scope` | 用途 |
|---|---|
| `complete` | 所有分句被现有语法解析，编码约束一致；可进入完整内容审查 |
| `parsed_fragment` | 保留已解析的部分供诊断；完整报告仍需复核 |
| `needs_review` | 没有可共同评价的已解析约束，保留原话和未解析分句 |
| `inconsistent_constraints` | 当前编码约束存在矛盾，保留原话、原编码状态和具体原因 |
| `missing` | 缺失记录，单列分母 |

一致性检查同时检查数值区域和相反的躯干方向。
当前编码中的矛盾可能来自语境省略、转录或编码尺度；需要回到原话复核。
`complete` 表示自动解析完整，人工语义核验尚待完成。

### “一半”参照的可选符号编码

2026-10-18增加可选设置`symbolic_half_reference: true`，默认值为`false`。
它完整解析“脖子和头均短于一半”等分句，保存部位、比较方向、分数1/2和原话，
将参照对象与数值阈值标为未知。`half_unknown:0:lt`表示第0个特征短于未明确参照的一半；
编号按本题特征顺序确定。`一半`、`1/2`和`二分之一`使用相同表示。
同一报告中的此类省略参照暂按同一参照处理；同一部位同时长于和短于该参照时，标为约束不一致。
带明确参照、否定或近似表达的其他句式继续保留待复核。

在参照尚未明确的符号版本中，这些符号记录完整的报告内容，数值几何解释保持未知。
完整内容支持因此保留为未确定。同句中已明确的数值判断若与规则冲突，仍记录该冲突。
完整解析率和可进行数值检验的比例须分别解释。

补充审查位于`results/model_0923/oral_symbolic_half_audit_20261018_v1`：
九人5,376题中，308的157题新增完整符号编码，完整解析总数由3,707变为3,864；
其第643—800题的158份报告中，157份得到完整符号编码，1份仍待复核。
该符号版本的新增157题均没有确定的完整内容目录支持。
此前机制比较使用`oral_constraint_audit_20261018_v2`，结果保留原编码定义。
补充编码版本为`0923-oral-structure-v1+symbolic-half-v1`，配置、17个方法实例及源码哈希见其manifest。

### 经确认的长度范围中点参照

2026-10-18，用户明确“一半”指长度范围的中点。新增设置`half_reference: range_midpoint`，
据此将“部位短于一半”编码为该特征小于0.5，将“部位长于一半”编码为大于0.5。
实验中的物理长度满足\(L=0.25+x\)，范围为[0.25,1.25]，其中点0.75对应归一化特征\(x=0.5\)。
这一参照来自语义确认；模型拟合、行为成绩及口述得分均未参与阈值选择。

编码保存原话、部位、方向、分数1/2、参照名称及归一化阈值，数值约束采用已有的平面表示和容差。
特征位置按每题的特征顺序确定。“一半”“1/2”“二分之一”使用相同规则。
完整合取照常参与支持、冲突与未确定评价；相反的中点判断和普通长短判断共同接受约束一致性检查。
带其他明确参照、否定或近似表达的句式继续保留待复核。

数值参照模式与`symbolic_half_reference: true`互斥。省略两项设置时，解析结果沿用原默认版本。
新配置为`configs/shared/model0923_oral_midpoint_audit.yaml`，编码版本为
`0923-oral-structure-v1+range-midpoint-half-v1`。九人均按相同新编码审查，
各模型使用已保存的行为状态重新评分；既有状态、参数与旧版结果保留。
重算需同时保留原可评分报告与新增完整报告的结果，以区分表征变化和评价范围变化。

488/576。解析覆盖随学习阶段变化，因此正式评价须同时显示覆盖情况，避免把可计分样本的变化
解释为表征对齐改善。64 题是本轮的描述性统计窗口，未进入模型学习机制。

从原话可以确定三项后续优先级：

1. **检验可表达规则是否在正确时刻成为作答依据。** 207 和 308 的最后 64 题均有目录支持。
   207 持续报告“脖子短时描述尾巴、脖子长时描述头”的四种组合；308 报告相反的分支安排。
   这些内容可用于比较行为推断出的局部依据及其转换时间，具体心理执行顺序仍需另行检验。
2. **厘清参照。** 108 最后 64 题全部是脖子与躯干比较，其中短 34 题、长 30 题。
   当前 0/64 的目录支持来自保留符号参照的评价定义；该结果尚不能归因为 H 模块失效。
3. **复核多项描述的内容角色与清晰表达的漏解析。** 例如 107 的完整内容支持很低，
   原话常包含多个部位；208 后期也混有“四个部位都长”等描述。需先核对这些内容是否都在陈述规则。
   待复核语料还包括“脖子比头长很多”82 题、“头和腿最长”48 题、“脖子没有尾巴长”43 题，
   以及“一半”参照等重复形式。语法扩展应逐类核实完整含义，再以独立实例验证。

这些被试已参与机制或评价方法开发。本轮提供方法调试与设计线索；冻结后的独立验证仍需保留样本。
