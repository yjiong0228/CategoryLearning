# Model 0923：口述表示与模糊参照

本文件对应 `0923-oral-structure-v1` 与 `R1_report_structure_and_kernel`。
这一步建立可审查的口述表示与候选概率矩阵，不选择学习机制、不估计被试参数。
主规范见 [model_0923.md](model_0923.md)。

## 1. 保留什么，暂不推断什么

每题保留原话、所选类别、试次身份和特征顺序。口述编码只读取原话与特征顺序；
不读取正确类别、反馈、拟合轨迹或 rapid/gradual/abrupt 标签。

仅完整匹配明确语法的分句进入候选代码：普通长短、成对比较、近似相等、最大/最小，
以及带明确方向的躯干比较。几何约束复用 `src/oral_coding.py::RegionEncoder`。
原解析器对其余文本给出的建议也保存，但不自动成为确定代码。
一句话有未解析分句，就将整句话标为 `needs_review`；保留已解析部分供复核，
不只给容易匹配的部分计分。

普通“长/短”暂沿用 0.5 编码约定，近似相等暂沿用 0.10 容差。
“很长”和“长”在当前代码层粗化为同一方向，并保存 `intensity_coarsened` 标记。
这些约定不是已测得的被试判断标准，后续需要敏感性检查。
同义句与分句换序可有相同代码；原话仍保留。矛盾的数值约束不作为有效报告。

## 2. 躯干的三个层面

| 层面 | 当前处理 |
|---|---|
| 物理长度 | 用户确认对应 0.75，保存为事实元数据 |
| 心理参照 | 具体位置未知，可能有偏移，不逐题赋值 |
| 口头表达 | 保存比较对象与方向，允许用“躯干”近似描述内部标准 |

例如，在 feature1=脖子、feature3=尾巴时：

- “躯干短于脖子” → `body:0:gt`；下标从 0 开始。
- “躯干长于尾巴” → `body:2:lt`。
- “躯干短于脖子、长于尾巴” → 同时保留上述两项。

这些代码不带一个硬性的心理阈值。旧解析器会把一些“躯干长于脖子”读成
“脖子长于躯干”；新编码修正主客体方向，仅写入新的审查结果。
旧 `oral_center`、`oral_A`、`oral_b` 和数据文件均保持原样。

个人参照偏移 $b_s=0.75+d_s$ 目前只作为未来可检验扩展。
先共用口述层的模糊性；如果反复报告支持稳定的个人差异，才检验个人偏移。
事后访谈不用于替每个历史试次指定精确分界。行为规则阈值是否需要改变，
必须另由真实选择提供证据，不能从口述参数直接推定。

## 3. 候选报告概率怎样生成

报告词表来自既有规则目录，与当前数据中出现了哪些句子无关。
每个类别的几何分量分解为关系项；近似相等的两侧边界合为一个关系项。
暂等概率选择该类别的一个分量，然后每项以 $q$ 被说出、以 $1-q$ 被省略。

对于单特征边界 $x_i\lessgtr a$，设用“躯干”命名该边界的概率为：

\[
v(a)=\rho\exp\left[-\frac12\left(\frac{a-\mu_B}{s_B}\right)^2\right].
\]

- $\mu_B$：共用参照中心；演示暂取物理参照 0.75，不表示已测得心理参照。
- $s_B$：共用表达宽容度；越宽，离参照较远的边界也越可能被叫作“躯干”。
- $\rho$：接近参照时使用这个名称的倾向。

因此，单个关系项有三种生成事件：

| 事件 | 概率 |
|---|---:|
| 省略 | $1-q$ |
| 普通关系表达 | $q[1-v(a)]$ |
| 躯干表达，保持原方向 | $qv(a)$ |

三者之和为 1。没有通过观察本题口述后再沿规则方向归一化。
这只是可检验的命名函数；它不是知觉噪声的估计，也没有建立共享潜在参照值的逐题动态。
多项表达目前条件独立，多个类别分量等权，暂不根据刺激选择描述分量。

另以 $\eta$ 生成粗粒度 `OTHER`，其余事件共同乘以 $1-\eta$。
`OTHER` 表示可解释但词表外的内容汇总，不能预测其中具体哪种新规则。
`EMPTY` 是所有关系均省略的生成事件。缺失记录、无法解析、转录可疑内容与
事后认知不确定性都不能自动映射到这两个事件。

实现生成 $R[h,y,o]$，再交给 `predict_choice_oral` 计算：

\[
P(y,o)=\sum_h\pi(h)p_h(y\mid x)R(o\mid h,y).
\]

未来 PF 接入时，须在同一粒子内计算联合概率，再按选择前粒子权重平均。
当前新工作流只生成矩阵和审查结果，不更新 PF 权重、不读取本题反馈。
演示中的 $q=0.8,\eta=0.02,\rho=0.5,s_B\in\{0.05,0.10,0.20\}$ 均未校准，
不因矩阵归一化就声称拟合有效。正式估计前需要冻结或在开发数据上校准这些观测参数。

## 4. 覆盖结果的含义

`full_component`：描述等于某个所选类别分量；不等于完整分类规则。
`omission`：描述是分量关系项的真子集，可由多条规则产生。
`fuzzy_reference`：使用了躯干词项，语法允许但概率依赖未校准的参照参数。

`other_label_only`：相同描述仅在其他类别标签下生成。
这揭示固定标签目录的限制，但也可能涉及报告/作答不一致；不能逐题重标以提高拟合。
若加入标签学习，需要与原模型使用共同表示的对照另行版本化。

`outside_report_grammar`：当前省略语法无法生成这组完整关系。它不证明认知规则
一定在目录之外。例如，用户可能补充刺激特征，也可能说了冗余比较关系。
结构与功能等价仍需单独判断，不能把语法不匹配当作心理差异。

`needs_review`：完整语义尚未确定，包括数量计数、组合表达没有明确参照、
矛盾或转录可疑句子。它不是口述“无效”或被试“没有规则”的结论。

S122 的“头、脖子、尾巴之和比四条腿之和长”保留系数 1、1、1 与 4。
若物理长度与归一化特征满足 $L_i=a+b x_i$，不等量求和中的偏置 $a$ 不会抵消；
只有躯干对应 0.75 这一条信息，尚不足以求出这个变换。此处不擅自猜测或改写数据。

这是值得检查的表示限制，暂不通过增加执行惯性或精度学习来弥补。
