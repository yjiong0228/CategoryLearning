## 2. 机制职责与精简顺序

当前1031在经验搜索中已停用旧模型的结构距离、功能距离及提议温度。
容量、搜索控制、信念保持、判断精度与执行维持由样例、概括和规则共享。
因此，后续精简会同时改变三种内容的学习过程。

| 机制 | 独立职责 | 建议与主要检验 |
|---|---|---|
| 具体模板、相似范围σ | 保存经历并推广到相似刺激 | 保留；检验相似刺激上的预测与检索 |
| 逐次删去一个维度 | 从具体经历提出局部概括 | 保留；检查错误概括与反例作用 |
| 目录规则及经验引导的提议 | 表达类别边界和关系判断 | 保留；核查具体错误规则及标签覆盖 |
| 有限容量K、替换最低信念内容 | 限制同时保留的内容 | 保留；K属于待估计或共同固定的结构选择 |
| 共同反馈似然与内容信念 | 让各种表示接受同一证据评价 | 保留；各条件使用各自反馈事件定义 |
| 证据保持δ | 控制历史信任在新证据中的作用 | 首轮保留；恒定保持及δ=1另作比较 |
| 额外执行维持κ | 让上一题执行内容获得额外优势 | 首先比较κ=0；现有恢复证据较弱 |
| 逐内容精度学习α | 随反馈调整每项内容的判断陡峭程度 | 比较α=0、共享固定β；保留有限精度 |
| 失败增益η及保持ρ | 让连续失败提高搜索机会 | 首轮保留；随后比较η=0的恒定搜索 |
| 规则提议比例g_rule | 控制从概括进入目录的机会 | 首轮保留；它直接影响经验阶段时长 |
| 满容量时的反馈依赖入场信念 | 决定新内容立即获得多少信任 | 首轮保留；与遗忘、搜索控制分开消融 |

κ=0时，内容仍会因信念集中而连续执行。取消κ检验的是超出信念的额外维持。
现有1024受控比较只有局部预测收益，机制恢复仍弱；这给出比较优先级，1031中的去留
仍需重新评价。固定β使每项内容保持相同的判断精度，信念、类别不确定性与相似度仍随
学习状态发挥作用。σ、β、类别信念和内容权重可能相互补偿，应检查其可辨识性。

建议先比较以下四个版本，以分开两个精简操作及其交互作用：

| 版本 | κ | 精度学习α | 个体候选参数数目 |
|---|---|---|---:|
| 原1031 | 自由 | 自由 | 10 |
| 取消额外维持 | 0 | 自由 | 9 |
| 固定共享精度 | 自由 | 0 | 9 |
| 首选精简候选 | 0 | 0 | 8 |

这里按现有先导的十个坐标计数，知觉设置沿用相同配置。八个保留坐标是
K、σ、β、p₀、η、ρ、g_rule、δ，其中p₀是基础搜索概率，其余符号的职责见上表。
学习率为零时，原实现的共同β初值及新内容精度继承

有效坐标。固定常数、候选生成策略和状态数量也属于模型复杂度，随参数数目一起报告。

## 3. 样例学习需要先通过的功能检查

当前抽取执行内容的概率由信念和维持决定。刺激与模板的相似度在抽取后影响类别概率。
这会使局部有用的样例受到其他内容的影响。例如，二分类中两个模板各占一半信念：
第一个与当前刺激完全匹配并确定支持A，第二个距离很远、给出均匀预测。在理想匹配极限下，
对执行身份求和得到A的概率为0.5×1+0.5×0.5=0.75。

这个计算说明全局信念抽取与按当前刺激检索具有不同预测。它尚未证明实际先导的问题由
检索导致。精简研究应先用两个分离的样例检验局部知识能否被调用，并比较已保存路径上的
匹配程度、被执行概率及竞争规则；全部候选及失败路径保留。

如该限制确实损害行为预测，可独立比较按相似度调节模板检索的版本。其需要明确规定
规则的适用程度、所有模板都远时的回退、以及内容信任是否仍接受全体试次反馈。
这属于新的选择机制；即使沿用σ、没有增加自由参数，也要单独检验。当前八参数候选
保留原抽取方式，从而能够定位取消κ和精度学习各自的作用。

## 4. 统一概率接口与贝叶斯解释

每项内容h接收刺激x并输出类别概率p_h(c|x)。π_h表示内容可信权重，总和为1。
κ=0时，单题先按π抽取内容再按其概率作答，对执行身份求和可得

\[
P(a\mid x,S)=\sum_h\pi_h p_h(a\mid x).
\]

S是本题选择前的工作区状态，a是实际反应。这一求和可用于计算选择似然，自主生成仍可
抽取具体内容。在当前1031中，给定已发生的选择与反馈，κ=0使上题执行身份不再影响未来
的认知更新。因此在保持其余随机过程及条件分布一致时，可逐题消去执行身份而保持完整
行为分布。现行代码仍实际抽取执行内容；工程上的解析求和尚待接入。

若报告选择后、反馈前的执行内容，其概率还需按本次选择更新：
P(h|a,x,S)正比于π_h p_h(a|x)。该条件分布用于解释或未来口述预测，π是学习者的内容
信念，两者的含义和时点分别标注。

同一次反馈定义所有内容的似然，即“在该内容给出的预测下，这个反馈事件出现的概率”。
条件1、2选a得到对的似然为p_h(a)，得到错的似然为其余类别概率之和。内容信念按
有效旧权重乘似然再归一化更新。

当前幂保持、候选出生、最低信念替换和依反馈分配入场信念，均属于认知过程假设。
特别是当前δ_t=δ+(1−δ)r依赖已观察反馈，属于反馈调节的学习规则。完整模型可定义为
有明确状态转移与选择分布的生成模型；其认知权重更新具有贝叶斯式结构。
“整个静态假设空间的精确贝叶斯后验”需要另外成立的先验和转移假设。
后续可比较恒定δ，以及δ=1下的普通似然累乘，检验更简洁更新是否足够。

## 5. 条件3的任务知识与反馈事件

条件3有四个选项，两科、每科两种。被试知道这种层级结构，具体哪些选项同科需要学习。
`category`用于环境评分；`choice`用于反应概率；`presskey`用于保存按键编码关系。
现有choice坐标可以继续使用，但认知计算将其视为四个无语义的选项编号。
真实的{1,2}|{3,4}仅由实验环境及评价使用。

令g表示一种可能的同科配对，取值为12|34、13|24、14|23，初始各为1/3。
s_g(a)表示在配对g下，与所选a同科的另一个选项。给定内容h和配对g，它对潜在正确
选项c给出概率p_hg(c|x)。三种反馈的似然为：

| 反馈r | 在配对g下包含的正确选项 | L_hg(r) |
|---|---|---|
| 1 | 所选a | p_hg(a|x) |
| 0.5 | 同科的另一项s_g(a) | p_hg(s_g(a)|x) |
| 0 | 另一科的两项 | 两项概率之和 |

每种配对下，这三个事件互斥且合计概率为1。半对提供的是关于科与种的约束信息。
它的似然由该事件所覆盖的类别概率计算。二值反馈可用同样的事件求和接口，条件差异
集中在事件定义和配对状态中。

当配对均匀且p_hg与g无关时，半对似然为(1−p_h(a))/3，全错为其两倍；二者给出的
相对内容证据相同。配对逐渐被学习后，两种反馈可以提供不同证据。
这一等价性有明确条件；新模板的类别与配对相关时，即使配对边缘仍均匀，等价性也可能消失。

## 6. 条件3的样例必须保存类别与配对的关联

假设第一只动物选择A得到半对。三种可能分别是：AB同科且动物属于B，AC同科且动物属于C，
AD同科且动物属于D。每一种组合都能解释反馈。只记录“B、C、D各1/3”会丢掉它们与配对
的对应关系。

这种信息损失能被直接检验：再次看到同一动物并选择A，在理想记忆下应能预测半对。
完整联合关系给出概率1；将类别与配对拆为独立的两个均匀边缘，会给出1/3。
因此，推荐在每个模板内保存每种配对下的类别分布θ_hg(z)，z是该模板关联的类别；
另保存内容权重π_h和条件配对信念q_h(g)。存储规模为每个模板3×4个类别概率，以及
每项内容3个配对概率。它们都是随经历更新的状态，任务层面新增的个体自由参数为零。

规则的类别概率沿用已有几何。模板的概率沿用1031相似度与精度，仅将θ改为条件分布：

\[
p_{hg}(c\mid x)=\frac{1-b_h(x)}4+b_h(x)\theta_{hg}(c),
\qquad b_h(x)=a_h(x)s(\beta_h).
\]

a_h是保留维度上的相似度，s是现行精度增益函数，b_h是两者乘积。
远处的刺激趋于均匀预测；近处的刺激体现该配对下的类别信念。选择概率对h和g共同求和。

下面说明一次反馈如何同时更新三类信念。令T_g(r|a,c)在该类别产生观察到的反馈时为1，
其余为0。模板假定其记忆类别为z时，反馈的概率为

\[
D_{hgz}=\sum_c T_g(r\mid a,c)
  \left[\frac{1-b_h(x)}4+b_h(x)\mathbf1(c=z)\right],
\qquad L_{hg}=\sum_z\theta_{hg}(z)D_{hgz}.
\]

用有效旧内容权重和配对分布分别记作π̃、q̃。先对内容与配对的联合权重更新，
分母对所有活跃内容j及配对k求和，以使联合权重总和为1：

\[
J^+_{hg}=\frac{\tilde\pi_h\tilde q_h(g)L_{hg}}
 {\sum_{j,k}\tilde\pi_j\tilde q_j(k)L_{jk}},
\qquad
\pi_h^+=\sum_gJ^+_{hg},\qquad q_h^+(g)=J^+_{hg}/\pi_h^+.
\]

模板类别则更新其条件分布：

\[
\theta_{hg}^+(z)=\frac{\theta_{hg}(z)D_{hgz}}{L_{hg}}.
\]

这些式子是同一个联合更新的边缘与条件形式，反馈似然在联合概率中仅乘一次。
规则直接使用反馈表计算L_hg。零后验质量的条件分布采用预先规定的回退值，零质量分支
对当前预测不贡献概率。有限β保证普通模板和目录规则的反馈概率为正；数值实现仍须
处理下溢并验证归一化。

保持机制应分别作用于内容边缘和条件配对：π̃由π的幂归一化，q̃在每项内容内分别幂归一化。
直接对πq展平后幂化，会因配对分散程度不同而改变内容的相对权重；现有0923的分层保持
已采用分别归一化。模板θ首版沿用1031的条件反馈更新，额外遗忘留待单独检验。

## 7. 条件3的出生、搜索和时序

首个反馈后保存具体经历。新样例的q继承工作区已经学得的配对边缘；在每一种g内，θ对
该反馈允许的类别均匀分配。正确保留所选类别，半对保留其同科另一种，全错保留另一科
的两个类别。各配对下的允许集合大小相同，这一步保持已继承的q。
来源反馈用于初始化，新增内容从后续真实反馈开始接受可信度评价。

删维概括继承父模板的q和完整条件θ；规则候选继承父概括的q，使用自己的类别边界。
首版规则提议可用父模板的类别边缘Σ_g q_h(g)θ_hg作为现有一致性评分的输入，
提议评分与反馈证据分别记录。内容替换时，幸存内容保留其条件状态，新内容按来源继承。
重复候选比较需检查完整条件类别内容，单个四维边缘不足以判断心理信息是否相同。

推荐条件3首版以u=1[r=1]控制“是否完全成功”：搜索累积在半对与全错时各增加一次，
正确时按ρ衰减；内容保持率取δ+(1−δ)u，配对保持率沿用基础δ；满容量入场信念中的
反馈标量同样采用u。原始r始终完整进入反馈核。
这使二值条件保持原定义，并避免在配对尚未知时，由线性半分插值额外引入不同的控制强度。
原1024辅助函数支持半分插值，本建议对条件3属于明确的行为假设变更，需要与插值版本比较。
按科保留、按种修改的定向搜索作为另一机制候选，先检验上述联合学习能解释的范围。

每题顺序为：按已完成历史提出内容，形成选择前分布，产生或观察选择，取得反馈，
从同一份旧状态计算似然，更新联合信念和模板类别，保存供下一题使用的经历。
固定精度候选省去逐项梯度更新；若恢复精度学习，梯度必须对同一L_hg及其反馈前配对
混合求导，并使用更新前θ。保存刚更新的q或θ后再计算同题似然会重复使用证据。

学习者的联合信念位于每个粒子内部。研究者的粒子权重继续由真实选择概率更新，反馈
推进认知状态。现有条件选择似然目标保持原定义。自主模拟的环境用真实类别和科结构
产生反馈，认知模块接收模拟反应及反馈。
