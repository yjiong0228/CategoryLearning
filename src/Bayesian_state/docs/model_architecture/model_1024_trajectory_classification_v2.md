# Model 1024：六类轨迹描述与图表修订

2026-10-27。用户要求先按讨论方案重新分类和绘图，分类标准的模拟检验暂缓。
本版本复用六条完整真人记录及11776条已保存的自主路径。分类用于描述图表，
原个体参数的选择似然、形态距离、相容性判断、保留集合和最近路径身份均保持原定义。

## 分类内容

主类别为未检出明确变化、突变式改善、渐进式改善、下降、多阶段变化、形态未定。
波动、末段正确率和改善后观察长度分别报告。观察不足保留为附加信息。
分类名称中不包含保持状态。原九类记录保留在数值研究文件中。

每条逐题正确性记录使用0/1结果拟合五种描述。每题贡献伯努利负对数似然，
即模型赋给实际答对或答错结果的概率越小，损失越大。各描述使用相同完整记录：

| 描述 | 自由量个数 | 计算方法 |
|---|---:|---|
| 恒定水平 | 1 | 整段正确率 |
| 单次阶跃 | 3 | 一个分界、两个正确率；每段至少32题 |
| 连续斜坡 | 4 | 前后水平及斜坡开始、结束位置 |
| 三段水平 | 5 | 两个分界、三个正确率；每段至少32题 |
| 四段水平 | 7 | 三个分界、四个正确率；每段至少32题 |

斜坡前后为水平段，斜坡内部的概率线性变化。位置全部限制在实际记录范围，
允许斜坡从首题开始或到末题结束。斜坡最短跨度为一个题间隔。
连续参数采用七个以内的确定性起点和SLSQP约束优化，单起点最多200次迭代。
概率限制为0.000001至0.999999以保持数值有限。起点规则、最佳解及收敛起点数量随结果保存。

阶跃和多阶段描述逐题搜索分界，动态规划给出各段数的最小损失。
先求无幅度约束下的最佳分割，再要求每个相邻水平至少相差15个百分点。
未通过该筛选的段数退出本次类别比较；当前实现不继续搜索该段数下其他满足幅度约束的分割。
这项计算约定保存在本记录中，后续分类检验需覆盖其影响。

BIC用于比较描述的损失和复杂度，定义为

`BIC = 2 × 负对数似然 + 自由量个数 × log(有效题数)`。

分数越小越好。边界参数仍按上表计数。当前BIC是描述性工作分数；
学习的历史依赖和分界位置搜索尚未通过专门模拟确定分类错误率。

## 判定顺序

1. 对幅度达标的变化描述按BIC排序。阶跃或斜坡的负向变化归入下降；
   三段和四段均归入多阶段变化。每类保留自己的最低分。
2. 最佳变化描述相对恒定水平的BIC改善不足6时，标为未检出明确变化。
   该标签表示本轮检测条件未满足，完整记录的水平和波动仍报告。
3. 明确变化的最佳类别与次佳类别差距不足6时，标为形态未定；
   保存候选类别及分数。达到门槛时确定主类别。
4. 最佳拟合未收敛，或未收敛的斜坡可能改变判断时，保留数值原因的形态未定。

每种描述的损失、分数、幅度筛选、水平、分界及收敛情况都保存。
因形态竞争而未定的路径仍保存最佳候选描述，用于显示趋势和候选变化中心。

## 附加指标和图表

末64题正确率直接由实际记录计算。波动继续报告16、32、64题块相邻正确率差的均方根。
趋势残差使用本版选出的最佳描述，按32题块计算标准化偏离程度。
多阶段趋势会吸收长期起伏，因此新残差与原单次S形曲线的残差分开报告。

阶跃的改善后观察从分界题开始；斜坡从其结束位置之后的首个整数试次开始。
记录完整的后续题数，以及其中最多64题的正确率。没有后续题时正确率为空值。
恒定或多阶段描述没有统一的单次改善终点，相关字段为空。

六张个体图继续使用四行三列布局。左列灰色保留所有路径，真人为黑色实线，
均值为蓝色虚线，原登记距离下最近的完整模拟为橙色实线。
中列使用六类比例；橙色柱及类别文字对应真人，空心菱形对应橙线的类别。
全部路径进入分母，形态未定表示分类不确定性。同类比例只描述类别一致性。
Wilson区间衡量有限模拟计数误差，未包含分类标准误差。

右列显示最佳描述为单次变化的路径中心：阶跃位置或斜坡中点。
多阶段和恒定描述不提供单一中心；形态未定的候选中心仍属描述信息。
右图不再显示原九类中的观察截断名称。绝对时点继续不参与最近路径的选择。

## 使用方式与数据边界

从仓库根目录运行，输出目录必须不存在：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 NUMEXPR_NUM_THREADS=1 \
python -m src.Bayesian_state.workflows.analysis.model_1024_reclassify_paths \
  --study EXISTING_STUDY --output NEW_CLASSIFICATION --workers 16

python -m src.Bayesian_state.workflows.reports.model_1024_individual_regions_report \
  --study EXISTING_STUDY --output NEW_REPORT --classification NEW_CLASSIFICATION
```

阈值与起点位于 `configs/shared/model1024_trajectory_classification.yaml`。
分类器位于 `metrics/trajectory_classification.py`，独立于原评分模块。
运行保存配置、源码、输入哈希、全部逐条结果、计算耗时和优化警告。
图表输出另存 `classification_paths.csv`、`classification_summaries.json` 和
`classification_manifest.json`；原 `candidate_scores.csv`、`path_shapes.csv`、
`shape_summaries.json`、`nearest_paths.json`、`retained_regions.json` 保留旧定义。

本次输出为研究目录下 `particle_precision_v2/classification_v2`，当前报告原位替换，
生成路径和原评分记录保留。实际拟合得到六人的暂定标签为：110突变式改善，
129形态未定，205形态未定，229、306、317多阶段变化。
205的多阶段与渐进分数差约3.06；129的突变与渐进分数差约5.93，均不足6。
317的最佳三段水平约为45.6%、23.4%、84.3%，分界为从0计数的362和807。
这些是同一规则的直接输出，分类标准的可靠性尚未检验。

软件检查比较分段优化与穷举结果，并核对斜坡梯度、全部路径身份、计数与图表。
用户暂缓的检验包括已知形态模拟的正确率、错分率、时间平移与截断稳定性。
软件计算完成和分类科学有效性分别报告。
