# Model 0923：关闭自主退出的结构对照

后续的连续证据保留、联合集合选择、15人扩展筛查及新增6人验证，见
[H模块连续研究](model_0923_h_design_study.md)。本页保留R0对照的原始分析。

**关闭自主退出能明显改善206和307；R1仍保留额外收益。**
本轮结果支持重新组织H模块中的规则保留、清除和容量替换。R1的4题窗口继续作为待验证假设。

[完整报告与9张路径／比较图](../../../../results/model_0923/no_autonomous_exit_20261014_v1/review.html)
包含7人、4版本、每组64条路径，共1792条。
其中新运行448条R0路径，复用[第一轮干预](model_0923_mechanism_interventions.md)中经校验的1344条路径。

## 1. 对照改变了什么

R0沿用full-v3，将自主退出率参数`exit_rate`设为0。
它保留失败状态更新、是否搜索的判断、局部／全局提案、容量替换和最终信念分配。
本轮沿用原拟合参数，退出率的设零是明确施加的实验干预；没有重新拟合。

R0每题仍经过原退出抽样代码，退出事件概率为0。保留这部分随机数消耗，使其他步骤的随机流定义保持一致。
集合未满时可以加入新规则；集合满时，原规则仍可能因新规则进入而被容量替换。
因此，R0允许候选集合更新，并使自主退出与容量替换的作用可以分开检查。

比较包含B、R_control、R1和R0：

| 版本 | 自主退出 | 容量替换 |
|---|---|---|
| B | 原概率`exit_rate × (1 − posterior)` | 原full-v3规则 |
| R_control | 原退出率乘0.25 | 原full-v3规则 |
| R1 | 最近至多4次在场反馈的净证据为负时，按原概率退出 | 原full-v3规则 |
| R0 | 概率为0 | 原full-v3规则 |

这项结构对照在原模型允许的参数边界上实现。共享认知算法保持原实现。
R0是运行配置中的实验名称，核心模块配置仍为`intervention: {kind: B}`，另以参数覆盖指定退出率为0。

## 2. 后期表现

下表为最后64题的平均正确概率；实际列为相同题段的被试正确率。

| 被试 | B | R_control | R0 | R1 | 实际 |
|---|---:|---:|---:|---:|---:|
| 104 | 0.810 | 0.810 | 0.810 | 0.810 | 0.875 |
| 215 | 0.366 | 0.386 | 0.420 | 0.418 | 0.969 |
| 206 | 0.332 | 0.369 | 0.612 | 0.775 | 0.906 |
| 307 | 0.424 | 0.431 | 0.678 | 0.758 | 0.953 |
| 222 | 0.471 | 0.471 | 0.471 | 0.471 | 0.891 |
| 334 | 0.407 | 0.518 | 0.540 | 0.583 | 0.906 |
| 335 | 0.320 | 0.334 | 0.340 | 0.379 | 0.828 |

206的R0较B增加0.280，307增加0.254。对应的整条路径配对差值Monte Carlo标准误为0.031和0.024。
R1较R0分别增加0.163和0.080，标准误为0.034和0.021；两人在4组各16条路径中的差值方向均一致。
这些标准误表示固定参数下有限模拟的波动；当前结果来自开发被试和完整序列拟合参数。

215的R0与R1后期表现接近，差值相对于路径波动很小。334的R0改善较明显，R1较R0的额外收益仍有数值不确定性。
335在R0下仍少有路径发现相容规则。104和222原退出率为0，R0的全部128条路径与已保存基线逐项精确一致。

## 3. R0改善了什么，又留下什么问题

### 3.1 206：自主丢失减少，容量替换成为主要丢失途径

任务相容规则的后期存在率从B的2.3%升至R0的47.4%，R1进一步达到86.0%。
相容规则持续至少8题的比例分别为6.5%、21.9%、67.4%，有足够观察长度的驻留分别为185、146、86段。
这些分母随生成过程变化。

64条路径合计，R0的相容规则自主退出为0，容量移除为115次；R1相应为12次和19次。
关闭自主退出使原有规则更容易填满容量，后续搜索仍会引起容量替换。
这表明两种移除途径需要联合分析：去掉一条途径后，另一条途径可以继续打断有效规则的学习。

同时，R1每条路径平均发生320.8次各类规则的自主退出，R_control为263.4次；
按所有旧规则的下一题转换机会计算，对应事件比例为9.66%和7.46%。
R1总体上仍有较多退出，但相容规则保留更好。该结果进一步支持检查退出对象及其证据条件。

### 3.2 307：容量占用和作答干扰都需要检查

R0平均同时保留5.80条规则，R1为2.92条。后期非相容规则的平均数量分别为5.26和1.79条，
这些规则合计分配到的作答贡献分别为43.5%和24.2%。
本轮把几何分类准确率低于0.8的规则记为非相容；它们对部分刺激仍可能给出正确答案。
数量描述容量占用，贡献描述这些规则实际影响回答的程度，两者分别解释。

以最近4次反馈计算净反证，首次出现净反证后64题内清除非相容规则的比例，R0为69.6%，R1为88.7%。
R0保留了一些有益规则，同时也让更多非相容规则持续占据集合并参与作答。
R1在当前参数点上取得了更好的保留与清除组合。

### 3.3 诊断结论对评分窗口的敏感性

本轮另用1、4、8题窗口对完全相同的轨迹重建反证；这只改变事后评分，R0的认知机制没有窗口。
64题内清除比例为：

| 被试与版本 | 1题证据窗口 | 4题证据窗口 | 8题证据窗口 |
|---|---:|---:|---:|
| 206 R0 | 97.4% | 97.2% | 97.2% |
| 206 R1 | 98.8% | 99.2% | 99.4% |
| 307 R0 | 69.4% | 69.6% | 69.9% |
| 307 R1 | 87.7% | 88.7% | 89.3% |

307的清除差异在这些评分窗口下方向一致。此检查支持该过程描述的稳健性；
它对R1认知机制本身的4题窗口未作验证。不同版本产生的规则、驻留及反证事件不同，比例须连同原始事件数解释。

## 4. 对H模块的设计判断

本轮显示，现有逐题自主退出在部分参数点上会打断已经能够支持学习的规则。
关闭这一过程可以恢复部分学习能力，但也会改变容量占用、后续提案来源和容量替换，产生新的限制。
因此，需要把规则是否继续参与作答、何时释放容量和新候选如何获得检验联系起来设计。

下一项机制方案应明确三个步骤：

1. 反馈更新后，分别记录规则对反馈的相容性和相对信念。前者用于检验这条规则的解释能力，后者表示集合内的相对支持。
2. 保留、准入与容量替换依据这些信息协调决策。已得到支持的规则应有持续检验的机会，持续受到反证的规则需要释放容量。
3. 新候选进入时明确初始支持和试用方式，后续反馈用于之后的保留决策。暂时不参与的规则是否保留已学精度，需要独立规定。

R0检验了关闭整个自主退出通道；匹配总体退出频率的对照仍待执行。
一种与总体退出率有关的最优中间水平仍可能解释部分差异。当前结果也未比较正式重拟合后的最优参数，
因而无法据此确立唯一的退出／保留函数。下一轮应先冻结这些结构假设，再设置有限的候选方案。

## 5. 记录、计算与复现

新增配置为`configs/shared/model0923_no_autonomous_exit.yaml`。
沿用原7人、原刺激顺序和每人64个种子，只有退出率受到R0干预。
新模拟分为224个两路径任务，最多128个工作进程，数值库每进程1线程。
包括准备和复用校验的运行阶段耗时26.3秒，新路径累计记录CPU时间1982.9秒；后者不包含进程导入与准备开销。

复用前检查机制配置、参数覆盖、反馈证据记录窗口、种子、题数、条件、原认知源码、干预源码、
参数文件、观察数据、规则目录和轨迹哈希。原记录只读引用，新输出中的校验文件注明来源及`reused`状态。
`simulation_manifest.json`和`analysis_validation.json`分别记录448条新路径及1344条复用路径。
原配置和第一轮已有输出保留。

从仓库根目录运行，指定新目录：

```bash
python -m src.Bayesian_state.workflows.analysis.model_0923_mechanism_interventions \
  --config configs/shared/model0923_no_autonomous_exit.yaml \
  --output results/model_0923/no_autonomous_exit_NEW
python -m src.Bayesian_state.evaluation.model_0923_interventions \
  --source results/model_0923/no_autonomous_exit_NEW
python -m CategoryLearning_codes.figures.fig3.model0923_mechanism_interventions \
  --source results/model_0923/no_autonomous_exit_NEW \
  --output CategoryLearning_codes/figures/outputs/fig3/model0923_no_autonomous_exit_NEW
```

`--smoke --subjects 104`使每个版本运行1条8题路径，使用1个工作进程；小规模模式会重新运行各版本。
`variant_parameter_overrides`指定各版本的参数干预，B保持原参数；R0仅允许退出率设零。
`reuse_source`与`reuse_variants`指定完整路径的来源，`comparisons`指定配对比较。
`counterevidence_windows`与`residence_horizons`分别指定事后证据窗口和观察期限。

`incompatible_residences.csv`保留每段非相容规则的进入、离开、原因及删失；
`clearance_sensitivity.csv`保存各窗口与期限组合的分子、分母和比例。
清除从本段驻留第一次净证据为负开始，要求有完整的后续转换机会；同题反馈只对应下一题及以后的移除。
容量占用和贡献另保存在逐路径及逐被试表中。9张PNG包含全部1792条路径和R0／R1差值；误差线为一个Monte Carlo标准误。

验证包括：143项相关测试通过；三类反馈条件的小规模运行通过；448条新路径的概率、反馈更新和事件校验通过；
104、222共128条零效对照与独立基线精确一致；1344条复用轨迹哈希通过；
新写的清除重建与原4题窗口、8题期限指标在28组中逐项一致。
正式重拟合、留出预测、参数恢复和总体退出频率匹配尚待执行。
