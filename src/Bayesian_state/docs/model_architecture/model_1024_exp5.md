# Model 1024：Exp5 Rule1 离散任务接入

日期：2026-10-30。阶段：行为输入与小规模计算接口验证。
运行命令、配置和产物格式见[Exp5配置说明](../../../../configs/exp5/README.md)。

## 任务与数据边界

刺激是从左到右排列的五个黑白方格，黑色记为−1，白色记为+1。32种图案组成完整设计。
第2与第4个方格同色属于类别1，异色属于类别2；实际反馈为选择正确时1、错误时0。
`choice`和类别使用同一坐标，F/J按键对应关系随被试变化。

原始行为含19人、23个会话文件、3296题。第一版行为表保留全部记录。按用户确认，515、517、518
的第二会话接着学习，模型跨边界保留全部认知状态。508在第一天第160题中断，第二会话隔日；
第一版仅将第一天纳入模型序列，第二天64题保留供跨日分析。共3232题符合本阶段分析范围。

515、518在第一会话已达到90%以上正确率，实验者因口述规则不同而追加学习。因此实际记录
长度同时反映行为表现和口述判断。本阶段固定实际长度与刺激顺序，结束时点作为实验元数据。
501–507的每块刺激频次不均衡，508起完整64题块为每种图案两次。输入审计保存逐块频次。
口述时间位于选择和信心评分之后、本题反馈之前；本阶段只使用刺激、选择和反馈。

## 规则目录与局部搜索

第一版沿用62条奇偶规则。每条规则由非空位置集合S和极性s组成，s取−1或+1。
对刺激x计算s乘以S中各位置黑白编码的乘积；结果为正时支持类别1，为负时支持类别2。
五个位置共有31个非空子集，每个子集含两种极性，因此目录有62条规则。正确规则为
S={2,4}且s=+1。规则编号保持原`DiscreteHypothesisSpace`的顺序。

该目录覆盖单位置颜色、两位置同异色及高阶奇偶判断。目录对数量、整体对称和连续同色分组
策略的完整覆盖尚待评价。规则先验沿用共享引擎的均匀先验，初始工作区随机包含一条规则。

局部搜索使用直接编辑关系：保持极性时，增添、删除或替换一个关注位置，成本为`position`；
保持位置集合时反转类别映射，成本为`polarity`。其他规则对的直接成本为无穷大。
共享搜索机制按exp(−成本)归一化可用邻居的概率；没有可用邻居时沿用功能关系回退。
两个编辑成本默认均为1，表示初版共同假设。工作区容量等个体参数仍由模型配置给定。

功能关系通过枚举全部32种图案精确计算。混淆张量的每个元素表示两条规则分别给出某一对
类别的图案比例；对相同类别求和得到分类一致率。一条规则及其反向规则一致率为0，其他
不同规则对均为0.5。局部结构编辑提供了功能一致率无法区分的位置关系。关系矩阵由所有
粒子共享为只读数组，计算过程使用均匀完整设计。

## 选择概率与精度学习

定义规则h到类别c的离散距离d(h,c)：h支持c时为0，否则为1。给定本题规则精度β，
选择概率按exp(−βd)归一化。因此支持类别的概率是1/(1+exp(−β))，另一类别为其补概率。
β越高，规则执行越稳定。五个黑白特征采用准确感知假设，保持−1/+1输入。

反馈学习使用同一组类别概率。规则赋予反馈事件的概率在所有与反馈兼容的类别上求和，
其对β的对数导数为“反馈前期望距离减去反馈条件下期望距离”。离散任务仅提供距离，
该梯度、信念更新和所有活跃规则的精度更新复用共享实现。

Model 1024沿用ADD10更新：精度增加10倍学习率乘以该梯度，并限制在[0.1,25]。
初始精度和学习率是模型参数，配置中的2与0.1为接口示例。离散距离单位为一次类别不匹配，
连续长度任务的距离单位不同，两任务的精度数值和学习率需分别校准。

## 共享机制与配置

使用`model_1024_runtime()`组合现有信念、槽位继承、结果相关保持、错误后新规则分配、
ADD10精度学习和持续执行机制。迁移保留九个参数：基础搜索概率、错误增益、失败累积衰减、
全局搜索比例、容量、信念保持、执行持续性、初始精度和精度学习率。
执行持续性设为0时使用同一生成机制的零持续性边界。

共享模块新增两个任务接口：`precision_category_distances`提供离散类别距离；
`rule_search_resources`提供目录编辑关系和精确功能关系。连续任务沿用原来的分支与数值运算。
`Exp5ParityPartition`对五维−1/+1输入做严格验证；旧离散分区保留原来的输入兼容行为。
配置校验固定感知、读出、反馈和模块顺序，避免过滤与生成采用不同模型。

## 验证范围和下一阶段

第一阶段检查32种刺激上的全部规则预测、精度梯度与独立数值差分、搜索图连通性和只读关系，
以及实际输入的身份/反馈一致性。计算检查涵盖固定种子、反馈因果时序、共享状态重放、
零持续性边界与持续执行模式，并使用连续任务和期刊保存的数值参考进行回归验证。

短序列输出保存生成真值，并用独立随机流运行已知参数下的过滤。该检查验证生成与恢复的
数据接口，样本量及粒子数用于工程检查。正式参数估计、参数恢复和状态恢复分别安排。
每题在场概率与正确规则进入时点的心理解释继续遵循[研究指南](../RESEARCH_GUIDE.md)的证据要求。
本阶段没有拟合个体参数，也没有新增口述编码或验证。
