\noindent\term{现在采用什么流程？}每个人先做一轮有覆盖的搜索，再根据问题追加计算：还在找到更好的参数，就继续找；参数的得分分不清，就把评分算准；碰到人为设置的范围边缘，就检查范围。只有这些检查均通过，才暂时停止。最后的规则信念和心理状态另行检查精度。

本文说明 Model 0826 的默认拟合入口及其解释边界。认知方程仍由 \texttt{model\_0826.tex} 定义。默认 v2 流程合并了重复数值检查，并缩小有上限的追加搜索；当前正在用每个 condition 两名新被试做完整序列验收。旧 v1 配置与旧 PDF 均保留。参数范围、恢复实验和状态解释仍需各自验证。

\section{先分清三件事：找参数、算得分、看状态}
搜索覆盖决定有没有到过较好的参数区域；评分精度决定能否分清候选的高低；状态精度决定最后画出的内部过程是否稳定。三者不能互相替代。

粒子滤波（particle filter，PF）用有限样本近似模型内不可见的随机过程。粒子数 $R$ 是一次计算保留多少条可能过程；重复数 $B$ 是用多少组独立随机种子重算。二者是计算预算，不是人的工作空间容量或学习次数。很多次低粒子运行不自动等价于一次高粒子运行。

S129 曾在低预算搜索后明显落后于历史候选，问题是搜索覆盖不足；S229 的固定参数也曾有较大评分波动，问题是数值精度。进一步搜索和增加粒子各有用途，不能一律给所有人增加相同预算。

\section{默认拟合怎样执行}
\subsection{第一步：分散起点，保留不同的较好候选}
同一条件使用一致的数据约定、参数支持和评分方式。默认从45个分散起点开始，覆盖当前九种容量/执行组合，并使记忆、搜索和精度参数也变化。发现候选用 $R32\times B4$；较好、较分散以及少量随机抽查的候选再用 $R128\times B16$ 比较。后续起点由后者决定，不能把不同预算的分数混排。

低预算筛选仍可能遗漏好参数。随机抽查和分散候选只降低这个风险，不能证明没有遗漏。默认数值是有上限的工作设置，不是对所有被试都足够的定理。新入口直接读取当前数据与引擎，不依赖旧试点目录或历史赢家。

\subsection{第二步：既单独调整，也同时改多个参数}
普通坐标下降每次只改一个参数块。假设当前分数是10，只改A得11，只改B得12，同时改A和B却得8，那么单块下降会停住，联合移动可以直接到8，不需要先接受11或12。

已有 $(M,\chi)$、$(E_C,\delta_E)$ 和 $(g_0,c_G)$ 联合块。新流程另外尝试跨块移动：局部调整、整块远跳以及同时改变两个块，并从多个较好候选继续。每轮还加入分散新点，以覆盖需要更多参数共同改变的区域。参数关系始终保持合法，例如 $E_E$ 随 $E_C,\delta_E$ 推导，不被当成另一个独立坐标。

默认每轮至多两个起点、每个48个提案，局部/整块/跨块预算比例为25\%/25\%/50\%，另提议18个分散点，重复点不重算。比例是提案配额，去重后实际数量可减少。有限联合移动不能保证全局最优。

\subsection{第三步：准备停止时，检查还有没有可靠改善}
默认最多四轮常规追加；连续两轮的引导评分改善不超过平均 NLL 0.001，记为平台。到达轮数上限不等于平台。

随后做一轮联合挑战，另提议90个分散点，并对最多两个近优边界候选各追加4个混合提案和4个方向提案。边界点本来就全部进入引导评分，因此省去它们无用的低预算评分。挑战前代表、挑战后代表和最终提名代表在独立检查前冻结；不同角色可以是同一个点。

只用一层新的独立种子，同时回答两个问题：最终提名相对复核库最佳者的平均 NLL 损失，是否已小于0.005；挑战是否带来了超过0.005的可靠改善。复核库保留常规搜索前4名、挑战前4名和必要代表。不要求把两个明显较差候选的差异也算得很准。

独立检查从 $R128\times B16$ 开始。尚未确定需要重搜且评分仍分不清时，升到 $R256\times B32$；通过后不再强制另做一遍全库复评。同一批概率回答两个问题，所以不是两份独立证据；$\alpha=0.05$ 按两个问题、两个预算档和最多两个循环预分配，每项每次0.00625。

只有挑战被独立确认有实用改善、提名代表被确认较差，或常规搜索仍未出现平台，才开启下一个搜索循环，最多两循环。引导评分的一点改善不自动触发重搜。用已见审查结果指导下一轮可以，但下一轮必须换新的审查种子；不能在同一批审查里换赢家后称其独立通过。数值不确定到顶时保留 unresolved 和近优候选。

这些调整不改认知方程，但会改变搜索覆盖和最终估计，仍需完整序列验收。单独省去必选边界点的低预算评分，则不改变该点的引导分数。

表中是离散搜索表的范围，不表示任意连续值都已搜索。范围仍为暂定支持，尤其 condition 3 不能因沿用同一范围而视为已校准。已有预选候选中 S103/S129 的 $\gamma=0.97$，S103/S129/S301 的 $M=5$，S129 的 $E_C=0.02,\delta_E=3.2$，都值得复核；这不是群体最终触边率。

默认先检查代表及得分接近的候选。自然边界保留解释；人为边界若没有预先配置的扩展点，就标记 boundary\_review\_required，不能自动判为拟合完成。扩展点必须在配置中声明，保持理论定义域和派生约束；程序同时尝试边缘参数变化及其与其他块的联合变化。扩展后还有明显改善，就继续；新上限又被碰到且没有更外层检查，仍标为待复核。不同被试使用同一套扩展规则，追加工作量可不同。

不能为消除触边而删被试、强迫零值为正、无限扩大网格或改变固定常数。扩大 $\beta_0$ 的搜索范围与改变 $\beta_{\max}$ 不是一回事，后者直接改变动态更新方程。默认入口不修改固定认知设置，也不自动给所有参数加先验或惩罚。

\subsection{第五步：输出状态，而不是只输出一个赢家}
只有搜索出现平台、联合挑战未留下可靠改善、选参精度通过独立复核、人为边界检查没有待解决项时，才记为“在本次已检验范围内暂时停止”。其他情况保留参数和候选库，但明确记录预算上限、评分波动、挑战改善或边界问题。

目前入口交付选参结果、逐试次选择概率及诊断，不自动宣称最终心理状态已可靠。规则信念、活跃概率与执行轨迹应在固定参数下另行生成并检查精度。多个近优参数的状态解释不同，也需要保留；增加同一个点的粒子不能消除参数之间的差异。

\section{哪些已经有证据，哪些仍需要校准}
此前固定候选试点中，S103/S203 在 $R128\times B16$ 通过选参检查并获独立复核；S129/S229 在 $R256\times B32$ 通过；S301 仍未稳定。预算依据应是当前候选的不确定性，而不是把被试编号当成永久难度标签。

S103 连续两轮进入平台后又接受237个新挑战候选；独立审查的损失上界约0.00464，低于试点容差0.005。挑战仍找到更低的分数，结论是“本次有限挑战未推翻容差内暂时停止”，不是“再搜也没有改善”。一个个案不能估计全体被试的误停率。
\source{results/model_0826/decision_precision_pilot_20260918/README.md}

S129 后续仍有两套参数几乎同样好：每试次 NLL 约0.50512和0.50565，255个计分试次的总差约0.134。它们可以保留为近优解释，不能据此挑一套宣称唯一心理参数。两套预测也并非完全一样：平均概率差约1.93个百分点，内部状态尚未比较。
\source{results/model_0826/precision_followup_20260919/README.md}

0.005是探索性实用容差，不是普适统计标准。S229有1087个计分试次，它对应总 NLL 约5.44；关心更小模型差异时必须收紧。重采样完整PF种子得到的区间只描述固定数据、候选库及有限粒子下的数值波动，不是心理参数置信区间，也不证明粒子积分收敛。

Task 1/2/3 对应 condition 1/3/2。Condition 2 的二值错误反馈不能推出唯一正确类别；condition 3 使用三值反馈和未知反应配对学习，不能用 condition 2 引擎代替。当前默认入口支持这三个条件的PMH选择拟合；condition 3 的联合状态精度、恢复和标签支持审计尚未完成。exp4/exp5 不由此入口隐式开放。

等价缓存、似然合并和并行属于工程加速。改变候选、粒子或种子属于估计方案调整，可能改变拟合参数；两者都不在这里改写认知方程。采用新入口不表示旧恢复配置或旧Hyper-CD记录被改写。

\section{读懂拟合结果：得分好不等于内部过程已被证明}
\subsection{我们到底在给什么评分}
对同一参数点，先把 $B$ 个 PF 重复的逐试次概率平均，再取对数：
\begin{equation}
 \bar p_t(c)=\frac1B\sum_{b=1}^B\widehat p_t^{(b)}(c),\qquad
 L(\theta)=-\frac1{|\mathcal T|}\sum_{t\in\mathcal T}\log\bar p_t(y_t).
\end{equation}
NLL 越低，模型给实际选择的概率总体越高。
这里不是先分别求每次 NLL 再平均，也不是选择最贴近数据的一条潜在路径。

当前约定保留完整 trial 序列递推，但首试次不进入默认评分掩码。
因此 S129 的256个试次中有255个计分，S229 的1088个中有1087个计分。
原始时间顺序、session/block边界和反应编码保持不变；不能为了稳定分数删掉高波动试次。

每次选择必须由作答前状态预测，再用已观察的选择与反馈更新状态。
即使每一步递推严格遵守时间顺序，\term{只要参数用整段数据拟合，成绩仍然是样本内拟合}。
独立 PF 种子只使计算复核独立，不会让同一份行为数据变成留出测试集。

\subsection{规则信念、活跃概率与完整路径不要混用}
规则信念表示各规则获得多少支持，归一化后总和为1；活跃概率表示规则进入工作空间的可能性，其总和通常等于容量。
两者不能相互替代。持续执行结构 $\chi=1$ 下还有执行规则；$\chi=0$ 的信念混合读出没有这个变量。
不能把最大信念规则的变化直接称为被试的执行切换。

作答前状态只使用此前信息；过滤后状态吸收了当前选择，需注明是否也已吸收反馈；
利用整段记录回溯的祖先路径还使用了后续信息。
这些输出回答不同问题，图和分数要使用一致的信息时点。
最佳完整路径适合辅助解释，不能每个试次挑一条不同的路径拼成“真实认知过程”。

较稳定的平均 NLL，也可能对应不同的规则信念或内部策略。
所以结果应分开回答：选择预测是否稳定、参数是否近似等价、状态解释是否一致。
真实被试没有已知的心理状态真值，历史拟合也只能作为参照，不能当作真值。

\section{拟合完成后，还需要哪些证据}
\subsection{行为：分开检查拟合、留出预测与自主生成}
样本内检查用于发现问题：学习曲线、类别偏向、错误模式、逐类别概率和极低概率选择。
正式泛化分析需按时间前缀拟合，在共同后缀评价冻结参数；比例应提前确定，不能随机打乱学习 trial。
若预测后继续吸收已发生的后缀选择与反馈，应称为固定参数的在线一步预测。

主比较以同一被试、同一评价试次的 NLL 差为单位，同时使用均匀、类别偏向及适当的简单学习基线。
不同类别数下先做任务内比较，不直接把二分类和四分类的原始 NLL 排名解释为模型优劣。
群体结果每个点代表一名被试；PF种子、重叠滑窗和时间段不能冒充独立被试。
失败或未稳定的个案也需要报告，不能只展示成功例。

\subsection{恢复：能找回什么，就解释到什么程度}
用模型自己生成的选择与反馈建立已知真值，再重新拟合。
分别检查模块架构、执行结构、连续参数和潜在状态；其中一项通过不代表其余都通过。
生成轨迹不能先平均成一个虚拟被试，每条轨迹应独立拟合。

参数恢复还要检查边界堆积、零值与正值混淆，以及参数之间的补偿。
状态恢复需在相同信息时点比较规则信念、活跃集合、执行与切换。
若多种状态产生近似相同选择，应报告不可区分范围，不把其中一条当作唯一心理解释。
现有恢复设计和已生成数据不等于完整恢复结论已经成立。

\subsection{口述：检验它是否增加选择之外的信息}
口述没有进入当前选择目标函数，但规则目录和编码开发曾参考口述，因此应保留开发与验证来源记录。
正式分析冻结编码尺度和规则目录，明确有效新报告、缺失、不可解析与沿用历史报告之间的区别。
当前报告在作答后、反馈前，模型状态的对齐时点也应事先确定。

可以比较完整规则目录上的模型分布 $q_t(h)$ 与口述分布 $o_t(h)$：
\begin{equation}
 O_t=\sum_h\min\{q_t(h),o_t(h)\}=1-\tfrac12\sum_h|q_t(h)-o_t(h)|.
\end{equation}
重叠接近1说明两种分布接近，不等于规则识别准确率，也未自动扣除机会一致性。
仅仅提到同一个特征，或两者都不支持目标规则，也不能证明双方采用同一条规则。

需要与静态偏好、共同刺激和选择所能解释的对应关系，以及保留时间结构的零模型比较。
主评分使用固定完整目录；仅在模型活跃集合内重归一化口述会改变比较问题。
在选择拟合近似相同的候选之间，口述能否进一步区分，是更直接的附加约束检验。
若用某批口述挑选模型，就需要新的留出报告或将结论明确标为探索性。

\subsection{自主生成与模型比较：让解释接受更强的挑战}
自主生成需要模型自己选择，环境据此给反馈，再由模型自己的历史更新。
继续输入真实人的选择与反馈是条件化重放，不是自主生成。
比较多条完整生成轨迹中的学习平台、改善、反转、持续错误和达到学习标准的时间分布，不能只挑最像人的一条。
有限日程结束仍未达标时，要记录删失，不能当作真实完成时间。

P、PM、PH、PMH 比较用于检验记忆与工作空间搜索的贡献；P 仍包含信念学习和动态规则精度，不能称为没有学习。
四种结构都保留动态精度，因此要证明动态精度本身有贡献，还需专门对照。
各模型应独立重拟合，采用共同评价集和对等的计算质量。
固定完整模型参数后关掉一个模块，只是敏感性检查，不能代表简化模型能达到的最佳表现。

模型内“错误累积后搜索增多”部分由方程决定。
要解释人的机制，还需独立口述变化、未来行为或其他测量的约束。
拟合、消融和事件相关本身不构成人类心理过程的因果证明。

\section{默认入口、执行顺序与复现记录}
\term{先检查，再启动。}入口为 \texttt{python -m src.Bayesian\_state.run\_model\_0826\_fit}。
默认配置为 \path{configs/exp123/specific_models/model_0826_adaptive_fit.yaml}。
用 \texttt{--dry-run} 核查条件、被试、范围和预算；用 \texttt{--subjects 103 --smoke --output-dir NEW} 作单被试短序列检查；正式运行去掉 \texttt{--smoke} 并指定新的输出目录。\texttt{--resume} 只继续同一份配置、数据、代码和数值环境的运行。显式指定后缀为 \texttt{\_v1.yaml} 的配置可使用原两层检查规则；默认配置现为 schema 2。

当前先冻结共同支持和停止规则，用 S102、S118、S206、S221、S307、S314 做完整序列验收。每条件按试次长度中位数和较长序列选两人，避开先前诊断个案，不按拟合好坏挑人。本轮不扩展参数范围，也不因触边或未通过而临时放宽验收线。验收后才决定如何推进其余90人；规则兼容时首批可保留，后续另建结果目录。参数解释前完成相应恢复；固定参数的状态分析与时间留出预测分别记录评价边界，最后才生成口述和论文产物。

正式并行使用最多128个进程，不主动预留核；每个进程一个数值线程，只有一层进程并行，跨被试、候选及种子分配就绪任务。没有足够任务时不增加无必要的粒子或候选。smoke使用一个进程、一个被试、32试次和小预算，只检验管线。

每次运行保存数据、配置、资源与源码指纹，候选来源、阶段预算及种子，评分掩码、逐轮改进、边界检查、独立复核、代表和近优候选、停止原因及未解决项。既有研究结果不覆盖；中断后复用已完整保存的数值任务，重新执行尚未保存的任务。独立检查失败不会自动生成标为正式稳定的心理轨迹。
