\subsection{选择预测必须在当前选择出现之前形成}
令 $\mathcal D_{<t}$ 表示此前已观察到的选择与反馈。固定参数 $\theta_s$ 时，主行为预测为
\begin{equation}
 \widehat p_t(c\mid\bm x_t,\theta_s,\mathcal D_{<t})=\sum_{i=1}^{R}w_{t-1}^{(i)}p_t^{(i)}(c\mid\bm x_t,\theta_s,\mathcal D_{<t}).
\end{equation}
先用该分布评价实际选择，再根据当前选择更新PF权重，再用选择/反馈更新认知状态。当前反馈不能提前进入声称的当前选择预测。\textbf{如果参数由全序列拟合得到，状态递推虽然是在线的，整体评估仍然是样本内拟合。}“没有使用未来状态”不能消除参数选择已经看过后缀的事实。

规则信念在共同目录上的在线摘要可写为
\begin{equation}
 q_t(h)=\sum_i w_{t-1}^{(i)}\ind\{h\in A_t^{(i)}\}\pi_t^{-,(i)}(h),\qquad \sum_hq_t(h)=1.
\end{equation}
活跃概率 $a_t(h)=\sum_iw_{t-1}^{(i)}\ind\{h\in A_t^{(i)}\}$ 并非规则信念，其总和通常是活跃容量；若 $\chi_s=1$，另有执行概率 $u_t(h)=\sum_iw_{t-1}^{(i)}\ind\{e_t^{(i)}=h\}$。若 $\chi_s=0$，$u_t$不存在，不能把 $\arg\max_hq_t(h)$ 冒充实际执行规则，也不能据此制造执行驻留时长。

\subsection{全历史路径与最佳路径能回答什么}
终端加权的祖先路径可以回答“结合完整记录，哪些历史内部过程较相容”，但包含后续信息，不能放进在线预测成绩。按全序列选择NLL选出的 best complete path 还增加了事后选择偏差；它适合个案解释或调试，不应替代边际概率，不应通过每试次切换不同路径来拼出一条所谓最佳认知轨迹。

图中应分别标注在线边际信念、过滤后状态、全历史路径与自主生成；不能把来自不同运行、不同信息时点或不同seed集合的曲线拼在一起却共用一个分数。PF路径变异、有限PF重复造成的Monte Carlo误差、拟合参数不确定性与被试间变异也不是同一种区间。

\section{当前单被试拟合：优化的是什么，完成意味着什么}
\subsection{目标函数与实际评分掩码}
当前先在同一参数点上对B个PF重复的逐试次概率取平均，再计算选择负对数似然：
\begin{equation}
 \bar p_{s,t}(c)=\frac1B\sum_{b=1}^B\widehat p^{(b)}_{s,t}(c),\qquad
 L_s(\theta)=-\frac{1}{|\mathcal T_s|}\sum_{t\in\mathcal T_s}\log\bar p_{s,t}(y_{s,t}).
\end{equation}
这不同于先对每个重复求NLL再平均；也不同于对最佳路径评分。原始试次顺序、session/block边界、类别与反馈编码必须保留。

现有代表性运行设置 \texttt{evaluation\_protocol.mode=all}。但指标函数未接收显式valid mask时，会将首试次排除于评分：S129保留全部256试次的状态与预测，评分使用255试次；S229保留1088试次，评分使用1087试次。报告必须同时列出保留试次、有效试次与实际评分试次，不能只看到all就写“所有trial都进入NLL”。本轮不暗中修改这个历史约定；未来若调整，需要单独版本与可比较的重新评分。

\subsection{搜索流程与数值预算}
代表性运行的coarse预算为R16/B4，fine为R64/B8，最终shortlist重评分和拟合后模拟为R128/B16。Hyper-CD先搜索较粗的支持，再以coarse shortlist初始化fine；当前fine有4个起点，每个最多6轮，带停止规则与候选缓存。最终独立seed重评分降低搜索阶段随机赢家被保留的风险，但不能保证搜索到全局最优，也无法找回已经被低预算搜索淘汰的所有优良区域。

候选比较应保持共同随机数的配对规则；搜索、最终重评分、数值审计使用各自明确的seed集合。$E_E$通过 $\operatorname{sigmoid}[\operatorname{logit}(E_C)+\delta_E]$ 构造，工作空间容量/执行结构、反应参数及全局搜索参数采用联合候选。因此“候选次数”不是完成百分比，各参数组每批耗时也不同。

性能优化和并行调度必须维持概率、种子、候选顺序和评分定义不变。原任务中断后已迁至systemd用户服务；状态JSON只是心跳记录，服务存活、子进程CPU时间、检查点推进与正常退出记录需一起检查。断点续跑保留已写入候选，未保存的批次可能重算。正文不需叙述机器运维细节，但复现清单要保留。

\subsection{这轮为什么只选代表性被试}
S129与S229来自Fig1 v10记录的行为代表例，均属于“Longer / larger gain”类别，选例发生在当前拟合结果之前。它们用于发现输入、时序、结果序列化、状态导出和绘图问题；不是按最低NLL或最高口述一致性挑选的成功案例，也不能估计群体优胜比例。后续全体拟合必须采用预先冻结的纳入规则，而不是从这两人的表现反推筛选标准。

\subsection{状态恢复需要补充的内容}

\section{第三层检验：行为解释与泛化}
\subsection{样本内核查、留出预测与自主生成是三项分析}
第一项是当前个体拟合后的样本内核查：逐试次选择概率、学习曲线、错误模式、类别偏向、校准及极低概率trial。第二项是正式泛化：仅用训练前缀选择参数及结构，在共同后缀上评价固定参数预测。第三项是后文的自主生成：模型不再依赖被试后缀选择，而由自己的选择改变之后的状态。

留出划分必须按时间顺序；随机混洗trial会破坏学习过程并泄漏未来。前缀比例可参考已有恢复设计的70/30，但真实被试方案仍应在正式分析前冻结，并确认短记录是否有足够训练与评价试次。若后缀预测后允许吸收已经发生的后缀choice/feedback，应明确称为固定参数在线一步预测，而非完全自由运行。

\subsection{行为指标与基线}
主指标建议使用被试级每trial NLL及相对基线改善
\begin{equation}
 \Delta_s=L_s(\text{baseline})-L_s(\text{PMH}),
\end{equation}
正值表示PMH较好。均匀基线按任务为 $\log2$ 或 $\log4$；还需考虑仅使用过去选择计数的类别偏向基线，以及可解释的较简单学习模型。学习型基线应按相同前缀拟合和后缀更新规则执行，不能让某个模型看到额外信息。不同类别数下仅按原始NLL排序没有统一解释；优先在任务内比较，再总结相对改善。

学习曲线直观但不能替代选择评分。四分类要检查全部类别概率、混淆与类别条件校准，不能将所有错误当同一响应。校准分箱、时间窗和异常trial处理事先固定；尾随32trial的展示窗与优化中window=16的配置是不同用途，均须说明。滑窗只影响展示，不应悄悄改变NLL试次集。

\subsection{群体推断以被试为单位}
正式群体图每个点代表一个人，主要比较同一人的共同评价集上分数差。若使用bootstrap，应以被试为外层重采样单位；需要trial层推断时，必须处理块结构和自相关。PF seeds、重叠滑窗、同一被试的多个时间段都不能充当独立被试。报告效应量、区间、有效人数与失败/缺失比例；多个次级指标的检验策略提前确定。本文不预先承诺显著性或指定尚未计算的效应方向。

\section{第四层检验：口述是否增加选择之外的约束}
\subsection{外部证据的含义与潜在循环}
口述与反应时不进入当前choice目标函数，这是重要的信息分离；但“未进入损失函数”不等于统计独立或完全未被看过。候选规则目录曾参考口述内容扩充，口述编码也有设计选择。因此应记录哪些报告用于目录/编码开发，并考虑被试层留出或独立编码复核。开发与验证来源重叠时，应明确为条件于既定目录的验证，而不能声称口述从未参与任何模型设计。

当前报告发生在作答后、反馈前。模型作答前信念与当前报告之间的差别可能包括作答带来的选择效应；过滤后状态已经纳入当前choice，也可能使一致性由共同输入推动。主图可用作答前信念展示，但正式评分应事先指定时点，并用适当对照检验新增信息，而不是择优选择对齐时点。

\subsection{弱证据、分布编码与完整规则识别}
\texttt{feature1\_use}至\texttt{feature4\_use}仅表征特征提及。相同特征集合可支持方向相反或结构不同的规则，所以它们不证明精确规则识别。\texttt{oral\_center}与\texttt{oral\_A/oral\_b}可提供更强的几何约束，但需检查方向、可解析性、类别映射及多对一编码。

当前图使用完整规则目录上的口述分布 $o_t(h)$ 与模型分布 $q_t(h)$。\texttt{latest\_by\_category}使用每类别最近有效报告，缺失时可能沿用旧状态；因此必须分别保存“本trial是否有有效报告”和“是否存在历史构成的可用状态”，并记录报告年龄。不能把沿用值当成新报告，也不能把缺失与不可解析混为一谈。

当前采用的中心编码尺度为 $\sigma_{\rm oral}=0.05$，这是独立于被试感知噪声和模型beta的编码参数。历史0.10尺度下约0.818的理想目标质量是指定目录/理想中心的参考平台，不是所有口述的普适上限；不能除以该值来人为校正，也不能继续调小sigma直到模型与口述好看地重合。正式分析需冻结主尺度，保留预先定义的敏感性范围。

\subsection{主指标、零模型与额外解释力}
可用完整目录重叠作为易解释的描述指标：
\begin{equation}
 O_t=\sum_h\min\{q_t(h),o_t(h)\}=1-\frac12\sum_h|q_t(h)-o_t(h)|.
\end{equation}
它在0到1之间，1表示两分布相同，\textbf{不是分类准确率，也不是已经扣除机会水平的统计量}。对目标规则质量的一维比较可作为辅助：两边都不支持目标时仍可能支持完全不同的错误规则，故不能替代全分布比较。

主要外部验证应在\textbf{固定完整目录}上评分。active/union空间会用模型决定的支持重新归一化口述，可能放大一致性，不宜作为唯一主证据。建议比较：静态规则/特征偏好；仅由刺激和当前choice构造的报告预测；保留被试、类别、阶段和时间依赖的零模型。可采用块级置换或受约束时间移位，但具体块长、允许移位及保持条件要在验证前冻结，并检查其是否仍保留或破坏了想排除的共同结构。不能把任意全trial混洗当作充分零模型。

被试级结果建议报告真实对齐减去匹配零模型期望、有效新报告数量、沿用比例及编码敏感性。更强的检验是：在选择预测相近的候选之间，报告还能否提供区分。若用这次oral结果选择结构，则同一批oral不能再次被宣称为未触及的确认性检验，需新的留出报告或明确标记探索性。

\subsection{更直接的报告预测：后续方案而非已有实现}
进一步可定义独立报告观测模型
\begin{equation}
 p(v_t\mid\mathcal D_{<t},x_t,y_t)=\sum_h p(v_t\mid h,x_t,y_t)q_t^{\star}(h),
\end{equation}
其中 $q_t^{\star}$ 的条件信息与报告时点要一致，报告噪声应由独立数据或训练划分确定。这样能直接评价报告空间的预测，而不只比较两种编码后的分布。目前不能把现有分布重叠当作已经建立了该生成观测模型，也不能声称已经能自主生成真实口述。

\section{第五层检验：自主生成与机制事件}
\subsection{自由运行必须闭合选择--反馈循环}
在固定拟合参数下，模型自己采样choice；任务环境根据该choice和刺激类别给出反馈；后续工作空间、记忆和精度均使用模型自己的历史更新。持续输入真实人的choice/feedback属于条件化重放，不是自主生成。生成多条完整轨迹后，应比较分布而非寻找最贴近人的一条。

建议检查平均学习趋势之外的联合现象：平台、突然改善、反转、持续错误、错误类别偏向、切换与学习标准达成时间。若仅使用真实人的有限刺激日程，自主轨迹到日程结束仍未达标准是右删失，不能当作真实完成时间；若要检验停止时间分布，需要可继续采样刺激的环境，并复现任务的停止规则。固定参数rollout区间不包含参数估计不确定性。

\subsection{机制事件应接受独立测量约束}
反馈与搜索变量的关联部分来自模型方程，不能仅展示“模型失败累计上升后模型搜索增加”就证明心理机制。应进一步检验推断事件是否解释独立的口述变化、未来行为变化或反应时，并控制任务、学习阶段和共同选择/刺激影响。

所有事件窗口、滞后方向和匹配对照应先定义。切换次数与工作空间替换不是同一量；$\chi=0$时没有持续执行切换。原稿中出现的mastery、rule commitment、misconception capture等名称不能因现有框架有可选代码就写成当前PMH已启用的机制。RT关系目前只能提出探索性检验；动态beta是规则预测精度，不是已经验证的RT参数。没有额外实验设计时，模型消融和相关事件分析也不自动建立人的因果机制。

模型比较的预期结果不必须是PMH获胜。若简单模型同样解释选择和口述，论文应承认机制证据不足或更支持简单解释；若选择区分不了、oral能区分，也需报告区分条件和不确定性，而不是预写成已经成立的“双重分离”。

\section{论文结果段落怎么写，哪些句子暂时不能写}
\subsection{建议的论证顺序与段落模板}
每段围绕一个读者问题组织：问题、比较、可复核结果、结论边界。可以使用以下\textbf{待填证据模板}，但不能直接替换成过去时完成句：
\begin{enumerate}
\item 行为：在共同的时间后缀上，PMH相对于[基线]的被试级每trial评分改善为[效应与区间]；[任务/个体]仍出现[失败模式]。若只有全序列拟合，将本句改成样本内描述，不使用“泛化”。
\item 外部证据：在冻结目录与编码下，模型--oral对应超过[共同输入/时间结构对照]，增量为[效应与区间]；这约束了[可识别层级]，没有证明每trial唯一规则。
\item 结构：独立重拟合的[简化模型]在[共同指标]上表现为[差异/不可区分]；结合[恢复结果]，支持或限制[特定机制主张]。
\item 生成：模型自主闭环下，[现象统计]的分布覆盖为[结果]，同时不能再现[反例]；这检验生成充分性，不是仅重画条件化拟合曲线。
\end{enumerate}

\section{单被试交付应怎样帮助发现pipeline问题}
一名被试的结果包应使读者从原始trial追到论文面板，而不只看到一个最优参数文件。
\begin{enumerate}
\item \textbf{输入与来源：}被试/condition/Task映射、全部trial键、choice/category/feedback一致性、感知校准路径、规则目录、配置/代码/数据哈希、选例依据。
\item \textbf{优化：}完整候选表、坐标轨迹、各起点、停止原因、边界解、候选缓存与检查点、final-rescore及独立seed；不能只保存赢家。
\item \textbf{行为：}每类逐trial概率、选择概率、正确类别概率、有效/评分mask、每trial损失、聚合NLL、基线与校准；从概率独立复算分数。
\item \textbf{状态：}在线信念、活跃概率、适用时执行概率；过滤/反馈后与全历史路径分开；代表seed状态与跨seed概率平均的关系明确。
\item \textbf{oral：}解析与类别编码、完整分布、缺失/沿用/年龄、主分数和对照；源表与图使用同一运行及sigma。
\item \textbf{生成及限制：}适用的自主轨迹、停止规则与覆盖；未支持的诊断标记not applicable或尚未迁移，不能生成假变量凑齐目录。
\item \textbf{总览：}一页README、分阶段退出状态、完整文件索引、核验清单、当前发现的问题和下一步。运行完成与全部科学检查通过分别记录。
\end{enumerate}
