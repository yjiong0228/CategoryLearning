# Model 1024：状态推断方法验证的阶段交付协议

参数背景、随机种子、评价时点、验收门槛与计算上限在新增模拟结果产生前登记冻结。
本文补充术语与交付说明，具体冻结值以运行登记文件及配置校验值为准。
交付目标是说明哪些状态及整段功能量能够怎样报告，
并将可用、有限可用、未通过及证据不足分别记录。口述继续待用户完成最终人工检查。
认知机制、参数范围和默认拟合入口沿用既有候选。本阶段检验推断方法及其使用范围。

## 范围与预定资料

目标状态为正确规则在场、高信念（目标规则总信念至少0.5）、目标规则执行概率，以及
错误题的三类来源。时点固定在本题选择之后、反馈之前。在线过滤、32题固定滞后、前缀
终点平滑和完整终点平滑分别报告。每个平滑终点统一条件于截至该终点的观察。
规则在场与高信念保留各自的定义。

内部信念是学习者分配给规则的归一化权重，其总和为1。状态后验概率表示推断者结合行为后，
对某个内部事件发生的判断。例如“高信念”的内部阈值是0.5；“较明确的高信念标签”另要求
该事件的后验概率至少0.8。三类错误来源在回答错误的试次评价：正确规则缺席；正确规则在场
且执行其他规则；执行正确规则后仍答错。三类互斥，概率总和为1。

整段功能量包括在场题数比例、首次进入分布、最长在场片段及进入次数。观察期内未进入的
路径保留未进入概率和截断标记。执行题数的条件随机性与状态路径间差异共同计入。

新增恢复资料按固定种子生成，沿用C000、C002、C005、C007、C010、C013六个参数背景，
每个背景8条完整路径，共48条。参数背景来自三个开发条件，每条件两个已登记点。路径
生成后全部进入评价，包括从未出现正确规则的路径。状态真值用于评分，数据创建、过滤
种子、粒子数及评价范围按配置决定。旧路径的状态筛选结果继续作为开发诊断。

每条新路径进行两次512粒子过滤；每个背景固定第0条路径再进行两次1024粒子过滤，
合计108次。非零执行维持参数使用既有单规则抽样；零参数使用已核对的身份解析求和。
参照取同一参数背景原有128条自主路径。主参照用各路径产生当前观察选择的概率加权，
形成仅条件于本题选择的状态预测；原始自主状态频率另行保存。这些参照与新增恢复路径
分开，用于检查完整观察历史提供多少额外信息。参照模拟的半库差异及权重有效样本量
单独记录；评分区间对这批固定参照库条件化。

参数敏感性另复用既有12条固定恢复案例的真值点、采用点和似然参照点。点间差异是条件
敏感性证据；完整参数后验和参数不确定性积分继续单独验收。

## 整条历史的更新方法

新方法生成多个相互独立的完整粒子系统。每个系统保留连贯祖先路径、终点权重及整段
行为证据估计。相同参数下，按各系统的证据估计重新分配权重，使整条早期历史能够在不同
系统之间替换。它与对独立过滤结果等权平均分别比较，系统内部的路径权重继续保留。

一个系统指一次完整的粒子过滤运行，其中的粒子共同近似状态分布。不同系统使用独立种子，
表示同一推断问题的独立数值运算。对照同时报告系统数、粒子数和CPU时间，分别检查增加
独立历史与证据加权带来的变化。

令第j个系统的整段对数证据估计为l_j，归一化系统权重为
`a_j = exp(l_j - max(l)) / sum_k exp(l_k - max(l))`。系统内路径权重记为w_ji，
联合近似权重为a_j w_ji。w_ji取观察终点选择后、反馈前的粒子权重。
这里所有系统使用同一组认知参数。外层有效样本量定义为
`1 / sum_j a_j^2`，衡量独立系统权重的分散程度；最大系统权重另行报告。

行为证据是固定参数下观察选择序列的模型概率，过滤通过对可能状态积分来估计它。
l_j由每题观察选择预测概率的对数相加得到。归一化将各系统的非负证据缩放为总和为1的权重。
每个汇总使用其观察终点的证据：过滤截至本题，固定滞后截至本题后32题或序列末尾，前缀
平滑和完整平滑各使用其固定终点。整段功能量由同一固定终点的连贯路径计算。

该计算使用粒子方法扩展空间上的重要性权重。扩展空间同时记录系统内的粒子、重采样记录
和终点路径选择；它保留了粒子过滤运行中的随机量。标准粒子过滤的证据估计满足无偏关系，
即重复独立运行的估计平均等于观察序列的模型概率。系统内归一化状态分布及有限系统汇总
保留其近似误差。粒子独立Metropolis–Hastings（PIMH）
以新旧系统证据之比决定整条历史是否替换；在精确基准中一并核对该转移。本阶段的独立
系统加权、有限迭代PIMH及精确后验分别标注。方法依据见
[粒子MCMC原始研究](https://www.stats.ox.ac.uk/~doucet/andrieu_doucet_holenstein_PMCMC.pdf)和
[PIMH平滑研究](https://proceedings.mlr.press/v89/middleton19a.html)。

完整模型定向检验固定为C006的512粒子和C013的1024粒子，每例首先生成32个独立系统。
若外层有效样本量低于8、最大权重超过0.25，或前后半批在原96题进入窗口的在场概率平均
绝对差超过0.05，
该例追加一次32系统批次。之后按预定标准记录结果。有限系统的加权近似保留其数值误差。

## 两类精确核对

有限状态执行基准使用原有8题、128题观测，比较64、256粒子，各4批独立种子，每批512
个系统。8题按全部执行路径枚举核对；128题按精确前向/后向概率核对独立系统加权与
PIMH。精确运算的绝对容忍为1e-10；概率平均绝对误差的工作门槛为0.03。

共享模型受限核对固定整段工作区、规则信念、精度及知觉路径，使用共享规则信念、作答似然和执行维持规律，
精确计算条件执行后验。C004、C005、C007、C010、C013全部保留。该基准使用额外真实
状态知识，验收条件执行运算，完整行为条件下的所有潜在状态仍由恢复评价。

作答似然表示给定本题规则及其精度、知觉后，产生当前观察选择的概率。参照传播所有可能
执行身份，通过前向更新和后向计算得到完整执行后验。生成时的真实上一题执行身份用于
核对对应转移行；后验计算对上一题身份积分。零维持参数下，给定上述状态路径后，各题执行
可按本题选择分别求和。非零维持参数下，执行延续使后续选择能够提供额外信息。

## 数值与恢复验收

以下门槛是本阶段的工作标准，按配置冻结，表示本轮允许报告的分辨率与证据要求。

| 项目 | 预定检查与标准 |
|---|---|
| 运算与时序 | 概率归一化、有限值、共同终点、祖先连贯及固定种子重现；精确核对1e-10 |
| 逐题数值稳定性 | 512与1024粒子或独立批次比较，概率平均绝对差不超过0.025，差值95分位不超过0.10 |
| 概率校准 | 五个固定概率区间，按完整路径分层自举2000次；有足够路径的区间中，实际频率减平均预测概率的95%区间须落在±0.10内 |
| 区间资料覆盖 | 每个概率区间至少8条独立路径和100题；不足的区间标为证据不足 |
| 状态覆盖 | 正、负状态各至少出现在8条独立路径中；错误来源至少30个事件、分布于6条路径 |
| 信息增益 | 与仅条件于本题选择的自主路径参照比较Brier及对数评分，并报告路径层面差值区间；原始状态频率作为补充参照 |
| 较明确的状态标签 | 二元概率至少0.8或至多0.2；三来源最大概率至少0.8；同时检查精确率至少0.8、95%下界至少0.7及报告覆盖至少0.2 |
| 少数错误归因 | 另要求检出率至少0.5，并满足事件与路径覆盖；原0.5阈值和最大概率分类结果继续保存 |
| 整段功能量 | 在场比例数值变化不超过0.05；进入中位数以32题为工作分辨率，未进入质量及区间宽度同时报告 |
| 系统层面历史多样性 | 外层有效样本量至少8且最大系统权重至多0.25；系统内祖先多样性及半批差异继续检查 |

Brier分数为概率与0/1真值差的平方均值，较小表示较好的概率恢复。校准检查概率的含义，
例如预测概率约0.7的一组事件，在重复资料中应约有70%发生。信息增益检查完整行为历史
在本题选择参照之上提供多少区分。真值筛选窗口的开发结果与未经筛选的恢复分别汇总。
自举以完整生成路径为单位，在各参数背景内重抽；试次及共享近似的分支保留依赖结构。

可用表示在登记条件、参数和资料范围内通过相应检查。有限可用表示只支持概率描述、较粗
功能量或部分范围。未通过表示运算、数值或恢复检查有明确失败。证据不足与计算上限内
未解决分别保留，给出继续使用所需的资料或方法。真人外部验证继续保持待检查状态。

## 计算上限与阶段结束

共享模型上限为236次新过滤；有限状态基准的系统数按上述登记数量执行。总计算上限为96个
累计CPU小时及4小时正式数值墙时。并行预算为128，按可用CPU
与就绪任务数收缩，每进程一个数值线程。新增路径生成与精确核对先经过小规模检查。
只允许上述一次定向追加，结束时交付全部结果、使用范围表、失败与未解决清单及下一阶段
衔接。计算上限到达时保留未解决状态，当前认知机制保持候选地位。

配置见[model1024_state_validation_stage.yaml](../../../../configs/shared/model1024_state_validation_stage.yaml)。
所有新输出使用独立版本目录，原数据、结果与口述编码完整保留。

## 复现入口

命令从仓库根目录运行。控制器按配置登记资料和种子，小规模采集检查使用`--smoke`。
正式运行的输出目录必须尚未存在。下列模块均位于`src.Bayesian_state.workflows.analysis`：

1. `model_1024_state_validation_stage --phase prepare --config 配置 --output 新登记目录`冻结协议。
2. 同一模块的`--phase panel --prepared 登记目录 --output 新目录 --smoke`检查三个条件的采集。
3. `model_1024_stage_reference --prepared 登记目录 --output 新目录`执行两类精确参照；
   `--smoke`提供相同算法的短检查。
4. 控制器的`--phase long`执行初始历史系统，`--phase panel`执行全部48条恢复路径。
   总进程预算为128；多个队列同时运行时按全部在运行的工作进程合计。
5. `model_1024_stage_summary --phase history --prepared 登记目录 --run 完整历史结果 --output 新目录`
   写出历史诊断。诊断确定追加时，控制器的`--phase long --previous 初始历史结果`执行一次追加。
6. 汇总模块的`--phase panel`和`--phase sensitivity`分别产出未经筛选的恢复与固定点敏感性表。
   阶段交付入口为`src.Bayesian_state.workflows.reports.model_1024_stage_delivery`。

共享模型工作进程由控制器设为单数值线程。精确参照和汇总的启动环境使用
`OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1`。
各入口的`--help`给出必需路径；登记文件、完成标记和结果校验值共同记录复现依据。

运行中断时，`model_1024_stage_resume --partial 中断批次 --output 新补算目录 --sealed 新封存目录`
先核对完整结果，再将缺失登记项按原观测、参数、粒子数和种子恢复到新目录。封存记录逐项
保留原结果与补算路径，检查每个登记种子恰好出现一次。中断尝试及其未保存的CPU时间
上界另行记录，计算预算同时检查这些开销。
