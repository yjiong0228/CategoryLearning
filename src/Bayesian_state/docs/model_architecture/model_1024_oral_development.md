# Model 1024：未学会阶段的口述理由研究

登记日期：2026-10-31。用户授权在最多12小时内推进口述与内部状态的对应，允许根据结果作出研究判断并记录。
本轮重点是S205、S306，六名既有被试全部保留。原始录音转写、旧编码、旧状态与旧报告均保留。
口述尚待用户人工复核；本轮结果属于开发研究。配置见
[model1024_oral_development.yaml](../../../../configs/shared/model1024_oral_development.yaml)。

## 研究问题与交付

研究要解释被试尚未掌握任务时采用的判断。例如，“头最长，所以选这个类别”包含一个相对长度判断，
以及它与选项的联系。仅说模型关注“头”，不足以说明它找到了该错误策略。

本轮交付六人的目录表达诊断、两个重点被试各128条按试次均匀抽取的复核记录、全部逐题结果、
连续片段图和中文解释。优先争取在两个被试的前中期找到有证据的对应；未达到目标的案例与方法一并报告。
“前中期”的主比较固定为完整有效记录的前一半，同时逐64题展示全程。这个分段仅用于汇总，
原有行为拟合继续使用完整记录，状态仍逐题更新。

## 先区分三种原因

1. **表达范围。** 检查整个规则目录中，是否有局部规则能支持口述的各个判断及整句话。
   目录中的最好分数用于衡量表达上限；实际模型成绩使用原有概率加权。
2. **口述含义。** 原有编码把未说明参照的“长、短”按刺激范围中点处理，并把“最长”拆成对其他三部位的比较。
   本轮保留这种解释，逐条标明它与当前刺激是否相符。实验程序中部位长度为归一化数值加0.25倍躯干长度，
   因而“躯干的3/4”对应归一化0.5；这一物理换算与被试主观阈值分别记录。
3. **内部状态。** 在目录能表达且语义较明确的条目中，检查行为推断是否把概率放在相符的规则上。
   若表达上限较高而实际概率很低，就记录为状态对应不足。

口述中的每个理由均保留。自动处理保留原文、解析范围和参照约定；人工修订栏保持待复核状态。
判断方向、关系对象与未解析内容分别呈现，避免把部位重合当作完整理由成立。

## 口述调整与内部留出

在任何新评分前，按有效试次划分32题连续块，0起算偶数块用于调整，奇数块用于比较。
每块开头和末尾各4题设为缓冲，保留展示但不用于调整或主比较。
这种交替分块覆盖学习各阶段，允许阶段内变化；全部实际选择与反馈仍可用于行为状态重建。
这些被试及其历史图已被查看，留出的口述用于本轮内部比较，独立外部验证仍需新资料。

第一批比较直接复用17组状态，不重新估计行为模型。P1固定作为参考；另在调整块中选择有限候选及口述读出参数，
冻结后评估留出块。读出指给定模型状态与刺激，计算一个具体口述内容出现的概率。
若使用概率评分，候选口述必须属于预先定义的完整集合，各种内容的概率之和为1。
现有“几项判断得到支持”的比例继续作为描述量；其数值没有口述生成概率的含义。

参照包括原有目录均匀分配、仅用当前刺激和选项，以及仅用调整块口述频率的预测。
新的表达读出同样应用于模型与参照。逐题、逐块、整段都保存，重点看留出前中期是否超过参照，
并检查有没有把改善集中在学会之后。若调整块改善而留出块没有改善，则记录为调整未能推广。

后续分支依据首批诊断登记追加条款：局部刺激反事实、部分口述辅助状态重建或目录扩展，每项在运行前记录
输入、数学定义、选择规则、计算量和停止条件。反事实分析固定规则、精度与粒子权重，只改变刺激，
并先检验原刺激下能否复现原选择概率。口述辅助分支明确口述进入了哪一步，其调整成绩与留出成绩分开。
目录扩展需要先显示具体表达缺口，并作为新机制开发；既有模型结论保留原版本。

## 判断进步的方法

主要比较使用同一组可评分留出条目上的平均对数概率；给实际内容较高的概率会得到较好的分数。
同时报告具体判断支持、冲突、表达上限、原始条目数量，以及连续片段中各条的原话。
工作上的可见增益设为平均每条0.02自然对数单位，并要求前中期至少一个连续64题片段中有12条可评分留出报告。
该阈值用于决定是否值得继续开发，没有显著性检验或心理状态恢复合格线的含义。
相邻报告相关，逐题数量不能当作独立被试数；片段之间是否方向一致另列。

解释成立需要同时说明“怎样的错误判断”“在哪些题上出现”“模型分配多少概率”“简单参照是否同样能解释”。
只改变分数定义带来的数值上涨单独报告。已知数值限制、S129参数未确立、S229仅一个保留点继续保留。
完整潜在状态真值仍只存在于模拟；本轮口述对照用于发展和检验可报告的决策内容。

## 时间、计算与停止条件

任务始于北京时间2026-10-31 00:05:04，最晚12:05:04结束，最后一小时用于核验和交付。
总预算上限512 CPU小时，其中首批诊断2 CPU小时，新状态捕获最多384 CPU小时。
最多128个进程，每进程一个数值线程，按实际就绪任务数安排；轻量数组分析优先复用既有结果。
新计算前冻结源码及输入哈希，避免其他任务同时修改工作区影响结果。

最多登记两次依据诊断作出的追加。若目录表达明显不足，先交付缺口和有限扩展测试；若原始语义仍无法确定，
交付复核清单及明确的条件性结果。若连续两个方案在留出前中期没有增益，则停止继续调参。
新增任务预计无法在交付预留时间前完成时不启动。重复计算不稳定时，保留数值受限标记。
不以两个成功案例作为无限追加计算的条件；时间、CPU预算及方法边界优先。

运行时保存登记、判断日志、源码与输入哈希、分块表、参数选择表、实际CPU和壁钟时间。
所有图默认PNG，完整逐题文件与失败案例随报告交付。代码通过相应验证后创建本地提交，生成结果留在新目录。

## 追加一：固定状态下检验口述读出

首批诊断完成4288条记录、256条预定复核抽样，21567个原评分逐值复现。
S205前半段的目录平均判断支持上限为0.450，P1为0.054；S306对应为0.646和0.409。
这说明两个被试的困难程度不同。本次追加先检验一种明确、可比较的读出，保留原有状态权重。

口述词表由两类任务的既有规则目录中所有数值判断构成，另设OTHER接收词表之外的判断。
词表在读取新评分前固定。每条完整数值口述包含若干判断，逐判断计算对数概率，再在该条内取平均。
它评价“从这条理由中等概率抽取一个判断，模型能否预测其内容”；整句话成立的几何支持继续另列。

对每个局部规则分量，给词表中的各判断一个分数。语义分数在规则支持该判断时为1，矛盾时为−1，
无法判断时为0。部位分数为判断涉及的部位中，局部规则也涉及的比例。两种分数作为独立读出比较，
部位分数保留其方向解释限制。分数经指数变换并在完整词表上归一化，得到条件内容概率。
各分量的概率按原来的执行分量权重平均。

读出同时允许两项表达因素：调整块中常说哪些判断，以及判断是否符合当前物理刺激。
这些因素也提供给所有参照。主参照仅用上述表达因素；另比较目录均匀分配和刺激选项相容的规则分配。
模型与参照各自在调整块选择相同网格内的温度及背景混合比例。数值范围见
[readout配置](../../../../configs/shared/model1024_oral_readout.yaml)。背景混合使零支持内容仍有正概率。
OTHER没有额外规则支持，词表覆盖率单独报告。

参数方案包括固定P1和在已有候选中选择一组。主比较使用相同的可评分留出条目，所有网格成绩均保存。
主选参只用前半段调整块的口述，直接对应未学会阶段的研究重点；另保存使用全程调整块的方案作为对照。
另将P1状态在同一选择、同一64题块内打乱，检验逐题对应是否优于该时段的一般规则倾向；随机种子固定。
状态打乱只作为诊断。新读出分数与原始几何支持具有不同含义，分别画图和解释。
本追加最多2 CPU小时，无新增粒子滤波，留出结果不用于继续选择本追加的参数。

## 追加二：少量口述能否帮助解释相邻试次

追加一的六人比较中，S205前中期留出几乎没有增益；S306有小幅增益，S229更明显。
本追加仍以S205、S306为预定重点，检验一个完整理由能否帮助重建其后相邻片段。
配置见[anchor配置](../../../../configs/shared/model1024_oral_anchor.yaml)。

每64题单独重建一次，使用截至第64题末的行为。先从该段调整块的可编码报告中选择距离第16题最近的一条；
距离相同取较早一条。没有合格条目则该段保持行为结果。选取只看试次及编码范围。
该段其他口述不进入状态加权，后32题的预留口述提供比较。相邻64题段使用各自的条件资料，
每段的结果表示该段行为及一条口述条件下的回顾性重建。

加权对象为既有16次独立粒子计算中的祖先路径。每条路径保持原有规则、精度与学习顺序。
在相同段末，用粒子权重和截至段末的行为证据合并计算；加入口述后，再乘以该路径产生所选理由的概率。
所有试次共享其所在路径的新权重。因此可以检查一条理由对后续状态的约束是否延续。
行为对照使用相同的段末、路径和合并方法，便于单独衡量口述的增益。
S205的每个粒子保存一条实际执行规则；S306在κ=0边界保存条件执行分布。
S306的口述概率先在粒子内部对执行规则求和，再更新粒子权重。锚点本身的执行分布也按口述更新，
其他试次沿原路径传播。这个处理使用κ=0时执行身份不改变后续工作区学习的已核对条件。

为给完整编码理由定义概率，本追加把它看作固定词表中的一个无重复判断集合，并条件于集合大小。
一个集合的权重等于其中各判断权重的乘积；归一化常数为词表内所有同等大小集合的权重之和。
用逐词递推精确计算这个常数。这样，包含三项比较的“头最长”作为整组判断进入加权。
表达权重沿用调整块的用词频率及物理刺激因素，语义强度主值固定为2，另列1和4两个敏感性值。
每条理由的生成概率有一半来自与规则无关的表达背景，允许口述省略、补充或不准确。
这些是本次新增的观察模型假设，尚待人工口述审核及后续校准。

数值检查记录独立计算的有效数量、最大权重、口述锚点的祖先多样性和重新加权损失，
并把16次计算分成两个固定半组重复汇总。超过配置中的工作阈值时，该段标记为数值受限。
原模型的状态恢复限制继续保留。本追加不重新运行认知模型，也不把口述调整成绩当作外部验证。

同时检查S205的排序表达缺口：在原目录外，枚举“按最长部位分类”及“按最短部位分类”的全部24种标签安排，
共48个候选，用于计算表达上限。另在前中期调整块估计最长／最短部位与选项的频率联系，
在留出块与只用选项频率的参照比较。该检查定位是否值得将排序规则接入完整模型，结果作为结构诊断报告。
现有认知模型、参数与完整学习机制均保持原版本。本追加最多12 CPU小时，最多32个单线程文件分析进程。
