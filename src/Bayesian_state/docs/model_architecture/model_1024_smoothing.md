# Model 1024：精确执行基准与连贯状态平滑

本轮继续检验内部过程推断。真实口述待用户完成最终人工检查，分析仅使用已有模拟行为、
生成参数和模拟状态真值。7个案例沿用上一轮事先登记的进入窗口，属于已检查的开发资料。
模型的学习、搜索、容量、知觉及执行机制保持原有定义。

## 问题与比较

在线过滤计算本题选择之后、反馈之前的状态分布，条件资料为截至本题的选择及此前反馈。
回顾性平滑进一步使用后续选择；后续反馈通过原有学习机制影响状态传播。两者都指向本题
反馈之前的状态。平滑检验完整行为记录能否帮助重建过去，后续行为预测另行评价。

令 \(Z_t\) 为本题反馈前的内部状态，\(a_{1:t}\) 为截至本题的选择，\(f_{1:t-1}\)
为此前反馈，\(x_{1:t}\) 为刺激，\(\theta\) 为固定的生成参数。过滤的目标为
\(P(Z_t\mid a_{1:t},f_{1:t-1},x_{1:t},\theta)\)；终点为 \(u\) 的平滑将条件资料扩展到
\(a_{1:u},f_{1:u-1},x_{1:u}\)。未来反馈通过原模型的状态更新参与重建；原过滤器仅用选择
似然更新外层粒子权重。本轮保留这一生成与观测约定。

首先建立三条规则的有限状态执行基准。活跃规则、规则信念和作答概率固定，只保留执行身份
随试次转移；信念乘以执行维持权重，再归一化，得到转移概率。第一、第二条规则产生相同的
作答分布，第三条不同。这个设置同时包含可区分与行为相同的执行身份。精确前向计算给出过滤，
精确后向计算给出平滑；短序列再用全部执行路径枚举独立核对。该基准验收推断运算与时间对应，
完整模型中的规则搜索和连续状态仍由模拟恢复检验。

## 连贯祖先路径

完整模型复用原过滤器的重采样记录。每题保留每个粒子的目标规则在场、信念、执行身份和
选择后权重。终点使用最后一题选择后、反馈与重采样之前的粒子权重。从终点沿祖先索引回溯，
得到具有共同历史的路径。最后一题的重采样映射单独保留，用于时序审计。

平滑比较三个观测终点：上一轮窗口所用的共同前缀终点、完整模拟序列终点、以及本题之后
32题的固定滞后终点。前两种各自共享一套条件资料，可以计算整段在场题数、首次进入和持续
长度的路径分布。固定滞后结果的条件终点逐题变化，作为逐题诊断保存。在线过滤概率累计和
仍按在线描述量报告。

首次进入的路径统计同时保留“截至终点仍未进入”的概率。CSV将未进入编码为终点加1，
该编码的均值用于数值记录；已进入路径另报条件平均进入时点。真实片段延伸到观测终点后
时，片段覆盖质量针对已观察部分计算，并保留观察长度和右截断标记。

祖先路径在较早试次可能合并。逐题报告具有正权重的不同祖先数及祖先有效样本量；后者为
各祖先总权重平方和的倒数。它衡量保留的祖先多样性，同一祖先的复制不会增加该量。
单个祖先导致的确定结果保留数值退化标记。粒子数较高或状态在场粒子存在，均需结合此项检查。

## 固定预算与验收

参数使用每个案例的生成真值。7例各用512粒子及原有前3个种子，从任务开始过滤至完整终点，
共21次过滤；与原有512粒子逐题预测和状态数组核对。三种反馈条件均参加小规模被动记录检查。
精确基准的长度、种子与粒子数见[配置](../../../../configs/shared/model1024_smoothing.yaml)。

评价在场、高信念、目标执行、三类错误来源的概率评分、误报漏报，以及真实在场片段内的
阈值检出；首次阈值达到定义为该真实片段内第一次在场概率达到0.5。另保存连贯路径的首次
进入、在场题数和最长片段分布及真值。模拟种子之间的差异描述数值波动，逐题数据存在依赖。
全部案例与全部祖先权重保留；口述、真人重新拟合和认知机制改动在本轮范围之外。

验收分为精确运算、被动记录不改变原过滤、完整模型的祖先多样性和实际恢复效果四项。
前两项通过后，再解释后两项的结果。若祖先多样性不足，后续优先改进状态推断算法，并保留
已有机制与状态恢复失败作为研究证据。

## 运行入口

从仓库根目录依次建立新目录：

```bash
python -m src.Bayesian_state.workflows.analysis.model_1024_smoothing --phase benchmark --config configs/shared/model1024_smoothing.yaml --output results/model_1024/smoothing_benchmark_NEW
python -m src.Bayesian_state.workflows.analysis.model_1024_smoothing --phase run --config configs/shared/model1024_smoothing.yaml --output results/model_1024/smoothing_smoke_NEW --smoke
python -m src.Bayesian_state.workflows.analysis.model_1024_smoothing --phase run --config configs/shared/model1024_smoothing.yaml --output results/model_1024/smoothing_run_NEW
python -m src.Bayesian_state.workflows.analysis.model_1024_smoothing_summary --run results/model_1024/smoothing_run_NEW --benchmark results/model_1024/smoothing_benchmark_NEW --output results/model_1024/smoothing_summary_NEW
python -m CategoryLearning_codes.figures.fig3.model1024_smoothing --source results/model_1024/smoothing_summary_NEW --output CategoryLearning_codes/figures/outputs/fig3/model1024_smoothing_NEW
```

配置绑定7个案例、原有种子、512粒子和32题滞后。工作进程采用来源归档中的模型实现，并
加载已有信念与执行适配层；新增模块被动记录状态并计算平滑。固定种子的原有逐题预测和
状态数组要求精确相同。结果保留每个粒子的事件值、祖先索引、选择后权重、源文件哈希和
数值线程信息，可以重新计算全部连贯路径。保存的目标事件值覆盖本轮检验范围，完整认知
状态快照另有既有工具。

## 本轮结果与后续工作

精确执行基准与三种反馈条件的小规模记录检查均已完成。21次正式过滤的预测和全部原有
状态数组逐项相同，覆盖10,223,616次粒子状态更新。7个进入窗口的平均在场Brier分数由
过滤的0.281降到前缀平滑的0.151、完整平滑的0.125；完整平滑在4/7个窗口改善，在其余
3个窗口变差。该均值描述既定开发窗口，各案例及富集路径分别保留。

63次“正确规则在场但未执行”的错误中，过滤检出3次、误报5次；固定滞后32题检出13次、
误报4次；前缀平滑检出21次、误报14次；完整平滑检出22次、误报23次。3题、14题的短暂
片段仍持续漏报。6个窗口的完整平滑祖先有效样本量中位数仅约1.05至1.89，部分种子的路径
区间退化为单点，跨种子的早期历史仍有较大差异。恢复改善、误报及祖先多样性共同决定解释范围。

这一步建立了精确运算检查、完整模型的被动平滑和连贯事件分布。状态推断的数值可靠性仍
需提高。下一步核对零执行维持参数下的解析求和条件，并校准能够保留早期历史多样性的
回顾性推断方法。口述继续待最终人工检查，认知机制与参数沿用既有研究候选。
完整表格、数值审计和证据边界见[本轮报告](../../../../results/model_1024/smoothing_report_20261025_v1/report.md)。
