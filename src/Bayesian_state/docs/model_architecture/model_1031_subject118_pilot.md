# S118：经验到规则的首个开发案例

本次按用户要求选择一名口述呈现“先具体描述、后集中于规则特征”的被试，运行 Model 1031。
选人先于本轮参数结果。研究对象为条件1的 S118，共256题，完整行为记录用于选参。
口述用于选人及结果描述，原文、现有数值编码和特征编码保持原状，人工检查尚未完成。

## 选人依据

先在条件1中按固定前64题和后64题检查部位词的出现情况，再阅读 S102、103、108、110、113、114、
118、119、120、128的部分原文。S118前64题有63条明确提到四个部位，后期反复使用尾巴长短作为理由。
第33题为“头短，脖子长，腿短，尾巴短”，第113题为“三个部位都很短”，第177题为“尾巴比较长”。
S118保留较长的具体描述阶段，中间有部位数量的概括，后期形成稳定单特征理由，适合首个开发检验。
四部位描述与示例记忆相容；它也可能反映逐项观察或已有规则之外的补充表达，机制解释需要后续证据。

## 本轮计算

冻结配置为`configs/exp123/specific_models/model_1031_subject118_pilot_v1.yaml`。
Model 1031与Model 1024各使用16个预先产生的参数组合：原示例值和15个分散组合。
共同坐标采用相同候选，1031另含相似范围；1024保留既有规则搜索结构。两者分别选参。
本轮是有限候选比较，优化质量和完整参数区域尚待后续研究。

1. 每个候选用32粒子、2个独立种子计算全256题的选择负对数似然。该分数越低，
   模型平均给被试真实选择的概率越高。
2. 各模型前4名用128粒子及2个新种子重算，前2名再用512粒子及2个新种子重算。
3. 每个最终候选独立生成64条完整自主路径。每条路径使用相同实际刺激日程，
   由模拟回答产生自己的反馈。保存全部路径，比较32题正确率分布和整段行为特征。
4. 最终参数仅按行为似然排序。自主分布逐候选并列展示，口述不改变候选排序或状态权重。

计算至预定数量完成或45分钟墙钟／12 CPU小时上限即停止。达到上限时保存已完成结果，
记录未完成任务。单一进程并行层，每个进程一个数值线程，进程数不超过可用CPU、128及就绪任务数。
粒子档之间差异及两次重复差异均报告；每题NLL差0.01为本轮工作诊断值，
它不代表参数已恢复、状态已验证或候选差异具有统计显著性。

## 如何解释口述对应

状态采用当前选择后、当前反馈前的过滤分布，参数由全记录估计。
分别展示具体示例、局部概括、目录规则的执行概率，以及本题执行内容涉及哪些特征。
部位集合按16种四维掩码汇总。模板使用保留维度；目录规则使用其定义中的全部判断维度。
将这些概率与现有`feature1_use`到`feature4_use`并列，计算部位集合完全相同的概率。
该量说明特征使用范围的相容程度，具体长短判断、关系方向和整句口述生成概率需要另外评价。

一条完整四维模板在最初经验进入后自然支持四个维度，因此早期部位吻合包含初始化假设的作用。
报告同时检查这种状态保持了多久、是否在行为拟合后仍得到支持，以及后期是否转向被试使用的尾巴。
所有试次及缺失／含糊编码情况进入逐题复核表。保留部位数量概括等现有编码难以明确表达的原文。
口述已参与案例选择，本轮结果属于开发性对照。
