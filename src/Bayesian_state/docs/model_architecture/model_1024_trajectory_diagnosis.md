# Model 1024：自主路径分布与参数敏感性诊断

登记日期：2026-10-25。研究目标与资料解释遵守[研究指导文件](../RESEARCH_GUIDE.md)。
本协议在新路径分析与模拟之前固定。此前已查看这些被试的行为及原比较摘要，全部结果属于开发研究。

## 问题与预算

本次检验真实学习形态在模型分布中的位置，以及相近训练评分的参数是否产生不同的学习过程。
分析108、110、129、205、209、229、306、309、317的MIX、MAP和持续执行候选，复用每组128条
完整自主路径，共3456条。原拟合结果、参数提名和路径均保留。
MIX按规则信念加权选择；MAP采用最高信念规则；持续执行每题采用一条规则，并具有跨题维持倾向。

参数敏感性限于129、229、317的MIX与持续执行候选。每组保留原提名，再从原独立确认阶段
选至多两组参数。各点用新的128个种子自主生成，最多2304条完整路径。单层进程并行最多128个
任务，每个进程一个数值线程。先运行一个被试、一个种子、16题的流程检查，再开展正式模拟。
预算用尽即总结证据及缺口；下一轮机制修改依据诊断另行制定协议。

## 参数选择与资料边界

候选仅来自原确认阶段。相对本机制训练NLL最优点的每题NLL增加不超过0.02，构成此次敏感性
候选集。NLL是负对数似然，越低表示对实际选择的概率预测越好。
0.02是开发工作容忍量；其统计含义限于指定数值门槛。保存每个差值及按共同过滤种子
计算的蒙特卡洛标准误。该候选集用于参数敏感性，不赋予后验概率权重。

每个参数在原预定网格中的序号除以网格最大序号，得到0至1的坐标；固定坐标不参与距离。
坐标的平均绝对差定义参数距离。以原提名为起点，每次选择到已选点的最小距离最大的候选，
并列时依次用训练NLL及候选标识排序，最多追加两点。选择过程只读取训练确认记录和参数空间。
真人后段选择、口述和新生成路径均不进入参数选择。输出全部候选资格记录及冻结清单。

新种子按被试和重复编号生成，在机制与参数点间配对。共享种子提供配对蒙特卡洛比较；不同
参数下的具体随机调用可能分岔。新种子与原128个种子不重合。独立模拟评价数值稳定性。

## 完整路径特征与形态类别

路径特征沿用共享指标：不重叠32题块的种类正确率，以及以真实类别为条件的反应频率。
两类特征各占0.5权重，并分别按维数缩放；距离为该特征向量的欧氏距离。缩放仅由预定权重、
维数和任务类别覆盖决定。所有试次、反应类别及完整路径进入计算。

每个被试独立建类。三个机制各取原种子顺序的前64条路径，合并192条，用K-means建立共同
类别中心；后64条用于检查类别概率和距离。主分析固定三类，两类及四类作为敏感性检查。
K-means固定种子、30次初始化。按建类路径的末段平均正确率从低到高命名类别；类别表示
当前任务中的路径形态。各机制在合并建类资料中权重相同，这一约定不表示模型后验权重。

报告每一类在各机制下的路径数、概率及95% Wilson蒙特卡洛区间。最近中心确定真人所属的
描述性类别，同时报告真人到该中心的距离、该类模拟距离的90%分位数及真人距离在独立模拟中
的位置。类别频繁与真人靠近中心是两项信息。保留全部类别和路径参与分布评分。

稳定性检查在后半模拟上重新建类，用两套中心对全部原路径分类，计算调整兰德指数（ARI）。
ARI衡量两次分组的一致性；新参数点按原前半模拟冻结的中心分类，检查原提名新旧批次的
类别概率变化。每类代表路径取该类中到其他成员平均欧氏距离最小的一条完整路径。
分位区间和平均曲线用于描述分布，代表路径保留实际的一次贯序历史。

## 行为量与评分

完整序列和冻结后段分别计算共享Energy分数及逐路径删一法蒙特卡洛标准误。原条件预测NLL
作为既有参照。新增参数点的自主评价与原条件预测分开呈现。Energy越低表示在所选特征中的
预测分布越接近观察；特征之外的内部过程仍需独立检验。

沿用原相邻32题最大改善、随后完整32题保持、最低128题正确率（步长64）、低表现窗口的
反应与类别边际独立基准。原最大改善靠近结尾时，保持记为缺失，明确可观察路径数。

另定义具有完整保持窗口的改善量：只在结尾仍留有两个32题窗口的位置搜索最大改善，
并记录随后第二个窗口的正确率；最大值并列取最早位置。此量与原最大改善分别命名和保存。
以真人这两个数值作为描述性参照，报告生成路径中同时达到其改善和保持的比例；再报告同时
达到真人后段正确率的比例。对于低表现，报告最低窗口正确率及其相对边际基准的差值，
同时达到真人低值的路径比例。所有被试使用同一规则，结果保留事件分子、分母和蒙特卡洛区间。
这些比例描述当前个案的位置，包含选择窗口的过程，不作为多重筛选后的显著性检验。

## 内部过程诊断

复用原几何审查中仅依据训练刺激确定的全部正确规则。保存每条路径中的首次在场时点、
累计在场比例、首次在场后退出比例、正确规则信念及作答贡献、信念加权精度、实际执行比例
和搜索/切换频率。首次在场未发生时保留右截断状态。

种类正确概率分别按正确规则缺席、在场但执行其他规则、执行正确规则分组；MIX记录在场与
贡献权重，离散执行身份指标记为不适用。对具有离散执行的路径，错误按上述三个互斥来源分解，
检查各来源相加等于全部错误。条件3同时保留平均反馈得分，规则几何正确与未知配对学习分别解释。

比较原提名和相近训练参数的路径形态及过程量，可说明哪些解释依赖参数选择。模拟状态属于
已知生成过程；其条件关联描述可能的瓶颈，因果贡献需要机制干预或更强设计。这一步得到的
生成路径解释与真人状态重建的准确率分别报告。原执行状态恢复的限制继续保留。

## 完成记录：2026-10-25

18个参数点、2304条新路径及3456条原路径均已分析。三类分组的跨批次ARI为0.40—0.89，
129的细分类尤其敏感。129、229、317的真人轨迹虽有最近类别，其距离分别处于该类原检查路径
的100%、约98%、100%经验百分位。类别概率与相似程度需要同时解释。

129和229的预定最大改善—保持联合事件在各参数点分别为0/128；单点95% Wilson区间上界
约2.91%。317的低表现联合事件在新增各点为0或1/128。有限模拟保留小概率不确定性。

训练接近候选改变了生成过程。129的MIX候选1在末段正确规则在场比例相近时，提高条件精度，
平均后段正确率从0.690升至0.759；229的MIX候选2将末段在场比例从0.444提高至0.902，
正确率从0.581升至0.707。多个参数同时变化，这些结果提供定向干预线索。317的部分候选
提高后段正确率，同时使完整路径Energy变差，后续估计继续保留完整序列约束。

下一轮优先把训练内选择评分与自主分布约束共同接入当前执行比较，并保留候选解释。
随后用共同前段状态隔离精度校准与规则发现/保持。新增机制同时接受状态恢复检验，口述继续
提供外部约束。完整参数后验、独立人群验证及准确的执行状态重建仍待完成。
