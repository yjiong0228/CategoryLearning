### 极小选择概率

对每个类别区域的凸多面体部分，计算它到单位立方体16个顶点的最大距离。到凸集的距离是凸函数，因此顶点最大值给出整个立方体上的上界；类别区域由多个部分组成时，选取一个部分即可得到有效上界。对当前29／152条规则逐项核对后，所有类别距离均不超过1。

当精度不超过25时，单条规则的各类别概率至少为 `exp(-25)/C`：二分类约 `6.94e-12`，四分类约 `3.47e-12`。连续规则混合和粒子混合继续保留这一界限。粒子更新与NLL中既有的 `1e-12` 下限在当前目录和参数范围内不触发。将来改变目录、距离定义或精度上限时，应重新核对。
