# Model 1022：前段状态自主续跑诊断

本轮检验前段行为所支持的内部状态，能否在随后自主学习中维持较高的正确率。
比较固定参数下的两种起点，可以定位规则发现、规则保持和规则使用中的主要困难。
本轮沿用 Model 1022 的 TRANSFER 机制与既有候选；行为参数、口述编码及认知机制保持冻结。

## 研究问题和范围

既有从任务起点生成的结果中，205、306、309的末128题正确率都高于各自128条模拟路径。
本轮保留这些路径，并增加从前段行为推断状态出发的自主续跑。原结果见
[简洁模型重拟合记录](model_1022_compact_refit.md#六人冻结参数后的行为与自主路径)。

每人使用本轮选中点、上一轮参考点和既有备选点，共九个参数点。205的前段为480题、
后段为224题；306和309的前段为512题、后段为256题。所有参数均来自原前段行为估计。
这些被试已用于开发诊断，309的既往设计影响继续标为未确定。本轮提供固定参数下的定位证据。

## 状态形成与续跑

前段使用真实选择和反馈进行粒子滤波。每个粒子表示一种可能的内部学习状态，
末端权重表示该状态得到前段行为支持的相对程度。程序保留最后一次反馈后的完整状态分布。
每条未来分支按末端权重抽取一个粒子状态，并分配独立的随机流。

后段依次提供原刺激。模型自主选择，任务根据模型选择和真实类别产生反馈，再更新内部状态。
后段被试的真实选择用于计算评价指标。口述不参与参数估计、起点推断或续跑。
起点状态的在场比例、精度和配对分布由完整粒子云加权计算；后段轨迹由抽取的分支等权计算。

每个参数点运行8个独立滤波种子，每次1024粒子，每个滤波生成16条分支。
九个参数点合计72次前段滤波、1152条续跑路径，并复用1152条任务起点路径。
队列上限为128个单线程数值进程；当前72个独立任务全部并行调度。
同一次滤波的16条分支共享后验近似，计算模拟误差时整体保留为一组。

## 比较指标

两种起点使用相同后段刺激和评分边界。正确率按32题分块，并保留全部路径。
Energy和CRPS沿用既有分布评分，评价整段曲线分布与观察曲线之间的差异。
末段指标使用最后128题，包括正确率均值、中央80%范围、观察值的分布位置和达到观察值的路径数。
路径数为有限模拟中的频数。模拟误差只描述固定参数下的计算波动。

内部过程分别记录目标规则在场比例、作答权重、在场时精度、搜索、容量替换和规则数量。
新增记录还保存目标规则对当前刺激的选择概率，区分规则获得的影响比例与规则自身判断。
目标规则缺席时精度和目标概率用零编码；汇总时仅在规则在场的试次计算这些条件均值。
条件3同时记录三种类别配对的条件分布和边缘分布。配对编号遵循模型顺序，
配对分布集中本身不证明配对正确。原任务起点路径未保存配对轨迹，该项只呈现续跑结果。

## 判断与停止标准

若起点已有较可靠的规则依据，且续跑表现接近被试，则重点检查前期规则发现和状态形成。
若规则在续跑中消失并伴随表现下降，则重点检查保持和容量替换。
若规则持续在场而正确率仍低，则检查作答竞争、判断精度与类别配对学习。
若参数候选之间的结论不同，则保留参数敏感性，并优先明确参数估计的影响。

本轮完成九点对照、全部轨迹和数值一致性检查后结束。阶段报告说明哪些判断跨候选稳定，
哪些仍有不确定性，并据此提出一到两个简单的后续机制对照。定向对照和重拟合属于后续阶段。

## 2026-10-23：正式结果与阶段决定

九个参数点均已完成。72次前段滤波与1152条续跑路径使用72个单线程工作进程，正式计算耗时
约23.5分钟，累计约19.0 CPU小时。前段每题预测均与原记录逐值一致。
全部结果见[六张PNG与读图入口](../../../../CategoryLearning_codes/figures/outputs/fig3/model1023_prefix_forecast_20261023_v1/index.html)。

### 主要差距发生在哪里

当前选中参数下，末128题的结果如下。范围为128条路径的中央80%，按每条路径的末段正确率计算。

| 被试 | 观察正确率 | 从任务起点自主生成 | 从前段状态续跑 | 续跑中央80%范围 |
| --- | ---: | ---: | ---: | ---: |
| 205 | 83.6% | 62.3% | 69.9% | 64.8%–75.8% |
| 306 | 94.5% | 77.1% | 77.7% | 73.4%–82.0% |
| 309 | 85.9% | 69.7% | 76.1% | 71.6%–80.5% |

前段状态改善了205和309的自主表现。306选中点的改善很小：Energy差值为−0.00385，
两种起点的独立模拟误差合成为0.00300，当前计算尚未清楚区分这个评分变化。
三个选中点的128条续跑路径均未达到各自观察值。

三个选中点在整个续跑段都保留了目标规则。其末段状态说明剩余差距的位置：

| 被试 | 目标规则在场比例 | 目标规则作答权重 | 在场时平均精度 | 目标规则自身给正确选项的平均概率 |
| --- | ---: | ---: | ---: | ---: |
| 205 | 100% | 99.3% | 8.55 | 69.6% |
| 306 | 100% | 65.3% | 15.95 | 83.5% |
| 309 | 100% | 83.0% | 14.72 | 78.5% |

205已经几乎完全由目标规则影响作答，规则自身给正确选项的概率仍只有约70%。继续加强这一状态下的
规则保留或作答权重，改善空间很小。306同时存在规则竞争和规则判断精度的限制；目标规则自身的正确概率
仍低于观察的94.5%。309选中点也有相同线索。这些结果支持将后续重点转向判断精度及其到作答的转换。

条件3的配对记录显示，306各候选的目标规则配对已集中于同一项；309的配对分布仍较分散。
配对分布影响反馈学习，当前分类选择概率由规则预测直接形成。这里的配对图用于描述学习状态，
配对是否正确以及它对后续学习的因果作用，仍须使用任务语义和定向对照确认。

### 哪些判断跨参数候选成立

205三个候选的续跑正确率为69.4%–69.9%，目标规则持续在场，末段作答权重为95.9%–99.3%。
规则判断与作答转换的缺口在三个候选间一致。306三个候选为77.7%–82.9%，目标规则也持续在场；
三组各128条路径均未达到观察值。306具体差距的大小受参数影响，后段仍有明显不足的判断稳定。

309需要保留候选差异。其备选点从任务起点生成的末段均值为49.7%，从前段状态续跑则为83.5%，
中央80%范围为79.7%–87.5%，128条中31条达到观察的85.9%。这个候选能够在已形成的状态下产生
合理后期表现，主要困难更偏向前期发现和状态形成。选中点和参考点的续跑均值分别为76.1%和75.7%。
本轮保留原参数选择，报告这种敏感性。

### 保存状态上的作答确定性诊断

主对照完成后，追加一项仅读取保存数组的探索性诊断，用于判断作答读出是否有值得检验的改善空间。
对每个既有状态，令其原作答概率为\(p_k\)，其中\(k\)表示一个可选类别。将概率平方并归一化得到
\(q_k=p_k^2/\sum_j p_j^2\)。这一变换提高原本较可能选项的相对概率，保留选项排序。
随后在相同刺激和相同保存状态上，比较模型给真实类别的平均概率。

| 被试：选中点 | 原平均正确概率 | 平方归一化后 | 观察正确率 |
| --- | ---: | ---: | ---: |
| 205 | 69.5% | 83.7% | 83.6% |
| 306 | 77.3% | 88.2% | 94.5% |
| 309 | 75.5% | 85.9% | 85.9% |

这些数值是固定状态上的即时概率诊断。变换后的选择、反馈和后续状态尚未生成，参数也尚未重新估计。
平方作为统一的定向探针使用，其数值尚未成为模型的最终设定。原概率最大类别的平均正确比例
在三个选中点分别约为97.0%、95.9%和95.2%，说明较多保存状态已经把正确类别排在首位，
同时仍将一定作答概率分配给其他类别。该结果进一步支持优先检验作答确定性。

### 下一轮的两个定向对照

第一项优先对照是保留当前H模块与精度学习，只在最终类别选择时使用更集中的概率。
先以统一的平方归一化作为探针，运行完整自主路径和前段状态续跑，观察新增反馈如何改变后续学习。
若动态结果有一致改善，再用相同参数搜索预算重拟合，并同时评价前段、后段及常规口述支持。
共同的读出设置与个体精度如何区分，应在这一比较中明确。

第二项对照是在现有机制内定向检查精度初值与学习率的联合变化，保留原类别选择方式。
这回答提高作答确定性的需求，能否通过已有精度参数及其学习过程解释。先使用已声明的参数范围和
固定预算；若已有参数能解释改善，则优先保持现有简洁机制。两项对照的差异在于，提高确定性
发生在最终作答时，还是同时改变规则对反馈的解释及后续学习。

本轮支持暂时固定H的整体架构，优先解决205、306在已形成规则之后的精度和作答问题。
309的发现困难作为参数敏感的并行线索保留。上述证据限定于三个开发诊断被试和九个既有参数点，
个体参数的稳定心理含义与跨模型优越性仍需后续验证。
