# Model 1024：关键状态恢复与口述内容检验

登记日期：2026-10-25。研究遵守[共同目标与证据标准](../RESEARCH_GUIDE.md)，接续保持率与
容量对照，检验状态推断能否区分正确规则缺席、在场未执行及执行后错误。模拟真值与真人
口述分别提供内部状态恢复和外部内容相容性的证据。

## 参数点与固定种子模拟案例

三个开发被试为129、229、317。每人在STICKY下使用当前训练采用点，以及一个训练NLL初筛
合格备选点。备选点在保持率与容量的归一化网格秩距离上离采用点最远；并列依次取训练NLL
更低及标识字典序更前者。筛选只读取上一轮训练表，口述与后段表现均保持评价用途。

每个参数点固定取上一轮128条完整生成路径中的第0、1条，共12个案例。两条种子在同点内独立，
不同参数点之间保留原有种子配对关系。完整模拟状态是真值。拟合输入使用无参数标识的案例编号，
真值、生成点及原路径另存；训练仅接收刺激、选择和任务反馈。

另设每人至多一个稀有事件压力案例：在两个已登记参数点的其余126条路径中，选择“正确规则
在场、执行其他规则且作答错误”的次数最多者，平局取路径顺序及参数点顺序。次数为0则记录
缺乏相应压力案例。压力案例只使用真实参数重建，评价对已有关键事件的识别；总体概率校准和
事件发生率在固定种子案例中报告。压力案例的选择依据为模拟真值，推断不接收其选择条件。

## 条件参数恢复

每个案例使用相同的15点网格：零分反馈后的信念保持率δ为0、0.3、0.6、0.8、1，活跃规则
容量上限K为2、3、6，其他参数固定在相应
被试STICKY的既定数值。δ、K的生成值不告知拟合过程。该设计评价两个坐标在已知其余参数
条件下的恢复，完整参数恢复及执行维持参数的恢复继续分别检验。

每点以两个新种子、128粒子计算训练NLL，另生成32条训练长度路径。先取训练NLL最小点为
似然参照，再在相对该点每题NLL增加不超过0.02的集合中取训练Energy最小点。Energy沿用
32题块正确率及类别条件反应频率各半的特征。并列按NLL及标识处理。0.02定义选参时的工作
容忍范围；参数后验和置信区域另需明确的先验或统计校准。

每例至多一次替换提议。以四个新种子、256粒子确认似然参照和提议点，另以128条新训练路径
比较两点。NLL差加两倍模拟标准误不超过0.02，且Energy差加两倍模拟标准误小于0时采用
提议点；其余情况采用似然参照。所有估计冻结后再读取真值评分。

似然参照由该模拟案例自己的训练资料估计，候选网格对每个被试的全部生成点一致。真值在
预先固定的支持中，网格未因某条模拟路径的真实参数增加起点。筛选与确认禁止读取后段数组。

## 状态推断与数值精度

冻结后，真实参数与采用参数分别以四次512粒子过滤重建完整行为。相同参数角色复用同一组
结果。若似然参照与采用点不同，另以相同种子计算其行为概率，检查数值排序与目标取舍。
报告真实参数、似然参照和采用点的独立训练NLL，区分有限过滤误差与生成选参的影响。

状态分别报告选择前、反馈前的预测分布，以及纳入当前选择、反馈前的过滤分布。当前反馈和
未来选择均不进入逐题过滤更新。重估参数使用整个训练前段，因此训练段内的状态属于固定
该估计参数后的回顾性重建；后段选择保持评价用途。不同过滤重复先合并当前选择的联合质量，再条件化。
Brier分数为预测概率与0/1真值之差的平方平均，数值越低表示概率误差越小；log loss为赋予
真实状态概率的负对数平均，数值越低表示真实状态获得的概率越高。同时报告逐类事件数、召回、误报、
近零真值概率、执行身份、首次识别与真实首次进入的时点。逐试次观测属于同一贯序路径，
汇总保留案例身份和过滤种子。

每人第一个采用点固定种子案例另用前两个相同种子、1024粒子检查真实参数与采用点的数值
敏感性，比较配对512粒子结果，分别记录状态与行为概率变化。这项检查用于判断有限粒子
近似的影响，参数与机制保持不变。

## 真人口述的外部内容检验

真人使用MIX、STICKY的当前点与按同一训练距离规则选择的备选点，共四组参数/模式。每组
重放两个512粒子行为过滤。当前点与已保存逐题概率精确匹配，备选点先运行无记录过滤，再
以相同种子记录状态并核对概率。记录过程不读取口述。

口述时点为选择后、反馈前。沿用既有编码和目录。作答内容由本题执行规则、选择似然及知觉
状态形成；同一类别含多个连通部件时，取距知觉刺激最近的部件，并列时均分质量。口述约束
判定容差保持为10⁻⁹。主解释为已确认的长度中点，相对解释作为统一敏感性分析。
原始文本与处理表按会话和题号一一核对。报告完整编码、片段、
缺失和不可编码的数量，并分别列出目录覆盖。主分母为全部完整编码报告，目录支持子集另列。

动态内容质量由共享读出给出，按支持、冲突、未确定三部分评分。功能支持质量累计能够推出
完整报告的规则部件概率，结构支持要求报告谓词在部件中明确出现。部件与报告约束不能同时
成立时计为冲突，其余计为未确定。报告生成概率及完整活跃集合的真值需要另外的观测模型和验证。

使用两个基准：原有的按作答类别冻结前段平均内容，以及只给定当前选择、按固定目录在规则间
均匀、在各规则该类别的连通部件间均匀分配的内容。后者使用当前选择和目录，前者保留前段
学习到的内容，帮助判断当前状态的信息增量。基准不读取评价口述拟合参数。

编码由既定程序自动完成，当前没有新增独立人工编码一致性结果。所有被试与口述均保持开发
资料标签。内容相容性、状态恢复、参数恢复及跨被试推广分别验收。

模式比较同时记录执行维持参数及其余参数。执行维持参数为0、其余参数相同时，MIX与
STICKY具有相同的边际选择规律；该边界的数值差异作为过滤近似线索。其余参数不同的两组
结果表示完整参数配置的比较，单个机制的作用按固定其余参数的设计评价。

## 有界预算与停止

12个固定种子案例，每例15点、两个128粒子初筛和32条训练生成；最多12次独立确认。状态
推断最多144个512粒子过滤，压力案例最多12个512粒子过滤，精度检查最多12个1024粒子过滤。
真人24次记录过滤，备选预检查最多12次。相同参数或既有行为结果按身份复用，保留实际数量。
每次只开一层数值工作进程、一个数值线程；最多128个准备就绪的任务。先用单人、短序列和
单工作进程检验完整流程。预算固定，稀有事件缺乏及恢复较弱均属于完整结果。

交付固定案例与真值、冻结估计、概率恢复与错误来源、数值敏感性、口述全分母及两个基准、
PNG和报告，并更新研究指引。新的认知机制继续根据状态效度及行为证据另行比较。

## 运行与复现

所有入口从仓库根目录运行。每个阶段使用新目录，前一阶段的完成记录和哈希用于绑定输入。

```bash
python -m src.Bayesian_state.workflows.analysis.model_1024_state_oral_validation --phase prepare --config configs/shared/model1024_state_oral_validation.yaml --output results/model_1024/state_oral_cases_20261025_v1
python -m src.Bayesian_state.workflows.analysis.model_1024_state_oral_validation --phase fit --prepared results/model_1024/state_oral_cases_20261025_v1 --output results/model_1024/state_oral_fit_20261025_v1
python -m src.Bayesian_state.workflows.analysis.model_1024_state_oral_validation --phase infer --prepared results/model_1024/state_oral_cases_20261025_v1 --fit results/model_1024/state_oral_fit_20261025_v1 --output results/model_1024/state_oral_inference_20261025_v1
python -m src.Bayesian_state.workflows.analysis.model_1024_state_oral_validation --phase oral --inference results/model_1024/state_oral_inference_20261025_v1 --output results/model_1024/state_oral_oral_20261025_v1
python -m src.Bayesian_state.workflows.analysis.model_1024_state_oral_summary --inference results/model_1024/state_oral_inference_20261025_v1 --oral results/model_1024/state_oral_oral_20261025_v1 --output results/model_1024/state_oral_summary_20261025_v1
python -m CategoryLearning_codes.figures.fig3.model1024_state_oral_validation --source results/model_1024/state_oral_summary_20261025_v1 --oral results/model_1024/state_oral_oral_20261025_v1 --output CategoryLearning_codes/figures/outputs/fig3/model1024_state_oral_20261025_v1
```

短流程在prepare阶段加`--smoke`，随后对其新目录运行其余阶段。短流程使用一人、128题输入、
实际前8题计算和单个工作进程；口述编码保留该被试全部文本，再对齐前8题。该结果用于检查
接口、时点、训练边界和概率一致性。正式结果另行评价。

当前状态记录覆盖规则在场、信念与执行分布，精度数值和条件3的完整配对信念恢复留待单独
检查。参数表同时保留生成值、似然参照和共同选参结果，概率表保留逐例及前后段评分。

## 本轮结果

[完整报告](../../../../results/model_1024/state_oral_report_20261025_v2/report.md)记录12条固定路径、
3条富集压力路径、1400个训练任务及146个冻结后重建任务。两参数精确恢复2/12；固定路径的
关键错误识别为真实参数38/146、重估参数36/146，后段分别为14/39及13/39。三个案例的粒子数
检查保留逐题概率变化和稳定的关键分类计数。

完整口述1768/2368条，后段动态内容在229中提供较清楚的增量。功能支持要求规则部件能够
推出整条报告；129与317的主要质量落在未确定部分。它们未获目录支持的完整后段报告大多
含躯干参照，下一轮先核对其刺激语义与编码。当前程序与选参完成，完整参数恢复、短暂在场
事件的高精度重建及独立人工编码一致性继续分别验收。图和逐类数据保留原分母及全部案例。
