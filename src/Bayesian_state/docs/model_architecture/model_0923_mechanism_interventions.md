## 1. 已实施的六个版本

配置位于`configs/shared/model0923_mechanism_interventions.yaml`。
`modules.hypo_transitions_mod.kwargs.intervention`指定一种干预，其他认知模块和行为参数保持原值。
省略该字段或指定`{kind: B}`时，执行原full-v3流程。

| 版本 | 配置 | 具体作用 |
|---|---|---|
| B | `{kind: B}` | 原full-v3基线。 |
| S_control | `{kind: S_control, factor: 4.0}` | 每题搜索赔率乘4；检验总体提高搜索机会的作用。 |
| S1 | `{kind: S1}` | 失败累计，完全成功后按原衰减参数释放累计量；检验失败历史的作用。 |
| R_control | `{kind: R_control, factor: 0.25}` | 原退出率乘0.25；检验统一延长保留的作用。 |
| R1 | `{kind: R1, window: 4}` | 最近至多4次在场反馈的规则证据之和为负时，才按原概率抽样自主退出。 |
| C1 | `{kind: C1}` | 满容量时，新候选与旧候选比较临时权重，最小者离开；新候选也可能被拒绝。 |

实验实现集中在共享的`mechanistic_rule_search.py`。S1增加一个累计失败状态，R1增加逐规则证据窗口，
二者均写入状态快照和配置签名。事件日志明确记录搜索发生、候选入场、候选拒绝、自主退出及容量移除。
实验开关仅支持`0923-full-v3`；当前用途为机制诊断，尚未接入正式机制选择流程。

### 1.1 搜索：S_control与S1

搜索概率决定本题是否提出一条新规则。基线使用有界失败平均：

\[
F_{t+1}=\rho F_t+(1-\rho)(1-f_t),\qquad
p_{t+1}=\operatorname{sigmoid}\{\operatorname{logit}(p_0)+aF_{t+1}\}.
\]

其中，\(f_t\)为第\(t\)题反馈，取0、0.5或1；\(\rho\)为失败保持参数，\(p_0\)为基础搜索概率，
\(a\)为失败增益。logit将概率转为对数赔率，sigmoid将其转回概率。
S_control在花括号内加\(\log 4\)，使赔率\(p/(1-p)\)乘4。

S1用累计失败量\(A\)替代搜索公式中的\(F\)：

\[
A_0=0,\qquad
A_{t+1}=\begin{cases}\rho A_t,&f_t=1,\\ A_t+1-f_t,&f_t<1.\end{cases}
\]

完全错误增加1，半对增加0.5，完全正确使已有累计量乘\(\rho\)。持续失败可以使搜索概率继续提高。
全局／局部提案比例仍读取原来的\(F\)，从而将此次改动限定在搜索发生率。
本轮各版本共用原结构提案、功能提案和全局提案算法。

### 1.2 保留：R_control与R1

自主退出发生在下一题作答前。R1先衡量每条在场规则对已完成反馈的支持：

\[
e_{h,t}=\log L_{h,t}-\log q(f_t),\qquad
E_{h,t}=\sum_{j\in W_{h,t}}e_{h,j}.
\]

\(L_{h,t}\)是规则\(h\)赋予实际反馈的似然，即在该规则和当时内部状态下观察到这次反馈的概率。
\(q(f_t)\)是均匀类别预测下对应反馈事件的概率。二值反馈任务有\(C\)个类别时，正确的基准为\(1/C\)，
错误的基准为\(1-1/C\)；条件3的完全正确、半对、错误基准分别为0.25、0.25、0.5。
条件3的\(L\)已按模型遗忘后的配对信念求和，保持实际记忆更新使用的定义。

\(W_{h,t}\)包含该规则本次连续在场期间最近至多4次反馈；离开后清空，重新进入时重新累计。
\(E<0\)表示这段反馈在该规则下的联合似然低于相应中性预测。R1据此设置退出概率：

\[
d_{h,t+1}=\delta(1-b^+_{h,t})\mathbf1(E_{h,t}<0).
\]

\(\delta\)为原退出率，\(b^+\)为反馈后规则信念。R_control将同一基线公式中的\(\delta\)乘0.25。
抽样之后继续执行原有的至少保留一条规则的修复步骤；容量移除按各版本的容量规则另行发生。
因此，R1直接调整的是自主退出。

实现于下一题准备阶段读取上一题已经完成、精度更新前计算的似然。当前题的选择和反馈在此时尚未发生。
诊断记录器独立地根据保存的似然重建窗口，并逐题核对R1读取的证据。所有本轮路径均执行正常反馈状态更新。

### 1.3 容量：C1

C1先按原流程抽样自主退出和新候选。集合已满时，对每条幸存旧规则\(h\)与新候选\(u\)
计算亲和性\(a_{hu}=\exp(-D_{hu}/s)\)，其中\(D\)为原功能距离，\(s\)为原支持迁移尺度。
亲和性决定旧规则向新规则转移临时信念的比例。设幸存旧规则的归一化信念为\(\gamma_h\)，则

\[
\widetilde w_h=\frac{\gamma_h}{1+a_{hu}},\qquad
\widetilde w_u=\sum_h\frac{\gamma_h a_{hu}}{1+a_{hu}}.
\]

将所有临时权重放在一起比较，移除最小者，并列时均匀抽样。
若新候选最小，则保留旧集合；若旧规则最小，则将新候选纳入最终集合。
最终信念按原full-v3的幸存集合重新归一化并分配一次。临时权重只用于决定谁离开。

C1也计算给定当前剩余集合和提案分布时的准入概率，包含新候选被拒绝及并列抽样的概率。
因此`swap_probability`记录搜索概率乘条件准入概率，`admission_event`记录实际进入，
`newcomer_rejected`记录提出后被拒绝，`capacity_dropped`只记录实际移除的旧规则。

### 2.1 R1：反馈相容的规则可以持续支持学习

206的任务相容规则后期存在率由2.3%升至86.0%，307由9.6%升至85.1%。
对应规则的自主退出总次数分别由181降至12、由70降至1。
每32题比较模型平均曲线与被试正确率，平均绝对误差分别由0.285降至0.084、由0.238降至0.098。
改善同时出现在规则保留和整段行为曲线上。

相对R_control，R1后期正确概率在206增加0.407，在307增加0.326；完整路径差值的Monte Carlo标准误
分别为0.026、0.024。预先按种子顺序分成4组、每组16条路径，两人的差值在四组中均为正。
这些标准误只衡量固定参数下有限模拟路径的波动。

错误规则收到近期净反证后的8题清除比例，206由B的95.7%变为R1的93.7%，307由45.1%变为39.3%。
相应R_control为79.3%和28.6%。R1较好保留相容规则，同时仍清除了较多受到反证的错误规则。
各版本的错误规则、驻留和反证事件构成不同，清除比例需要连同事件数阅读；它们属于过程诊断。

334也有改善，但R1相对R_control的后期差值在4组种子中有1组为负，优势还需进一步检验。
104和222的原退出率为0，R1和R_control均精确保持基线路径，这两人的不变结果符合干预定义。

### 2.2 S1：改善发现之后，保留与容量仍决定结果

215曾发现任务相容规则的路径比例由25.0%升至98.4%，后期正确概率由0.366升至0.496，
提供了继续研究搜索历史的依据。206的失败增益为0，因此S1与B精确一致。

335的曾发现比例由7.8%升至93.8%，但后期正确概率由0.320变为0.308。
相容规则的容量移除由0次增至118次；有足够观察长度的驻留中，持续至少8题的比例为15.5%。
该结果将335的问题推进到下一环节：搜索增强后，有效规则会到达，但大量候选替换破坏持续学习。
222和334同样显示更多搜索伴随更多容量移除。当前数据支持同时研究搜索与保留、容量的相互作用。

### 2.3 C1：迁移前的临时权重使新规则难以获得试用

222提出44次相容候选，仅1次获准进入；334提出289次，仅35次获准进入。
相容新候选拒绝比例分别为97.7%和87.9%。两人的自主后期正确概率均下降。

C1的临时支持完全来自旧规则。新规则与旧集合亲和性较低时，临时权重较小，容易在获得自身反馈证据前被拒绝。
本轮显示这种即时准入条件会妨碍纠正已有规则。下一版容量机制应明确新候选如何获得反馈试用，以及如何据此退出或替换。

## 3. 下一轮应修改什么

下一轮按以下顺序设计并冻结比较。本轮完成上述六个版本的模拟与诊断。

1. **保留R1作为候选机制。** 在更多已有被试上核对收益与错误规则滞留，再进入等预算重拟合。
   固定4题窗口的结果用于提出机制假设；窗口选择和参数估计需使用训练数据并记录选择过程。
2. **把候选试用与容量替换联系起来。** 新候选先获得有限的反馈观察，再比较候选对近期反馈的预测。
   重点使用222、334及搜索增强后的335检查；试用长度、同时试用数量和容量处理必须在运行前明确。
   此分支的目标是让有效新候选进入并得到检验，同时避免反复移除已得到支持的规则。
3. **在保留与容量方案明确后检验搜索强度。** 比较较温和的搜索增强与S1，并检查它们和R1的组合。
   335需要同时提高发现和长期存在；215用于检查搜索改善能否保留。
   组合实验要保留单项版本，才能区分交互作用。
4. **用预测和恢复决定最终取舍。** 各候选在相同参数搜索与数值评估预算下重拟合，保留停止状态；
   使用冻结的训练／评价边界比较选择对数评分、自主过程分布和独立口述，再检验关键参数及机制恢复。

本轮所有参数来自已有全序列拟合，7人均属于开发样本。结果说明某项机制改动在这些参数点怎样改变路径。
对被试认知特征的解释还需检查近优参数、恢复结果及独立过程证据。新增机制尚未经过等预算重拟合或留出验收。

## 4. 指标、路径和计算边界

任务相容规则在完整物理刺激序列上的几何分类准确率阈值固定为0.8，使用已有诊断目录。
真实类别仅用于生成任务反馈和事后评分。模型沿真实刺激序列自主作答，后续反馈由自己的回答产生。
本轮没有使用被试回答重加权或筛选自主路径。

所有64条完整路径均在逐人图中保留，按连续32题取均值显示；粗线是等权平均，黑线是被试实际正确率。
后期取最后64题。另输出每32题实际正确率在模拟作答80%区间中的覆盖、区间宽度及曲线均值误差。
这些指标描述当前固定刺激序列下的表现，相关时间块的覆盖比例仅作描述性检查。

相容规则连续存在至少8题计为保留；不足8题观察的末尾驻留单列删失。
错误规则清除从每段驻留第一次近期净证据为负开始，要求后面有完整8次转换机会，
并统计这8次转换内是否离开。它包含自主退出与容量移除。原始事件表保留规则、路径、时点和删失状态。

共同种子来自已保存的64条基线路径，路径顺序固定。机制分叉后随机抽样数量可能不同，
共同种子保留完整路径的配对关系，逐题随机事件可随分叉改变。
`comparisons.csv`对同种子的整条路径指标作差，并输出均值与Monte Carlo标准误；
`batch_comparisons.csv`保留4组各16条路径的差值。未计算被试总体效应或显著性检验。

计算只替换原拟合源码中的规则转换类，其余认知模块从校验过的源码快照执行。
替换发生在独立进程内；原快照、原结果和原数据均保留。基线使用新类的B配置，
与此前独立保存的448条稀疏状态轨迹逐项精确比较，包括规则、概率、选择、反馈和事件。
R1另按记录的反馈似然逐题重建证据窗口，验证因果时点。

本轮启动336个路径分块任务，最多128个工作进程，每个数值库线程数为1，使用单层进程并行。
模拟总时长109.4秒，记录到的路径计算累计CPU时间6092.3秒；后者不包括进程导入和准备开销。
完成较快的任务立即释放进程名额，末尾并发数随剩余任务减少。实际线程池信息写入逐任务校验文件。
