## 1. 本轮如何使用数据和参数

规则目录检查覆盖上一轮全部九人：107、108、109、205、207、208、305、306、308。
过程干预集中于207、208、308：前一轮已分别观察到状态维持不足、搜索充分而表现仍偏低、
以及后期学习转折难以生成的问题。这三人本轮均作为开发资料。

每人保留上一轮三套完整参数：独立保持率FREE、持续累积CUMULATIVE、共享记忆保持率SHARED。
同一套参数内的干预只改变指定操作。三套参数之间的差异同时包含其他拟合参数的变化。
本轮参数固定，原来的训练选择负对数似然（NLL）估计目标保持不变。
NLL将模型分给真实回答的概率取负对数后汇总；数值越低，真实回答序列在模型下的概率越高。

所有路径从任务起点自主生成，回答产生对应任务反馈，后续学习使用模型自己的回答和反馈。
干预从原训练边界后的第一题开始：207第673题、208第385题、308第609题。
各干预在此之前的选择、状态和预测必须逐值一致。
这组实验的起点状态来自自主生成；前一轮从滤波训练末状态续跑的结果另行保留。

规则身份由训练段物理刺激与任务类别确定，被试选择仅在后续评分时读取。
提供正确规则使用了任务答案，属于带有额外信息的诊断干预。
它估计特定环节被改善后的可能影响，正式候选机制仍须仅依赖被试当时可获得的信息。
全部生成沿用被试实际刺激顺序，完整自适应任务的刺激安排和停止过程仍待检验。

每组使用原自主评价记录中的前128个种子，取法在本轮结果生成前固定。
共生成8064条诊断路径；另生成1152条候选重放路径，检查重放是否精确保持原结果。
后续精度读出审计再精确复现1152条ONLY路径。
主实验与读出审计合计约7.12 CPU小时，单层进程并行，上限128个工作进程，每进程一个数值线程。

## 2. 规则空间能够表达已记录的分类

逐条规则对物理刺激计算类别概率，将最大概率类别作为分类结果。
并列最大时，各类别平分正确率贡献。检查采用β=100，以评估规则的几何分类。
先在训练刺激上选择分类全部正确的规则，再核对剩余刺激。

九人各有一条训练分类全对的规则，该规则对各自剩余刺激也全部分类正确。
目录采用从零开始的编号：条件1为规则0；条件2、3为规则42。
规则42先按维度0的0.5阈值分支，再分别按维度1或维度2的0.5阈值细分为四类。
其完整结构与每条规则的训练、后续和全程正确率保存在每人的`catalog.csv`。

这项结论覆盖已记录的物理刺激。带知觉噪声的作答概率、有限β下的作答概率，
以及全部可能任务输入的形式证明具有各自的检验范围。

## 3. 七种对照具体改变什么

| 对照 | 干预操作 | 用途 |
|---|---|---|
| BASE | 原方案自主生成 | 提供基准路径和候选记录 |
| ONCE | 干预当题使正确规则进入集合；已存在则继续保留当题；后续按原机制运行 | 检查一次发现正确规则的作用 |
| ONCE_EQUAL | 在ONCE基础上，当题将集合内规则先验设为均匀 | 检查初始信念分配是否限制效果 |
| KEEP | 在ONCE基础上，后续每题保护正确规则的集合成员资格 | 检查持续保留的额外作用 |
| KEEP_EQUAL | KEEP加当题均匀先验 | 检查保留与初始信念的配合 |
| ONLY | 从干预当题起，集合仅含正确规则，先验和作答贡献均为1 | 检查消除规则竞争后的剩余误差 |
| REJECT | 干预后重放BASE候选时点与身份，满容量时将新规则加入移除比较 | 检查一个具体的允许拒绝方案 |

ONCE和KEEP沿用现有亲和度信念分配。亲和度由规则的功能距离决定，新规则从保留规则分得信念。
KEEP若需要恢复刚被移除的正确规则，先恢复其成员资格；超过容量时，移除其余成员中平均证据最低者。
该额外保护使用正确规则身份，只用于诊断。所有保护事件均单独记录。
EQUAL的均匀操作仅发生一次，后续继续使用原记忆更新、惯性和连续作答贡献。
ONLY保持知觉、反馈学习、β更新和条件3配对学习的既有操作。

REJECT沿用原自主退出和证据计算。集合满时，旧规则使用累计证据除以有效暴露量所得的平均证据；
新规则以零证据加入同一次比较。最低者被移除，并列时随机选择。
若新规则最低，该次候选被拒绝。该规则属于一个明确的准入假设：未经历反馈的新规则从零分开始。

重放记录保存每题候选身份和转移随机数状态。每条BASE路径用相同记录再运行一次，
选择、预测、规则集合、贡献、提议和移除事件均逐值复现。
REJECT发生分歧后继续使用BASE的候选时点和身份，其自身选择与反馈可以改变。
若记录中的候选在该题转移前已处于集合中，记录为“已在集合”，沿用现有排除旧候选的约定。
这一对照固定了外部候选机会；使用状态变化后产生的自然候选序列，还需单独检验。

### 207：发现与保留均有限制

FREE的128条基准路径中，只有17.19%在干预前曾纳入正确规则，28.13%在全程曾纳入。
末128题中，正确规则平均仅在8.67%的路径与试次组合里存在。
提供一次正确规则后，末段正确率提高15.74个百分点，配对模拟标准误为1.72个百分点。
持续保护在ONCE之上再提高16.00个百分点，配对模拟标准误为1.42个百分点。

FREE中，ONCE提供后的首段连续保留平均观察到172.02题，39.06%的路径一直保留至记录结束；
完整后续观察窗口为288题。CUMULATIVE和SHARED对应的持续至结束比例为88.28%和94.53%。
这里把记录结束视为右删失：该时点之后是否继续保留尚无观察。
原FREE参数中的证据保持率为0，其基准路径全程记录到26次正确规则自主退出和4次容量移除。
这些事件数来自128条模拟路径，描述该参数组合下的过程。

### 308：共享方案主要受发现限制

SHARED基准路径中，14.84%在干预前曾纳入正确规则，全程比例为21.88%。
提供一次正确规则后，末段正确率由52.81%升至73.33%，改善20.53个百分点，
配对模拟标准误为1.29个百分点。全部128条ONCE路径均把正确规则保留至记录结束，
额外持续保护得到相同末段表现。该组合的主要H缺口落在发现环节。

FREE提供规则后也能持续保留，但正确规则末段平均作答贡献为45.71%，其自身平均正确概率为61.31%。
SHARED的对应值为90.92%和74.57%。因此，发现相同规则后，整套参数仍会产生不同的使用与读出表现。

### 208：已有规则仍受其他环节限制

FREE在全部128条基准路径的干预前均已纳入正确规则，末段成员资格比例为100%，
作答贡献为85.94%。提供与保护正确规则得到相同正确率；将其贡献固定为1，
末段正确率只从69.75%升至72.90%。该组合需要优先解释正确规则自身的作答概率。

CUMULATIVE存在容量竞争问题：基准路径全程记录到1671次正确规则容量移除和183次自主退出，
末段成员资格比例为56.76%。持续保护将末段正确率提高5.18个百分点，配对模拟标准误为0.60个百分点。
这一结果说明同一被试的不同参数方案可以产生不同的内部失败过程。

### 初始信念和零证据准入的结果

207 FREE在ONCE当题分给正确规则的先验中位数约为\(7.33\times10^{-23}\)。
将当题先验改为均匀后，其末段正确率改变−0.31个百分点，配对模拟标准误为0.48个百分点。
当前记忆更新会在后续试次改变各规则的相对信念，因此极小的入集先验对长程表现的影响需要结合后续更新理解。
九组组合中，ONCE_EQUAL相对ONCE的末段均值变化均小于0.5个百分点。
本轮结果降低了“只调整一次入集权重”作为主要修复方向的优先级；首区块变化仍保存在逐区块源表中。

REJECT使九组中的八组末段正确率下降，另一组改善0.06个百分点。
以208 CUMULATIVE为例，每条路径干预后平均拒绝181.95次候选；
正确规则平均被提议4.05次，其中3.96次被拒绝。
308 FREE和CUMULATIVE也会拒绝部分正确规则候选。
零证据新规则与已积累正证据的旧规则直接比较，容易阻碍探索。
这个结果评价的是本轮明确实现的零分准入规则；其他准入评分需要独立对照。

## 5. 正确规则自身为什么仍然不够准确

ONLY使后续每题的规则身份与贡献确定。其末128题正确率仍为61.88%—75.03%。
随后对这1152条路径全部重放，在每题原有已学习β和知觉刺激上做额外读出计算。
额外计算只输出概率，后续状态与反馈沿用原ONLY路径。

β表示规则精度：β较大时，类别概率更集中于规则几何上更支持的类别。
下表固定同一规则与同一批末段刺激，列出平均正确作答概率。
“物理刺激”列保留原路径学到的β，只将当前知觉输入换为对应物理值；
固定β的两列保留原知觉输入。

|---|---:|---:|---:|---:|

固定β的计算仅重算既定状态下的读出概率；修改后模型的完整生成正确率须通过重新生成反馈与学习路径检验。
知觉输入替换只评估既定状态下的即时作用；知觉噪声对早期规则发现、配对和β学习的累积影响另有检验范围。

## 6. 对下一版机制设计的具体约束

本轮支持把下一版原型分为三个相互配合的改动方向：

1. **先提高候选生成的信息利用。** 保留结构与功能邻近关系作为基础提议分布，
   增加使用已完成反馈评价候选的对照。第一版仅使用上一题的知觉刺激、模型回答及任务反馈，
   以候选规则的反馈似然调整其被提议概率；反馈似然是该规则给已发生反馈的概率。
   条件3按当前可用的反应配对分布对反馈似然加权求和。
   这可以直接检验：相同搜索次数下，正确规则能否更早、更频繁地出现。
   候选目录和搜索频率先保持固定，使改动作用可定位。
2. **把新规则的可检验证据接入准入与保留。** 零分新候选与旧规则平均证据直接竞争的方案已完成检验，
   其表现降低了采用该具体方案的优先级。下一对照应为新候选提供基于已完成反馈的证据评价，
   再比较强制入集与可拒绝入集。旧规则使用连续积累证据控制保留；持续累积和共享保持率继续作为对照。
   每次退出和替换均记录证据、暴露量和新旧规则身份，以检查有支持的规则是否被短暂波动移除。
3. **同步检验β学习与最终作答概率。** 先在固定正确规则的简化条件下比较当前更新与更快达到稳定精度的候选更新，
   并核对β范围。之后把保留下来的β方案接回完整H机制。
   验收需同时覆盖低正确率时期、学习转折和后期表现，避免仅凭后期正确率选择精度设置。

相应的原型流程为：已完成反馈更新旧规则证据；判断搜索；生成并评价候选；
依据新旧规则证据决定集合成员；对最终集合进行一次信念分配；由规则精度和作答贡献产生下一题回答。
该流程是下一轮待检验的原型设计。本轮实施了诊断工具，正式认知模型与默认配置保持原状态。

后续正式比较继续以训练选择NLL估计个体参数，冻结参数后评价后续选择概率、自主曲线分布及内部过程。
本轮提供的是修改方向和可排查的失败过程。H最终结构、个体参数解释与迁移能力，
仍需要等预算重拟合、未参与设计的数据、参数恢复和完整自适应任务检验共同支持。

## 7. 评分、复现与验证
