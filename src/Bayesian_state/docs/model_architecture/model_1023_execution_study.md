# Model 1023：持续执行与信念学习的比较

日期：2026-10-24。状态：63项检查、九名被试的行为比较、状态重放及口述检验已完成；30个模拟案例的正式恢复拟合正在运行。

本研究检验规则信念与实际执行之间是否需要一个持续执行状态。基础模型见
[Model 1023](model_1023.tex)。当前文档记录新增候选、比较协议和实施进展。

## 认知机制

规则信念 $\pi_t(h)$ 表示活跃集合内各规则的相对可信度。执行状态 $e_t$ 表示本题采用的规则。
每位被试有一个执行维持参数 $\kappa_s\geq0$，在一次拟合的整段试次内固定。
规则身份随试次变化，维持参数控制已有执行方式在下一题的延续倾向。
在一条具体的模型路径中，每题执行一个规则。拟合时汇总多条潜在路径，
得到研究者对选择的预测概率及对执行身份的不确定性。

本题按执行规则的类别预测生成选择：

$$P(y_t=c\mid S_t,e_t,\widetilde{\boldsymbol x}_t)=p_{t,e_t}(c).$$

其中 $t$ 是试次，$y_t$ 是作答类别，$c$ 是一个候选类别，$S_t$ 汇集当前活跃规则、信念、
精度及配对知识，$\widetilde{\boldsymbol x}_t$ 是知觉后的内部刺激。
$p_{t,h}$ 由内部刺激到规则类别区域的距离及规则精度决定。
全部活跃规则继续接收本题反馈，更新信念、精度和条件3的配对知识。
搜索、容量替换和新规则继承完成后，按下一状态的信念选择下一题的执行规则：

$$
P(e_{t+1}=h\mid e_t,\pi_{t+1},\mathcal A_{t+1})=
\frac{\pi_{t+1}(h)\exp[\kappa_s\mathbf1(h=e_t)]}
{\sum_{v\in\mathcal A_{t+1}}\pi_{t+1}(v)\exp[\kappa_s\mathbf1(v=e_t)]}.
$$

这里 $\mathcal A_{t+1}$ 是下一题的活跃规则集合，$s$ 表示被试。
指示函数 $\mathbf1$ 在规则与上题执行身份一致时取1。乘以 $e^{\kappa_s}$ 后归一化，
使已有执行方式获得更高的延续概率。信念仍决定各备选规则的相对吸引力。
执行规则被容量机制移除时，候选中所有指示函数均为零，下一执行规则直接按新信念抽取。
执行规则适用与其他规则相同的容量替换规定。

首题只有一条活跃规则，执行该规则。每次执行选择发生在本题刺激判断和反馈之前。
规则进入、信念达到较高水平、实际开始执行是三个分别记录的时点。
主动执行切换与规则被移除后发生的强制切换分别统计。

例如，活跃集合只有两条规则，当前执行规则的信念为0.2，另一条为0.8，且 $\kappa_s=2$。
在信念与活跃集合暂时不变的条件下，继续执行原规则的概率约为0.65。
一旦切换到信念为0.8的规则，下一题继续执行它的概率约为0.97。
这个例子说明，较高的规则信念可以先于稳定执行出现；切换后的维持倾向可以形成较突然的行为改善。
实际数据中是否存在这种过程，由行为比较和恢复检验共同判断。

$\kappa_s=0$ 时，每题按信念独立选择执行规则。积分掉执行身份后，选择分布等于基础模型的
信念加权预测；全部规则继续学习，使该等价关系延伸到完整行为序列。
有限粒子数下，两种计算方式可以有不同的蒙特卡洛误差。规则在场、信念和执行均由行为推断，
其可辨识范围通过恢复检验确定。

## 三个比较模型

| 标记 | 选择机制 | 个体参数数目：条件1/2；条件3 |
|---|---|---|
| MIX | 规则信念加权混合类别预测 | 8；9 |
| MAP | 使用信念最高的规则，并列时等概率抽取 | 8；9 |
| STICKY | 根据信念和上一执行身份选择规则，再按该规则作答 | 9；10 |

三个模型共用规则目录、知觉、反馈似然、反馈调节保持、精度学习、搜索、容量及继承。
MAP的并列选择采用均匀抽样，使该对照在并列时具有明确定义。
STICKY增加的参数初始搜索范围为 $\{0,0.5,1,2,3,4,6,8\}$。
参数边界上的候选、相近似然候选与新增参数的恢复情况均保留。

## 参数估计与行为评价

每位被试按原有约70%、对齐32题边界的时间顺序划分训练和后段评价。三种机制分别拟合，
保留共同的基础参数范围与起点设计。已有被试的训练估计作为共同起点；新增被试使用参数空间
中点与分层起点。STICKY的起点同时覆盖执行维持参数。

先对每个模型运行40个起点，再运行两轮各32个新候选的联合细化。
每个模型使用相同的12个候选确认名额，包含本模型的最佳起点、最佳细化点、共同训练起点
及其他模型的参数投影。独立滤波种子确认候选后，按训练段负对数似然选择参数。
负对数似然衡量模型赋给实际选择的概率，数值越小表示这些选择越符合模型预测。
正式流程把前段估计和后段评价分开；
本次已查看行为的案例均按开发资料解释。
当前比较首先使用共同的训练似然目标。训练自主生成选参若后续加入，将作为单独登记的分析，
与仅按训练似然选参的结果分别保留。

初筛及细化采用每点两次128粒子滤波，确认采用六次512粒子滤波。
参数冻结后，用另外八次1024粒子滤波评价条件预测，并从任务起点生成128条完整自主路径。
随机种子按阶段和被试固定，三种机制使用配对种子。自主生成中的反馈由模拟选择和实验评分
规则共同产生，全部路径参与评价。
初筛和确认阶段另汇总MIX与零维持STICKY的全部同参数、同种子匹配点。
这些点的理论预测相同，数值差异用于检查粒子近似对机制比较的影响。
每次滤波还核对执行、反馈和保持更新的记录次数，确认所声明的机制实际参与了全部试次。

确认名单中，108和309的STICKY候选均为 $\kappa=0$。在高精度确认结束前，另登记了两人的
条件参数检验，用于检查初筛是否漏掉有用的非零取值。其他参数固定在MIX的训练段估计点，
使用六个新配对种子和512粒子，分别评价全部八个已登记维持参数及同点MIX参照，共108次滤波。
评分只使用原训练段，结果作为固定其他参数时的条件似然曲线单独报告。
配置与登记文件记录了按候选名单选择这两人的依据。

主要行为评价同时包括逐题选择似然和完整路径的行为分布评分。32题正确率与类别条件反应频率
沿用既有特征和Energy评分；该评分综合真实路径与生成路径的距离及生成路径之间的距离，
评价整个生成分布，数值越小表示越贴近观察到的行为特征。补充指标记录相邻32题窗口的提升幅度、
提升后的保持及128题低表现窗口。类别条件反应频率描述各类别中重复出现的正确与错误作答模式。
模型自主路径使用相同的统计步骤。
指标的极值及发生时间均由整个路径决定，观察到的最佳窗口按探索性描述解释。
改善后的保持以紧接提升窗口的下一个完整32题窗口评价。路径结尾无法容纳该窗口时，
记录为随访不足，并保留可评价路径数。条件3另列平均反馈得分；均匀作答下其期望为0.375。
最低正确率窗口还记录类别比例与反应比例独立时的期望正确率：将每一类别的出现比例与
对应作答比例相乘后相加。该描述性对照用于检查类别不平衡及反应偏好是否影响低表现，
原有均匀猜测基准和窗口筛选保持原定义。

## 恢复与外部检验

模型恢复分别从MIX、MAP和不同维持强度的STICKY生成行为，再交叉拟合各模型。
第一轮使用108、205、306的任务序列和既有训练参数；每种任务分别从MIX、MAP及
$\kappa=0,2,6$的STICKY生成两条固定种子路径，共30条，每条最多384题。
各路径按约70%的前段重新估计全部参数，冻结后评价后段。恢复采用24个独立起点、
一轮16个新候选和每模型6个确认名额。确认使用4次256粒子滤波，评价使用4次512粒子滤波。
每个生成点两条路径用于初步检查可辨识范围；该数量提供的模型恢复比例精度有限。
MIX与STICKY的$\kappa=0$边界具有相同的边缘行为分布，模型恢复按该等价关系解释。
参数恢复检查执行维持与信念保持、精度及搜索之间的补偿，记录真值处的似然与独立估计处的似然。
生成参数在拟合完成前独立保存，恢复起点依据参数范围生成。

生成路径保存活跃规则、信念、精度、执行身份及切换原因。状态恢复从行为重建活跃规则、
规则信念和执行身份的分布，并比较首次进入、获得较高信念与执行开始的检测时点。
恢复评分检查单纯信念变化被归入执行滞后的频率。解释结果时，结合零维持边界的行为等价关系，
以及规则预测相同或规则信念很低时的区分困难。
当前检验采用在线过滤。每个生成点先在真参数处重建状态，再在重新估计的参数处重建状态，
两者的差异用于评价参数估计对状态推断的影响。两种重建均包含有限粒子误差，
零维持边界另用相同参数和配对种子检验等价模型的数值差异。
参数表保留真值、估计值、范围缩放误差、离散网格步数及触边情况。

当前状态捕获保存两种分布：预测分布只使用前面各题的选择；条件分布进一步使用本题选择。
二者均在给定冻结参数的条件下计算，并在本题反馈前记录。个体参数由整个训练段估计，
所以训练段的状态属于拟合后的回顾性重建；后段使用冻结参数逐题更新状态。
正确规则集合包含所有在训练刺激上完全符合任务分类的规则。
对一次错误选择，将其证据分为正确规则缺席、正确规则在场但其他规则贡献作答、
正确规则贡献作答三项；三项概率之和为1。MIX中的贡献是规则混合权重，单规则模型中的
贡献由执行身份决定。给定行为后的状态分布仍可分散，表示研究者对潜在路径的推断不确定性。
执行滞后使用联合事件定义：正确规则在场、其信念至少为0.5，同时执行其他规则。
该事件包含两条规则各占0.5时的并列选择，MAP也可出现。因此，事件概率与维持参数的
机制证据分别评价，后者结合模型比较和恢复检验判断。
该概率直接从每条潜在路径计算，再按路径权重汇总。恢复评价记录Brier误差，即预测概率与
真实状态指示值之间的平均平方误差，同时记录对数评分、
真事件次数、误报和漏报；高置信误报采用0.8阈值。首次边缘概率达到0.5的试次表示检测时点，
并分别记录真实事件未发生与事件未检出。三类实际错误来源和精确执行身份的恢复仅对具有
离散执行真值的生成模型评分。MIX与零维持STICKY用于检查缺少持续执行机制时的误归因。
状态估计以冻结的个体参数为条件，当前结果尚未积分参数估计的不确定性。

口述用于检查选择之后、反馈之前的作答依据。单规则模型的口述预测依据各潜在路径中的实际
执行规则及其局部判断，研究者再按路径权重汇总。口述编码、参照歧义与目录覆盖保持原有定义，
口述内容不参与参数拟合。
口述检验预先固定中点参照与相对参照两种解释，保留全部可完整编码报告作为共同分母，
另列规则目录覆盖的报告子集。每个模型先捕获两次独立滤波，以评价数值波动。
评分表示报告内容与推断作答依据的相容程度；口述生成概率需要另行定义语言表达模型。
