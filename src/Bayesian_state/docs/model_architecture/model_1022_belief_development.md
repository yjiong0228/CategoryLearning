# 规则信念模型的持续开发

本任务由 2026-10-23 的持续改进请求启动。核心约束是用归一化规则信念组织模型，保留感知、
反馈与配对学习、精度学习、失败积累、局部与全局搜索、容量替换和继承。开发目标是使选择预测
与自主学习表现达到支持版相近或更好的水平。所有候选和失败结果均保留。

## 起点与需要区分的问题

[首次信念对照](model_1022_belief_comparison.md)已经分别拟合两版。108、205、306 的后段
每题选择负对数似然（NLL）差值分别为 +0.03795、+0.01358、+0.05420；正值表示信念版较差。
306 的信念版自主后段正确率为 0.624，支持版为 0.781。该轮每版仅有 12 个起点和 8 个新增
细化候选，参数搜索的覆盖有限。

这组结果包含两个变化：规则状态及其入场分配改变，拟合参数也改变。例如，306 的基础搜索概率
从支持版的 0.35 变为信念版的 0.05，精度学习率从 0.1 变为 0.003。因此，首先用固定参数交换
区分机制效应和参数效应，再决定后续修改。

## 第一阶段：固定参数交换

对每位开发被试完成以下四个组合：

| 计算机制 | 使用支持版已选参数 | 使用信念版已选参数 |
|---|---|---|
| SUPPORT | 参照组合 | 检查参数变化的影响 |
| BELIEF | 检查机制变化的影响 | 复核首次信念组合 |

三人沿用原训练／后段边界。四个组合使用相同滤波种子和自主路径种子；每个组合使用
256 粒子、4 次滤波，并生成 64 条完整自主路径。选择预测读取此前真实反馈，自主路径读取自身
选择产生的反馈。参数在计算之前固定。本阶段不估参，结果用于开发诊断。

输出保存四个组合的训练及后段 NLL、自主行为 Energy、正确率、目标规则在场比例、作答贡献、
在场时精度、搜索频率和被替换次数。Energy 沿用首次对照的行为特征及权重。差值的模拟标准误
按完整滤波重复或完整自主路径计算，只描述数值模拟的不确定性。

## 首个机制候选：替换时转移信念份额

首次信念版规定，每条新规则获得最终活跃集合的均匀份额。如果容量为 3，旧规则的后验信念为
0.90、0.09、0.01，移除最后一条后，新规则获得约 0.333，两条幸存规则分别得到约 0.606、0.061。
这一先验分配给新规则明确的试用机会，也会降低已经可信的规则对当前回答的影响。

新增的 SLOT 候选在容量满时让新规则接替被移除规则的概率质量。设被移除规则为 $d$，
新规则为 $u$，反馈后的规则信念为 $\pi_t^+$。下一题先验为

$$
\pi_{t+1}(h)=\pi_t^+(h)\quad(h\text{ 为幸存规则}),\qquad
\pi_{t+1}(u)=\pi_t^+(d).
$$

原例变为 0.90、0.09、0.01，最后一个数现在属于新规则。该分配保持幸存规则的信念及总概率，
把被移除候选占用的可信度交给新候选。它表达一个待检验的假设：被试尝试另一个备选解释时，
已有解释的可信度可以暂时保持。新规则随后按实际反馈更新自己的信念。

工作区尚未满时，继续使用均匀入场份额。规则选择、配对学习、搜索、替换对象和精度继承沿用
BELIEF。该候选没有新增参数或累计状态。若被移除规则的信念恰为零，新规则也获得零信念；
保持率大于零时，后续乘法更新会保留这个零值。这是需要在数值及行为检查中记录的边界情况。

## 后续比较与停止判断

下一轮对 SUPPORT、BELIEF 和 SLOT 使用共同参数范围与起点，分别优化训练选择似然。
共同起点纳入此前两版的训练估计，候选确认使用独立种子。单次固定参数的收益只用于诊断；
机制结论以重新估参后的结果为依据。若条件 3 仍有明显差距，再单独检查规则与配对信念的联合
更新，并在计算前记录该候选的方程、改变范围和预算。

下一轮的[配置](../../../../configs/shared/model1022_belief_refinement.yaml)已固定：每版每人
24 个共同起点，包含此前两版及原完整支持版的训练估计；两轮各提出 20 个新候选，并复核
2 个领先点。提案包含邻近单参数移动、跨范围单参数改变和双参数联合改变。
初筛与细化使用 128 粒子、2 个种子。三版初筛及最后细化的首位候选与已有训练估计合并，
每版在共同确认集合中用 512 粒子、4 个新种子独立选参。参数冻结后，用 512 粒子、
6 个新种子评价完整序列，并各生成 128 条自主路径。

```bash
python -m src.Bayesian_state.workflows.analysis.model_1022_belief_comparison \
  --config configs/shared/model1022_belief_refinement.yaml \
  --output results/model_1022/belief_refinement_20261023_v1
```

三版共用参数范围与本轮预算。支持版已经有较多历史估参，历史计算投入仍有差异。运行保存
全部候选及来源、源代码与配置快照；确认和评价阶段使用不同的种子。汇总表的 `arm` 字段区分
BELIEF 和 SLOT 相对 SUPPORT 的差值。

“相近”采用开发阶段的工作容忍值：每位被试的后段 NLL 增量不超过 0.02，Energy 增量不超过
0.03，并检查差值加两倍模拟标准误是否仍在该范围内。这两个值沿用已有模型开发中的实用量级，
用于安排下一步计算；它们不构成正式的统计等效性检验。三人逐一报告，保留个体代价。真实行为、
完整模拟路径分布和内部规则过程共同决定解释，训练分数改善本身不足以完成任务。

108、205、306 及其后段已参与模型开发。方案确定后再在 110、209、309 上按冻结流程重新估参和
评价，并检查可覆盖的口述报告。这三人的既往开发影响尚未确定，因此称为扩展检查。口述仅用于
检验预测。样本范围、口述覆盖限制和所有未通过项目随结果交付。

当前进展：固定参数交换、三版独立拟合及完整行为评价已完成。SLOT 的三种反馈条件概率守恒、
配对和精度继承、状态恢复检查均通过。条件 3 的表现仍需改善，扩展检查暂缓。

本轮验证覆盖 34 项相关测试，包含各版模块恢复、状态续跑、后验概率、配对和精度继承、

每组合 4 次 256 粒子滤波与 64 条自主路径。短序列结果只用于检查执行流程。
