本诊断使用335和307的已有拟合参数，追踪规则从进入候选集合到影响回答的过程。
输入为原有真实历史等权路径、自主轨迹、模型源码快照和参数；输出为完整驻留记录、

本诊断用两种方式定义关注规则。第一种取A的后期作答贡献最大规则作为事后参考。
第二种根据实验任务筛选：在完整物理刺激序列上计算每条规则的类别概率，固定精度为1，
以最大概率类别分类，并列最大类别平分正确计分。几何分类准确率达到0.8的规则列为任务相容规则。
这项评分考察规则的分类结构；实际路径中的知觉误差和精度仍影响其作答概率。
两个被试的152条规则中，第二种定义均只选中R42，其几何准确率为1；第一种定义也选中R42。
两种选择本次重合。它们用于事后定位，真实类别没有进入模型的反馈前认知更新。

## 2. 335：有效规则的到达很少

| 量 | B：512条路径 | C：64条路径 |
|---|---:|---:|
| 曾考虑R42的路径 | 30/512，5.9% | 5/64，7.8% |
| 每条路径的新规则提出次数 | 4.80 | 7.05 |
| 后期R42包含率 | 3.14% | 3.13% |
| 持续至少8题的驻留 / 有足够后续记录的驻留 | 28/30，93.3% | 5/5，100% |
| R42自主退出 / 容量移除 / 末尾删失 | 12 / 0 / 18 | 3 / 0 / 2 |

“后期包含率”以路径试次为单位：最后64题中，R42处于候选集合的路径试次数除以
路径数乘64。“曾考虑”以整条路径为单位，两者分母和含义不同。
驻留指一次连续处于候选集合的过程，离开后重新进入记为新的驻留。
末尾删失表示记录结束时仍在候选集合，后续离开时间未知。

335的B四个种子中，曾考虑R42的比例为3.9%–7.0%。C只有5段R42驻留，
其保留比例的解释范围受到事件数限制。两种信息条件都显示，大多数路径在整段记录中未考虑R42。
当前低搜索参数与有限提出次数共同形成这一现象；本次尚未区分参数选择和提案分布各自的作用。

当后期R42仍在候选集合中，B/C的平均作答贡献分别为0.858/0.771；
R42自身的平均正确概率分别为0.736/0.736。335的主导惯性为0，信念与作答贡献逐项一致。
这说明少数已到达的路径可以让R42影响作答。该规则的实际正确概率同时受到知觉和精度影响，
因此“进入规则”与“产生接近被试的正确率”仍是两个需要分别检查的环节。

## 3. 307：规则到达后持续保留不足

| 量 | B：512条路径 | C：64条路径 |
|---|---:|---:|
| 曾考虑R42的路径 | 208/512，40.6% | 44/64，68.8% |
| 每条路径的新规则提出次数 | 41.90 | 93.19 |
| 后期R42包含率 | 4.85% | 9.57% |
| 持续至少8题的驻留 / 有足够后续记录的驻留 | 212/311，68.2% | 57/74，77.0% |
| R42自主退出 / 容量移除 / 末尾删失 | 287 / 0 / 25 | 70 / 0 / 5 |
| 已结束驻留的长度中位数 | 14题 | 29题 |

307的B四个种子中，曾考虑R42的比例为35.2%–46.9%。C的75段驻留由44条曾到达路径产生，
表明一部分路径重复进入同一规则。全部记录到的R42移除来自自主退出，容量移除为0。
已结束驻留的中位数仅概括观察到的离开事件；25段B驻留和5段C驻留的后续长度未知，分别保留删失标记。

退出发生在下一题选择前。将每次退出与上一题反馈后的状态对应，得到：

| 退出前状态 | B：287次退出 | C：70次退出 |
|---|---:|---:|
| 反馈后R42信念至少为0.5 | 131 | 38 |
| 上一题R42作答贡献至少为0.5 | 170 | 47 |
| 本次反馈提高R42相对支持 | 204 | 50 |
| 上一题反馈为完全正确 | 170 | 40 |

“提高相对支持”指反馈后规则概率高于同题遗忘后、加入反馈前的规则概率。
模型先遗忘规则与条件配对信念，再按反馈似然更新；该比较分开反馈证据与遗忘的影响。
原反馈为完全正确描述整条路径的回答结果；R42对这次反馈的相容性由规则层面的证据计算。
这些条件可能重叠，表中各行不相加。

现有退出概率随规则反馈后信念降低而提高，其形式为

\[
d_{h,t+1}=\delta\left(1-b^+_{h,t}\right).
\]

其中，\(d_{h,t+1}\) 是规则\(h\)在下一题的退出抽样概率，\(\delta\)为退出率参数，
\(b^+_{h,t}\)为本题反馈后的规则信念。307的\(\delta=0.1\)，
例如信念为0.5时退出抽样概率为0.05。随后还有保留至少一条规则的修复步骤。
这个关系允许已经得到支持的规则在长序列中离开，实际事件表确认了这种离开。
本次记录提供了检验退出机制的具体依据；它尚未证明某种替代机制优于当前设计。

后期R42仍可用时，B/C的平均作答贡献为0.919/0.931，规则自身的正确概率为0.765/0.777。
这些条件均值表明保留路径中的读出能够较强地使用R42。
相应分母为1588/392个路径试次，来自少量仍保留该规则的路径，存在明确的存活条件。

## 4. 下一项机制假设与验收

优先提出一个针对307的修订假设：**规则的持续保留随其对近期反馈的相容性调整；
持续的规则特异反证提高退出概率，相容证据支持继续保留。**
反证表示某条规则赋予实际反馈的概率较低。条件3的三种反馈具有不同的基准概率，
反证计算应按对应反馈事件校准，并使用模型当时的配对信念。
具体累计方式及其参数化在实施对照前确定，本次未修改退出公式。

下一轮比较保留三类模型：当前退出机制、只改变整体退出率的对照、使用规则反馈相容性的退出机制。
整体退出率对照用于检查收益是否仅来自更慢的候选移除。各模型保持同一规则目录、知觉、
任务反馈、计分时点及其余模块定义；正式比较时各自重新拟合参数。

验收按以下证据分别进行：

1. **选择预测。** 在预先划定的留出序列上比较完整类别选择NLL，并检查模型差异相对独立数值重复的稳定性。
   评价段的选择只在发生后参与后续状态推断，评价结果不参与参数选择。
2. **有效规则保留。** 在固定参数的机制诊断中，比较已有支持之后的退出、持续驻留及后期可用程度。
   同时统计收到持续反证的错误规则清除时间，检查新机制是否导致错误规则长期滞留。
3. **自主过程。** 比较掌握比例、达到掌握的时间、连续错误及掌握后退步的分布。
   完整任务结论需要真实的停止及自适应刺激安排；固定刺激序列先提供相应条件下的诊断。
4. **可辨认性。** 对拟解释的退出、证据保持和惯性参数做参数恢复；对规则与转换时点做状态恢复，
   并检查不同近优参数是否支持同样的机制结论。
5. **独立口述。** 在冻结编码、表达机制及验证划分后，检验规则持续与转换的预测。
   307现有口述编码及表达覆盖问题先作为测量环节处理；335当前缺少口述。

335另设一个参数诊断：检查低搜索概率附近的拟合剖面和近优参数，观察更充分的候选到达是否能与选择预测同时成立。
这一步用于区分参数补偿与搜索结构的限制，范围和预算在运行前固定。
335与307是开发案例，正式机制选择需要预留数据。数值通过界限与可接受的实质差异，
应根据数值校准和所需科学结论事先规定；本次不从两个案例中反推通过阈值。

## 5. 计算时点与文件

分析在原源码进程中临时使用一个记录型`StateModel`子类。它在`complete_trial()`前读取
当前规则概率，在共享认知更新完成后读取反馈后状态；所有认知计算仍由原方法执行。
附加选择读出是无随机抽样的纯观察。进程结束前恢复模型导出，原源码快照保持只读。

每个试次只保存当时处于候选集合中的规则，使用规则编号恢复身份，保留双精度数值。
每条B路径和C路径的编号全程固定；这两种运行均没有粒子重采样。
记录包含候选编号、规则信念、作答贡献、规则正确概率、反馈前后精度、条件配对信念、
反馈似然以及提出来源、自主退出和容量移除事件。遗忘后的规则概率按实际factorized定义计算，
并逐试次验证其与反馈似然相乘再归一化后等于共享模型的反馈后信念。

驻留保留曲线逐一评价1、2、4、8、16、32、64题的长度。长度为\(k\)时，
只纳入从进入时点起至少还保留\(k\)题记录的事件；这些事件中实际驻留至少\(k\)题的比例为保留率。
这是各长度有明确纳入条件的描述性比例，各点的事件集合可能不同。
路径及路径内部的驻留相互关联，本次没有人群置信区间或显著性检验。

主要产物：

- `subject_*/traces/*.npz`：完整稀疏路径状态，B按种子、C按16条原轨迹分组。
- `subject_*/episodes.csv`：所有规则的完整驻留及移除原因，保留末尾删失。
- `subject_*/paths.csv`、`trials.csv`：整路径里程碑及逐题包含率、信念、贡献。
- `subject_*/rule_catalog.csv`：全部规则的几何任务评分。
- `subject_*/summary.json`：两种关注规则定义下的汇总。
- `validation.json`、`manifest.json`：重放检查、来源哈希、环境版本及计算预算。
- 图目录的`curves_plot_source.csv`、`retention_plot_source.csv`、`batches_plot_source.csv`、
  `feedback_plot_source.csv`、`exits_plot_source.csv`：绘图及反馈、退出诊断的源表。
