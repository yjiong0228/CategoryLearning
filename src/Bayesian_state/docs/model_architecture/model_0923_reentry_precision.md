# Model 0923：规则再次进入时保留已学精度

## 研究问题

208的容量对照发现，K=2与K=4对完整选择序列的近似相对似然约为1.18∶1。
K=2的行为条件口述支持较高，自主学习较差。各64条自主路径均曾发现正确规则，
K=2中正确规则平均被容量竞争移除2.97次，K=4中为0.59次。
两组分别发生176次与35次正确规则重新进入，记录的进入精度均为初值1。
对应证据见[研究记录](model_0923_research_progress_20261018.md#208容量参数的口述收益与自主损失)。

这项对照检验规则暂时离开活动集合以后，保留已学精度能否改善后续使用。
精度β控制单条规则的类别预测分布：在相同刺激与规则几何下，较高精度通常使预测更集中。
模型继续通过既有反馈梯度更新精度。干预对目录中的每条规则采用相同规定，
正确规则身份仅用于分析生成结果。

## 机制与状态时点

每条规则增加一个“曾经在场”标记和一个最近在场精度。具体过程为：

1. 本题集合转换前，读取上题反馈更新完成后的规则精度，保存旧活动集合中每条规则的值。
2. 按当前POOL或SEARCH方案完成退出、搜索、容量比较、信念分配和作答贡献计算。
3. 首次进入活动集合的规则沿用原初始化。曾经在场的规则重新进入时，恢复其最近在场精度。
4. 当前活动集合之外的规则在执行精度数组中保持为0，其缓存保持原值。它们离场期间不接受反馈更新。
5. 用最终活动集合、作答贡献和更新后的精度产生本题选择预测。之后的反馈按原精度学习规则处理。

本诊断假设缓存跨离场时段持续保留，未增加保持时长或遗忘率参数。
活动容量K限制同时参与作答的规则数；已学精度可保存在活动集合之外。
这一区分有额外的长期状态存储假设，其必要性由机制对照检验。
规则准入的回顾证据仍以原初始精度计算，原信念初始化及证据保持方式沿用既有实现。

缓存属于各条认知路径的内部状态，随H模块状态快照保存和复制。
重采样得到的粒子继承对应祖先的缓存；之后各自的反馈历史可以使其分化。
新状态签名标记该机制，读取时检查规则数、标记类型、有限数值、精度边界和未学习规则的零缓存。
当前实现仅接受full-v3连续选择及反馈梯度精度更新。

实现为[reentry_precision.py](../../model/modules/hypothesis_transition/reentry_precision.py)，
通过实验上下文安装。关闭该上下文时，模型方法、状态字段及随机数调用均保持原值。
原正式模型与正在运行的其他拟合使用各自已冻结的实现。

## 固定参数对照

配置为`configs/shared/model0923_reentry_precision_probe.yaml`，入口为
`python -m src.Bayesian_state.workflows.analysis.model_0923_reentry_precision_probe`。
使用`--config 配置 --output 新目录`运行；`--smoke`使用一个进程、每个参数点一个既有种子及前16题。

本轮保留208的两个既有行为参数点：K=4的原SEARCH点与K=2的六格完整行为NLL最低点。
两点γ均为0，其余参数相同。每点64个原随机种子分别生成恢复精度的完整自主轨迹；
RESET基准直接复用对应的64条既有轨迹，另完整重跑每点一条基准路径，要求所有数组逐值一致。
因此，本轮新增128条机制路径和两条完整复现控制，共34个计算任务，上限32个单数值线程进程。
新机制与旧机制均根据自身生成的回答接受任务反馈。口述内容未进入本轮计算。

主要过程指标为整段路径分布的Energy、后段正确率、首次发现时点、发现后缺失比例、
容量移除次数、在场时作答贡献和精度。Energy越低，生成曲线分布与被试曲线越接近。
全部路径保留，差值通过共同路径种子的删除一个完整路径重算得到配对模拟标准误。
该误差只描述固定参数下的模拟误差。全部规则的精度恢复次数与恢复值另存为逐事件诊断，
用于检查错误规则也会继承其历史学习状态。

本轮先判断精度重置在已有容量差异中具有多大作用。若自主过程得到改善，
再用选择似然检查对真实行为序列的影响，并按原预算检验参数调整后的结果。
行为条件口述检验在参数冻结后进行。自主入口负责生成过程，选择似然与口述由后续入口分别评价。
