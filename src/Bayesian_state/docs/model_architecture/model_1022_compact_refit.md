# Model 1022：简化机制重拟合与参数恢复

## 当前结论

六人的共同预算比较、四条原模拟序列的追加恢复、以及固定参数的单规则作答对照均已完成。
当前保留的简洁候选是**统一在线支持＋新规则精度继承＋多规则加权作答**。统一支持同时用于规则使用、
搜索父规则和容量替换；精度继承使已有判断精度能够延续到新规则。它在开发组三人的自主预测上有所改善，
扩展组的自主预测总体接近原COMPACT。209的后期选择预测存在明确代价，个体参数的稳定心理解释仍需检验。

本轮已经定位两个具体问题。第一，若干被试的自主路径后期正确率系统性偏低。第二，原COMPACT的模拟
恢复中，行为似然相近的估计仍可给出不同的精度学习率与内部精度轨迹。后续检查分别针对估计所用行为阶段
和精度继承候选的参数恢复；当前结果支持机制候选的取舍，尚不足以把全部点估计直接解释为稳定的个体特质。

## 本轮目标

本轮继续检验简洁的规则学习机制，并明确个体参数可以解释到什么程度。上一轮保留了统一在线支持的
COMPACT主干；205的固定参数对照显示，新规则继承当前活跃规则的平均精度可能改善自主学习。
本轮比较原COMPACT和加入精度继承的TRANSFER。两者分别重新估参，行为参数只使用训练段选择似然。

完整Model 1021的已有结果作为历史参照。本轮直接的共同预算比较是COMPACT与TRANSFER，两者共享
参数范围、初始候选和评分种子，得到相同的搜索机会。旧完整模型的计算预算单独列出，跨轮差异同时
包含估计流程的变化。正式默认模型保持原装配，本轮通过独立工作进程启用实验机制。

## 机制与被试

COMPACT用每条活跃规则的在线支持控制作答权重、搜索父规则和容量替换。反馈到来后保留一部分旧支持，
再加入本次反馈的证据。新规则的支持从零开始，精度使用个体初值；移出工作集合后清除该规则的支持与精度。
TRANSFER在后续新规则进入时，使用新规则进入前的全部活跃规则，按上一题反馈更新后的支持计算加权平均精度，
并将该值赋给新规则。参与平均的精度已经完成上一题的反馈学习。新规则随后继续原精度学习，首题仍使用
个体精度初值。该操作使已有判断精度能够跨规则延续，参数数目保持不变。

当前候选的逐题过程可以按五步理解：

1. 根据上一题反馈，更新每条活跃规则的支持摘要和判断精度，并更新控制搜索的失败累积量。
   支持摘要由保留的旧支持与本次反馈证据相加得到，保存的是当前累积结果。
2. 根据搜索概率决定是否提出新规则。搜索时，在活跃规则的结构邻域与全局目录之间选择一条路线；
   局部搜索的父规则按当前支持形成的权重抽取。
3. 将新规则纳入工作集合。集合已满时移除支持最低的旧规则；新规则的支持设为零，
   精度继承入集前全部活跃规则的支持加权平均值。移出的规则清除其支持与精度状态。
4. 用各规则的基础权重和当前支持计算本题作答权重，并归一化，使权重之和为1。
   多条规则按这些权重共同形成对本题刺激的选择概率。
5. 产生选择并接收反馈，进入下一轮更新。条件3同时保留其类别配对证据的学习过程。

首题使用原初始化过程。候选中的主要记忆状态是活跃规则的支持摘要、精度及任务所需的配对证据，
所有被试遵循同一更新过程，个体参数决定搜索倾向、证据保持、容量和精度学习的差异。

两种机制的条件1、2各有八项自由参数，条件3有九项。完整过程定义见
[前一轮研究](model_1021_simplification.md)。本轮保持已确定的任务语义、规则目录、精度更新及预测时序。

## 估计流程

每名被试的两种机制共享40个起点。起点包含同一个既有训练估计点，其余从参数支持范围中构造，
覆盖容量取值并分散抽取联合组合。随后进行两轮有上限的搜索：每轮从两个表现较好且不同的候选出发，
各检查24个单参数方向上的取值和8个双参数联合改变，共增加64个不同候选。每轮同时重新评价八个
已保存候选，其中包含原起点。每例本轮共评价168个不同参数点。

单参数方向的检查先轮流覆盖各坐标，再增加同一坐标上的其他取值。该安排使每个可变参数都获得搜索
机会。两种机制可以根据各自训练表现选择不同候选；搜索次数和评分精度保持一致。

| 阶段 | 候选 | 每次粒子数 | 独立滤波次数 |
| --- | ---: | ---: | ---: |
| 初筛 | 40 | 128 | 2 |
| 每轮追加 | 64个新点＋8个既有点 | 128 | 2 |
| 高精度选择 | 6 | 512 | 4 |
| 独立确认 | 4 | 1024 | 8 |
| 参数冻结后的行为评价 | 每机制的选中点 | 1024 | 8 |

确认阶段保留原起点和三个候选位置。选择、确认和评价使用分开的种子；同一人的两种机制使用共同种子，
便于估计差值的模拟误差。自主评价每人每机制生成128条完整路径，并保留路径分布与内部规则过程。

## 参数恢复与心理解释

下表列出全部自由参数的模型含义。含义来自机制定义；个体差异的解释还取决于估计与恢复结果。
参数范围、边界解、不同候选的补偿关系和已知零作用情形会与点估计一起报告。

| 参数 | 在模型中的作用 | 个体解释时要检查的事项 |
| --- | --- | --- |
| 基础搜索概率 | 失败累积量为零时，发起搜索的概率 | 与失败敏感度、失败状态共同决定实际搜索率 |
| 失败敏感度 | 失败累积量对搜索对数优势的影响强度；对数优势为概率与其互补概率之比的对数 | 数值为零时，失败状态的保留参数失去作用 |
| 失败状态保留 | 成功反馈之后，保留多少既有失败累积量 | 需要足够的失败和成功交替，才能观察其影响 |
| 全局搜索比例 | 搜索时从全局规则目录提出新规则的比例 | 结合局部邻域结构、搜索次数和规则发现过程解释 |
| 规则容量 | 同时保留的规则数上限 | 反映当前规则表达方式下的有效容量 |
| 初始精度 | 开始学习时，规则对刺激差异的区分程度 | COMPACT中新规则也使用此值；TRANSFER后续入口继承当前精度 |
| 精度学习率 | 每次反馈对规则精度更新的影响大小 | 与初始精度、规则存续时间及规则选择相互影响 |
| 支持保留 | 每次更新后保留多少此前的规则支持 | 描述每条活跃规则的累积证据保持程度 |
| 配对证据保留（条件3） | 保留已有的规则组成条件与类别之间的配对证据 | 结合该条件的类别配对学习检验，条件1、2中固定 |

已核实一个精度继承的作用边界：精度学习率为零时，活跃规则始终保留初始精度，新规则继承的也正是这个值。
六人的共同初筛中包含16组这类参数。每组使用两次128粒子的共同种子滤波，两种机制逐题的实际选择概率
和正确选项概率都完全一致。该检查复用了已有滤波，记录见
`results/model_1022/compact_equivalence_audit_20261022_v1/`。若最终个体估计位于这个边界，该估计采用
固定精度，规则支持仍按反馈更新。精度继承的额外行为作用无法从这一估计点区分；精度学习率的
可辨认性还需要结合其他候选与恢复结果判断。

108的正式确认已经给出一个实例：两种机制选中了完全相同的参数，精度学习率为零，初始精度为10。
八次1024粒子滤波在448题训练段上的选择概率和正确选项概率逐项一致，记录见
`results/model_1022/compact_selected_boundary_audit_20261022_v2/`。这对估计对精度继承的作用没有区分力。
108的失败敏感度也为零，因此失败状态保留参数在这个估计点没有行为作用；其心理含义无法由这一估计确定。

本轮同时重新估计上一轮的四条模拟序列：205和306各两条。每例以既有行为拟合候选与支持范围内的
分散起点启动，再执行上述两轮搜索。旧模拟数据、原恢复结果和追加搜索结果分别保留。
生成参数单独存放，在全部估计冻结后才参与评分；候选产生过程只读取模拟行为的既有拟合记录。

生成点与估计点使用相同确认种子评分。估计点明显较差时，记录搜索不足；似然接近但参数不同，
则进一步检验有限序列的信息量、参数补偿及个体排序。存在已知零作用情形的参数单独标记。
目标规则的存在、作答贡献和精度通过原滤波被动记录，保留状态不确定性。

这四例用于检查估计方法的瓶颈。精度继承候选另用其生成数据检查参数与状态恢复，
据此确定能够解释的个体过程。机制比较综合后期选择、自主轨迹、口述支持及模型复杂度。

学习阶段的差异也保留在评价中。TRANSFER在训练段的完整报告功能支持依次为108的0.481、205的0.001、
306的0.242、110的0、209的0.212和309的0.259。训练段目录可覆盖报告分别为281／418、71／383、
162／381、0／159、27／103和246／472。早期支持较低同时涉及表达覆盖和状态推断；其中205即使在
可覆盖的71条训练报告上，平均支持也只有0.003，值得继续检查学习过程的对应。后期的高支持只证明
相应阶段的内容兼容性。全程结果、训练段结果和后期结果均保存在同一汇总表中。

已有评价还提供静态表征对照：按被试所选类别，平均训练段的模型作答依据，并将该分布固定用于后期。
这个对照共用同一模型的早期状态，用于检查表征随学习变化的作用。TRANSFER的后期完整报告功能支持，
在205为动态0.255／静态0.092，306为0.906／0.422，209为0.923／0.484，309为0.992／0.311；
108为0.018／0.035，110两者均为0。每人动态与静态的比较使用相同报告分母。
这些差异支持部分被试的内部表征随学习变化；其他模型家族的优势比较需要独立的完整对照。

205的逐句核对进一步说明表达覆盖的来源。训练段有53次“脖子最长。”，其中40次选择类别1，
当前目录仅在其选择类别3的3次报告上存在支持分量。规则的几何内容与类别标签共同决定这个覆盖结果。
这一现象与[已有极值类别对应诊断](model_0923_research_progress_20261018.md#极值规则的几何内容与作答类别对应)
一致。对于目录可覆盖的全部71条训练报告，符合内容的规则至少一个分量在场的平均概率约为0.033，

### 已知模拟序列：估计改善与解释边界

原COMPACT四例的重新估计与生成点使用共同的八次1024粒子确认评分。估计NLL减去生成点NLL为：

| 模拟序列 | 差值 | 配对MCSE |
| --- | ---: | ---: |
| 205 R0 | −0.001214 | 0.000324 |
| 205 R1 | +0.000445 | 0.000167 |
| 306 R0 | −0.002955 | 0.000997 |
| 306 R1 | −0.000127 | 0.000868 |

此前306两例明显低于生成点的似然差距已经消除。205 R1仍有很小的数值差距，结果保留其搜索不足标记及
实际差值。与此同时，306的生成精度学习率为0.3，两次估计分别为0.03和0.06，其他参数发生补偿。
在已知生成点下，目标规则精度的滤波均方根误差约为0.08和0.23；用估计参数时升至5.44和4.66。
这说明本次有限行为序列允许相近似然对应不同精度解释。该结果限定在这些生成点和序列上，
模型全部参数的结构可辨认性仍需更广泛的检验。

205 R0的已知路径全程没有目标规则，内部状态依然存在推断不确定性；205 R1的估计参数下，目标规则

参数估计误差。当前个体解释优先报告规则发现、保留和使用的过程证据及候选敏感性，精度学习率的
跨个体排序需要恢复支持。
