# Model 1024：渐进形态与同类代表路径

2026-10-27。用户指出S205的缓慢上升被列为形态未定，且橙线与真人类别不一致。
本次修订统一改变类别比较顺序，并把同一类别作为橙线选择的必要条件。
修改用于开发资料的描述和图表。分类标准的模拟检验继续按用户要求暂缓。

## 单次变化和多阶段的比较顺序

沿用[v2的五种描述曲线](model_1024_trajectory_classification_v2.md)：恒定水平、
一次阶跃、连续斜坡、三段水平和四段水平。拟合方法、幅度15个百分点、
每段至少32题及明确变化相对恒定水平改善6分的要求均保持不变。

比较使用BIC分数，将曲线拟合误差和描述复杂度一起计入，分数越小越好。
v3先比较幅度达标的一次阶跃和连续斜坡，得到最佳单次变化描述。
多阶段描述须比它再改善至少6个BIC分数，才进入最终类别比较。
这样，几个台阶近似连续上升且额外收益较小时，单次变化的判断继续有效。
多阶段进入后，原来的类别差距6分要求继续适用；同属下降类的描述合并比较。
只有多阶段达到明确变化门槛、但其相对单次描述的增益不足时，保留形态未定。
没有幅度合格的单次描述时，多阶段直接与恒定水平比较。
数值拟合未确定的标记继续保留。

所有真人和模拟路径使用同一规则。代码不读取被试编号来决定类别。
这项规则调整由已观察的S205等开发案例启发，当前尚无独立分类准确率证据。

S205的三个相关分数是：阶跃878.75，斜坡869.27，三段866.21。
三段比斜坡仅改善3.06分，未达到增加阶段所需的6分；斜坡比阶跃改善9.48分，
因此v3将其描述为渐进式改善。原拟合结果完整保留。
S129的阶跃与斜坡差距仍不足6分，继续为形态未定。
S229、S306、S317的多阶段增益超过6分，继续保留多阶段描述。

## 橙线先匹配类别

每个确认组合执行以下步骤：

1. 读取真人的v3标签，以及该组合全部模拟路径的v3标签。
2. 仅保留标签与真人相同的模拟作为橙线候选。
3. 在这些候选中，以原登记加权形态距离最小值选一条完整路径；并列时取保存顺序最早者。
4. 没有同类路径时橙线留空，图中注明，类别计数保持0。

原形态距离继续比较水平、变化幅度和宽度、波动及原版观察信息。
本次新增类别约束，内部距离的指标及权重保持不变。改善时点可以不同，
展示使用原始题序和原始完整路径，选取后不平移或拼接。
同类比例的分母仍为全部路径。图中的灰色路径和蓝色均值也仍使用全部路径。
橙色柱对应真人的标签，空心菱形标明选中橙线的类别；有橙线时两者一致。

同类是必要条件，当前未另设绝对相似度的通过门槛。
真人形态未定时，匹配的是同一未定状态，尚不代表已确立相同的学习类型。
类别内部的差异和距离继续报告。旧的全体最近路径保留在 `nearest_paths.json`；
当前橙线单独保存为 `display_nearest_paths.json`，包含编号、种子、类别、
距离、同类候选数及选择内容的哈希。

## 复用计算与执行入口

本次仅改变判断顺序，五种曲线的拟合设置相同，因此复用v2保存的拟合结果。
复用前核对拟合设置、完整对错序列哈希、路径编号和种子，逐条结果保存新版本。
原v2分类文件、原生成路径和参数评分均保留。

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 NUMEXPR_NUM_THREADS=1 \
python -m src.Bayesian_state.workflows.analysis.model_1024_reclassify_paths \
  --study EXISTING_STUDY --output NEW_CLASSIFICATION \
  --config configs/shared/model1024_trajectory_classification_v3.yaml \
  --reuse-fits PREVIOUS_CLASSIFICATION --workers 4

python -m src.Bayesian_state.workflows.reports.model_1024_individual_regions_report \
  --study EXISTING_STUDY --output NEW_REPORT --classification NEW_CLASSIFICATION
```

省略 `--reuse-fits` 时按配置重新拟合描述曲线；拟合设置不同的结果禁止复用。
原v2配置仍使用v2的平行类别比较方式，保留重现入口。

本次结果位于研究目录的 `particle_precision_v2/classification_v3`。
当前 `report_v1` 内六张个体图原位替换，报告和解读同步更新。
原参数保留集合、选择似然、形态相容性分数及两张总览图保持不变。
软件检查覆盖复杂描述进入门槛、同类限制、空类和并列选择，另核对所有图表计数与路径身份。
这些运行检查与用户暂缓的分类标准模拟检验分别记录。
