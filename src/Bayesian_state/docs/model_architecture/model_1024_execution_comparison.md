# Model 1024：执行维持与零维持边界的受控比较

2026-10-29用户授权开展长时任务。本轮比较执行维持参数κ为0与κ可变化的模型，
检验跨题维持能否改善行为解释、后段预测及自主学习分布。全部模型复用共享信念、
精度、搜索、容量和反馈模块。零维持的作答概率通过现有MIX读出对执行身份求和。
非零维持使用现有STICKY读出。自主路径按单规则生成，零维持时的完整行为分布与MIX相同。

## 资料与三个问题

真人资料固定为S110、S205、S306、S129、S229、S317，均为已经查看过的开发案例。
每人进行两次用途不同的估计。完整记录估计使用首题至末题，检查受支持参数和自主路径。
前段估计沿用原登记的约70%时间分界，只读前段选择；参数冻结后才评价剩余试次。
前段估计可使用旧的前段拟合候选，完整记录候选只进入完整记录研究。
前段评价属于开发资料上的顺序预测，尚无独立真人样本推广含义。

第三个问题通过18条新模拟路径检验：三个任务背景S110、S205、S306，各取κ=0、2、6，
每点两次独立生成。其余生成参数取旧前段STICKY估计点，在开始计算前固定。
路径使用实际刺激日程的完整长度、模拟选择及相应反馈；所有生成路径均参加恢复。
恢复从共同参数范围产生起点，生成参数不用于起点或搜索排序。拟合完成并冻结后，
再比较生成机制、估计机制及生成点的评分。两次重复限定了恢复率的解释范围。

## 对齐搜索与数值估计

每个提出的学习、搜索、精度及容量组合，同时评价κ=0和一个非零κ。
初始候选包括分散起点；后续两轮分别围绕零维持和非零维持的领先点改变一至三个参数，
并继续对每个非零候选评分其零维持投影。完整记录、前段和恢复各自有独立搜索。
κ自由模型包含所有已经评分的零维持点，因此两个模型的嵌套关系在候选库中保留。
参数范围、候选上限和种子角色在YAML中固定。有限搜索的覆盖及未完成项随报告保存。

初筛使用128粒子、2个独立系统。零维持与非零维持分别提名，统一用512粒子和新种子确认；
每边先保留两名新搜索领先点，再优先纳入已评分的历史锚点及其零维持投影，其余名额按初筛分数填充。
这样保留已有较高预算候选，降低低粒子初筛误排造成的损失。前段研究的历史锚点仍限于旧前段估计。
两边各两名领先候选进入2048粒子、8个新系统的数值审查。模拟恢复对应使用1024粒子、6个系统。
相邻粒子数的差异超过工作门槛时，至多追加一次更高粒子数。未解决的结果保留数值未确定状态。
确认、审查、追加、后段评价与自主生成分别使用独立种子；候选间使用配对种子。
后段评价使用审查粒子数及其一半，各用新种子，单独检查后段条件NLL的数值稳定性。

序列似然表示模型给予整段实际选择的概率。每个粒子系统保持自身连续历史，先得到整段似然，
再在独立系统间求平均；负对数似然NLL除以该段题数。后段条件评分使用完整序列与前段
平均似然之比，保留前段对独立系统权重的影响。标准误以完整独立系统为重复单位计算。
零维持点在两个模型中复用同一份评分，避免把重复计算差异误作机制差异。

数值工作标准为：相邻粒子数NLL绝对差加两倍合并蒙特卡洛标准误不超过每题0.005；
单点两倍标准误不超过0.005；最大系统权重不超过0.9。差值还报告配对标准误。
这些阈值衡量计算精度，候选的参数置信覆盖尚未校准。

## 行为评价与判断

选参以选择似然为主。自主生成在参数冻结后评价，全部路径参加评分。
每个最终候选生成256条路径；模拟恢复每个候选64条。主要Energy评分使用已有32题块正确率
和类别条件反应频率，报告完整记录及后段。Energy是比较生成路径特征分布与实际路径的分数，越小越好。
另保留最大相邻32题改善、发生时点、后续保持、末段水平及波动等分布摘要。
行为评分、改善事件、数值误差及参数取值分别列出，单条最近路径不参与判定。

机制判断同时考虑：零维持与自由维持各自充分搜索后的差值、后段预测方向、自主路径分布、
模拟模型恢复和优化质量。完整记录NLL改善表示同资料拟合收益；模型复杂度和过拟合由
前段冻结评价与恢复结果共同检查。观察到非零最优点时继续保留其零维持竞争点。
数值未确定、搜索未完成和已完成但未检出稳定收益分别报告。结论允许保持无明确胜者。

## 计算范围与停止

正式计算上限12小时、1536 CPU小时，至多128个单线程进程，单层进程并行。
CPU预算分为校准32、完整记录600、前段400、恢复480、汇总24小时。
CPU和墙钟以实际任务开始计时；每项保存耗时、退出状态、输入与源代码校验值。
调度及汇总进程的CPU单独累计，并计入总预算。
达到时限、累计CPU上限或三项工作进程失败时停止发起新任务，并结束本轮工作进程。
未启动和中断任务保留清单。后续追加另登记，原结果保留。

先运行一个短序列、单进程的小规模流程，再冻结正式协议和启动队列。
每阶段有独立完成记录；续跑核对协议、输入、源码及已保存数组身份。
旧结果、原始数据和口述编码保持原样。

配置：[model1024_execution_comparison.yaml](../../../../configs/shared/model1024_execution_comparison.yaml)。
运行入口为`python -m src.Bayesian_state.workflows.analysis.model_1024_execution_comparison`，
先用`--phase smoke --output NEW_SMOKE`验证，再依次使用`--phase prepare`和`--phase run`，
两者指定同一个新的正式输出目录。`--phase report`汇总当前已有产物。
具体命令与输出位置见[工作流说明](../../workflows/README.md#model-1024执行维持与零维持边界比较)。

独立确认后，每边最多两点进入数值审查；某例有点需要提高粒子数时，该例的全部审查点
都进入同一高粒子档，保持最终排序的分辨率一致。首次小规模试跑发现的串行队列提前退出

## 独立结果审查

`workflows/reports/model_1024_execution_comparison_report.py`读取已保存产物，在新目录中
核对每例各阶段的登记数和成功数。缺少阶段或任一独立重复时，拟合计划标记为未完整执行。
最终候选、所有阶段的候选评分、条件后段评分及全部自主路径的分布分别保存。
每名真人等权的平均保留缺失人数；全部被试尚未完成时，全体均值留空。

后段数值方向同时要求拟合任务完整、拟合粒子检查通过和后段粒子检查通过。
通过这些检查后，差值加减两倍蒙特卡洛标准误用于描述数值方向；该标准不赋予人群统计显著性。
模拟恢复保留未确定类别，生成点评分优于搜索结果时另标搜索不足。
未确定案例的机制一致性留空，已完成且可判断的错误分类单独计数。

Energy差值按相同种子的完整自主路径配对，用删除一条配对路径的刀切法估计计算标准误。
真人前段参与参数估计；自主路径从任务起点生成，其后段分布没有以真人前段状态为条件。
改善幅度、发生时点、保持和低谷摘要保留所有路径，保持窗口越过记录终点时记为缺测。
恢复路径另记录切换数、被迫切换数、上一规则仍在场时的执行保持率和最长连续执行段。

## 比较图的证据安排

比较图检查三个问题：自由维持的完整记录拟合收益是否延续到前段冻结后的后段预测，
自主路径分布是否同时改善，以及已知生成机制能否被恢复。绘图沿用已保存的Python偏好，
使用matplotlib，默认仅输出PNG。图宽183 mm；正文和坐标文字至少7 pt，保留CSV来源与绘图参数。

真人图按六名被试逐行展示完整记录NLL差、条件后段NLL差和自主后段Energy差。
后段预测为主要比较，其他两栏分别说明拟合收益和生成分布。误差线为正负两倍蒙特卡洛标准误，
表示计算误差。任务未完整执行和数值检查未通过使用不同标记，缺失分数明确留空。
三栏均采用自由维持减零维持，负值表示自由维持评分较低。

## 原批次结束后的缺项补算

高精度审查后需要追加的任务可能超过单批次的计算预算。原批次按登记的停止条件结束，
实际成功、未启动及中断任务分别保留。补算在新目录登记新增墙钟和各阶段CPU额度，
沿用原模型、资料边界、候选提议、粒子数、重复数、随机种子和评分定义。
达到最高登记精度后仍未通过的案例继续标为数值未确定。

补算准备工具先核对原批次的完成记录；正式研究另要求监督进程的终止记录。
源码和输入哈希与原登记一致，成功工作进程的参数、种子、粒子数、数组形状、概率范围
及文件哈希通过核查后，保存结果才进入复用清单。成功结果通过文件链接供新目录读取，
原参数冻结文件和阶段汇总保留在原目录。原数值入口在新目录重新汇总全部候选，并执行缺失任务。
模拟真值按原流程在估计冻结后使用；准备阶段按字节复制真值文件并核对哈希。

调度器计入复用账本的历史CPU，因此补算上限包含历史账本的精确偏移量和新增额度。
最终报告分别列出原批次消耗、补算新增消耗及合计，历史计算量计一次。
准备工具和小规模复用检验属于计算流程验证；正式补算的范围、预算和实际完成情况另行登记。
