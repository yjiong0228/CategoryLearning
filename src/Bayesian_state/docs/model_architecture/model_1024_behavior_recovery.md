# Model 1024：行为与模拟真值下的状态恢复检验

登记日期：2026-10-25。用户尚未完成真实口述的最终人工检查，口述验证待定。本轮使用已有
模拟行为及已知状态，检验短暂规则进入的数值稳定性，并计算其余内部状态已知时的执行基准。
研究遵守[研究指导文件](../RESEARCH_GUIDE.md)。真人采用参数、模型机制及已有研究产物保留。

## 目的与推断范围

当前状态恢复同时受到行为信息、未知内部状态、参数估计和有限粒子近似的影响。本轮固定
生成参数，分别检查以下两项：增加粒子数后状态概率的变化；已知活跃规则、信念、精度、知觉
和上一题执行规则时，本题选择对当前执行身份提供的信息。两项结果帮助定位后续推断改进。

状态时点保持为纳入本题选择、反馈前的过滤分布，并保留选择前预测。当前反馈和未来选择均
保持过滤更新之外。已知状态基准具有额外信息，是机制内的条件参照；真人状态准确性继续
另行验收。完整参数恢复和似然网格重排按独立协议开展。

## 预定路径与数值预算

全部15条既有固定或富集路径按原种子重放，保存已知状态下的本题执行条件分布。富集案例
使用其原有标记，主要概率校准使用12条固定路径。

粒子数检查固定为C004、C005、C006、C007、C008、C010、C013。它们分别覆盖三个反馈条件、
短暂进入、持续在场及进入后的执行事件。选择依据是前轮模拟真值与恢复结果，本轮属于针对
既有失败的开发检验。该选择不提供总体恢复率的独立估计。

每例以正确规则首次进入为中心，主评分窗口从进入前32题到进入后的第64题；起点截于任务
开始。过滤从第1题运行至窗口结束，并向后取整至32题边界，最长保持在原序列范围内。保存
整段前缀以核对历史，窗口用于主要数值比较。截断前缀包括窗口之后的取整题，但逐题过滤
依次处理历史。窗口及案例登记后不按本轮预测调整。

比较512、1024、2048粒子，同例采用原有四个过滤种子中的前三个。已有512结果及C005、C010
的两个1024结果按种子和参数身份复用。新增17次1024、21次2048过滤。另为C004、C008、C010
各重放一次512过滤，逐数组核对截短前缀与原完整过滤的同一前缀相等，检查前缀截断和被动
监测的影响。共41次新增过滤，15次原路径重放；先运行一人、8题、单工作进程短流程。

单层数值进程最多128个，每个工作进程一个数值线程。实际并行数取可用CPU、预算与准备就绪
任务数的最小值。预算保持固定，数值未收敛与恢复较弱均进入结果。

## 已知状态条件下的执行分布

设ρₜ(h)为生成机制在本题抽样之前分配给规则h的执行概率，Lₜ(h,c)为该规则对选择c的预测
概率。两者均从共享机制读取。L使用真实的反馈前知觉、规则精度及类别映射，ρ使用本题
信念和上一题真实执行身份。给定已知状态Zₜ与当前选择cₜ，计算

\[
q_t(h\mid c_t,Z_t)=\frac{\rho_t(h)L_t(h,c_t)}{\sum_j\rho_t(j)L_t(j,c_t)}.
\]

分母是对本题执行抽样积分后的选择概率，分子是规则h与当前选择的联合质量。当前执行身份
保持待推断变量。重放中实际抽中的规则只用于核对原生成概率和最终真值评分。

若正确规则缺席，错误来源的第一类概率为1；若在场，将q在全部正确规则上求和，得到正确
规则执行概率，其余质量为“在场、执行其他规则”。错误来源评分沿用原三类定义，报告实际
错误上的概率评分、召回及误报，同时保留完整试次。

另外计算在已知状态下，当前选择对执行身份提供的互信息，以及最优分类器在可能选择上的
平均准确率。互信息是选择前执行熵减去对可能选择平均的选择后执行熵；熵描述分布的不确定
程度。最优分类器的平均准确率为各选择下最大规则—选择联合质量之和。这些量描述模型的
局部信息，单个选定案例的实现准确率和稀有类别召回分别报告。

全部读取与记录均保持原随机流。重放核对选择、反馈、完整选择概率、活跃规则、信念、精度
及实际执行身份与原路径相同。基准不读取真人口述，也不用于挑选真人参数。

## 数值评分与交付

各粒子数先合并过滤重复的当前选择联合质量，再条件化。报告在场、信念和执行状态的概率
评分、误报与漏报、错误来源、逐题及窗口平均概率差、重复间模拟误差。规则在场的真实连续
片段保留长度、进入/离开时点和检测延迟，便于定位短暂事件的识别困难。
片段内检测定义为该真实在场片段内首次过滤概率达到0.5的试次；此前的误报及之后的持续识别
分别通过概率曲线和漏报比例评价。完整后验的首次进入时点分布另需连贯状态路径推断。

新过滤被动记录选择前与选择后有效样本量，以及正确规则在场粒子数。有效样本量为归一化
粒子权重平方和的倒数，反映权重集中程度；在场粒子数用于检查有限粒子是否覆盖目标状态。
数值诊断、条件信息与实际状态恢复分别解释。

结果进入新版本目录，包含配置和来源哈希、前缀一致性、状态与错误评分、已知状态执行参照、
PNG及报告。本轮口述验证状态保持待人工检查，模型的科学验收依据保留当前范围。

## 运行入口

从仓库根目录运行，输出目录每轮使用新版本。

```bash
python -m src.Bayesian_state.workflows.analysis.model_1024_behavior_recovery --phase prepare --config configs/shared/model1024_behavior_recovery.yaml --output results/model_1024/behavior_recovery_prepared_20261025_v1
python -m src.Bayesian_state.workflows.analysis.model_1024_behavior_recovery --phase run --prepared results/model_1024/behavior_recovery_prepared_20261025_v1 --output results/model_1024/behavior_recovery_run_20261025_v1
python -m src.Bayesian_state.workflows.analysis.model_1024_behavior_recovery_summary --run results/model_1024/behavior_recovery_run_20261025_v1 --output results/model_1024/behavior_recovery_summary_20261025_v1
python -m CategoryLearning_codes.figures.fig3.model1024_behavior_recovery --source results/model_1024/behavior_recovery_summary_20261025_v1 --output CategoryLearning_codes/figures/outputs/fig3/model1024_behavior_recovery_20261025_v1
```

短流程在prepare阶段加`--smoke`，对其新输出运行后续阶段。短流程使用一名被试、实际前8题、
2粒子和单个数值进程，额外的无记录过滤用于核对被动状态记录。它检查接口与精确重放，正式
状态恢复与数值比较使用独立登记的完整预算。

汇总同时记录真实累计在场题数、累计执行题数及相应在线过滤概率的累计和。每题概率使用
当时已观察的历史，累计和用于描述性占用比较。整条轨迹的占用量后验需要在同一组完整资料
下重建连贯的状态路径。逐题识别、在线累计量、全序列后验和个体参数稳定性分别检验。
