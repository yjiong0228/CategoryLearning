# Model 1024：共同前段状态的续跑诊断

## 问题与证据位置

上一轮训练共同选参改善了317的后段条件预测，却降低了自主学习表现，正确规则的在场和保持
也随之下降。本轮在固定参数下，从同一个前段状态分出不同后续路径，检查前期状态形成、
规则进入、规则保留、判断精度与作答执行分别能改变多少表现。129和229采用相同的诊断，
检查此前陡升与保持差距的过程位置。

本轮属于开发诊断。参数和模型结构保持上一轮冻结状态，所有干预组和结果均保存。定向操作
使用任务中已知的正确规则，是模型内部的理想条件检验。其效应说明模型中哪些环节足以改变
后续表现；人的学习机制及可估计的新模型仍需要另外比较和恢复。

## 参数、起点和共同状态

检查129、229、317的MIX与持续单规则执行（STICKY）。129、229的原估计同时是共同选参
的最终点，317保留新旧估计，共八个参数/模式点。MAP的结果保留在上一轮比较中；本轮聚焦
两种具有随机作答或执行分支的机制。

每点从两个固定位置开始：训练试次数一半向下取整到32题边界，以及训练结束。每个位置运行
六次512粒子的行为过滤，使用上一轮六个已保存种子。每个过滤器抽取16个前段末端粒子，
按其最终权重抽样；八组干预共用粒子身份和后续种子，形成96条配对分支。完整状态包括规则、
信念、精度、失败轨迹、条件3的配对信念、执行身份和随机流。所有被抽到的完整状态单独保存。

共同状态指同一参数点、同一过滤器内各干预组的起点。新旧参数各自形成前段状态，跨参数对照
同时保留起始状态与后续演化差异。容量不同的参数点分别保留自身合法状态。固定参数使用过
整个训练段，因此中点的状态属于回顾性开发推断；训练结束后的续跑使用冻结参数。

## 八组定向操作

正确规则由已有的训练刺激几何审查确定，三个被试各有唯一一条训练全对规则。未来真人作答
和反馈只进入报告评分。续跑使用既定刺激、任务类别、模型自行选择及由任务语义给出的反馈。

| 组别 | 操作 | 所回答的问题 |
|---|---|---|
| BASE | 完整原机制 | 现有状态下的基准后续分布 |
| RETAIN | 正确规则已在场时，取消将它逐出的替换 | 进入之后的丢失能造成多少差距 |
| DISCOVER | 在第一道续跑题确保正确规则在场，随后按原机制演化 | 一次进入机会能保留多久、改善多少 |
| AVAILABLE | 第一道确保进入，后续取消逐出 | 持续可用性足以改善多少 |
| PRECISION | 正确规则在场时，每题判断前将其精度设为已有上限25 | 已有规则的判断精度能改善多少 |
| AVAILABLE_PRECISION | 持续可用性及上述精度操作 | 可用性和精度的联合作用 |
| AVAILABLE_EXECUTE | 持续可用，并由正确规则影响全部作答 | 信念分配或执行竞争造成多少差距 |
| AVAILABLE_EXECUTE_PRECISION | 持续可用、全部执行及精度操作 | 这三个理想条件下还剩多少差距 |

每题先运行原来的规则选择并消耗原有随机数，再施加声明的集合操作。确保进入时，若原选择
仍无正确规则，则从上一题集合中替换信念最低的一条；并列时取最早的槽位。其信念分配、
精度继承和配对继承继续使用共享模块。保护规则时取消整次逐出提议，其余信念照常更新。
精度操作发生在规则选择后、当前判断前，随后当前选择与反馈继续影响学习。
精度控制规则预测的类别概率的集中程度；精度越高，概率越集中于该规则在当前知觉下最可能的类别。
执行操作将正确规则的作答权重设为1，规则间信念和全部规则的反馈学习继续保留。

这些操作可以改变后续选择、反馈和搜索机会，报告的效应包含整个后续闭环。一次进入与持续
可用性的差异用于检查保持。持续可用与其精度组合、执行组合的差异分别用于检查另外两个
环节。组间差异允许相互作用，效应方向由结果决定。

## 预定评分和数值检验

主评分使用全部续跑路径的行为特征Energy：32题块正确率与类别条件反应频率各占一半权重。
Energy衡量所选行为特征上的预测分布与实际续跑段的距离，越低越好；U统计量去掉同一路径
与自身的距离项，有限样本估计可以出现负值。另报告只使用不同过滤器之间路径对的Energy，
检查共享过滤近似对路径间距离项的影响。主要差值同时保留这种敏感性核查。
报告完整续跑段及最后64题的Energy、正确率分布、达到实际末段表现的路径数。最后64题在
两个起点间保持相同日程，既有任务起点生成的全部128条路径作为描述参照。

过程指标包括正确规则首次进入、在场、作答贡献、条件精度、曾经在场后缺席及执行错误来源。
条件3同时保留配对状态。陡升—保持事件在各自续跑段内计算：以32题前后正确率之差最大且
仍有第二个后续32题的位置为中心，平局取最早位置，比较生成增幅及第二个后续窗口保持
是否同时达到该段真人值。低表现事件在具有至少128题随访的续跑段，以64题步长检查128题
最低正确率及与同窗口类别、反应边际独立基准的差值，沿用已有指标。日程不足时报告不可评价。
中点之后包含部分训练资料，两个起点的评分分别报告。

96条分支共享六个过滤近似。配对差值先在每个过滤器内计算，再以六个过滤器为独立单位给出
模拟标准误。Energy的不确定性采用删除整个过滤器的jackknife（每次删除该过滤器全部后代
并重算评分）。标准误只描述有限模拟误差，路径分位数描述前段状态分布及未来随机演化共同
形成的预测变异。事件计数保留96分母及
过滤器聚类关系，零次观察保留有限模拟的不确定性。

正式前逐条件短检查：八题过滤、八题续跑、四粒子、两分支、单工作进程。核对前段预测与
独立原过滤逐值一致、被动记录不改变路径、调换分支顺序不改变结果、全部干预后重跑BASE
仍一致，以及保存完整状态可以恢复。正式每题前段预测须与上一轮同种子512粒子结果逐值一致。
检查所有输出哈希、反馈语义、概率归一化、缺席精度编码、目标可用与精度操作、共同祖先和
种子、单线程设置。初始预算固定为96个过滤/续跑任务、12288条分支路径。完整状态保存后，
另以相同祖先和种子重放这12288条路径，核对状态恢复和后续演化；重放保留原路径的身份，
路径计数分母仍为每点每组96条，模拟标准误以六个过滤器为独立单位。
