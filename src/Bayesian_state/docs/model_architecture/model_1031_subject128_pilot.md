# S128：无数量概括的经验到规则个案

用户要求换一位没有S118中段数量概括的被试。本轮先检查条件1口述，再确定S128，共192题。
已按出现顺序读取全部不同原文及其覆盖的试次，没有发现以长短部位的个数分类的数量概括，
也没有“最长／最短”的排序策略。前64题均明确涉及四部位；第141至192题均只描述尾巴。
第1题为“头长，腿长，脖子、尾巴短”，第129题仍为“脖子、尾巴长，腿中等长度，头较短”，
第141题为“尾巴较长”。特征顺序为尾巴、腿、脖子、头，与S118的中间两维顺序不同。
所有192题保留，口述原文和既有编码保持原状；第65题措辞不顺及第104题重复提到腿另列复核备注。

筛选先使用部位词、数量及排序词检查条件1全部被试，再读S103、S109、S113、S121的标记原文，
完整检查S113和S128的不同原文及其试次。S113含大量排序和跨部位比较，S128的理由过程更直接。
S128的选择在本轮模型拟合之前确定；既有S118资料已参与研究开发，两人均属于开发案例。
早期具体描述与示例记忆相容，实际是否依靠示例记忆仍需检验。

## 固定比较与预算

沿用[S118执行设计](model_1031_subject118_pilot.md)的16点候选、随机种子与数值预算。
配置为`configs/exp123/specific_models/model_1031_subject128_pilot_v1.yaml`。
Model 1031与Model 1024分别使用32粒子两次初筛，前4点128粒子两次复核，前2点512粒子两次确认；
各最终点独立生成64条完整路径。全部192题选择和反馈用于估参，参数排序只用选择似然，口述只参与选人和描述。
自主路径沿固定刺激日程生成自己的回答和反馈，所有路径保留。模型机制和候选范围保持与上一轮相同。

预计核心计算约5—10分钟，硬上限45分钟及12 CPU小时；达到预定任务数或任一上限即结束。
最多128个单线程工作进程，实际进程数受就绪任务数限制。计算完成与心理状态可靠性分别记录。
两次重复、粒子档差异、两个最终候选均报告；逐题NLL差0.01沿用为数值工作诊断值。
