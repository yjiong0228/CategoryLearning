## 第一轮结构假设

为规则维护连续反馈证据，初值为0；每次实际反馈后的递推为

\[
E_t(h)=\lambda E_{t-1}(h)+\log[L_t(h)/L_t^0].
\]

其中，\(L_t(h)\)是在本题学习更新前计算的反馈似然；\(L_t^0\)是无类别知识时的反馈概率。
二值反馈根据类别数区分正确与错误；条件3中错误的参照概率为0.5，半对与全对各为0.25。
\(\lambda\)控制旧证据的保持。共享记忆参数与独立保持率分别比较。
规则退出后证据和精度按现有机制重置，重新进入从初始状态开始。

1. 连续证据控制退出：只有净证据为负时，才使用原自主退出概率；容量仍按相对信念处理。
2. 连续证据控制退出及容量排序：退出同上，容量替换按连续证据选择最弱旧规则。
3. 联合集合选择：搜索先提出候选，再从旧候选与新候选中选择非空、符合容量上限的集合。
   集合的权重为\(\exp[\sum_{h\in S}(E_t(h)-c)]\)。\(c\)是保留成本；负值表示保留偏好。
   新候选的反馈证据为0。分别检查每题选择与仅在搜索事件发生时选择。

联合集合的采样需精确满足上述分布。固定种子、容量边界、空旧集合、全负证据、极端证据、
状态保存恢复和反馈时点均单独验证。联合选择的移除独立记录，不计作原自主退出或容量替换。
原B、R1及旧版本继续兼容；每轮B必须重放独立保存的基线轨迹。

## 顺序研究与停止依据

先做单条件小规模运行和不变量检查，再以相同种子比较第一轮开发被试。
考察完整曲线误差、后期表现、规则发现、驻留、移除、候选作答贡献及路径分布。
模拟单位为整条路径，逐被试报告Monte Carlo误差；后期正确率升高须与完整学习过程共同判断。
根据结果保留少量方案，记录淘汰原因，再开展参数敏感性、独立种子复查和扩展被试检验。

有希望的结构进入相同计算预算的参数搜索和新被试训练／留出比较。
参数搜索预算、粒子数、随机种子及数据分界在相应轮次运行前写入配置。
有限预算的结果标记为有界比较；计算完成与数值或科学验收分别记录。
机制结论需要跨被试保持、数值误差可控，并说明参数可恢复性和结构可区分性。

最多128个工作进程，每进程1个数值线程，只有一个进程并行层。
每轮写入独立结果目录，保存配置、源码校验值、运行环境、所有候选结果和决策记录。
已有数据、拟合及报告保持只读。新增机制代码集中在共享核心。

直接联合选择的主要限制是重复的集合缩减。没有搜索时，可选范围只有旧候选，
删除会减少下一题的可选范围。两条候选的证据及成本均为0时，三个非空集合等权，
一次选择就有2/3概率只留下一个候选。原先设想的静态集合权重尚未表达持续考虑旧解释的倾向。
首轮因此支持增加并单独检验集合变化成本，保留初版作为对照。

容量按累计证据排序对215、222、334有收益，对206的长保持率版本有代价。
候选进入时间不同，累计量同时包含解释能力和观察长度。第二轮将比较按折扣观察量归一化的证据，
并保留原累计量版本，以检验这种时间差是否影响有效规则的准入和驻留。
搜索与保留的组合另列版本，避免将搜索改善归因于保留机制。
