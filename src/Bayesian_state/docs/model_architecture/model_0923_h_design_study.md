## 第一轮结构假设

为规则维护连续反馈证据，初值为0；每次实际反馈后的递推为

\[
E_t(h)=\lambda E_{t-1}(h)+\log[L_t(h)/L_t^0].
\]

其中，\(L_t(h)\)是在本题学习更新前计算的反馈似然；\(L_t^0\)是无类别知识时的反馈概率。
二值反馈根据类别数区分正确与错误；条件3中错误的参照概率为0.5，半对与全对各为0.25。
\(\lambda\)控制旧证据的保持。共享记忆参数与独立保持率分别比较。
规则退出后证据和精度按现有机制重置，重新进入从初始状态开始。

1. 连续证据控制退出：只有净证据为负时，才使用原自主退出概率；容量仍按相对信念处理。
2. 连续证据控制退出及容量排序：退出同上，容量替换按连续证据选择最弱旧规则。
3. 联合集合选择：搜索先提出候选，再从旧候选与新候选中选择非空、符合容量上限的集合。
   集合的权重为\(\exp[\sum_{h\in S}(E_t(h)-c)]\)。\(c\)是保留成本；负值表示保留偏好。
   新候选的反馈证据为0。分别检查每题选择与仅在搜索事件发生时选择。

联合集合的采样需精确满足上述分布。固定种子、容量边界、空旧集合、全负证据、极端证据、
状态保存恢复和反馈时点均单独验证。联合选择的移除独立记录，不计作原自主退出或容量替换。
原B、R1及旧版本继续兼容；每轮B必须重放独立保存的基线轨迹。

## 第二轮与进入留出比较的决定

第二轮使用全部15名开发被试、17个版本、每组32条路径，共8160条。
128个工作进程的运行时间为260.8秒，累计轨迹CPU时间26933.4秒。
480条B路径与独立基线精确一致。此轮源码提交为`41c29191`。

平均证据为\(Q_t(h)=E_t(h)/N_t(h)\)，折扣观察量递推为
\(N_t(h)=\lambda N_{t-1}(h)+1\)。初始\(E=N=0\)，首次观察前的分数定义为0。
退出由累计证据的正负控制；容量不足时，ECM按平均证据移除分数最低的旧规则。
这种除法区分规则解释反馈的质量与它已经获得的观察量。

联合选择加入旧规则保留偏好后，集合分数变为
\(\sum_{h\in S}[E_t(h)-c+b\,1(h\in A_{t-1})]\)。
\(A_{t-1}\)是上一题的候选集合；\(b\)提高继续保留旧候选的权重。
搜索增强沿用已有S1：错误累积失败量，正确反馈按失败保持率衰减该量，再影响搜索概率。

累积失败改变了搜索压力的数值尺度。以二值反馈作近似，假设正确概率固定为\(p\)，
并暂时忽略它与当前失败量的依赖；错误使失败量\(A\)增加1，正确使其变为\(\delta A\)。
当\(0<p<1\)且\(\delta<1\)时，平稳均值为
\(\mathbb E[A]=(1-p)/[p(1-\delta)]\)。
这里，\(\delta\)是正确反馈后失败量的保持率；该近似只用于解释数值尺度。
例如\(p=0.9,\delta=0.99\)仍对应约11.1的平均失败量，可能让搜索概率长期接近1。
因此，累积搜索的保持率和失败增益必须在该机制下重新估计，并结合实际搜索频率解释。

## 路径分布评分与第三轮检查

自主路径的分布评分使用模拟产生的实际正确率，纳入潜在规则变化及作答随机性。
每32题为一块，块顺序保持不变。energy score衡量完整块曲线与实际曲线的距离及预测路径间的差异；
CRPS分别衡量每块的预测分布。两者以越低越好为方向，对全部路径等权计算。
energy score的欧氏距离除以块数的平方根，以便比较不同序列长度。
80%预测区间另外报告覆盖率、宽度与interval score；后者将宽度和观测落在区间外的距离共同计分。
公式使用[Gneiting与Raftery，2007](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf)的定义。
固定参数的路径变异未包含参数估计误差。同一被试的各块相互依赖，当前覆盖率作为描述性诊断。

第二轮15人等权平均的energy score为B 0.1760、R1 0.1362、ECM 0.1274、ECM_S 0.1077、JS_S 0.1164。
ECM_S的80%区间覆盖率为0.645，宽度为0.308；拟合偏差仍然明显。
预测分布的完整性检查与均值曲线给出相近的开发阶段排序。

### 本轮结构决策与参数解释

现阶段采用ECM_S作为后续开发的工作结构，B和R1作为持续对照。其操作顺序保持为：

1. 读取上一题学习更新前的反馈似然，更新在场规则的连续证据、折扣观察量及失败状态。
2. 净证据为负的旧规则按`exit_rate × (1 − posterior)`接受退出抽样；非负证据关闭本次自主退出。
   若抽样后没有得到原信念支持的规则，恢复原信念最高的一条，以定义后续条件化。
3. 根据当前失败状态确定搜索概率及全局搜索比例；发生搜索时提出一条局部或全局新规则。
4. 容量已满时移除平均证据最弱的一条旧规则，新候选获得试用位置。
   平均证据为累计折扣证据除以折扣观察量，帮助比较不同在场时长的旧规则。
5. 在最终集合中归一化幸存者信念，再依功能相似性向新规则分配支持。随后反馈决定新规则的保留证据。

连续证据记录规则解释反馈的能力，归一化信念记录规则的相对作答贡献；这两项状态分别服务于保留和作答。
该流程已经实现、拟合并完成上述预测。默认B配置保持兼容。
本轮证据支持暂留有条件退出与新候选试用，尚未确立唯一的证据保持率、退出函数或搜索控制形式。

失败状态不再改变搜索发生概率。搜索范围仍按其自身参数计算。
这些边界点说明现有拟合涵盖多种实际搜索动态，统一的长时失败累积尚不能解释为所有人的共同学习机制。
