登记日期：2026-10-28。用户授权在已完成的计算精度专项之后开展长时后续工作。
本轮重点是解释已有行为记录，并检查同一被试的其他保留参数是否给出相同解释。
模型、行为资料、参数保留集合及口述编码保持原版本。口述等待用户人工复核，本轮不新增口述分析。

S205作为详细案例：结合真实行为，展示正确规则在场、信念和执行概率随试次怎样变化；
再比较四组保留参数，区分共同结论与参数依赖的解释。S110、S306和S317也逐组比较。
S229只有一组保留参数，展示该条件下的结果并记录无法比较参数的限制。
S129的四组参数尚未通过选参数值检查，单列已有诊断结果，不作为已确立的个体参数集合。

交付包含：逐人状态概率图、S205详细说明、逐状态量的数值检查表、参数间差异表、
每64题的状态与行为摘要、原始输入与源码记录，以及预算和停止原因。旧结果全部保留。
全体案例均为已检查过的开发资料；图表描述完整记录内的重建。

## 状态量与条件

状态记录在本题选择后、反馈前。过滤使用截至本题的选择；完整历史重建进一步使用后续选择。
两者均以完整记录估计出的固定参数为条件，因此过滤曲线也属于拟合后的回顾性分析。
各候选分别计算，候选间范围表示有限参数集合的敏感性，没有后验概率或置信区间含义。

四个正确规则摘要分别为：

1. 正确规则在场概率：这条规则处于当前可用规则集合中的概率。
2. 正确规则平均信念：模型中学习者分给该规则的信念权重，在可能状态上的加权平均。
3. 正确规则在场且信念至少为0.5的概率：同时满足两个条件的概率。
4. 正确规则执行概率：在已观察到本题选择的条件下，本题执行该规则的概率。

另外保存整个规则目录的信念和执行分布。规则在场概率可以同时对多条规则很高；
信念和执行分布各自在完整规则目录上加总为1。S205的详细图保留这一区别。
“正确规则在场却执行其他规则”的概率可由在场概率减去执行概率得到，但其模拟恢复证据仍弱；
本轮不据此给逐次错误下确定的心理原因判断。精确进入时点也继续保留验证限制。

曲线使用全部有效试次；行为背景采用最近32题的正确率。64题摘要从首题按固定长度分块，
末块不足64题时保留实际分母。第一块、最后一块与整段均值用于通俗解释，原逐题结果同时保留。
这些分块只服务结果展示，所有拟合和状态计算仍使用完整序列。

## 计算安排

配置为 `configs/shared/model1024_state_interpretation.yaml`。
上一轮S110、S205的4096粒子结果及S229、S317的8192粒子结果直接复用。
对其余9组保留参数新增2048、4096粒子各16次计算，共288项；使用独立种子和原被动状态记录器。
每组的16次按固定顺序分成前8次与后8次，比较两组加权状态结果；另比较2048与4096粒子。

本轮逐量使用既有数值容忍：平均绝对差不超过0.025、差异的95%分位不超过0.10。
规则信念和执行分布的差异采用总变差距离，即各规则概率绝对差之和的一半。
独立计算的有效数量至少4，单次计算最大权重不超过0.5；每档需完成16次。
原合并分数仍可记录，本轮状态解释逐量判断。工作容忍反映计算接近程度，心理解释准确性另需真值检验。

若S205的新增候选在任何一个上述状态量的完整历史检查上未达到工作容忍，
允许对该候选追加8192粒子16次，每个候选最多一轮，共不超过48项。
该轮同时检查独立重复与4096—8192粒子的差异。检查仍未通过时，交付相应限制及已完成结果。
其他被试本轮以2048—4096补算和已有高精度结果为范围，不持续加量至通过。

正式队列使用最多128个单线程进程、单层并行；资源不足或待运行任务较少时按实际条件降低并发。
预计4—8小时，硬上限为8小时和640 CPU小时，达到任何一个上限即停止队列。
每项最多6 CPU小时，累计3项工作进程失败即停止并排查；启动前预留预测耗时的1.3倍。
源码或输入核验失败立即停止相关计算。报告整理另记录耗时，不追加新的粒子计算。
沿用原记录器与已验证的有界调度器，启动前完成相关小型测试及入口检查。

## 怎样判断换参数后的解释

每个状态量先分别标明固定参数下的数值检查结果，再计算各保留候选之间的最大差异。
正确规则摘要使用每题最大值减最小值；整个规则分布使用各参数对的最大总变差距离。
逐题、每64题及整段摘要均保留。参数间差异和计算重复差异分别展示。

所有候选对某量均完成数值检查后，参数间平均差不超过0.025、95%分位差不超过0.10，
记为“在已检查候选中接近”；超过任一容忍记为“随参数改变”。
有候选的数值检查受限时记为“计算差异仍影响参数间判断”，同时展示观察到的范围。
仅一组候选记为“无法比较参数”。这些标签限定于本轮有限候选和工作容忍。

报告逐句区分模型的概率解释、计算稳定性、参数间一致性及模拟真值证据。
对于S205，详细说明哪些规则概率变化在不同候选下都能看到，哪些内部解释仍随参数变化；
其他人的结论按状态量给出，不用一个被试总体标签替代局部证据。

该分析不增加粒子计算，不改变上述六项状态量的追加条件。逐分布的重复、粒子数及参数间差异另列。

## 行为概率对照

为解释S205的状态变化怎样对应实际表现，同时读取原有逐题类别预测。
