# Model 1024：持续较高与快速改善的分类

2026-10-27。用户提出恢复S110所代表的stable high类别，并将S129描述为突变式改善。
本版在[v3规则](model_1024_trajectory_classification_v3.md)上增加持续较高类，
并按上升所用题数合并单次跃升与短斜坡。全部真人和模拟路径采用同一组数值规则。
规则受到已查看开发案例的影响，分类准确率与阈值稳定性尚未独立检验。
分类标准的模拟检验继续按用户要求暂缓。

## 持续较高：整体水平和局部表现同时达标

持续较高（stable high）定义为以下三项同时成立：

1. 整段正确率至少80%。这个水平沿用初版高表现门槛。
2. 任意连续64题的正确率至少65%。窗口每次前移一题，包含开头和结尾；
   这项要求防止较高的整体均值掩盖一段持续低表现。65%允许64题窗口中的有限波动。
3. 当前选中的描述曲线，其最高与最低水平相差不超过25个百分点。
   这项要求把持续较高且继续有限提高的路径，与经历较大幅度变化的路径区分。

先完成v3的描述曲线选择，再检查这三项。符合时主标签优先采用持续较高。
数值拟合未确定的记录继续为形态未定。这个标签描述记录范围内的高表现，允许进一步改善；
它没有把正确率规定为常数，也没有确定学习开始于实验之前。

S110整段正确率为81.03%，任意连续64题的最低正确率为67.19%，
所选描述曲线从74.16%升到91.16%，相差17.00个百分点，因此归为持续较高。
这些阈值是本次开发阶段的工作定义。当前采用绝对正确率，二分类与四分类的机会水平仍有差异；
跨任务比较这一类的心理含义需要后续证据。

## 突变式改善：同一速度可以由不同曲线描述

原规则将单次阶跃称为突变，将所有向上斜坡称为渐进。
本版把向上斜坡按从起点到终点的完整宽度区分：

- 不超过32题：与单次阶跃一起归为突变式改善。
- 超过32题：归为渐进式改善。

32题沿用现有图中的一个显示块，作为暂定的行为分辨尺度；拟合仍使用逐题对错记录。
改善可以发生在记录中的任何位置。宽度衡量变化用了多久，绝对改善时点继续单独展示。
下降仍属于下降类；多阶段描述沿用v3的额外收益要求。

曲线类别先合并，再比较不同类别。比较仍使用BIC：同时计入拟合误差和描述复杂度的分数，
越小越好。明确变化相对恒定水平至少改善6分，不同类别之间也要求至少6分。
阶跃和短斜坡现在共同支持快速改善，它们之间的分数差不再作为突变与渐进的分歧。

S129的阶跃描述在第191题之后提高；另一条斜坡描述的完整上升宽度约20.03题。
两条描述均支持突变式改善。阶跃与恒定水平的分数差为33.21，达到明确变化门槛。
原先两条曲线之间约5.93分的差距继续保留，但二者现在属于同一类别。
S129的参数数值精度问题仍按原参数研究报告，轨迹标签的改变未解决该问题。

## 输出、代表路径和证据范围

七类依次为：持续较高、未检出明确变化、突变式改善、渐进式改善、下降、多阶段变化、形态未定。
S205继续为渐进式改善，S229、S306、S317继续为多阶段变化。

橙线继续先筛选真人同类，再取原登记形态距离最近的完整模拟路径。
全部路径保留在灰线、蓝色均值及类别比例的分母中。没有同类候选时橙线留空并注明。
持续较高类不指定统一改善中心，右列相应竖线留空；原曲线拟合及趋势变化幅度仍完整保存。
同类是代表路径的必要条件，类内相似程度另报距离。

配置为 `configs/shared/model1024_trajectory_classification_v4.yaml`。
分类结果写入先导研究的 `particle_precision_v2/classification_v4`，
当前六张个体PNG及 `report_v1` 的报告、解读和来源记录同步更新。
逐条记录新增 `level_audit`，保存高表现检查的三个量、检查前标签和数值确定状态。
类别目录由配置决定，原v2/v3配置仍输出原六类。

五种描述曲线的拟合设置保持不变，使用现有分析入口的 `--reuse-fits` 复用v3结果。
核对原始对错序列、种子、拟合损失和曲线参数后，重做类别判定及同类代表路径选择。
参数似然、原形态相容性评分、保留组合和两张总览图均沿用原登记结果。
新增分类仅用于开发资料的描述，未重新运行模型参数搜索或自主生成。

软件检查覆盖短斜坡的宽度边界与方向、高均值下的持续低表现、趋势变化幅度、
同类最近路径及空类处理。逐条核对与软件检查的完成状态，与分类标准的研究验证分别记录。
