# Model 1024：训练选择预测与自主分布共同选参

登记日期：2026-10-25。研究遵守[共同目标与证据标准](../RESEARCH_GUIDE.md)。
本轮接续[路径诊断](model_1024_trajectory_diagnosis.md)，检验参数估计对生成表现的影响。

## 选参规则

使用原九名exp123开发被试的MIX、MAP、持续执行候选，每组原有12个独立确认点。
MIX按信念加权选择，MAP执行最高信念规则，持续执行每题执行一条规则并具有跨题维持倾向。
候选资格依据原训练负对数似然（NLL）确定：相对本组最优值的每题增加不超过0.02。
原NLL提名作为共同参照。0.02是既有开发工作容忍量，候选集用于敏感性评价。

每个合格点生成64条新的训练长度路径，计算Energy。Energy评价32题正确率及类别条件反应
频率的预测分布，两类特征各占0.5权重；距离缩放沿用共享指标。所有路径进入评分。
每组选择Energy最低的点，依次以原训练NLL及候选标识处理并列。规则在本轮模拟之前固定。

原提名与拟议点接受一批独立确认：每点128条训练路径，另以六个新过滤种子、512粒子重算
训练NLL。完整路径或完整过滤重复是蒙特卡洛误差的单位，比较使用配对种子。
当两个条件同时满足时采用拟议点：

1. 新减原的训练NLL差，加两倍蒙特卡洛标准误，不超过0.02。
2. 新减原的训练Energy差，加两倍蒙特卡洛标准误，小于0。

拟议点等于原提名时直接保留原点。其他确认失败时保留原点。本轮每组只提出一次替换，
使用一批确认，随后冻结。全部合格候选及其分数保留，不赋予参数后验权重。

## 资料与数值边界

训练生成只读取训练数组；训练过滤和生成工作进程均禁止打开准备目录中的后段数组。
原候选由整个训练段开发，因此本轮的独立种子确认属于数值确认。训练与后段是本轮的人类
资料划分，已经查看过的后段继续标为开发评价。口述保留外部检验用途。

本轮沿用固定约束规则；选择NLL和Energy来自同一行为记录，按多目标准则使用。
研究分别记录两个评分及其误差，候选之间的差异属于有限搜索库中的估计差异。

排序、生成确认、似然确认、冻结后过滤及冻结后生成使用不同种子角色。种子在参数点与
机制间配对，后续阶段与以前结果使用的种子不重合。一个进程一个数值线程，单层进程并行，
最多128个准备就绪的任务。流程先以一人、短训练序列和一个工作进程检查。

## 冻结后的评价

参数清单及确认决定全部冻结后，才打开本轮后段数组。每组原点和最终点采用共同的六个
新过滤种子、512粒子，沿真实前段历史更新，评价后段条件选择概率。两点相同时复用同一结果。
从任务起点分别生成128条完整路径，沿自己的选择和反馈更新；两个估计使用相同种子预算。

报告训练与后段NLL、自主路径完整序列及后段Energy、后段正确率分布，以及既定的最大改善、
改善后保持和最低128题表现。评分及其配对蒙特卡洛标准误同时报告。具有完整保持窗口的
最大改善联合事件沿用上一轮定义，改善与保持保留在同一条路径上。
训练参数冻结后、读取本轮后段评分前，另登记训练段Energy的补充数值复核；它采用冻结后
同一批新路径，保留已经冻结的参数决定。主要评价量和选参规则沿用上述登记。

正确规则由既有训练刺激几何审查确定。生成路径记录规则发现、在场、贡献、精度与适用
模型中的执行错误来源，比较新旧估计的过程解释。它们是已知生成状态；真人状态重建的
准确性继续由恢复及口述检验评价。当前执行恢复的识别限制继续保留。

## 预算、停止与复现

上限为27组、324个候选，每点64条训练排序路径；每组至多一对参数、128条确认路径、
六次512粒子训练过滤。冻结后每组至多两点，各六次512粒子全序列过滤及128条完整自主路径。
实际任务数由训练资格和同点复用决定。计算预算固定，确认失败属于本轮完整结果。

配置见[固定配置](../../../../configs/shared/model1024_generation_selection.yaml)。从仓库根目录运行：

```bash
python -m src.Bayesian_state.workflows.analysis.model_1024_generation_selection --phase train --config configs/shared/model1024_generation_selection.yaml --output NEW_TRAINING
python -m src.Bayesian_state.workflows.analysis.model_1024_generation_selection --phase evaluate --config configs/shared/model1024_generation_selection.yaml --training NEW_TRAINING --output NEW_EVALUATION
```

交付冻结清单、所有训练候选、决定与未通过原因、逐路径及逐组比较、PNG和报告，保存输入
与源码哈希、种子、版本及运行状态。更复杂机制的比较根据本轮仍未解释的现象另行制定。

## 完成记录：2026-10-25

本轮评估263个合格候选，完成16832条训练排序路径、6656条独立确认路径及312个训练过滤
任务。27组指九名被试各三种机制；其中9组通过双重确认。冻结后以共同的新种子完成216个
全序列过滤任务和4608条完整自主路径。所有原参数、未通过的提议和新参数均保留。

九组新估计的后段NLL均下降；自主生成的后段Energy在六组改善、三组变差。110的三种机制、
205的MIX和持续执行、306的持续执行获得生成收益。例如205的MIX平均后段正确率由0.492
提高到0.655，110的持续执行由0.704提高到0.828。三个机制共享被试，这些计数描述开发比较。

317的三组新估计后段NLL改善，但平均自主后段正确率由约0.573—0.620降到0.406—0.412。
其训练段Energy在新的冻结后路径中继续改善，完整序列及后段Energy则变差。这项分歧说明，
本次选参可以更好地描述其训练低表现，同时削弱自主生成后续学习的能力。条件预测沿真实历史
更新状态，自主生成沿自己的历史形成状态；两项结果共同约束个体参数的解释。

在317的自主路径中，末段正确规则在场比例由约0.38—0.42降至约0.12；首次在场后的缺席比例
由约0.02—0.05升至约0.39—0.40，正确规则的条件精度均值变化较小。持续执行新估计中，约
96.8%的生成错误发生在正确规则缺席时。多个参数共同变化，发现/保持是下一轮需要隔离检验
的过程线索。129、229的最终参数保留原点，预定最大陡升—保持联合事件仍分别为0/128。

下一步优先从共同的前段状态开展自主续跑，区分状态形成与后续规则发现、保持和精度更新
造成的差距。新选参规则下的参数恢复、状态恢复和口述预测另行检验。当前选参规则保持研究
候选状态；本轮结果用于制定下一轮定向干预，冻结后较差的个案继续保留。
