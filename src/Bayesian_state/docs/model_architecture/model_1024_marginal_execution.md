# Model 1024：零维持参数下的执行身份解析求和

本轮检验状态推断中的计算误差。口述待最终人工检查，资料沿用已有模拟行为与生成真值。
执行维持参数为0的6个固定抽取案例参加比较，生成参数与模拟行为的开发用途保持原有记录。

## 为什么可以求和

在当前信念候选中，知觉、规则搜索、候选替换、所有活跃规则的信念与精度更新，都根据刺激、
已观察选择和反馈推进。执行身份与规则信念分别记录。执行维持参数为0时，给定本题其他
状态，各规则的执行概率等于其选择前信念。计算作答概率时可以把所有可能的执行身份逐项求和，
减少为执行身份额外抽样造成的波动。心理过程仍保留每题执行一条规则的潜在变量。

令规则 \(h\) 的执行先验为 \(\rho_h\)，本题选择为 \(a\)，该规则产生这一选择的概率为
\(L_h(a)\)。对执行身份求和得到 \(m(a)=\sum_h\rho_hL_h(a)\)。观察选择后，该规则的条件
执行概率为 \(q_h=\rho_hL_h(a)/m(a)\)。\(q_h\) 描述执行身份的不确定性，规则学习中的
信念保持原有反馈更新。执行先验和选择后执行概率分别保存。

例如，两条规则的执行先验为0.25、0.75，它们产生本题选择的概率分别为0.9、0.1。该选择的
边缘概率为0.3；观察到选择后，两条规则的执行概率变为0.75、0.25。这里改变的是观察者对
本题执行身份的推断。学习者的规则信念仍按既定反馈机制更新。

当前共享的加权读出可以计算上述边缘作答概率。这里将它作为对单规则执行身份求和的计算
载体；模拟真值与错误来源继续按单规则执行模型解释。在这些限定条件下，两种读出的
完整行为概率相同。行为差异检验需结合执行维持、执行影响学习等具体假设。

## 验收条件

先核对共享模块的依赖关系，并在三种反馈条件中改变执行身份，检查信念、精度、候选、配对
及搜索随机流是否相同。小规模共享模型路径逐项枚举执行身份，核对整段行为概率和选择后
执行后验。精度仅更新当前执行规则、非零维持参数或额外作答调节属于其他配置，单独检验。

正式运行使用C005、C006、C007、C008、C010、C013，每例512粒子及原有3个种子。
C006的过早进入、C008的14题片段及C013的长序列历史丢失另外使用1024粒子检查，合计27次
过滤。与原512粒子单规则抽样法比较在线过滤、32题固定滞后、共同前缀及完整序列平滑。
两个粒子数用于数值比较，最高粒子数保留本轮预算的含义。

评价目标包括在场、高信念、执行目标规则的概率，以及三类错误来源。选择后执行身份使用
\(q_h\)，与选择前执行先验分别计算。连贯祖先路径保存目标在场、信念及该路径下的条件
执行概率；在场题数、首次进入和持续长度从共同观测终点的路径计算。祖先有效样本量、
跨种子差异和概率恢复共同约束结论。固定滞后逐题使用不同观测终点。

祖先有效样本量衡量保留的历史多样性，定义为各个不同祖先的总权重平方和的倒数。

自主生成继续抽取每题的执行身份。回顾性推断沿每条祖先路径保存条件执行概率，并按该
路径的后验近似权重求和。执行题数的方差同时计算同一路径内的执行随机性，以及不同状态
路径之间的差异。这样可以在减少数值抽样误差的同时，保留模型规定的过程随机性。

## 运行与输出

配置为[model1024_marginal_execution.yaml](../../../../configs/shared/model1024_marginal_execution.yaml)。
每次运行创建新目录，保留原模型、原路径、已完成的过滤与平滑结果。新增代码只提供当前
候选下的数值求和与被动记录，模型默认入口和自主生成机制沿用既有实现。

从仓库根目录运行，分别使用新的输出目录：

```bash
python -m src.Bayesian_state.workflows.analysis.model_1024_marginal_execution --config configs/shared/model1024_marginal_execution.yaml --output results/model_1024/marginal_execution_smoke_NEW --smoke
python -m src.Bayesian_state.workflows.analysis.model_1024_marginal_execution --config configs/shared/model1024_marginal_execution.yaml --output results/model_1024/marginal_execution_run_NEW
python -m src.Bayesian_state.workflows.analysis.model_1024_marginal_execution_summary --run results/model_1024/marginal_execution_run_NEW --output results/model_1024/marginal_execution_summary_NEW
python -m CategoryLearning_codes.figures.fig3.model1024_marginal_execution --source results/model_1024/marginal_execution_summary_NEW --output CategoryLearning_codes/figures/outputs/fig3/model1024_marginal_execution_NEW
```

两个完整无记录载体对照与27次正式过滤共用一个进程池，分别对应C005、C013的首个512粒子
种子。运行完成后逐数组核对预测，验证新增记录操作。数值工作进程沿用归档模型及既有
信念适配层，每进程一个数值线程；就绪任务数与可用CPU共同限制并行数量。

输出保存每个粒子的目标在场、信念、条件执行概率、祖先索引和选择后权重。共享读出的
原始记录以计算载体命名，科学评分使用重建后的单规则执行概率。执行题数报告均值与总
方差；在场题数和首次进入区间从完整祖先路径计算。首次进入的未进入编码为终点加1，
对应的未进入概率另行保存。

## 本轮结果

三条件共享模型的执行身份干预与短路径穷举检查通过。正式完成27次过滤及2次完整载体
重放，两次重放的预测数组逐项相同。Brier分数为预测概率与0/1真值差的平方均值，越小表示
概率恢复越好。512粒子下，6例在线在场Brier均值由0.250降到0.239，
完整平滑由0.135变为0.141。关键错误的完整平滑检出由15/54变为18/54，误报由17降到9；
在线检出由3/54变为0/54。不同评价量反映恢复中的不同取舍，各案例及种子均保留。

每次完整过滤的平均重采样次数由204.2降到109.5。解析求和提高了部分祖先多样性，完整
平滑仍保留很少的早期历史。C013的在场概率在512与1024粒子间最大变化约0.382，前缀
平滑约0.437；其整段在场题数的1024粒子均值则约为570、571、572题，真值为569题。
逐题进入与整段功能量分别检验。C007的3题及C008的14题片段继续漏报。

本轮验收支持使用解析求和描述零维持参数的条件执行分布。完整后验的数值可靠性仍需
提高，接下来优先检验能够重新更新早期状态历史的方法。口述继续待最终人工检查，当前
认知机制保持候选地位。表格、图与来源见[完整报告](../../../../results/model_1024/marginal_execution_report_20261025_v2/report.md)。
