## 原建议的六步分别在做什么

### 1. 先保证程序在正确输入上可靠运行——本次完成的部分

处理“程序能否正确运行、遇到坏输入能否拦住、结果能否追溯”这三件事。例如，把 `1.25` 当作
类别 1、把倒序表当学习序列，都可能产生看似正常的拟合。本步骤通过明确报错避免这种情况。
旧断点也不能只因路径相同就继续用：同一路径下的数据或引擎可能已变。

产出是经过测试的实现、当前文稿／配置的一致版本、明确的新旧断点规则。它不证明心理参数可被识别。

### 2. 让同一模型算得更快

先把已验证原型变成正式实现：零 beta 规则直接返回均匀预测；重复的同一规则／实际感知刺激距离
按需缓存。正式缓存需有容量上限、生命周期和返回数组的保护，避免长任务内存不断增长或缓存被改坏。

验收应比较同一输入、参数和 seed 下的完整预测与状态，而不仅是最终 NLL。覆盖多种容量、执行结构、
condition、长序列和并行后，再测时间与内存。前次小样本的约 1.65 倍只是原型结果，不能直接作为正式承诺。
这一步主要节省后续反复拟合与恢复的计算成本。

### 3. 让模型正确表达 exp4 和 exp5 的实验规则

exp4 的 `probCat1/probCat2` 决定随机反馈，不能用最大概率类别代替实际抽样反馈；同一被试跨 session
延续知识。观察拟合使用实际记录的反馈，自主生成时才依据任务概率抽样。

exp5 先接 Rule1 的 501、503：核对五维离散刺激、相应规则空间与离散感知机制。其余被试、Rule 和
多 session 的扩展按已交付 PDF 规划逐步加入。接入后先验证数据、反馈与短序列生成的含义一致，
再进入恢复与正式拟合。“接口能运行”只是这一阶段的一项检查。

### 4. 检验能算准、能找到好候选、能认回已知机制

这一步包含三个不同实验：

1. **PF 数值校准**：固定参数，增加粒子数 R 和独立 seeds 数 B，检查预测、NLL、候选排序与潜在状态
   是否足够稳定。目的是确定计算预算，R 不是被试的工作记忆容量 M。
2. **搜索预算校准**：以高预算为参照，检查低预算粗搜是否会提前淘汰最终有竞争力的候选。
3. **恢复实验**：用已知模块、参数和潜在状态生成模拟数据，再隐藏真值重新拟合；检查是否找回它们，
   哪些参数互相补偿、哪些状态不可靠。choice NLL 收敛不等于状态路径已恢复。

exp4 与 exp5 都要按自己的任务重新验证。若参数／状态恢复不好，应先收窄可解释结论或调整设计，
再决定是否正式拟合；不能仅增加 PF seeds 就宣布可辨识性问题解决。

### 5. 拟合真实被试，并检验后续预测

先固定训练／验证分界和评价指标，再在训练数据上选参。参数冻结后评价后续行为；验证序列中可以
逐试次使用已经出现的选择和反馈，但不能用将来试次重新选参数。留出预测与自主生成分别报告。

保留不同结构与参数组合中分数相近的候选，标记触边参数，并与合理竞争模型比较。产出包括估计、
近优集合、预测性能与不确定性，而非每人仅一个被当作真值的 best 参数点。

### 6. 用通过验证的状态解释瓶颈、补偿与知识继承

把模型状态转成可检验问题：目标规则没进入候选、进入后留不住、预测精度低，还是选择执行环节受限？
利用未参与选参／结构开发的口述或后续行为检验这些解释，并比较行为历史基线。若口述反复用于修改
模型，它就不再是独立检验资料。

知识继承需分别操纵“新人提议是否更局部”和“新人信念是否继承旧规则支持”，匹配新人总质量等因素，
避免一个参数同时改变两种机制。模型内反事实说明模型依赖，不等于已经建立人类学习的干预因果证据。

第 1 步解决实现可靠性，第 2 步减少计算成本，第 3 步确定任务语义；第 4 步为第 5、6 步提供数值与
识别依据。可以提前准备分析代码和口述编码，但正式心理解释依赖这些检验结果。
