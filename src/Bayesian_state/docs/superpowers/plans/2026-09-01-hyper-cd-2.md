# Hyper-CD 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the existing Hyper-CD optimizer with effective minimum-improvement control, deterministic coarse-to-fine initialization, same-stage checkpoint/resume, and independent high-precision final rescoring.

**Architecture:** Keep `HyperCDOptimizer` and the public Grid/CD workflow intact. Put checkpoint serialization and fine-point projection in a focused helper module, while the optimizer remains responsible for candidate evaluation and artifacts. New behavior is opt-in through `search_schema_version: 2`; legacy configurations retain their current semantics.

**Tech Stack:** Python 3, NumPy, PyYAML, joblib, pytest, existing Bayesian_state simulation and optimization contracts.

**Spec:** `docs/superpowers/specs/2026-09-01-hyper-cd-2-design.md`

## Global Constraints

- Do not change Model0826 cognitive equations or particle weighting.
- Preserve all existing Hyper-CD configurations unless `search_schema_version: 2` is set.
- Never silently delete a schema-v2 output directory.
- Candidate-level PF repeats must be averaged as trial probabilities before choice NLL.
- Exact zero and mapping-valued coordinates remain exact candidates.
- New generated plots are PNG only; this optimizer phase does not need plots.
