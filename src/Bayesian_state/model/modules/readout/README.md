# 读出层（R）：从内部状态到可观察反应

`readout/` 集中实现模型的输出层。`StateModel` 在作答阶段调用它，输入是当前认知状态，
输出是选择、口述或反应时的概率描述。学习更新由 engine 的认知模块负责。Model 0923 文档将两个读出分支分别记为
选择读出模块（RC）与口述读出模块（RO），对应 `choice.py` 和 `oral.py`。

| 文件 | 职责 |
|---|---|
| `choice.py` | 选择读出（choice readout）：类别选择概率、输出噪声及本题规则来源快照 |
| `oral.py` | 口述读出（oral readout）：读取所选类别的局部规则，生成省略、表达变体和刺激补充 |
| `report_space.py` | 固定口述词表与规则内容的表达核 |
| `observation.py` | 使用同一规则来源计算选择与口述的联合概率 |
| `oral_kernel.py` | 给定规则权重和报告映射的归一化观测核 |
| `reaction_time.py` | 反应时观测接口 |
| `shared.py` | 共享概率归一化和配置校验 |

典型时序为 `begin_trial → predict_choice → predict_oral → complete_trial`。
口述读取 choice 保存的内部刺激、规则来源和类别概率；采样使用调用方单独提供的口述 RNG。
选择和口述配置分别保留在 `choice_readout` 与 `oral_readout`，由 `StateModel` 调用。
engine 的 `agenda` 继续管理知觉、假设转换、记忆和精度的学习步骤。

Model 0923 的行为参数仅用选择数据估计；oral 使用事先固定的共同表达设置产出报告
预测，与真实口述比较。真实口述不进入行为或表达参数拟合，不修正粒子权重，也不更新
学习状态。选择—口述联合概率用于保留输出的共同来源和汇总预测。当前接口显式生成
单条路径的口述，批量预测与真实报告比较仍待接通。

2026-10-11 修订设计采用连续作答贡献与主导惯性，口述按本题贡献表达一条主要依据，
补充对象按内部长短显著度选择。当前 full 的单规则执行和口述的均匀补充仍待同步，
设计与实现状态见[主规范第16.4节](../../../docs/model_architecture/model_0923.md#164-本次修订与运行实现的对应2026-10-11)。

代码统一使用 `src.Bayesian_state.model.modules.readout.choice` 和 `.oral`，
口述词表及联合概率分别使用 `.report_space` 和 `.observation`。

152条四分类目录也通过上述入口生成口述。新增相近规则沿用二分类的表达：
长度差至多0.10时可说“差不多长”；差距大时，按本题内部知觉选择相应方向的区域来表达。
再与第三个部位的长短组合，例如“脖子和腿差不多长，尾巴短”。省略以这两个判断为单位。
核心报告矩阵为152×4×692，包含刺激补充的口述读出模块另行生成完整词表。
