# Model 0923：拟合、一次补查与逐人评估

完整队列按顺序运行被试拟合。全部拟合结束后，程序按验收标记执行一次有上限的追加检查，
再为每人生成评估v2报告和PNG。程序完成、参数验收与行为解释分别记录。
每个已完成的参数结果都进入后分析，报告保留未解决问题和缺失数据状态。

## 追加检查的输入和步骤

输入为完整Plus拟合的候选参数、人工边界标记、原数据配置和冻结源码。
处理后数据、13项认知机制、试次顺序与反馈前计分约定沿用原拟合。
源码快照保存原模型计算层，并接入当前分析层；原拟合目录保持只读。

1. 根据近优候选的人工边界生成外侧参数点。概率参数与迁移尺度保持严格大于零；
   容量保持整数。自然边界保留原机制含义。每个外侧点只改变一个参数，
   这一步检验指定方向上的范围限制，联合方向和整体最优性仍需结合完整搜索判断。
2. 原候选和全部外侧点使用同一组新种子，以128粒子、16次重复重新引导评分。
   每名被试最多追加48个外侧点。各试次概率先跨种子平均，随后计算选择负对数似然（NLL）。
3. 引导评分选出提名参数，并冻结独立审查库。审查库保留全部原候选和最多6个引导评分最好的外侧点。
4. 使用另一组新种子，以256粒子、64次重复做一次独立评分。
   共享数值诊断估计预先提名参数相对审查库的每题NLL损失上界，容许值固定为0.005。
   此次追加审查在两名被试间分配总alpha=0.05，每人alpha=0.025；
   原审查的alpha分配和原验收记录各自保留。
5. 根据新评分复核扩展范围的边界。新外侧点仍接近最优且继续触边时，结果继续标为未解决。
   程序随后进入后分析；本协议追加一次，到规定预算后保留结果。

随机种子的数值区间描述有限粒子积分的波动。参数统计区间、粒子数收敛、参数恢复、
留出泛化和完整内部路径分别记录为后续检验。独立审查结束后保留原提名参数，
独立审查分数用于判断该提名参数的数值证据。

追加预算和边界值集中在
[`model0923_continuation.yaml`](../../../../configs/shared/model0923_continuation.yaml)。
这份配置用于MEG 335与exp123 307，任务按335、307顺序推进。

## 后分析交付

每人使用评估v2：行为对齐、口述对齐、内部表征、自主学习以及数值诊断。
完整有效序列用于拟合内预测；固定参数下的粒子分布描述逐题状态，
自主学习沿用该人的刺激日程并生成模型自己的回答与反馈。
缺失口述和未配置的实验结束标准保留明确状态。
结果包含逐题与逐人表格、可复核的种子数据、HTML报告和五张逐人PNG。
各参数结果的验收标记写入评估报告，接近的参数组合保留在候选表。

## 已完成的旧队列

```bash
python -m src.Bayesian_state.workflows.runs.run_model_0923_complete_pipeline \
  --source-queue results/model_0923/plus_335_then307_20261013_v1 \
  --output-dir results/model_0923/plus_335_then307_continuation_NEW
```

可先加`--prepare-only`冻结追加预算、源码与评估设置，再用同一新目录的`--run-prepared`执行。
`--smoke`保留两人，使用每人前32条拟合验证序列、2/4粒子、各2次重复和一个worker；
评估验证使用前16条有效试次和两条自主轨迹。短验证仅检验程序连接和产物契约。

`pipeline_status.json`记录当前被试和阶段，`index.html`链接逐人报告和PNG目录。
每人的`continuation/`保存冻结提名、逐种子概率缓存、独立审查和新参数结果；
`evaluation/`保存评估报告。原候选、原评分和原边界状态保存于原目录。
同一冻结版本下，追加评分可以按缓存续跑；已完成评估先核对产物与输入哈希，再跳过计算。
中断产生的部分评估结果保留，恢复时自动选用新的重试目录。评估目录最多尝试两次，
达到上限后记录失败原因和已有产物。已通过验收的原拟合直接进入评估。

正式计算最多使用128个worker，每个worker一个数值线程，一次只运行一个阶段。
新参数点、随机种子和预算在计算前冻结；模型源码与输入改变时，恢复校验会报告差异。
