# 0923 到 1031 的架构变化

## 科学状态

本仓库目标为 CategoryLearning `249144de` 的最终十参数 `1031-unified-v2`。
0923 的活跃内容是目录规则；1031 的工作区同时保存具体样例模板、局部概括模板和
固定标签目录规则。每项内容具有信念质量、判断精度和持久内容身份 uid。
槽位仅用于存储；不同粒子同一槽位中的内容可以不同，跨粒子汇总按语义类型进行。

初始 null 状态给出均匀类别预测，Cond3 的三种配对各为 1/3。第一次有效完成经历形成
首个样例并替换 null 状态。样例保存感知中心、保留维度与关联类别分布；匹配亲和度
（affinity，输入与模板的匹配强度）随保留维度上的距离增大而下降，由相似宽度控制。
精度控制匹配时的类别偏向，未匹配部分贡献均匀预测。局部概括通过删除一个保留维度
形成，继承父模板的条件标签和配对信念；端点探测可提出目录规则。候选去重、反馈相关
接纳和容量检查共同决定下一题工作区。容量下界为 1，与目录规则数量独立。

## 条件标签

Cond1/2 的模板保存类别分布。Cond3 每项内容保存三种同科配对的条件概率
`q_h(g)`，每个模板再保存 `theta_hg(c)`，形状为 3×4；每行表示给定配对下的四类别分布。
联合内容与配对质量为 `J_hg = pi_h q_h(g)`。该结构保存类别与配对的统计依赖。
例如半对反馈在每种配对下限定一个不同类别，即使配对边缘暂时仍均匀，条件类别已经
受到约束。新样例在每种配对的允许类别中均匀初始化，并继承工作区配对边缘。
所有内容依据实际选择与反馈更新，包括当题未执行的内容。

## 搜索与保持

1031 用累积失败量 `F` 决定搜索机会，初值为 0。完全成功后
`F_next = failure_decay * F`；其余结果使 `F_next = F + 1`，Cond3 的半对也计一次。
下一题搜索概率为 `sigmoid(logit(baseline_probability) + error_gain * F_next)`。
`logit(p)=log(p/(1-p))` 将基准概率转为对数优势，`sigmoid(x)=1/(1+exp(-x))`
将累积证据映回概率。该量取代 0923 的指数移动平均失败压力。
1031 的搜索通过全局检索与局部模板操作生成内容，移除了旧自主退出、结构编辑混合和
按功能距离向新内容转移信念的机制。

保持采用幂归一化：先把旧概率提升至保持指数，再除以总和，使其重新构成概率分布。
完全成功时内容保持指数为 1；其余反馈使用 `retention`。每项内容内部的条件配对分布
每题均使用 `retention`。保持后的联合质量乘以反馈似然，再归一化得到反馈后信念。
似然指在当前内容与配对下产生实际反馈的概率。指数为 0 时使用活跃支持上的均匀分布。
模板的条件类别分布随后依据同一反馈更新。

## 执行与精度

执行按内容信念和上一执行 uid 的惯性偏向抽样，一题实际执行一项内容。该内容给出
当题行为分布。上一内容被移除后，其 uid 不再产生惯性偏向。粒子滤波按观察选择给
路径加权；自主模拟抽样选择并由任务协议生成路径自己的反馈。两者共享状态演化，
诊断需标明选择前、选择后及反馈后的条件时点。

ADD10 精度更新为
`beta_next = clip(beta + 10 * learning_rate * d(log L)/d(beta), 0.1, 25)`。
`L` 是实际反馈的内容似然，导数表示提高精度如何改变该反馈的对数似然。
计算使用反馈前的精度和类别信念，Cond3 对保持后的条件配对概率求和并在求导时固定
该概率。内容、配对和模板标签更新共同使用精度改变之前的预测；模板标签最后更新。
新内容继承加入前的信念加权平均精度。固定倍数 10 是本版 ADD10 约定。

## 优化与身份

唯一十参数接口为 `capacity`、`similarity_width`、`baseline_probability`、`error_gain`、
`failure_decay`、`global_search`、`retention`、`execution_inertia`、`beta_init`、`learning_rate`。
有限支持搜索保留分散起点、单坐标邻居、双坐标邻居和全局提议。三个阶段为 search、
rescore、audit，阶段种子独立，同阶段候选共享种子。目标是在每个计分试次先对重复运行
的选择预测概率求平均，再取负对数，最后对计分试次平均；零概率对应无限负对数损失。

任务采用单层动态 OpenMP 调度，种子由根种子、数据指纹、阶段和重复编号决定，结果
按候选索引归集。Windows 上限为 8 workers。缓存身份包含实际输入数组、任务与知觉
信息、计分掩码、十参数、资源、粒子数、种子、模型及 RNG 身份；线程数不改变科学身份。
原子发布拒绝覆盖已有结果。缓存 schema、优化 RNG 与 provenance 显式包含
`1031-unified-v2`，保证与旧 0923 命名空间分离。CLI 的恢复清单匹配由父任务集成。
NPZ 的校验式 ZIP 读写、CRC 检查、标量形状与拒绝覆盖行为保持原样。
