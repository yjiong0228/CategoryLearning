# Behavior 图核查

## 两张蓝图为什么相同

原第二张图统计自主模拟选择是否命中真实类别：

\[
c_{r,t}=\mathbf 1(y_{r,t}=y^*_t).
\]

原第三张图统计同一条自主学习路径从任务实际得到的 feedback credit。
Cond1/2 的任务定义是答对得 1、答错得 0，所以逐路径、逐 trial 有
`feedback[r,t] == c[r,t]`，不只是两条均线相近。相同输入经过相同滑窗和分位数运算，
100%/90%/50% bands 和均值必然完全一致。这不是复用了错误数组，也不是所有 repeats
使用相同随机轨迹。两个面板原本展示的是同一个量的两种命名。

Cond3 则是答对得 1、选错同科类别得 0.5、选错科得 0。第三张不能删掉或当作正确率。
该 feedback 由真实任务的固定类别/科映射决定，不由模型学到的 pairing belief 决定。

核查了 `results/cond1_full_eval` 的 32 名被试：所有自主选择与反馈均满足该等式；
其保存图像数值中的八条蓝色 band/mean 序列也逐值相同。原始 exp123 有效记录核查：

| 条件 | 有效 trial 数 | feedback 与 0/1 正确率不同的 trial 数 | 其中半对 |
| --- | ---: | ---: | ---: |
| Cond1 | 10,048 | 0 | 0 |
| Cond2 | 31,872 | 0 | 0 |
| Cond3 | 20,800 | 4,172 | 4,172 |

另外核对 Cond3 的固定同科划分 `{0,1}` / `{2,3}` 与实际反馈，20,800 条记录全部一致。

修改后，只在 Cond1/2 的 observed 值、mask 以及全部自主 bands 确实相同时省略重复
面板，并在图标题说明。若数据不等价，即使是 Cond1/2 也保留第三张。Cond3 始终保留。
所有数值指标和原始数组继续分别保存。另增加保存结果校验：自主 feedback 必须与任务
协议一致，防止错误反馈数组或错误类别映射悄悄进入画图。

## Observed 为什么看起来有曲线

没有对 Observed 用 LOESS、样条、指数平滑或插值。代码先计算 trailing mean，再由
Matplotlib 的普通 `plot` 用直线连接相邻 trial。

令 `v_j` 表示有效且计分的 trial，窗口大小为 W；窗口不跨 session：

\[
A_t=\frac{\sum_{j=\max(s_t,t-W+1)}^t v_j c_j}
{\sum_{j=\max(s_t,t-W+1)}^t v_j}.
\]

`s_t` 为当前 session 起点；分母为零时结果是 NaN。首个有效 trial 按原计分约定排除。
窗口未满时分母从 1、2、3……增加。例如首四个计分结果是 `[1,0,0,0]`，显示值为
`1, 1/2, 1/3, 1/4`，连接起来像一段弯曲的下降；窗口满后分母固定，Cond1/2 每步变化
通常是 0 或 ±1/W，视觉上更像折线。缺失题或 session 重启也会改变有效分母。
Cond3 的 feedback 还可能以 0.5/W 为步长，但 true-category accuracy 仍是 0/1。

## 结果与边界

直接重画已有 32 名 Cond1 被试的输出至 `results/cond1_full_png_checked/`，共 96 张 PNG。
没有重跑拟合、PF 或自主 repeats；原图不覆盖。逐项对照确认正确率、Observed、
条件预测和自主 bands 数值不变，改变仅是冗余面板、标题和输入校验。
