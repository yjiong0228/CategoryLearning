## 已实现

- C++20 模型、粒子滤波、自主模拟、有限支持参数搜索、数据与结果读写。
- 样例模板、删除单维的局部概括、基于端点探测的固定目录规则检索。
- 失败累计驱动搜索、容量替换、反馈相关新人质量和 uid 持续执行惯性。
- Cond1/2 的内容信念与模板类别学习；Cond3 的内容-配对-类别条件依赖。
- 反馈前预测/Beta、ADD10 梯度更新、choice-only PF 权重与重采样后下一题搜索。
- 单层 OpenMP 候选×种子/模拟任务；按任务种子复现，不依赖线程完成顺序。
- Python 仅离线读取结果、计算展示统计和输出 PNG，不重新运行模型。
- 状态图按四种语义类型汇总，不把不同粒子相同槽号误当作同一内容。

优化流程沿用简化库的分散起点、邻域/全局提议、独立重评和验收，不复刻原 Python
仓库的完整研究性优化流水线。目标是逐 trial 的种子平均选择概率之负对数。
