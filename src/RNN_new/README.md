# RNN Models for Category Learning

## Files
- `RNN_no_permutation.py`: RNN without feature permutation
- `RNN_with_permutation.py`: RNN with two-permutation manipulation

## Usage
Both scripts require `Task2_processed.csv` in the same directory.

### No permutation version
```bash
python RNN_no_permutation.py
```

### With permutation version
```bash
python RNN_with_permutation.py
```
