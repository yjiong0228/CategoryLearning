# Cohen–Schneidman 特征混合模型：复现核查与连续刺激扩展

本目录是 Cohen & Schneidman (2013) 的独立复现。2026-10-30 核查依据为
[论文正文](https://pmc.ncbi.nlm.nih.gov/articles/PMC3545760/)、本目录保存的正文 PDF
和文件名以 `curve 1.pdf` 结尾的 Supporting Information（SI）。原作者代码尚未取得。
二元实现保留原来的默认学习约定；连续版是针对 exp123 任务另行定义的模型扩展。

## 核查结论

| 核查项 | 结论与处理 |
| --- | --- |
| 二元刺激及特征 | 原实现的 ±1 编码、所有非空子集的乘积特征与正文一致；四维共有 15 个特征，五维共有 31 个。 |
| 类别内分布（式 1） | 对全部二元模式枚举并计算归一化常数，正确实现所定义的指数分布。 |
| 选择概率（式 2） | `log Z_pos - log Z_neg`、`alpha_neg - alpha_pos` 与 `gamma` 的符号正确；已用直接贝叶斯计算独立核对。 |
| 学习方向（式 3、S1–S3） | 特征更新方向和 gamma 更新符号一致。步长写法存在下述歧义，旧实现头部的“formula-faithful”断言已移除。 |
| 学习时序 | 当前题先预测，随后用反馈更新；默认记忆窗口为 1。 |
| 拟合目标（式 5） | 累加实际作答的逐题对数概率，初始 gamma 固定为 0，符合正文 Methods 的定义。 |
| 优化器 | GA 加模拟退火与论文描述的算法家族一致。公开材料未给出完整搜索超参数；当前种群、范围、变异与退火日程均为复现选择。 |
| 数值似然 | 原程序把选择概率截断到 `1e-12`，会改变极低概率回答的目标值。现用稳定的 log-sigmoid 计算，移除这一截断。 |
| 数据校验 | 原程序把所有非 1 类别映射为 −1，并可能因数组长度不同而静默截断。现显式拒绝非法类别、长度、刺激 ID、步长及拟合前缀。 |
| 状态复制 | 原 `copy()` 丢弃反馈历史，影响窗口大于 1 的续跑。现复制参数和历史。 |
| 输出 | 原 `--formula-csv-name` 未生效，现已接入。运行入口拒绝覆盖已有目录，并保存拟合初始参数。 |

### 学习步长的三个明确约定

令 `g_c` 为正文式 3 中去掉学习率后的向量，即

\[
g_c=(1-P(y\mid x))\,y\,c\,[f(x)-E_c(f)],\qquad c,y\in\{-1,+1\}.
\]

这里 `f(x)` 是当前刺激的特征向量，`E_c(f)` 是类别 c 的内部刺激分布下的特征期望。
eta 表示学习率，beta 表示模型的确定性参数，控制类别分布的集中程度。
该向量把错误预测相关的特征向正确类别调整。窗口大于 1 时，使用窗口内各题向量的均值。
每次更新后都做归一化：将向量除以其欧氏长度，使每个类别的权重长度恢复为 1。

正文式 3 与 SI 的 S1–S3 后文字给出 `alpha + eta*g`；SI 第 1 页左栏的旋转角推导
使用 `beta*alpha + eta*g`。此外，对式 2 按其所写的 alpha 直接求导，结果为 `beta*g`。
因此，这三个表达式在一般 beta 下给出不同的更新幅度。实现把它们作为显式选项保存：

| `update_rule` | 归一化前的权重 | 用途 |
| --- | --- | --- |
| `si_ratio` | `beta * alpha + eta * g` | 原代码默认值；对应 SI 旋转角公式，保留旧结果的学习约定。 |
| `paper_eq3` | `alpha + eta * g` | 按正文式 3 与 SI 更新文字执行。 |
| `exact_gradient` | `alpha + eta * beta * g` | 对条件对数概率使用严格导数；连续版默认值。 |

二元 gamma 均按 `gamma += eta * (P(+1|x) - I[y=+1])` 更新，其中 I 是条件成立时取 1 的指示函数。
仅改变 alpha 的 eta 不能同时保持 gamma 的轨迹，因此不同约定的参数需要分别拟合。
公开材料足以检查各公式的实现，原作者实际运行采用的步长约定仍待作者代码或说明确认。
极小或零长度权重继续采用原代码的确定性回退：第一个特征置为 1，其余置为 0。

## exp123 连续刺激模型

### 输入与特征

使用 `data/exp123/processed/Task2_processed.csv` 的 `feature1` 至 `feature4`，保留其
被试内特征顺序与 `feature*_name`。原值已经在 `[0,1]`，按固定变换 `z_j = 2*x_j - 1`
中心化。所有非空子集 J 定义 `f_J(x) = ∏ z_j`；`max_order` 控制最多组合几个维度。
默认四维、最高四阶，共 15 个特征。相近刺激保留相近的连续数值，各特征的幅度参与计算。

这是有限的多线性交互基，包含单维项及跨维交互。它在连续空间中的表达范围有限，
未加入单维平方项或任意阶多项式。其对实际任务的学习速度、突变及最终表现需要行为检验。

### 类别密度与选择

模型为每个类别 c 定义连续刺激密度，并用其计算选择概率：

\[
p(x\mid c)=\frac{\exp[\beta\alpha_c^\top f(x)]}{Z_c},\quad
Z_c=\int_{[0,1]^4}\exp[\beta\alpha_c^\top f(u)]\,du,
\]
\[
p_c(x)=\operatorname{softmax}_c[\beta\alpha_c^\top f(x)-\log Z_c+b_c].
\]

`alpha_c` 是单位长度的类别特征权重，beta 调节分布集中程度，`b_c` 是类别先验的对数权重。
softmax 将各类别的指数得分除以得分总和，得到和为 1 的选择概率。最后一个类别的 b 固定为 0，
其中 K 为类别数，其余 K−1 个偏置随反馈更新；所有偏置初始为 0。两类情形下 `gamma = b_neg - b_pos`。

积分域采用固定单位立方体和均匀体积测度。Gauss–Legendre 张量求积在各维放置节点与权重，
以加权和近似积分；默认每维 8 个节点，共 4096 个。内部特征期望使用同一组积分权重。
节点和积分域由配置确定，与后段刺激及作答无关。`category_density()` 返回密度，
密度值可以大于 1；各类别的选择概率由 `predict_proba()` 返回。

### 按实际反馈学习

反馈语义核对自 `exp_program/exp123/Task2_learning.m` 的 `compare` 函数。
下表使用 CSV 中的 condition 编号；论文图中的任务顺序可能另行排列。

| CSV condition | 选择类别 | 观察到的反馈与保留的可能类别 |
| --- | --- | --- |
| 1 | 1、2 | 1：已选类别；0：另一个类别。 |
| 2 | 1、2、3、4 | 1：已选类别；0：除已选类别外的三个类别。 |
| 3 | 1、2、3、4 | 1：已选类别；0.5：同家族的另一个类别；0：另一家族的两个类别。 |

condition 3 的模型假定学习者已知公开的家族配对 `{1,2}` 与 `{3,4}`。
condition 2 的学习过程只使用正确/错误反馈。CSV 中的 category 用于一致性检查和结果评分。
原二元模型接受完整正确标签；连续版接口将学习证据改为当前选择与实际反馈。

具体地，令 S 为该反馈允许的类别集合，学习目标为 `log Σ_{c∈S} p_c(x)`。
先在 S 内重新归一化当前类别概率，得到 `q_c = I[c∈S] p_c / Σ_{j∈S}p_j`。
严格梯度更新在单位长度投影前为：

\[
\Delta\alpha_c=\eta\beta(q_c-p_c)[f(x)-E_c(f)],\qquad
\Delta b_c=\eta(q_c-p_c)\quad(c<K).
\]

`q-p` 表示反馈使各类别概率向哪个方向调整；`f-E_c(f)` 表示当前刺激相对于该类别内部
平均特征的差异。两者共同决定每个类别特征权重的变化。每次权重更新后恢复单位长度。
连续版每题更新一次，只使用当前反馈，对应记忆窗口 1。

### 时间、拟合与生成边界

- 每人独立初始化；同一被试按 `iSession, iTrial` 稳定排序。配置必须声明 `session_policy: carry`，
  表示同一任务跨 session 延续学习。重复试次 ID、混合条件及非法类别直接报错。
- 保留所有可用试次，包括 `ambiguous=1` 的刺激。`max_trials` 只取排序后的连续前缀。
- 每题先保存状态并计算选择概率，再接收反馈。固定参数和给定选择/反馈历史确定一条状态轨迹。
  `states.npz` 保存这种条件下的权重，参数不确定性尚未积分。
- 拟合估计各类别初始权重、beta、eta，以实际选择的负对数似然（NLL）为目标。
  `fit_first_n` 指定估计前缀；后段仍随实际反馈更新，标记为 `conditional_test`。
- `simulate` 根据模型选择概率抽样，实验评分函数依据模拟选择产生反馈，然后更新模型。
  给定种子可重复。模拟使用提供的刺激和目标类别序列；自适应刺激抽样及实验停止规则尚未接入。
- 原论文全标签任务在固定参数下的状态更新不依赖实际选择。连续版的部分反馈依赖选择，
  因此自主选择会引起后续状态分支。重放与自主生成共用相同的反馈函数和状态更新。

## 使用方法

从仓库根目录执行。原二元入口和导入保持可用：

```bash
python -m src.Cohen --help
python -m src.Cohen.cohen_schneidman --help
python -m src.Cohen.exp123 --help
```

连续版小规模重放（三种条件各一人、各 16 题）：

```bash
python -m src.Cohen.exp123 --config configs/exp123/cohen_continuous_smoke.yaml
```

同一小配置可用 `--mode fit` 检查拟合、`--mode simulate` 检查自主生成，并用 `--outdir`
指定新的输出目录。例如：

```bash
python -m src.Cohen.exp123 --config configs/exp123/cohen_continuous_smoke.yaml \
  --mode fit --subjects 101 --outdir results/Cohen_model/exp123_fit_smoke_v1
```

正式研究需另建 YAML，显式设置被试、试次数、拟合前缀、搜索预算和积分精度。
小配置的 4 个候选、2 代、2 步退火仅用于检查流程。连续版每个输出目录包含：

- `config.yaml`、`summary.json`：配置、数据与代码 SHA256、Git 状态、依赖版本、范围与完成状态。
- `subject_<ID>/trial_predictions.csv`：类别概率、真实类别概率、期望反馈分数、选择对数概率和估计范围。
  `choice/feedback` 保留观测，`model_choice/model_feedback` 记录本次使用或生成的历史。
- `subject_<ID>/parameters.json`：初始及最终参数、特征子集，可重建模型。
- `subject_<ID>/states.npz`：反馈前 alpha、偏置、连续题号及 session/trial 标识。

`summary.json` 的积分诊断比较初始和最终状态在两种节点数下的归一化常数、特征期望和选择概率。
这是固定状态的局部精度检查；高 beta 或长轨迹需要比较完整路径及拟合结果对节点数的敏感性。
