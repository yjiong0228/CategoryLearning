> **最新生成充分性结论（2026-07-29）：** 下文保留的是早期开发记录，不能再作为当前模型决策。按照“真实行为只是同一人、同一刺激日程下众多可能轨迹的一次实现”的新目标，已经完成不读取未来选择的自主 posterior-predictive 检验。精确有限容量 `M=5` 在末块仅覆盖 `9/32` 人，而静态 full-set 覆盖 `30/32`，因此条件 1 已掌握阶段改用静态 full-set 生成边界；但从第一块后预测整个学习过程时仍仅覆盖 `8/32`。前缀选择的个体 beta、衰减 lapse 和随机反馈写入均未通过开发门槛，不进入保留集。当前下一候选只允许一个不可逆的随机获取时点，不恢复 D0 或复杂三状态路线。完整、可核查结果见 `results/zhuran/cond1_newplan/trajectory_ppc_report/report/condition1_trajectory_ppc_report.html`，正式表述以 `manuscript/model_newplan.tex` 为准。

> **后续数值验证（2026-07-28）：** 已将无重采样的序贯重要性采样升级为在线粒子滤波。数值 ESS/收敛门槛现已通过，但 B0/D0 家族恢复与个体 `theta_s` 定量恢复仍未通过，因此下文“先解决数值积分”的任务已经完成，而“动态机制确认性解释暂缓”的结论不变。完整结果见 `manuscript/model_newplan_particle_filter_results.md`。

> **后续模型止损（2026-07-29）：** 进一步检验了 `theta_s=z_s theta_+` 的零边界共享强度简化。它在独立 R=64 评估中的敏感度/特异度为 `0.250/1.000`，冻结后增至 R=128 为 `0.000/1.000`，仍未通过恢复门槛。当前确认性主模型收缩为 B0；D0 只保留为探索性预测基准，不再继续开放共同参数或增加隐藏状态。完整结果见 `manuscript/model_newplan_shared_theta_results.md`。

## 结论先行

这一轮实现支持把 **D0（swap-only）保留为下一阶段唯一的主候选**，但尚不支持把它写成已经确认的最终模型；**常数 lapse 不应继续作为主模型的默认自由参数**。

原因是三组证据方向一致：

1. 在固定共同核心、128 条潜在路径下，D0 相对 B0 的 held-out Brier 平均改善为 `-0.157635`，7 名有留出区块的被试中 4 名改善；D1 相对 B1 的改善为 `-0.095654`，同样为 4/7。
2. 在严格共享随机数的四种共同核心敏感性分析中，经训练段选择共同核心后，D0 相对 B0 的 held-out Brier 平均改善为 `-0.151886`，D1 相对 B1 改善 `-0.099732`。swap 的方向不依赖单一 `w0` 或 `rho` 设定。
3. lapse 在已有 swap 后没有增量价值：联合核心分析中 D1 相对 D0 的 held-out Brier 反而增加 `+0.014186`，7/7 名被试均未改善。闭环恢复中，lapse-present 的敏感度也只有 `0.333`，6 个含 lapse 的真实数据集家族没有一个被精确恢复为对应的 B1 或 D1。

不过，确认性门槛尚未通过：

- `theta` 的总体 RMSE 为 `0.4270`，还不能进行精细的个体参数解释；
- 64→128 条路径的四家族选择一致率为 `9/12`；
- 真实数据 128 路径运行的最终 ESS 中位数为 `5.61`，恢复运行中位数仅 `2.66`，说明序贯重要性采样在长序列末期仍有明显权重退化；
- 当前共同核心只比较了四个预设边界/参照点，尚未完成 `gamma,w0,rho` 的连续联合重优化、层级收缩和独立确认集检验。

因此，本轮判定是：**工程实现通过；swap-one 获得开发阶段支持；常数 lapse 淘汰出主路线；动态机制的确认性解释暂缓。**

## 已实施的最小模型

新增的 `FeedbackSwapHypothesisModule` 独立于旧三状态 controller，只包含一个动态参数：

\[
p_t^{\mathrm{swap}}=\theta(1-r_{t-1}).
\]

模块实现了以下精确边界和不变量：

- 首试次不交换，当前反馈不能影响当前选择；
- `theta=0` 严格退化为固定 active set；
- 正确反馈后的交换概率为零；
- 交换时只删除一个最低后验假设，并从 inactive pool 均匀引入一个 newcomer；
- active-set 容量始终固定为 `M=5`；
- newcomer 获得 `1/M` 的先验质量，survivors 按上一后验比例分配剩余质量；
- newcomer 的 beta 严格初始化为共同的 `beta_init`；
- 每试次固定消耗三枚转移随机数，使不同 `theta` 值可以使用 common random numbers；
- 保存反馈来源、交换概率、交换事件、候选集合、被删除/新进入假设、迁移先验和 fallback 日志。

常数 lapse 只作用于外显选择概率：

\[
P^{\mathrm{obs}}_t(c)
=(1-\varepsilon)P^{\mathrm{cog}}_t(c)+\frac{\varepsilon}{N},
\]

不改变 active set、memory、posterior 或 beta。`epsilon=0` 是精确无 lapse 边界。

此外还实施了：

- 完全自主的生成循环：先预测并抽取选择，再由真实类别生成反馈，最后更新 likelihood、memory 和 beta；
- 训练/最后区块 held-out 掩码；测试试次只允许使用其过去历史，不反向参与参数选择；
- B0、B1、D0、D1 的共同参数格和配对随机流；
- 以过去选择因果加权潜在路径的序贯重要性边际化；
- 闭环模型家族与参数恢复；
- 64→128 的嵌套 Monte Carlo 收敛诊断；
- `w0=0`、`w0=1`、`rho=1` 和当前内部混合核心的严格配对敏感性分析。

## 验证结果

全仓库测试结果为：

```text
190 passed, 5 warnings
```

5 个 warning 均来自既有的空切片/无穷损失汇总路径，没有新增失败。新增测试覆盖：

- `theta=0/1`、正确反馈、首试次、满容量空间和非法参数边界；
- 最低后验并列时的均匀删除；
- 固定随机数消耗和跨 `theta` 的 CRN 对齐；
- newcomer prior、beta 初始化及 active-set 容量；
- `epsilon=0/1` 的精确观测层边界；
- held-out trial mask；
- 序贯重要性预测不读取当前选择；
- 自主生成的可重复性、概率归一化和选择—反馈因果关系。

## 真实数据：固定共同核心，128 条路径

开发被试为 `103, 105, 111, 112, 117, 118, 127, 131`。被试 105 只有一个区块，只参与训练诊断，不进入 held-out 配对汇总，因此有效 held-out 样本为 7 人。

共同核心固定为 `gamma=0.55, w0=0.10, rho=2.0`。负 Brier 差值表示更复杂的第一个模型更好。

| 比较 | 平均 held-out Brier 差值 | 中位数 | 改善人数 |
|:---|---:|---:|---:|
| B1 − B0：只加 lapse | -0.066184 | -0.109710 | 5/7 |
| D0 − B0：只加 swap | -0.157635 | -0.213800 | 4/7 |
| D1 − B1：lapse 后加 swap | -0.095654 | -0.091273 | 4/7 |
| D1 − D0：swap 后加 lapse | -0.004203 | 0.000000 | 2/7 |

64→128 的嵌套诊断为：

- 固定格点 train Brier 平均绝对变化：`0.005152`；
- 固定格点 test Brier 平均绝对变化：`0.013201`；
- 选择的 `theta/epsilon` 一致：`26/32`；
- 选择模型的 test Brier 平均绝对变化：`0.005796`；
- 最终 ESS 中位数：`5.61/128`，最小值约为 `1.00/128`。

预测方向已经可见，但 ESS 不足以支持参数的小数级解释。

## 共同核心敏感性：严格 CRN，64 条路径

四个核心为：

- `mixed`：`gamma=0.55, w0=0.10, rho=2`；
- `expectation`：`gamma=0.55, w0=0.10, rho=1`；
- `fade`：`gamma=0.55, w0=0, rho=2`；
- `static`：`w0=1, rho=2`，此时 `gamma` 对 posterior 不可识别。

40 个被试×`theta` 缓存点的随机种子逐一核验相同。每个家族只用训练 Brier 在四个共同核心、`theta` 和 `epsilon` 中选择，随后评价 held-out Brier。

| 核心 | B1 − B0 | D0 − B0 | D1 − B1 | D1 − D0 |
|:---|---:|---:|---:|---:|
| mixed | -0.062946 | -0.208236 | -0.093275 | +0.052015 |
| expectation | -0.012133 | -0.117174 | -0.091325 | +0.013716 |
| fade | -0.020545 | -0.084013 | -0.042918 | +0.020550 |
| static | -0.091272 | -0.160410 | -0.096247 | -0.027108 |
| 训练段联合选择核心 | -0.037967 | -0.151886 | -0.099732 | +0.014186 |

关键模式是：

- 四种核心下，D0 − B0 均为负，且均为 4/7 人改善；
- 四种核心下，D1 − B1 也均为负，且均为 4/7 人改善；
- 训练段联合选择后，D1 − D0 为正，0/7 人改善；
- 共有核心本身存在明显个体异质性，没有一个 `w0/rho` 点支配所有被试，因此下一阶段必须公平联合估计共有参数，不能冻结为单一点。

## 闭环恢复

恢复使用 3 种真实刺激日程（103、117、131）×4 个生成家族，共 12 套 128-trial 合成数据。每套数据使用完整 `5×6` 的 `theta×epsilon` 格和 128 条拟合路径。

四家族混淆矩阵为：

| true \ selected | B0 | B1 | D0 | D1 |
|:---:|---:|---:|---:|---:|
| B0 | 3 | 0 | 0 | 0 |
| B1 | 3 | 0 | 0 | 0 |
| D0 | 0 | 0 | 3 | 0 |
| D1 | 0 | 2 | 1 | 0 |

由此可见：

- 精确四家族恢复：`6/12`；
- swap-present 恢复：`10/12`，敏感度 `0.667`，特异度 `1.000`；
- lapse-present 恢复：`8/12`，敏感度 `0.333`，特异度 `1.000`；
- B0 和 D0 各自 `3/3` 正确；
- B1 全部退化为 B0；D1 从未被精确恢复；
- `theta` bias 为 `0.2708`，RMSE 为 `0.4270`；
- `epsilon` bias 为 `0.0325`，RMSE 为 `0.1222`；
- 64→128 家族一致率为 `9/12`；
- 最终 ESS 中位数为 `2.66/128`，最小值为 `1.16/128`。

模型能较好避免把真正稳定的数据误判成动态，但对动态数据的敏感度仍不充分；它尤其不能可靠地区分“带 lapse”与“不带 lapse”。

## 下一阶段的最小路线

1. **冻结认知候选为 B0 与 D0。** 主比较不再默认携带 `epsilon`；B1/D1 只作为观测层稳健性分析。
2. **先解决数值积分，不增加认知机制。** 将当前无重采样的序贯重要性采样升级为带 ESS 触发重采样的粒子滤波，或证明更大路径预算能达到预先规定的 ESS 与损失收敛阈值。
3. **公平联合估计共有参数。** 在 B0 与 D0 中使用相同的 `gamma,w0,rho` 搜索、边界、正则化和模拟预算；明确包含 `w0=0,1` 与 `rho=1`。
4. **重新做恢复和时间留出确认。** 至少要求 swap-present 恢复、`theta=0` 边界和非零 `theta` 的定量恢复达到预注册门槛，再讨论个体差异。
5. **随后比较 full-set 与容量边界。** 只有 D0 的确认门槛通过，才检验有限 active set 和精确 `M=5`。
6. **最后才看异常被试残差。** 先在冻结 D0 的 held-out 残差中定义错误持续长度、选择熵、替代规则一致性和恢复速度；只有出现可重复结构时，才一次加入一个 burst-lapse、结构化 newcomer 或 Refresh。

本轮最重要的结果不是“模型已经完成”，而是成功把路线缩小了：**动态交换值得继续，常数 lapse 暂不值得，任何更复杂的异常机制现在都不应加入。**
