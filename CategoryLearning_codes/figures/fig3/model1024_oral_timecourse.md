# Model 1024 口述对齐：随试次变化的图

核心问题是口述与行为推断内容的对应如何随试次变化，以及这些变化覆盖了多少可评分口述。
图用于开发结果审阅。使用已保存的 Python 绘图偏好，布局为定量网格：六人总览与每人四行详图。
总览宽11英寸、高8.4英寸，详图宽11英寸、高10.5英寸，300 dpi，仅输出PNG。
中文采用可用的 Noto Sans CJK 字体；代码与逐题绘图数据保留以便编辑。

## 图的内容

1. 具体判断支持：每条彩线对应一组既有参数；灰色虚线为仅依据当前刺激与所选类别的参照。
   模型和参照使用共同有效的完整数值编码报告。P1的逐题值用浅灰点保留。
2. 双向部位覆盖：蓝线为口述部位被规则涉及的比例，橙线为规则部位被口述提及的比例。
   实线固定展示P1，色带为全部候选的最小值至最大值。各候选的平滑线也存入数据。
3. 具体判断分解：固定P1，蓝色为支持，红色为冲突，灰色为未确定。使用全部主语义有效报告。
   三部分在同一窗口内合计100%；无可用平均值的窗口留空。
4. 编码范围：黑线为最近窗口内可做完整判断评分的报告比例；底部逐题色条区分完整判断可评分、
   仅部位可评分和暂不可评分。全部原试次保留，原口述可由既有逐条对照页查看。

曲线是截至当前试次、最近32题内有效报告的等权平均。各内容指标至少需要8条有效报告；
不足处留空。编码范围的分母是该窗口内实际存在的全部试次，开始阶段的窗口短于32题。
窗口随实际试次移动，缺失试次占据原位置。32和8是固定展示设置，参数和状态估计保持原样。
窗口跨越场次边界时保留相同累计有效试次坐标。灰底标记判断支持不足8条的窗口。

## 证据边界与复现

主图读取选择后、反馈前的过滤状态；参数由完整行为记录估计。所有六人、17组候选保留，
其中S129四组为诊断参数，其余五人共13组为保留候选。P1是固定编号，口述没有参与选择它。
候选色带描述有限参数差异，独立重复误差与置信区间均未在本图估计。
原口述人工复核状态、原数值限制及语义编码约定继续保留。本轮没有显著性检验或模型拟合。

从仓库根目录运行；两个输出目录须为新目录：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MPLCONFIGDIR=/tmp/model1024_oral_plot \
python -m CategoryLearning_codes.figures.fig3.model1024_oral_timecourse \
  --alignment results/model_1024/oral_alignment_20261030_v2 \
  --output CategoryLearning_codes/figures/outputs/fig3/model1024_oral_timecourse_NEW \
  --report results/model_1024/oral_alignment_20261030_v2/timecourse_NEW
```
